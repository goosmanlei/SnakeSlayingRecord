# 按创作环节直接找到、阅读和评论实际生效的 SKILL，工作方法页改为 Tab 与平铺筛选

本文件是本任务完整执行与验收定义；已定方案来自协调主会话，事实与历史边界见[覆盖调查](working-methods-coverage-investigation.md)。SKILL 指执行者实际取得的工作方法正文；Tab 指可切换、明确选中并支持键盘操作的子页标签。代码路径相对故事仓根，Markdown 链接相对本文件；附属仓 source 相对主项目解析。

当前工作方法页用下拉框选择方法、资料、环节和版本，默认进入未绑定的旧“审阅意见措辞”；工作环节页默认新建并铺出机器配置。用户想优化创作能力，却先要理解内部目录和寻找真正生效的方法。本任务以已有方法为基础整理工作环节覆盖及其入口，将页面改为真正子页Tab、平铺筛选和可见目录，直接读正文、评论和改进方法。人的意见通过评论表达，不增加逐项审批。

调查正式已有16个方法、12种工作类型和5份共用资料。实体抽取和视频Prompt的实质重编分别归本轮另外两项任务；没有证据支持其余所有方法重写或按每个对象再造SKILL。正常方法页目前也没有审批/采纳按钮，不能把AI自检review阶段当作审批删掉。

## 完整改后路径

保留“方法／共用资料／工作环节”三个真正子页Tab，视觉连贯、明确选中，支持键盘；所有目录、筛选、正文版本和执行方法版本选择不用下拉框。选择一个对象后连续展示它的必要正文，不把全部方法全文铺满，也不使用折叠隐藏必要信息。

“方法”Tab下平铺“全部／故事创作／生产制作／协作辅助”业务筛选，以及“正在使用／全部方法”范围筛选；下方可见方法列表，项目仅名称和确有选择价值的短用途。默认“正在使用”，按故事创作→生产制作→协作辅助排序，首次选择第一个真实绑定方法（当前应为故事结构）。明确深链接优先，不因筛选默认跳离准确旧版。陌生新增类型归“其他”可见，不消失。

点击“生产制作→镜头视频方案与Prompt”，直接阅读真实SKILL，头部名称、必要用途、实际用于的后续工作及版本。版本用平铺按钮；多版本自然换行或明确可见历史列表，不下拉、不自动切换全部绑定。准确文件目录平铺，Markdown正文、引用章节、必要图示和附件直接可达；从手册返回仍在原方法段落。去掉无价值重复解释和不必要来源折叠，技术配置只在主动编辑动作中展示。

“共用资料”Tab有可见资料目录和平铺类别（连续性、影视知识、视频手册、独立读者、系统Review等依现有实际用途）；选择后直接读准确版本/文件，版本和文件也平铺。保持源文件只读投影、旧评论、图示及准确章节返回，不制造第二份可编辑手册。缺文件诚实报缺，不自动替换成最新版。

“工作环节”Tab沿相同业务筛选和可见环节列表，默认读第一个既有环节，不默认新建表单。每项展示“什么工作条件→哪个方法哪版”，默认与具体分支明白可读。主动编辑时用可见方法候选列表和平铺版本代替select；保持条件类型、精度、顺序和未修改分支语义。保留必要新建/删除条件能力，不作为默认阅读负担。

三页切换/刷新/返回保留筛选、对象、准确文件/版本、阅读位置和未发评论。快速切换不让迟到响应替换当前对象。桌面、窄屏、长方法、多版本均能完成相同工作，不以新增模态层或二级折叠代替下拉。

## 方法覆盖与生效职责

对现有真实环节形成一份简短有效清单，维护在既有`production/professional-methods.md`及必要入口，不新增方法管理数据实体。每项说明工作目的、准确输入、输出、实际入口和选择方法，区分已覆盖、共用知识、尚无可验证工作。

- 复用：结构、小说、剧本及表演原词、视听设计、图像、音色演唱、字层、生成准备、结果检查、独立读者、评论清晰表达、系统Review。
- 抽取方法与视频方法由另外任务升级；本页按稳定身份与真实版本读取，不硬编码v7/v10或在发布中覆盖其新版。确认它们进入正常生产筛选和真实工作入口。
- 旧未绑定comment-polish保留准确正文、评论、执行及链接，仅从默认正在使用目录排除；全部方法可查。generic media-plan仍承担工程/文档/默认分支，必须保留并写清范围，图像/声音/视频继续选择专门方法。
- 影视知识、视频手册、连续性等作按需共用资料，不各自伪装一个生产步骤。任务发布SKILL服务系统演进，和作品创作分开；不因本地有文件就注册空工作类型。
- 初期采编/方向比较、尚无实际成片的剪辑流程列为本次未验证，不为了凑齐而新造SKILL。本轮不重写已确认故事作品。

校正实际入口/文档中令人误解的“采纳/已审”等旧词，准确区分AI自检、人的评论、输入选择和付费授权，不削弱必要准确性与并发保护。真实步骤先取SKILL再工作，不能把页面能显示方法当作已约束创作。

## 评论与编辑应用

保留连续正文评论、跨版未回应意见、原稿/回应稿/当前稿及关闭重开；不增加审批、采纳、通过按钮，评论关闭不作为工作闸门。“保存并用于所选后续工作”和“仅保存待用”是必要配置选择，要清楚保留；新工作取显式选定版本，已经开始的工作仍取冻结旧版。部分应用失败/重试、并发冲突不丢正文也不误改其他条件。

## 实际验收

先用有效结构方法、视频方法、未绑定旧评论方法和视频手册做可操作页面样例，再覆盖其他类型。实际完成以下路径：

1. 首次进入默认有效方法；不打开下拉即可选生产制作、视频方法、准确模板，返回原阅读位置；全部方法和准确旧链接仍能找到旧意见措辞及评论。
2. 隔离实例跨段评论→编辑正文→仅用于一个真实条件分支→新作者步骤读取新SKILL；其他分支及已开始步骤仍旧版。旧意见在当前页可发现并准确回读，不出现审批。
3. image/audio/video/document/project实际入口均解析到正确方法；视频dialogue+need_sound取得恰当章节，UI切换不扩张执行资料。布尔true与文本true、复杂条件、大整数保持原语义。
4. 页面阅读和配置编辑路径均无select；新建与编辑、仅保存、部分应用失败及并发冲突正常。真实Chrome验证快速切换、窄屏、多版本、图示/源只读、准确深链接和评论草稿；源码/测试通过不代替操作。
5. 最终覆盖清单对应真实入口；方法与共用资料、历史绑定/执行、评论完整导出到新空实例后仍可复走。正式服务只读复验，不在正式实例造测试评论或随意改绑定。
