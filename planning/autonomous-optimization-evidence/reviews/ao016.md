## 核对依据

| 行为 | 独立判断 |
| --- | --- |
| 有效／缺失／失效修订参数 | 有效修订从现有不可变修订列表选取；否则取当前发布稿；没有当前稿时为空。初始化与结构页 popstate 共用解析规则，不以进入方式决定所读稿 |
| 显式切稿与历史恢复 | 按钮只在新 URL 不同时 pushState；popstate 不写历史。相同稿不会重建编辑器；从没有参数或失效参数的地址再次选择当前稿时，仅规范化一次地址 |
| 历史评论定位 | 先验证原修订仍存在，再选择准确稿；不存在或锚点已失效时保留评论并拒绝定位，不替换成最新稿。非结构页进入时先设置隐藏结构选择，再由切工作区写入一个准确地址 |
| 草稿和未确认提交 | 实际换稿清理临时编辑身份、锚点、选择、润色、绘图及评论范围；没有删除 localStorage 中原稿的正文或 submission。不存在把旧稿 pending 请求复制到新稿的分支 |
| 无关页面 | 仅目标工作区为结构时，popstate 才解析结构参数；其他页面不因地址中的结构参数改变隐藏阅读稿。结构选择函数只清理当前结构编辑器，不提前破坏当前资料编辑器 |
| 业务边界 | 没有新增控件、接口、对象、修订或数据库写入；不新增章节、弹窗或评论 ID 的 URL 持久化，也不改变接受和发布语义 |
