# 证据重放范围

本包不是完整实例备份。受管测试源在通用系统候选的 `tests/`；各准确测试命令、当时输入SHA与退出结果见 test-evidence.json。按该系统仓 README 准备Python/Node环境后，可用所列窄命令重建一次性合法库；无需连接正式实例。重叠测试不需要因为本包生成而再次运行。

Chrome记录包含原操作与准确对象/修订、环回实例和结果；一次性实例与媒体不收入Git，不能承诺仅凭此小包完全自动重放现场。根负责最终受影响页面补验；静态、HTTP和函数检查不能代替。
