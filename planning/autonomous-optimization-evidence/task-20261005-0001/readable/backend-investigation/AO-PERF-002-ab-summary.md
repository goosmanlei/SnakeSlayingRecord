# AO-PERF-002 增量后台性能结果

本次证据支持保留 AO-PERF-002：相对已含 AO-PERF-001 的基线，实体索引、素材列表、场景详情和李寄实体详情的 HTTP 中位耗时分别减少 100.17、106.87、84.49、155.82 毫秒，幅度为各自基线中位数的 16.0%、17.5%、9.9%、22.1%。四条路径的中间 50% 样本区间均不重叠，独立进程交替顺序的五对 CPU 测量也每对均改善。该结论仅限本机、固定快照和这些后台路径；页面收益由真实浏览器另行验证，不从接口耗时推算。

## 版本、环境与测量口径

- 时间：2026-10-05 北京时间 09:25:28 至 09:31:18，350 秒，小于授权 480 秒。根代理和其他代理暂停浏览器/测试/重 CPU 工作。前后守卫均 armed、监督锁持有、心跳有效、无停止标记；结束后 62607 自有服务已关闭并通知根代理释放窗口。
- 基线：`system-perf001`，提交 `7ba65822307d2099502b3f2046a943c100d6a565`。候选：同提交的 `system-worktree` 加本项补丁，两个文件 diff SHA256 为 `df1248e9f7ae8b30d3578320ed13c1cbac5ef24f1dbcbb4583b8cd9ab3f4fee1`。实际后台 Python 差异只有 `review_desk/material_storage.py`，候选文件 SHA256 `94fee3397c40cd306f060e014d5646aed819fd2e455776efa014340bbb4f3560`。
- macOS 26.6.2 arm64、Python 3.9.6；同一台机器、同一 loopback 62607、同一原生产 HTTP handler。测量包装器只禁用写请求，Store 使用 SQLite `mode=ro` 和 `query_only=ON`，绕过初始化迁移。它是后台接口实验，不含浏览器、页面渲染或网络远程延迟。
- 一致快照：`preview/.runtime/generation-base.sqlite3`，163000320 字节，SHA256 `5c6d00ee6efa7506201bbef46ffd69bde49f7300c4697fe66036e87ace7ed4f0`。两端均读该文件，前后 SHA 不变；后台 Python 源码逐文件 SHA 前后不变。数据规模见原 `window2` 库存：6236 个对象、10160 个版本、271 条评论、78889 个素材内容节点。
- 15 条路由，每条 3 次预热后 50 次正式样本；每端 795 次请求，全部 200，无中断。HTTP 从发起请求到完整响应体读完，规范化哈希计算不计时。不清空操作系统缓存，先基线整批、后候选整批；这是暖态顺序实验，不宣称冷启动结果。每个请求的 scope 缓存正常新建/清除。
- 中位数及 P95 单位毫秒，P95 使用最近秩法第 48/50 个样本。IQR 是含插值四分位法得到的 Q1–Q3，表示中间 50% 样本范围；MAD 是样本到中位数的绝对偏差中位数。完整原始值、最小值、最大值和统计公式在 `ao-perf-002-ab/comparison.json` 与 `summarize_ab.py`。

## 独立进程 CPU 与峰值内存

每条入口 5 对、总计 50 个独立子进程，AB、BA、AB、BA、AB 交替顺序。每进程只读一次相同逻辑入口，后台调用计时与 JSON 序列化分开。`resource.ru_maxrss` 在 macOS 原生单位是字节，表格除以 1048576 得 MiB；它是整个进程的高水位，不是缓存本身大小，也不是稳定运行服务的常驻内存。

## 内容正确性、剩余限制与证据入口

全部 15 路两端完整 JSON 规范化 SHA256 一致，25 对独立进程返回值也一致，没有删除字段。实体响应原始字节 SHA 不同，完整规范化 JSON 一致，这是跨进程对象键输出顺序差异；报告不能说原始字节完全相同。主要响应体字节数分别为 1568571、54627、7420969、16407761，两端相同。

监督者此前报告聚焦 67 项及额外两组通过；本报告不替代其原始测试回执。性能结果已由监督者独立从 samples.jsonl 重算 15 路统计，并核对 795×2 请求、50 个独立进程、哈希及前后源码/数据库身份；其报告无阻断问题，审计日志在上级目录 `reviews/AO-PERF-002-statistical-audit.log`。本次测量没有写入 API、数据库写延迟、页面渲染、媒体解码或真实用户操作数据；这些不能登记为通过。001 与 002 来自不同受控窗口，不能简单把百分比相加作为总收益。
