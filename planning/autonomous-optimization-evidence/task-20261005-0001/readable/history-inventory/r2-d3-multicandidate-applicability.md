# D3 多候选及多媒体组成适用性独审

**当前不可变基准快照不存在同一素材版本的第二候选，也不存在同一素材记录的第二个可展示媒体组成。两个子场景可标为本快照不适用。** 这不改变系统支持多候选和多组成的能力。

通过 SQLite `mode=ro&immutable=1` 读取 `preview/.runtime/generation-base.sqlite3`，没有构造 Store、调用接口或写库。按素材 ID 与素材版本号分组，读取 ASSET 的真实调用 ID 与去重原件 SHA 集合确定候选身份，与 `material_plans.identity` 一致；同时核对已存 candidate 索引，没有缺项。2547个素材版本中，459个含有真实结果，各组最大去重候选数为1，多候选组为0。不同素材版本即使各有一个结果也没有合并计数。

共有435个 ASSET 历史修订，对应417个当前对象。435个修订都含多个文件，共435个原件和846个 metadata 说明文件；62个修订是音频、373个是图片。每个修订的 image/audio/video 组成数均为1。`material-review.js` 只为这些 MIME 提供媒体切换器，因此“原件+回执/请求 JSON”不能充作第二个可展示媒体。P2 的采用组成下拉另有原件和说明文件契约，保留此前独立覆盖，不因本次 N/A 而取消。

D3 已有准确版本2未生成、切到版本1显示阿禾原图，以及阿蘅版本3空、版本2准确音频的真实页面证据；结合此次适用性确认，D3-05 可标为代表性功能通过。没有为了填满矩阵创建虚构候选，也没有用后台数据查询冒作实际切换过不存在的控件。

快照尺寸和修改时间与旧基准一致；其 SHA 引自 `run-baseline.json`，本轮没有再次读取163MB文件重算。完整分组、逐修订文件组成清单及 SQL 保存在 [机器报告](r2-d3-multicandidate-applicability.json)。结论限于该快照；后续数据或技术夹具新增多候选时应重新判断适用性。
