# 播放中关闭后的真实媒体状态独审

X-04 的最后一个直接观测缺口已闭合。隔离功能页同一音频节点 id=2 在可信关闭 click 前为 `paused=false`、`ended=false`、`currentTime=0.013897`；移除后的微任务直接读回同一节点 `connected=false`、`paused=true`、`ended=false`，随后可信原生 pause 事件也保留相同值。准确 WAV 仍为 `a7d678681c2e490de0a7dc8aca163131f68e196ceda703dc9c9282418c589272.wav`，长度14.5秒；因此没有把自然结束当作主动关闭暂停。

观察脚本用 WeakMap 保持节点身份，只监听媒体事件、关闭按钮的捕获阶段 click 和 DOM 移除。它没有调用 play/pause/seek，也没有设置媒体属性；唯一写入是保存证据的 JSON script 节点。产品的关闭处理本身先 pause 再移除，移除观察器另有兜底，与这次真实状态一致。观察脚本的微任务读取不能定位是哪条产品路径先暂停，但能直接证明最终 detached 节点确实暂停。

服务绑定 `127.0.0.1:62608` 和任务 `.runtime/autonomous-optimization/functional`；相对既有测量 server 唯一差异是一行拼接媒体观察脚本。拼接 SHA 为 `0ce392e42faeb7c59ea52b9061517d17bfaa71dd9b823c385db7c4f5c738849a`，与启动环境一致，HTTP 日志确认探针返回200。没有修改正式实例或性能原冻结探针。环境记录 HEAD `ddb602e3…` 不能单独代表所有未提交工作树内容，相关当前产品文件 SHA 已另存。

首次 id=1 样本在关闭前已自然播放至14.5秒结束，保留原文件并明确排除。新回执关闭后 dialog/audio 均为0、焦点回原素材卡，结合先前响应式、评论和嵌套返回证据，将 X-04 标为代表性功能通过。

本次观察写 JSON 到 DOM，可能影响性能探针的稳定检测，所以只用于功能结论，不能并入页面性能 A/B。HTTP 原日志同秒还有媒体请求 BrokenPipeError/status400 和后续206，本次未做网络定因，也不声称网络零错误；这不否定同一已加载节点的直接状态。1200像素下标题上部裁切仍保留为低影响限制。
