# R2 音频静音与素材弹窗关闭独审

此前矩阵称“共用音频播放器没有静音控件”是审查遗漏，现已纠正。源码 `review-ui.js:76` 本就提供静音切换，2192×1415 实际截图也能看到按钮。新浏览器快照在点击后显示“恢复声音”，恢复文件直接记录 `muted=false`。静音快照未单独保存 `muted=true` 属性；根据按钮同步赋值代码可推知该状态，根协调者另报告了直接观察。

2192 场景中的关闭按钮实际命中 `button.review-dialog-close`，按钮底部 162px，评论面板顶部 179px，截图确认不再覆盖。播放前 `paused=false`、时间 0.017601 秒，点击关闭一次后弹窗与音频节点均为 0，焦点回阿蘅原素材卡；外部评论保持此前关闭状态。该代表性关闭/焦点路径通过，其余视口仍由根协调者验收。

不能由节点移除推定离开 DOM 的音频已经暂停。这里有两层不同证据：`review-ui.js:150` 在移除前逐个调用 `pause()`，155–159 行另有移除观察器兜底；已有兼容测试通过按钮与 Escape 执行关闭处理并验证历史返回一次，却没有保留音频实例断言 `paused`。因此报告写为“真实关闭与焦点通过，暂停由静态路径支持”，不声称已实际观察 detached 音频状态。

本审查未操作浏览器、运行测试或修改产品；原始文件及哈希见同名 JSON。单次功能证据不作为性能前后对照。
