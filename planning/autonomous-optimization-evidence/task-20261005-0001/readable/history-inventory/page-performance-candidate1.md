# 页面性能：baseline 与 candidate1 的独立比较

本审查只分析已有 160 份页面 JSON（两阶段各 80 份），未发起 API、浏览器或测试负载。逐页场景和样本数相同；12 页各有 1 次 navigate，其余为 reload，制作拆解／实体管理／素材管理／镜头制作每阶段总计 10 次，其他页 5 次。

本批只有 **P1 镜头制作**达到本审查的保守典型波动规则：reload 中位 1385.3 → 1262.7 ms，减少 122.6 ms，两个中间半数区间没有重叠。此为当前隔离环境的页面语义就绪代理改善，不能外推为固定比例、所有操作提速或媒体已可播放。**C2 系统与 AI**存在未解释变慢信号，reload 中位 324.95 → 377.75 ms；不将未改路径的变化归因后端优化或评论避让。其余页未确认收益。

## 身份、口径和限制

- 探针实现 SHA 两阶段均为 `74a80b7f730a450f4fc00f5424120f8f60406e7fe9c4c65234e3d317958a804c`。160 个指定样本的原断言、准确页签、非空内容、无请求错误、前台及完成状态检查均通过；未覆盖绘制／解码／无遮挡等真实可读边界。
- 基线代码 `b874b959af9c918a482e8488dc25cb0204ab5772`；候选不是同一个干净提交。样本仍记该基底，准确改动保存在 `reviews/candidate-browser-1.patch`，SHA `98d4cd479763f379a8b06e84d3c8a0c6f5c0ac9cdcf12eb091316a889660215b`。root 记录 Python 已加载 AO-PERF001，之后后端提交为 `7ba65822307d2099502b3f2046a943c100d6a565`；静态同时包含 UX 候选。不要把该批标成只运行后端提交的纯单变量对照。
- Chrome 154、1440 × 900、DPR 1、macOS 26.6.2 arm64、preview 62606 与探针实现保持；同一隔离数据冻结由 root 运行记录证明，样本本身不含每次导航的完整 DB 哈希。
- 每次导航/刷新从浏览器 performance 起点到同刻语义捕获结束，包含捕获开销；CUA 操作起止另存为含工具开销的上界。navigate 不等于已证明的全冷缓存，reload 不等于所有 HTTP/OS 缓存状态相同。
- 所有计时样本评论面板关闭，因此这批不测桌面停靠操作。D3 文案由“生成状态/已生成”澄清为历史结果范围，区域文本由 3091 增为 3178；十组 D3 完整 CUA 快照在仅还原这五组已记录标签后逐字一致；其他页同刻语义、标题、控件和区域文本均逐样本一致。
- P95 采用 `(n−1)×p` 线性插值，n=5/10（reload=4/9）只可描述本批接近最大值的位置，不能当作可靠生产尾延迟。IQR=Q3−Q1；MAD=各值距中位数的绝对偏差中位数，未做尺度放大。
- 为避免把小漂移写成收益，本审查要求 reload 中位差同时大于两组 IQR 与 3×MAD 的最大值，且两组 IQR 区间不交叠。这是公开的保守描述规则，不是显著性检验或预注册因果实验。原始样本全部保留，不删除慢样本；后续交错窄复测可以更新判断。
