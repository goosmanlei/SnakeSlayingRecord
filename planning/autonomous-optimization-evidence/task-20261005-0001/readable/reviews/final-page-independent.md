# 最终页面 ABAB：独立性能与证据审查

本轮最终候选的 **D1 制作拆解、D2 实体管理、D3 素材管理、P2 组合与历史**，在两组相邻 A/B 的标准 reload 中均观察到超过沿用波动规则的页面语义就绪改善。**P1 镜头制作只有第二轮达到该规则**，不能报告为两轮稳定收益；**S2 故事结构第二轮变慢 29.65 ms**，低于本批 35.70 ms 阈值，仍须保留反向信号。其余页没有两轮均成立的收益证据。

这里的“语义就绪”是浏览器导航起点至页面目标内容与控件捕获完成的时间。它是实际页面测量，包含前端和后台等待，但不是图片全部解码、音视频可播放或所有交互可用的证明。尤其 D2 服务日志出现导航期间图片断管；本报告把它完整列出，不将 D2 的文字/控件就绪改善扩大为完整媒体可用提速。

独立审查者为 `/root/reset_supervisor`，不同于实现主协调及页面操作执行者。本次只读 280 份已完成浏览器记录、阶段回执/日志与本地 Git 对象；未操作浏览器、请求服务、读取数据库或媒体字节、运行产品测试。

## 样本和判断方法

12 页每阶段各 1 次 navigate（index 0）和 4 次 reload（index 1–4），标准样本共 240 条；C2 每阶段另有 10 次 reload（index 5–14），共 40 条。标准四次与额外十次始终分别保存，也列出 C2 合计十四次的描述结果。全部数组保留原始顺序，不删除慢样本，不把 navigate 和 reload 合并推断。

计时终点为 scenario_ready_ms，即导航 performance 起点到目标页签、目标区域的语义捕获结束；包含该捕获的小幅开销。探针之后的静稳确认负责样本有效性，不把操作工具往返时间当页面耗时。每条 CUA 操作起止另保留为带工具开销的上界。280 条原断言、前台状态、稳定结束、无 pending、准确页签及非空目标区域全部通过。

沿用前一轮已公开的描述规则：两组 reload 中位差的绝对值大于两组 IQR 宽度及 3×MAD 的最大值，且两组中间半数区间分离。IQR=Q3−Q1；MAD 为未经放大的中位绝对偏差；分位数含 P95 都按 (n−1)×p 线性插值。标准 n=4 很小，P95 仅为接近最大值的样本描述；此规则不是显著性检验、生产尾延迟保证或随机因果实验。
