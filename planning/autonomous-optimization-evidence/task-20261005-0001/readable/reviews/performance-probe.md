## 结论与适用范围

现有探针可提供**真实事件开始到“所有被包装的 fetch／body 完成、受观测 DOM 不再变化、经过双动画帧”的代理耗时**。180 毫秒是事后确认窗口，不计入 `content_ready_ms`；它不是应用成功标志，也不能保证所有内容、图片、定位和媒体已可用。不得将该字段直接命名为无条件的“内容可用时间”，更不能当作 INP 或实际页面已渲染的充分证据。

用于同条件前后对比的最低要求是：相同探针与采样顺序、前台可见页面、只选成功且未被后续操作覆盖的稳定样本、为具体场景核对正确内容，并将媒体、平滑定位及写后生效另设终点。只在稍后截图看到正确内容，不能反推它在早先 `content_ready_at_ms` 已经可用。

## 双帧与确认窗口的具体语义

fetch 包装在响应头完成后减少 `pendingFetches`；`Response.json/text/blob/arrayBuffer/formData` 在相应 Promise 结束后减少 `pendingBodies`。普通立即 `await fetch()`、再 `await response.json()`、同步渲染的调用链会在微任务后进入动画帧，双帧及观察到的 DOM 变化通常能覆盖该路径。本审查未发现必须在响应头返回时就错误完结的直接竞态。

但 `Response.body` 流式 reader、不经 fetch 的请求、延迟计时器、CSS 动画、浏览器解码和工作线程不在同一门控内。180ms 只证明被观察信号在这段时间内没有变化；不是这些异步工作的通用完成期限。当前源码搜索未发现 XMLHttpRequest 或流式 reader 使用，因此它们是探针边界，不是现有系统已复现的缺陷。延迟结束、smooth scroll 和图像加载则是当前路径需分别核对的事项。

首次 navigation 与交互的终点也不同：navigation 额外等待 `document.readyState==='complete'`，会纳入浏览器 load 之前的初始资源；后续 click/change 不等待新图片加载。因此两种样本不能混为相同“可用”指标。双帧带来约一至两帧的量化底噪，小而短的纯前端操作必须报告重复样本波动。

`timeout` 与 `superseded_by_*` 也写入相同的 `content_ready_ms` 字段，但它们不是内容可用样本。首尾 visibility 只能描述首尾，无法排除中途切后台；主协调应维持整段前台独占，异常轮次作废。

## 原生事件、媒体归属与现场核验

捕获监听器只接受 `event.isTrusted`，且在业务事件处理之前记录；这有助于拒绝脚本合成事件，但不能凭源码证明当前 CUA 操作已经触发正确控件。首次真实原生点击需现场核对：实际 UI 状态改变、目标文本/ID、事件类型、起止 URL、stable 样本及成功内容一致。没有样本或选错事件时，不用合成事件补成“真实页面”结果。

媒体另行记录 loadedmetadata／loadeddata／canplay／playing 等事件，这是合理区分；但 `action_id` 使用当前 active 或最后样本的回退归属，慢媒体事件可能被归给后来的无关点击。媒体性能须按明确素材 `current_src`、动作时间范围和预期事件匹配，不能只凭 `action_id` 计算点击到可播放；听到正确音频仍由实际试听判断。

每个请求记录 start、headers、fetch settled，没有逐请求的 body 结束字段；全局 `lastNetwork` 不应被描述为某个端点 JSON 解码完成时间。Resource Timing 可以补充网络维度，但不自动覆盖响应处理／业务渲染。

## 观测干扰与隔离

测量服务确实继承原 `ReviewServer(HTTPServer)` 与 Store 初始化，保留单线程模型，没有为测量暗中换成并发服务。原 `_file()` 也发送 no-store，因此测量 index 的 no-store 不构成新增缓存差异；然而插入在 head 最前面的同步脚本新增了阻塞请求、脚本解析和采集成本，绝对值属于“带探针预览”，不能直接当正式生产页面绝对值。

DOM 观察主动排除 `data-performance-probe` 节点，未发现探针发布直接让自己的 MutationObserver 无限复触发。其同步 JSON／DOM 写入仍消耗主线程；全局 longtask 记录也可能包含探针开销。这些只能通过控制采集方式和同条件重复判断，不能仅靠忽略节点消除。

`--instance` 只检查路径部件中有 `.runtime`，不独立证明是本任务实例；实际启动仍应由主协调核对已记录的隔离实例路径、端口及数据库。探针不进入产品候选，当前审查未运行服务或改动任何正式资源。
