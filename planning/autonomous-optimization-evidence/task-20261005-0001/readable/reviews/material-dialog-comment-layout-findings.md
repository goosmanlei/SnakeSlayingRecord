# 素材弹窗评论遮挡：独立调查与最小方案

结论：这是值得修复的既有主流程问题。评论面板遮住素材弹窗关闭按钮和右侧媒体，使鼠标退出弹窗失效、原件与评论不能同时查看。根代理已有真实页面证据；本调查没有启动浏览器、运行测试或修改产品。

证据为 `browser/R2-material-dialog-close-covered.json` 及同名PNG。2192×1415视口中，关闭按钮位于 x=1745.6875–1781、y=124–162；中心命中 `#comment-body`，`covered=true`。截图可见右侧波形、内容及素材关闭入口被评论覆盖。Esc能够关闭弹窗并恢复外部面板，是现存替代操作，不代表鼠标关闭已经通过。

## 来源与根因

- `unified-review.css` 第24–25行把统一素材弹窗设为最大1420px/96vw，又将其评论面板设为 `position:fixed;z-index:5`。
- `workspace.css` 第102行使全局评论面板从视口顶部开始、宽度440px；基础 `style.css` 保留 `right:0;bottom:0`。面板虽被移动到弹窗内，仍按视口固定定位。
- 共享 `review-dialog-header` 只有 `z-index:2`，没有给440px面板预留空间。提高关闭按钮层级只能暂时露出按钮，仍会遮住右侧原文、版本控件和媒体，不能完整解决用户问题。
- `openUnifiedMaterial` 保存外层状态、URL、评论面板父节点／顺序／hidden，再把同一个面板移动为弹窗直接子节点；关闭时按保存状态放回。`referenceReviewSession` 对音视频参考弹窗使用相同单面板移动机制。
- 上述统一弹窗布局、面板移动代码及参考弹窗布局，在基线 `b874b959af9c918a482e8488dc25cb0204ab5772` 已存在，本轮对应定义未变。因此可确定触发机制不是本轮新增。尚未在本调查中打开基线浏览器复现准确像素位置，不把静态一致性写成第二份真实页面证据。
- `.material-reference-dialog .comment-panel` 已另有相对定位、在内容后排列的规则；首次最小修改宜限定 `.unified-card-dialog`，不要用全局 dialog 选择器影响大图、剧情依据及其他独立弹窗。

## 建议实现边界

1. 只在**当前弹窗拥有可见的直接子评论面板**时改变布局，例如以 `:has(> #comment-panel:not([hidden]))` 判定。不能仅检测任意后代，避免嵌套弹窗或面板搬移时连带改变外层。
2. 宽屏（建议与故事阅读器统一为至少1200px）在同一弹窗内并排：头部跨两列，下方左侧原有卡片内容、右侧约360px评论。弹窗最大宽度可由1420px加上评论宽度，仍受视口边距限制；正文与评论分别滚动，面板使用正常布局定位并设置 min-width/min-height 为0。头部和关闭按钮不落在评论覆盖区。
3. 不因评论开合重建 `body`、素材卡、音频节点或编辑器。超宽屏优先保留原正文宽度；受限宽度下重排要保持当前原文锚点或媒体位置，不能只保存旧 scrollTop 后接受多次开合逐渐漂移。当前 `preserveCommentReaderLine` 明确排除了 dialog，不会自动保护这条路径。
4. 窄屏不硬塞三列。可让评论占弹窗正文区域、保留共同头部与关闭按钮，原内容DOM及滚动状态仍在。复用现有 `#comments-close`，明确表达“返回内容”或“收起评论”，无需新增第二个返回入口。返回后焦点应落在弹窗内的原评论触发器／相关媒体操作，不能跳到 modal 外不可操作的全局“查看评论”。
5. 保持现有 Esc／浏览器返回关闭顶层弹窗的语义，逐层恢复外部 URL、准确版本、草稿及原面板开合状态。不能为了窄屏评论返回偷偷更改所有 modal 的 Esc 含义。
6. 保留单一 `#comment-panel` 与现有保存／恢复机制，不复制第二套评论DOM或新增评论系统。参考音视频弹窗仍用自身布局；统一弹窗打开参考弹窗后评论被移走，父弹窗应自然恢复原布局，子弹窗关闭后再恢复并排。

## 根代理验收应覆盖

- 2192、1440、1200px：面板打开后按钮中心命中真实关闭按钮，点击一次关闭；右侧版本控件、波形完整，原件与评论同时可见。不要仅凭遮挡面积为0替代真实点击。
- 1024及390px：评论可读，已有返回控件明确且可点，弹窗关闭入口始终可达；返回时准确版本、播放时间／选段、草稿和正文位置保留。
- 宽屏有长正文时连续3次开合，当前评论锚点／媒体位置不逐次漂移；改变视口跨断点后再开合。
- 统一素材→关系素材→准确音频参考等至少两层弹窗：每层关闭、Esc和浏览器返回恢复相应面板父节点、hidden、草稿和焦点。外面板原本隐藏和原本打开各覆盖一次。
- 当前版未生成与旧版有原件继续准确显示；圈选／时间评论仍关联准确文件和版本。关闭弹窗时媒体暂停行为继续成立。
- 直接页面实体卡、故事宽屏评论避让、独立结构大图不应因该限定修改发生布局变化。

优先级P1；建议主协调实施。本文为方案与验收边界，不作为已修复或真实页面通过结论。
