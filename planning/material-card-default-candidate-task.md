# 实体大卡按进入来源默认展示准确候选

## 问题与目标

用户原话全文：

> 素材进入实体大卡的时候，如果是从参考素材列表进入且有选中候选，则默认选中该素材对应的候选；如果是普通的素材入口点击进入，则默认展示该素材最新的候选，没有候选的时候默认展示当前方案

让用户从参考列表查看正在使用的准确候选，从普通素材入口查看最新制作结果。只查看不改变参考选择、采纳或评论归属。本轮仅定义并发布任务，不执行目标；未来完成终点为本机正式可用，包括双仓受管集成、必要推送、正式服务生效和真实页面回验。普通执行后等待用户接受，`--auto` 沿未来启动授权。

## 依据与历史边界

## 已定行为与修改范围

1. **参考已选。** 从参考列表进入时，以点击时当前消费方、当前输入槽位真实已确认的选择为准，在规范素材身份下定位准确候选 `object_id + revision_id`（对象身份与修订），保留组件及必要范围。同素材被不同镜头／槽位选不同候选不得串用；不得使用初次渲染的旧引用或以最新候选覆盖已选。保存成功后不刷新立即点击也正确；保存中、冲突或失败沿既有真实状态处理，不将未确认预览当作已保存选择。
2. **普通进入。** 无显式目标的一次新进入默认最新真实候选；按当前规范素材身份与权威候选号排序，可复用 `materialCandidateChoice` 并核当前契约。候选号优先，时间／修订仅作既有稳定回退，不按数组位置、标题、评论时间或废弃版本模型猜最新。无候选才显示当前方案；最新候选原件失效／加载失败要准确提示并可重试，不悄悄改显示旧候选或当前方案。
3. **参考未选。** 作为无准确目标的查看入口，按最新候选／无候选当前方案展示；只查看，不自动保存显示候选为参考选择。
4. **准确目标优先。** 历史评论、实际生成输入、成片轨道来源、手动当前方案／历史候选链接、准确组件／字层条目继续定位原对象及修订。已选或显式目标缺失、失效、删除或不属当前素材时明确不可用，不降为最新，不串对象。
5. **同次会话保持选择。** 默认仅在无显式目标的新进入计算。卡内手动切换、同次卡会话切素材后返回、重绘、嵌套关闭返回及带准确路由刷新，保留明确选择、滚动／焦点与未提交评论。大卡左侧素材列表仍只切右侧，不开新卡；首次进入未访问素材用同一默认策略，返回已访问素材恢复选择。新一次普通打开重新取最新，其他素材 URL 残留、旧缓存及评论草稿不得暗中覆盖默认。
6. **查看无业务写入。** 进入大卡不能调用参考选择写接口（如 `POST shot-reference`），不能改输入、方案、采纳、评论归属或制作历史。候选选择控件仍沿既有显式写流程。保留普通实体与镜头独立体系及素材归属；不新增实体、候选、素材版本、默认设置、影子卡或中间弹窗，不迁移业务数据。

范围限共用大卡默认选择、实体工作区、参考列表当前选择到大卡的路由、相关异步状态及针对性检查／必要契约说明。不改作品或 Prompt，不生成媒体，不承担页面精简、OSS 迁移及旧 hover 播放器等独立残留。
