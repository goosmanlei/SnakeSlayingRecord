## 改后的工作顺序与行为

### 先阅读和定位，再决定是否选择

紧邻时间线上方设置右对齐的全局控制组：保留“全片概览／标准／细看／精细／逐帧”五级缩放；原“播放起点”的可见名与无障碍名改为“当前帧”，置于缩放组左侧，以留白或分隔线明确区分。当前帧只读显示实际播放头帧数，随播放、暂停定位和拖头更新，不增加可编辑跳帧功能，不改帧编号和时间换算。窄屏有序换行，仍保持当前帧在缩放组前的关联和区隔，不遮挡、不造成整页横溢。普通状态下当前帧与缩放继续可用。

范围起帧／止帧、起点时间／终点时间、循环选段、评论此范围、清除选择仍在时间线上方组成同一可见范围区。普通状态保留数值显示，控件真实禁用并有清楚的禁用视觉，不通过隐藏或折叠代替。进入选择后才激活范围输入；循环和评论还需合法非空范围与有效轨道，不能仅因进入选择就无条件启用。

删除截图中两行常驻说明及其占位：“起帧包含，止帧不含；时间显示到毫秒，实际范围以整数帧为准。”和“已选：…”摘要。不换成另一组冗余说明。整数帧仍为权威、起含止不含，帧与时间继续双向同步。非法帧／时间、空轨、越界、不相交等必要错误按需就地显示并保留可访问播报，不能删除校验或静默失败。

### 从角格进入选择，用轨道名称调整轨道

把“选择”从范围行移至时间线左上角，即固定轨道名称列与时间标尺的交界空白格。保留清晰短文字，增加能表达多轨框选的图标、可访问名称与按下状态。同一按钮再次点击退出。该格使用不透底色去掉栅格，仅处理此格，保留右侧时间标尺和时间区域栅格。

按钮在横向滚动、五级缩放、窗口宽度变化与标尺重建后始终固定可见，不被清除、不覆盖0秒或轨道名。点击按钮只切换模式，不误定位播放头、打开大卡或生成选区。

选择模式下每条轨道名称直接显示选中／未选中态，并接替原顶部轨道按钮的点击和键盘切换能力，支持非相邻轨与跨轨框选；修改轨道不改变时间范围。普通状态轨道名保持普通阅读语义，不修改选择。删除上方重复的“轨道”按钮整组及空白占位。轨道选中态不能冒充单片段选中；原片段点击、准确素材大卡、播放头定位和跨轨评论保持可用。

### 退出可以继续，清除才清空

| 操作 | 结果 |
| --- | --- |
| 普通→选择 | 沿现有行为暂停播放，激活范围输入；恢复同一准确成片内保留的范围／轨道和选区高亮。首次无保留范围显示空范围，不臆造整片选区。 |
| 选择→普通 | 保留范围／轨道、当前播放位置、横向滚动位置和未提交评论；停止循环，撤掉可编辑选区及轨道选择高亮，禁用范围操作。 |
| 再进入选择 | 恢复同一准确成片内的保留选择；循环保持关闭，必须显式开启。 |
| 清除选择 | 仅选择模式可执行；清空范围和轨道／高亮、停止循环，仍留在选择模式供重新框选。不删除评论或业务记录。 |
| 拖动中 Esc | 先撤销本次未完成拖动，恢复拖前范围。 |
| 非拖动时 Esc | 退出选择；保留输入框和评论编辑器已有 Esc 优先级，不抢占其操作。 |

切集或切成片版本沿既有隔离语义，不能把一版保留选区带到另一版；只保证同一准确成片内退出／重入复用，不新增跨刷新持久化要求。刷新或重开遵循现有恢复语义且不串集、串版本、串评论草稿。空成片、无轨道或无有效选区时正确禁用相应动作。

历史范围评论的查看和准确定位是只读路径，普通状态也能定位原准确版本和范围，不强制进入可编辑选择模式。历史锚点展示与本次可编辑选区分别处理；模式切换、历史定位和返回不丢评论草稿，也不将旧评论绑到新版本。评论失败保留草稿和上下文，恢复后可重试。
