# 素材管理默认全部集场、按场显示镜头筛选并调整顺序

## 原始需求与目标

用户原始需求完整保留：

> 请帮我把当前素材管理页面修改为：1）默认选定全部集、全部场；2）选定具体场的时候，出现镜头筛选项；3）素材分类和生成结果两个筛选项放到上面，集、场、镜筛选项放下面，默认镜头筛选项不出现

进入生产制作的素材管理，先按素材分类和有无真实生成结果找素材，需要缩小范围时再选集、场、镜头。普通进入不再自动带入视听制作或实体管理的集场选择；默认全部集、全部场且不显示镜头筛选。完成指受管双仓集成、必要推送、本机正式服务生效、真实 Chrome 验收及过程资源收尾，不能止于候选或代码提交。

## 改后行为与修改边界

- 筛选区域按素材分类 → 生成结果 → 视听集 → 视听场 → 镜头顺序排列；镜头行仅在选定具体场时出现。保留现有搜索、清除筛选和分页入口，不新增面板、折叠或重复说明。沿用相邻筛选的样式、选中状态及键盘操作。
- 素材页普通首次进入或从其他制作子页普通切入，默认全部集、全部场。明确携带素材筛选上下文的链接、刷新、浏览器前进后退及开卡返回，应恢复其准确选择，不能把默认规则应用为每次加载都清空状态。区分普通导航自动继承的范围与用户在素材页主动选定的范围；保留其他制作子页原有定位行为。
- 全部集时可选全剧具体场；选择场同步其真实所属集及准确范围依据。选中集而场仍为全部时不显示镜头行，不自动选首场。选定具体场后，显示“全部镜头”和该场按原编排顺序排列的镜头，初始选全部镜头，不自动选首镜。无镜头的合法场仍保留具体场选择及全部镜头，不造镜头选项。
- 选择具体镜头，列表与分类／生成结果数量共同缩小到该镜的真实素材用途；复用已有视听范围和素材关系投影，包含镜头自身需求及实际关联／输入素材，按唯一素材身份去重，不只靠素材名称或所有者猜测用途，也不把整场素材冒充本镜结果。
- 改集清除原场、原镜；改场清除原镜并回到该场全部镜头；恢复全部场时清除镜头条件并隐藏该行；清除筛选恢复全部集、全部场、分类／结果全部、空搜索及第一页，镜头行消失。再次点击已选具体项沿用现有恢复全部的单选行为，不让隐藏的镜头条件继续过滤列表。
- 分类、结果、搜索与范围筛选能组合，改变条件按现有规则重置分页，开卡返回保持筛选、页码及阅读上下文。保留分类父子合集、零数量分类可选、真实结果优先和五列分页／窄屏重排；不改素材分类定义或已有分类分组、图标。

修改限于素材管理筛选渲染、普通导航及准确 URL／历史恢复、镜头范围读取与必要服务端校验／计数、相关回归检查和交付记录。不得改写故事、素材方案、候选、评论、原件或用途关系，不迁移分类、不新增生成调用、不改实体管理或视听制作的默认定位。无付费生成、VPS 或其他外部发布授权；本机正式发布不要求业务数据变化，无变化时保全活库。
