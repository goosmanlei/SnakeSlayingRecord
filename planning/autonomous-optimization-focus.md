# 自主优化的历史意见重点

本文件将本项目已经确认的意见归纳为检查方向。归纳不是新的用户原话；当前会话明确原则优先，实际功能与数据以首次运行基准为准。已有修复只作回归样例，不因历史文档写过问题就认定当前仍有缺陷。原始意见与当前有效规则冲突时记录来源和替代关系，不根据文件日期单独判断。

| 重点 | 历史依据与可推广的要求 | 本轮怎样检查 |
| --- | --- | --- |
| 用户目的与必要性 | [制作审阅任务](production-review-ui-task.md) 要求移除手工录入、重复流程导航；[创作页面统一](story-creation-ui-unification-task.md) 要求去掉重复评论按钮、搜索入口及正文区“45份资料”；[素材审阅任务](material-review-optimization-task.md) 要求合并重复模型和实际输入展示 | 每个信息和操作说明服务哪个用户判断；既有入口已满足需求时不另加。精简保留理解必需的上下文和后台能力，不一律追求更少字 |
| 表达清楚且有依据 | [剧本评论归纳](screenplay-04-comment-summary.md) 的 C04、C07—08、C13—14 等涉及所指、目的省略；C01、C02、C16、C20 涉及读者可见证据。制作审阅任务要求阿蘅／李寄的关系标签与准确剧情依据相符 | 页面术语、状态、计数和缺项让读者理解对象、原因与后果；标签有准确版本和充分证据。只迁移这些阅读原则，不据此改写剧情或把故事内容意见变成系统需求 |
| 页面与交互一致性 | 创作页面统一要求一级导航、子页选中态和评论数口径一致；素材审阅任务要求共用按钮、版本、媒体和嵌套弹窗 | 对照主要页面相同动作的视觉与行为；桌面／窄屏、直接链接、前进后退和键盘操作实际可用，优先复用组件 |
| 阅读、评论与判断连续性 | 制作审阅任务要求采纳→取消→再次采纳；素材审阅任务要求准确块／版本评论、关闭重开及草稿。KNOWLEDGE 中已有拖选、定位、快捷键、关闭浮层保留草稿的明确要求 | 切版、筛选、弹窗和刷新保持合理上下文；评论不串块串版，计数不把事件当评论；内容认可不自动授权生成，测试不污染正式记录 |
| 真实成果与素材呈现 | 素材审阅任务要求横竖方图完整显示、真实参考顺序、保留历史实际提示词；制作审阅任务要求按媒体类型显示真实缺项；[歌曲阶段交付](../production/song-stage/README.md) 区分当前制作成果与实际听审接受 | 占位不冒充成果，方案不冒充调用，生成不等于质量接受；准确原件可查看／播放。声音是否听审单独记录，不用图像、接口返回文本或音频元数据替代 |
| 数据概念与历史清晰 | 旧素材审阅任务的“修订轮次”只作为历史口径；[制作拆解任务](production-breakdown-task.md) 及 素材版本任务 `task-20261004-0009` 明确需求→固定版本→同版多候选，开始实际提交后锁定版本。阿蘅四个旧修订不能虚构成四次生成；[素材轮次说明](../production/material-rounds.md)、[工作区流程](../production/generation-workspaces.md) 要求准确采用、历史和活库保护 | 核对实体、完整状态、共享需求、固定版本、候选、旧修订轮次、调用与采用各自含义；只在必要时改变表示，历史可追溯、旧链接可用、导出恢复一致，后台流程不反向侵入通用展示层 |

执行时还要按需读取 `AGENTS.md`、`KNOWLEDGE.md` 与相关任务原说明，检查新评论和当前行为。若需要回查任务媒体，从主项目账本所指的原输入路径只读获取，不把旧截图当当前页面。

为每条实际使用的意见在本机检查点保留来源（文件章节、评论 ID／准确修订或会话记录）、原意、当前有效性、检查场景和对应问题 ID。已解决意见登记回归结果；被后续明确意见替代的保留替代关系。没有评论者身份字段的记录，不自行断言全部来自用户；原归纳已获用户明确认可时沿用其注明的范围。

这六类不限制新发现。没有评论不代表已经通过，反过来，没有可复现问题也不需要强行修改。优先找对用户工作有实际影响的问题，独立审查须同时检查过度删除、证据不足和新增负担。

本轮优先复核近轮已明确要求：[整体 UI 统一](system-ui-unification-task.md) 与 顶部导航及素材版本模型任务 `task-20261004-0009`。以前置完成后的真实系统验证固定顶栏、集场镜指代、紧凑小卡、共用大卡与嵌套弹窗、整场逐镜布局、素材版本／候选切换、多状态共享素材、准确调用和历史恢复；这些是回归方向，不是预设仍有缺陷。历史意见只作依据，不能用旧轮次定义推翻后来确认的固定版本规则。

`task-20261004-0009` 的原说明定位由主项目任务账本所登记的工作区给出，文件为该工作区的 `planning/ui-material-model-task.md`；本工作区尚未包含该前置的成果，不补猜当前实现。执行时先同步已完成的准确上游，再读取其原说明及交付证据。

性能是本轮用户明确新增的目标，贯穿以上六类检查及各主要页面和功能。历史性能修复只作参考，仍须用本轮环境和数据建立真实基线；检查页面端到端等待、前端渲染、重复请求、服务与数据库读写、媒体加载和资源开销，并保护历史、准确版本与写后可见性。优化收益须同条件实测，不能把接口加速直接推广为整个页面已加速。
