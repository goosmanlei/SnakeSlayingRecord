## 可执行验收与恢复

1. **三级范围及正常对照。** 真实 Chrome 首次无有效定位时默认当前第一集／第一场／第一镜（调查时 AE001／AS001／ASH001），没有任何“全部”选项；按制作顺序展示。ASH001 → ASH002，切 AS002 自动到 ASH006，切第二集到它的第一场第一镜。有效深链、刷新、浏览器返回及重开实体恢复合法且准确的范围。旧全部地址、非法父子组合确定性归到已定默认；空集／空场显示无场／无镜，不能回退全剧。
2. **准确集合及去噪。** 按当前镜头 entities、states 归属、occurrences、continuity_context 与实际素材输入归属核对节点并去重，只含该镜及真正相关实体，不纳入本场其他镜头或递归关系邻居。实体管理图彻底不画 `involves:*` 派生边及其标签，不能只藏字保留虚线；可见节点间所有真实关系及有效孤立节点保留，业务记录不因界面简化被删。
3. **关系方向与可读性。** 当前无向关系无箭头；隔离夹具覆盖 A→B→C、多父 D→C、反向存储归一、混合无向关联、环和孤立节点。方向与端点正确，上游到下游分层，环在同组／层，实体不重复且真实边不丢。卡片、连线和短摘要互不遮挡，线不穿卡；无冗余关系 hover 明细，不为布局补造正式方向。
4. **准确打开及连续返回。** 在常用桌面宽度与窄屏实际读图、拖动／缩放／适应全图；不靠极小字号容纳内容。开 EN034 和镜头统一大卡，关闭回原范围和视野，再切镜／场恢复可读视野；关系原有有用点击、评论归属和草稿保留。素材管理原范围、筛选、分页、媒体分组及准确开卡返回作为正常对照保持。
5. **故障与恢复后的操作。** 在隔离环境验证图或目录读取失败、迟到响应、加载中连续换镜／换场及目标失效：当前选择不被旧结果覆盖，不把旧图冒充新范围，不迁移评论或草稿。解除故障后通过已有重试或重开重新加载，再走 ASH001→ASH002→AS002／ASH006、开卡关闭和浏览器返回，得到准确图与可继续的操作。错误处理复用现有机制，不新增默认说明面板。空范围及非法定位另外覆盖，不用网络故障伪装空数据。
6. **本机正式交付。** 在执行时最新双仓主干和正式数据隔离副本实现，登记并验证准确 desk 引用及 cleanup guard，受管先 desk 后 primary 集成与必要推送，再在共享窗口发布本机正式服务及目标必要的技术增量。此图改造不授权改写故事／镜头／关系业务事实或回灌快照；候选、原件、真实调用和评论摘要前后核对。正式 Chrome 从原入口走上述核心只读路径，核对配置、镜像、两仓身份及必要回执一致。自动检查辅助实际操作，不能代替页面验收。
7. **恢复、清理与报告。** 从准确导出恢复新空实例后继续三级选择、图与大卡往返，核对关系、素材、候选和评论保留。发布失败或中断先查已生效动作与回执，沿同一准确包恢复；候选变化重新准备和验证，服务回退不当作数据恢复。清理本任务无用途资源，按准确 ID／路径回读删除数量与范围，说明必要保留项用途、负责人和解除条件。最终回复先任务编号和实际解决的原问题，再给图 5 前后例、收益、正式版本／环境、真实验证边界、残留与下一步。
