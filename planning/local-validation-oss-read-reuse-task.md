## 已定实现范围

### 完整检查与云端验证各自负责什么

本地完整检查覆盖资源描述及引用闭包、全部必要原件与派生文件、数据库快照，检查 SHA256、字节数、预期媒体类型及适用媒体/业务一致性；恢复继续核对数据库完整性、表指纹和业务引用。校验范围完整性不因字节来源本地而缩减。允许沿用输入未变且绑定准确文件身份的有效检查证据，不以“文件存在”替代校验。

云端验证负责指定 bucket/key/VersionId 的访问和云端真实返回内容；需要完整验证时，实际读取全部字节并核对大小、SHA 和响应 MIME。保留显式远端完整验证入口，不能将它悄悄改成本地命中即通过，也不能使用 full=False、HEAD 或 ETag 冒充完整字节校验。

在既有接口和回执中清楚区分实际执行的本地完整检查、云端身份/可读性检查、云端完整字节验证及其证据时间。输入未变时可以按契约复用已有准确云验证证据，但不能把复用时间写成新验证时间。新上传原件、云身份改变、确有远端状态疑问及明确要求的云端审计/在线恢复，继续真实检查相应范围。内容相同的不同云版本可以共享本地字节，不能共享彼此的可读性结论。

### 让本机已有准确文件可复用

复用现有缓存、原件目录和离线介质机制，提供有边界的本地来源解析。新建受管工作区即使自身缓存为空，也能使用本机已保存且校验匹配的原件；不要求每个任务复制一份全量镜像，不新建文件同步平台或常驻缓存服务。准确文件的取得、读取及回执仍绑定任务使用的资源版本。

联网日常检查默认先查全部已配置且允许使用的受控本地来源；单个缓存缺失或损坏时，先从其他合格本地来源修复或复用，仍保持零网络。只有所有允许的本地来源均不能提供合格字节时，联网模式才按准确版本补取并完整校验，严格本地模式才报缺或报损坏。提供明确的严格本地检查方式：禁止云端补取，缺项、损坏或描述冲突准确失败，不退回同名旧版、旧路径或 latest。不要把正常创作/正式实例永久设为 REVIEW_RESOURCES_OFFLINE=1，该变量还改变凭据和新资源候选的发布语义；本任务要独立控制校验读源，保持正常新资源上传发布行为。

保留租约、并发锁、容量/磁盘余量、原子临时文件安装和归属清理。可淘汰缓存不当作永久恢复副本；不修改或删除其他在途任务持有的文件，不建立无限增长、无责任归属的缓存。中断、损坏及并发下不能安装半文件或误报验证成功。

### 让必要的远端读取只读取一次

确需远端完整验证时，将该次已读且验证通过的字节安全保存在可复用本地来源中，后续 materialize、探测、打包或恢复直接使用。冷缓存下“远端验证→本地使用”不应对相同准确对象再下载一次；失败、取消、未知结果先核实，保持有界重试和有效资源保护。

### 接入实际任务流程

覆盖工作区准备、制作和媒体预检、完整目录检查、集成/交付检查、完整导出及空实例恢复等实际入口；以调用清单明确每一步检查目的、读源策略与必要云验证触发条件，消除无目的重复全量远端读。

数据库快照与资源目录原件/派生共同纳入，不因媒体齐全漏掉快照；新空实例恢复必须证明所交付介质本身完整，不能依赖暖缓存掩盖缺项；此类介质验收限定本地来源为被验介质，禁止借用外部原件补齐。继续编辑或小范围渲染检查使用准确本地输入，无需新生成作品。

更新唯一流程文档及适用 SKILL，让未来任务默认采用新路径，保留明确的云端验证选择。报告给出本地和远端分别实际覆盖的范围、失败与残留，不向普通创作审阅界面增加无用技术信息。

## 验收与节省证据

以同一组准确资源和快照为输入，记录真实 OSS GET 次数、完整读取字节、本地复用/补取数量和必要耗时。使用计数或拒绝联网等可复核证据，不能只靠配置宣称零网络。

| 输入与场景 | 完成标准 |
| --- | --- |
| 本地齐全，重复完整检查 | 全部内容和引用检查通过；严格本地模式实际 OSS 读取为零；缺失/损坏检查没有被关闭。 |
| 新工作区空缓存，本机已有准确原件 | 复用受控本地来源；不因工作区新建重新下载全目录。 |
| 全部允许的本地来源均缺一个原件/派生文件或快照 | 严格本地失败并指明准确缺项；联网模式只补准确缺项；再次执行无需重复下载。 |
| 单个工作区缓存损坏，其他允许本地来源完好 | 从合格本地来源恢复/复用，完整校验通过且 OSS 读取为零。 |
| 同名旧版、同大小错 SHA、描述冲突 | 不误用、不跳过；损坏文件隔离或按既有规则处理，补取后重新校验。 |
| 快照与完整介质 | 当前准确导出能在无凭据、禁止网络且初始空缓存的新实例恢复，表指纹/完整性/引用通过，并完成继续编辑与必要小范围渲染；介质缺项时不能被外部缓存救活而误判完整。 |
| 本地正确而远端不存在/无权限 | 本地可通过，显式远端检查失败；回执明确区分。相同 SHA 的另一个可读云版本不能替代失败版本。 |
| 冷缓存远端完整验证后立即读取 | 一次必要完整下载产生可复用合格文件，后续读取不重复下载。 |
| 取消、失败、并发与淘汰 | 不安装半文件，不删除租约中的输入，不留下无归属大临时文件；并发重复读取受控。 |
| 正常在线制作及正式服务 | 新资源仍按既有候选/上传/发布语义运行，现有准确媒体播放和业务数据可用，无错误离线模式副作用。 |

常规本地完整检查和空实例恢复应使用当前准确实际资料；远端正反例优先用针对性故障测试与少量受限真实对象，明确真实与模拟证据边界。执行前核对必要实际云读取的范围/规模，避免为了证明节省反复全量公网下载。不能删除质量门槛来取得“零读取”，不能把避免字节数直接写成保证月度节省或将历史全部费用归本任务。
