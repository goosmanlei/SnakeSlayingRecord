# 实体大卡统一素材入口，直接审阅所选素材的结果与生成方案

用户要在实体大卡中选择一个实体或实体状态的素材，直接看生成结果与它的生成方案，再比较版本、候选和反馈。现在两个素材入口分散，右侧堆放关联对象与通用说明，切状态描述版本还会跳到实体级素材。本任务交付完整的新实体素材审阅路径，覆盖共用素材大卡，不以只修 M2597 或默认展开旧内容结束。

## 改后怎样使用

实体基本介绍和必要关系沿当前有效设计保留。在下方原“实体状态”位置统一组织素材入口，用“实体素材”“实体状态”两个 Tab 切换，删除上方重复的实体素材区。实体素材 Tab 列身份母版、音色等实体级需求；实体状态 Tab 列状态，所选状态下直接显示该状态的描述版本及其素材需求。复用现有实体、状态和需求身份，不为这次布局再造一套对象。

从状态或具体素材链接进入时，直接选中准确 Tab、状态和素材；从实体列表首次进入沿当前默认状态，进入实体状态 Tab。主动切换 Tab 时恢复该 Tab 上次有效选择，首次进入实体素材 Tab 才选第一项。无需求时在当前范围显示简短空态，不能跳到另一 Tab 补位。

状态描述版本与素材版本是不同选择。切状态描述版本时保持当前状态；原素材在新描述版本下仍有效则保持，否则选择该状态该版本的第一项有效素材；没有则留空。绝不能跨到实体级需求，也不能把当前素材或新状态描述套在旧版上。浏览素材版本、候选及返回不改变用户的采纳、参考选择和未提交意见。

右侧顺序固定为：所选素材名称及版本／候选切换 → 生成结果（未生成则占位）→ 该准确版本的生成方案。生成方案直接显示实际参考素材列表、模型和参数、完整 Prompt；缺少历史生成依据时明确缺失，不用当前方案补造。候选原件与所显示方案必须准确对应，计划输入与真实调用输入仍可辨认。图像可看原图、音频可听准确范围，沿用必要评论、采纳或原件判断操作，不增加新的审批。

删除右侧“本版采纳范围与理由／本版内容”展开链、无关的“已有形象14个”“沿用方案13个”“尚未选择·待比较”、逐项“用途与意见”等展示。方案信息从藏在历史按钮后的内容变成直接正文；不改成全展开长页、其他折叠、另一个杂项 Tab 或说明弹窗。真正属于所选方案的输入保留在生成方案的纯列表中，准确版本、候选及必要裁切／时间范围是判断输入所需信息。

通用“素材要求／检查要点／审阅标准”不再作为正文重复出现，收敛到审阅操作旁一个“？”按需帮助入口，可 hover 或键盘聚焦读取，点击后可稳定阅读；不复制另一份标准。此规则覆盖全系统审阅场景中同类通用提示，重点核实体大卡、独立素材卡、视听制作素材入口与图像／音频。具体作品独有的约束应在相应描述或准确 Prompt 中表达，不能将整段当前作品藏到帮助里。
