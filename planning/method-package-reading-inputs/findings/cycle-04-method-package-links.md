## 共同原因和不同责任

源码定位适用于系统 `b3fa3fef77851c544c5350cb4a99ab0af622cbd3`；系统路径相对同级 `../story-review-desk/`。

1. `content/creative-system-review-method.json` 把完整 SKILL、项目适配和愿景定义成三个独立 source section，没有 `preserve_paths` 或 `companions`。系统 `methods.py:347-375 sync_source` 因而将原始文件名映射为 `references/skill.md`、`references/project-context.md`、`references/vision.md`，没有记录必须一同保留的包内目录关系。
2. 简短入口正文又写死 `shared/0.md`、`shared/1.md`、`shared/2.md`。它假定标准导出布局，没有覆盖通用作者交付。
3. `scripts/method_runtime.py:52-68 deliver_files` 对无附属文件的 section 写 `shared/{序号}-{section}.md`；系统 `methods.py:320-340 export_execution` 写 `shared/{序号}.md`。两条路径具有相同方法、资源与字节，局部文件名协议却不同，造成第一层差异。
4. 两条路径均将无附属资源扁平化，也都不重写原正文。原本以 `skills/creative-system-review/SKILL.md` 为基准有效的 `references/project-context.md` 已不成立，造成共同的第二层断点。
5. 现有 method 校验保证文件安全、章节存在、准确依赖和摘要，并不负责根据 Markdown 判断哪些链接必须可读；这些检查通过不能代替“从入口读到方法及适配”的实际使用验收。

源码中已有适合复用的能力：`sync_source` 支持保留源相对路径和精确附属文件；`resolve` 会携带该章节的 `files`；两个交付函数对这类资源均保留 `shared/{序号}/{原相对路径}`。因此无需新建方法平台、包加载器或要求使用者学习并手工替换文件名。

## 最小修复范围与真实验收

目标应是“新的执行者仅按交付包入口即可读到本步骤完整方法、准确适配和愿景，知道哪些额外项目材料仍须补齐”。优先复用当前路径保留及附属资料机制，明确两种交付方式共同遵守的文件布局；只调整必要源定义、引用入口、交付布局与对应说明，不改三份批准方法正文的业务含义，不把所有项目资料塞入包。

具体实现可先做一个 Review 包样例：保留完整方法到适配的目录关系，同时让根入口在受管作者交付和标准导出中都指向存在的文件。所选方案须保住源字节和准确引用。修改只应追加新的资源／方法／绑定版本；旧执行不补写“采用新方法”，旧记录与源摘要继续可回查。历史包重新导出的布局兼容怎样处理应写清，不能静默替换其方法正文。

不要以正则链接扫描作为主要验收。执行者应实际完成下面的阅读与恢复任务：

1. 在当前准确隔离实例取得新的 Review 执行，通过既有 `creative_method.py begin` 交付。把交付目录移到一个不同于项目根的新本机目录，从根 SKILL 开始顺序打开“完整方法→项目适配→愿景”，不查源码、不猜 shared 文件名。读后能明确复述本次授权、正式只读边界、继续工作的项目入口和未提供的专业资料；这是阅读结果，不是测模型内部理解。
2. 对同一准确执行做标准 method-export，在另一个干净目录走同样阅读路径。两种路径各自实际打开，不以其中一种成功代表另一种。
3. 从完整方法的“项目适配”链接进入适配，实际读到路径基准说明和当前规则入口；从包入口找到愿景并读到结尾。项目根的 AGENTS／STATE 等额外材料应明确来自本次输入或所在项目，不能让缺项目材料被误报为包已完整交付，也不要求复刻正式业务数据。
4. 回读准确执行、请求和来源摘要，证明没有把当前最新版混进已冻结执行。将导出 registry 恢复到新空隔离实例后重取同一执行、再导出和阅读；旧执行应保持旧正文，新执行使用显式新绑定。恢复属于修复任务隔离验证，本辅助调查未执行。
5. 复用一个已有专业方法正常样例：从媒体方法读到 record-contract；从所选影视章节打开其来源和图示，并实际观看图示。未选章节仍按原按需策略处理。这个对照保护已有可读路径，不扩成全剧创作或付费生成。

预期收益是少一次中断、少一次文件名猜测和人工解释，并使可移植 SKILL 真能按入口开始工作。只有文件数、哈希和 prepare 成功不足以证明这个收益；完成上述阅读才可称“本包可以直接读”。
