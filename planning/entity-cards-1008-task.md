## 任务目标

### 实体大卡：看清关系链并控制查看范围

1. 在“实体信息 → 关系”中，单击非当前实体节点、关系连线或关系说明框，联动高亮对应连线、两端实体和说明框。点击节点时标出当前实体与该实体之间已展示的直接关系；点击连线或说明时只选中该条准确关系。选中另一项替换高亮，点击图中空白可清除；不递归增加关系，也不写业务采纳。保留双击／既有键盘方式打开关联实体、来源阅读、文字圈选评论及关闭后返回的能力，拖动不误触选择。
2. 重新安排节点、完整说明和路径，更多使用平滑曲线，以关系清楚、查看成本低为目的。当前直接关系图的路径不得相互交叉、叠合到无法区分或穿过无关节点／说明；共同连接到同一端点除外。保持真实方向、端点、关系说明及剧情依据，不靠隐藏内容或改写关系事实获得整洁布局。
3. 在“关系”标题同行提供“展示完整关系图”“原始大小”“扩大”“缩小”。完整图适配当前视窗并包含全部节点、说明和连线；原始大小恢复 100% 逻辑比例，扩大／缩小连续作用于同一图面。概览后可以放大阅读，缩放保留当前查看中心和选中关系；到比例边界有明确反馈。节点、文字、连线、点击区域和评论定位同步缩放，继续支持图内平移，操作不引起外层页面跳跃。
4. 将大卡的“完整状态”章节标题改为“实体状态”，保留状态数量、选择与准确引用。此项是界面标题调整，不改完整状态的数据含义、内部身份或历史清理规则。

### 两类小卡：在标题和底部读懂对象

1. 全站实体小卡、素材小卡分别把类型图标、名称和业务编号放在同一标题行，移除独占的编号行和重复类型文字行。图标提供可访问名称及必要提示；真实缩略图继续使用，长名称和窄卡不遮住图标、编号或底部信息，完整名称仍可取得。
2. 实体小卡底部明确显示“状态 N 个 · 素材 M 个 · 采纳状态”。状态数沿大卡当前有效状态列表按状态身份去重，不计历史修订和已清理状态；素材数沿现有真实关联及规范素材身份去重，同一素材的多个状态关联、版本、候选、文件或分组重复不增算。采纳读取真实决定与范围，分别表达未采纳、已采纳和需重新采纳，不从是否有生成结果推断。
3. 素材小卡底部明确显示“版本 N 个 · 候选 M 个”，移除“有生成结果”及同类重复结果标记。普通小卡统计该素材已登记的真实制作版本，包含尚无结果的方案；候选数按各准确版本中的候选身份去重后汇总，不把文件组成、重复渲染或单纯调用失败算作候选。零值显示 0；旧数据缺失时明确未登记，不能伪造版本或把未知当作 0。
4. 数量与镜头参考已选位置分开：V2／C2 表示选中第二版／第二候选，不表示有两个版本／候选。保留既有准确参考选择语义；1009 章的镜头参考专项排版、关联补全与 Prompt 重建不在本任务内执行。

所有共用入口使用一致表面与计数口径，必要时补齐只读投影和调用方字段。普通小卡仍打开准确大卡；实体大卡左侧底部素材列表仍仅切换同卡右侧。保持准确版本／候选、真实原件、评论、采纳和采用历史，以及返回后的筛选、页码、滚动和草稿。

本任务交付隔离实现、真实浏览器验收及可审阅的双仓候选和恢复步骤。管理页改四列、场镜导航和关联／Prompt 重建、全站性能或缓存改造分别属于其他章节；本任务不生成媒体、不重做历史数据清理。正式集成、部署和推送沿执行阶段的有效授权及项目交付流程办理。

1. **完整覆盖来源。** 对照本章全部要求形成需求—实现—证据对应；准确保留章节身份与文本哈希。确认本章和会话媒体均为空，不声称研究或保存了不存在的图片。

3. **曲线布局可读。** 覆盖阿蘅等多关系实体、单关系、长名称／长说明及多项依据，在记录视口的桌面和窄屏核对：节点及说明无覆盖，曲线无交叉或不可辨的共线，不穿过无关文字，方向与端点正确；完整内容均可达。保留改造前后截图和必要几何证据，不以把大部分内容藏起来通过验收。
4. **缩放四项可用。** 标题同行四个控件可见且可操作；完整图模式容纳全部内容，原始大小回到 100%，多次扩大／缩小及边界状态有效。选中、命中、平移、文字圈选／评论定位、窗口尺寸变化与叠层返回一起实测，外层滚动和草稿不丢失。
5. **实体状态与实体小卡。** 大卡标题为“实体状态”，原状态行为与数据契约不变。实体小卡标题行包含类型图标、名称和编号；底部明确显示状态数、素材数和真实采纳状态。用 0／1／多状态、共享素材、未采纳／已采纳／需重新采纳实例核对权威记录，重复关联不多算。
6. **素材小卡。** 类型图标、名称、编号位于同一标题行；底部为实际版本数和候选数，不再显示“有生成结果”这类汇总文字。覆盖无候选、单／多版本、同版多候选、最新方案未生成而旧版有结果、多个文件组成与旧数据缺字段；统计不随当前浏览版本或重复分组改变，V/C 选定值不冒充总数。
7. **全站共同回归。** 在实体管理、素材管理、制作拆解、镜头制作、实体大卡左侧素材列表、无实体归属素材及引用／叠层入口实测；覆盖桌面、窄屏、长标题，普通打开与同卡切换例外、准确版本／候选、评论和采纳、返回阅读位置与草稿均正常。必要自动检查验证计数和交互逻辑；接口及静态检查不替代真实浏览器验收，受阻项如实标记未验证。原件、已有评论及采纳／采用历史不被本次浏览和界面调整改写。
8. **交付与收尾。** 提供准确双仓候选、逐项验收证据、受影响的使用／读取契约及发布恢复步骤。核对并清理本任务无效过程资源，报告实际删除数量／范围、回读结果和保留用途；有未清理项则说明原因及下一步。阶段状态以任务账本与实际回执为准。
