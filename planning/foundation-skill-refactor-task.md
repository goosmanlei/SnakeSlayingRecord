# 基础流程与 SKILL 按创作职责重构，并保持连续阅读

## 目标与已确认的工作方式

人进入「制作思路 → 基础流程」，应能看懂每个创作环节做什么、产出什么，原位选择节点，顺畅阅读、比较和评论它实际使用的 SKILL。AI 取得的方法应与页面一致，能指导专业创作判断，且符合当前简单的数据模型和基础流程。

当前存在三个相互关联的问题：点击左侧节点或文件会丢失整页和左侧滚动位置；方法只引用公共资源的某章，页面却列出整个资料包；方法混合了通用准确性规则、角色专属要求、历史试用限制和内部准备流程，专业创作判断反而不足。用户已逐项讨论并确认下面全部取舍。本任务将页面、当前有效方法和实际执行绑定一起交付，不仅修改流程图或缩短正文。

本任务是系统和创作方法演进。保留已确认故事结构、小说、剧本和有效制作成果；在隔离环境以小样本创作、制作和阅读验证方法，不重做全剧，不批量改正式作品或素材方案。正式写入范围限本任务方法、资源引用、绑定、流程配置及必要系统发布。

## 一、按实际职责整理流程与方法

保留现有「制作思路」五子页、故事结构与小说联动回修、逐步创作和独立读者反馈。主线在素材需求之后明确为：**素材方案 → 生成与制作 → 候选 → 结果检查与返修**；候选是生成与制作的产物，不新增一个工作阶段或审批节点。

### 取消独立的“生成准备”阶段

删除当前流程图中独立的“生成准备”和“准确输入·提交前准备包”交接，把必要准备并入“生成与制作”的实际 SKILL 能力。后者须可点击阅读、具备真实生效的执行绑定，不能只改节点名称而继续要求作者先完成一项独立准备任务。

| 工作 | 负责什么 | 交付什么 |
| --- | --- | --- |
| 素材方案 | 从素材需求形成创作要求、制作方式、工具／模型、参数、Prompt、参考素材及使用方式；需要补选候选或片段时修订同一当前方案 | 素材 M 的单份当前方案 |
| 生成与制作 | 取得准确原件／片段，核对当前方案、实际参数、授权与适用额度；调用模型或完成本地制作，再回收真实结果 | 候选 MC、实际提交快照和原件；失败或缺项如实返回 |
| 结果检查与返修 | 真正看、听、读结果，结合原目的判断，定位应修改的方案或上游内容，再实际比较 | 有依据的反馈与当前方案修订 |

既有准备接口、输入检查、不可变提交快照、调用身份和防重复保护作为执行内部能力保留。超时先查询，结果未知不重复付费；本地字层制作不伪造模型调用；准备包不伪装成业务实体或创作成果。旧 generation-preflight 的文件、评论、执行及准确链接仍可追溯；当前入口与新工作使用合并后的方法。技术身份可复用或迁接，不能产生两份当前能力或让调用者绕开必要检查。

### 取消“准确依据与连续性”的统一公共依赖

当前 `method.resource.continuity` 将作者、独立读者和评论润色的规则混在一起。取消所有当前有效 SKILL 对它的统一引用，把必要要求融入各方法已有输入、工作及检查段落：作者可依据全剧和已确认设定，核对因果与连续性；首次独立读者只依据开放到当前位置的正文；评论润色保持用户原意，不新增修改要求。保留准确历史，不删除旧执行所引用的原文。无需新增另一个“公共规则总表”替代它。

### 材料分类与节点表达

保留当前九类职责及其唯一素材分类：图像包含角色、场景、道具、镜头画面；声音包含人物音色、场景音、演唱；视频、字层继续独立。字层负责准确文字、排版、出现时机、遮挡与可读性，可交付可编辑工程；普通背景字迹由图像承接。此次不把字层归入图像，不重分类全剧。

素材方案的图像、声音、视频、字层使用一致的分组边界和操作样式。前两组包含各细项；视频、字层作为单项能力直接可点击，不为对称再加同名子层。全部必要节点和产出平铺可读。小说和剧本中的“独立读者”明确加上与其他可点击能力一致的边框、焦点、选中态；保持旁支含义，不误画为必须人工审批后才能继续的主线。

## 二、完整重构当前有效 SKILL，补足小说创作方法

从当前正式绑定、流程节点和作者入口核对实际使用的方法，逐个阅读全文、整理职责、改写并实际试用。范围包括：故事结构、小说、独立读者、剧本、视听设计、实体／状态／素材抽取、图像共用正文与四专项、人物音色、场景音、演唱、视频、字层、合并后的生成与制作、结果检查，以及流程旁支的评论表达与创作协作 Review。保持后两者原本授权和项目适配边界。退休而未绑定的旧方法只保留历史，不为齐套重新启用；没有真实能力的采编／剪辑节点不虚构 SKILL。本任务不改造任务调度或增加管理实体。

每个方法从自身工作目的出发，讲清准确输入、重要创作取舍、实际步骤、产出、检查和适用参考。删除“本轮方法库试用只做准备”等一次性限制，去掉与当前职责无关的复制段落。共用评论／保存／发布协议沿唯一现有入口维护，各 SKILL 说明本环节怎样理解意见和验证修订即可；不把技术日志或内部字段搬入人的阅读正文。必要执行入口及恢复条件不能因精简失效，也不把每个方法都强行写成同一套章节或相同的 draft/review/result 仪式。

### 故事结构与小说创作

故事结构属于小说创作过程，**取消当前影视专业知识与 Seedance 的固定依赖**。小说同样不以影视或视频生成条件为前置。必要的通用叙事判断由这两个 SKILL 直接承接，允许小说通过叙述者、内心活动、视角与语言表达，不过早要求所有内容外化为可拍摄动作。

执行者有针对性地研究可靠的小说和故事创作资料，将适合本环节的专业技巧融入方法。资料来源与适用边界可核验，不照搬整本书，不为完成任务先建立大而全的小说知识库。重点如下：

| 环节 | 必须形成可执行指导的创作判断 |
| --- | --- |
| 故事结构 | 人物欲望与内在矛盾怎样推动选择；选择、阻力与后果怎样递进；人物关系和支线怎样参与主题；读者的信息获得、悬念、伏笔与兑现；结构与正文如何在实际创作中联动修订 |
| 小说创作 | 谁在叙述、读者能知道多少；视角和心理距离怎样影响阅读感受；哪些过程展开为场景、哪些概述或省略；动作、心理和对白如何共同表达人物；语言声音、细节和段落节奏怎样服务作品 |

正文保留必要工作顺序与关键判断，读完能开始做事；确需深入的专项放在方法随附参考，用少量短例说明适用条件、不同处理的效果和回读办法，正文给出何时查阅。方法帮助作选择，不强制固定幕数、节拍、篇幅比例或每章反转。保留逐自然片段理解、写作、回读、修订以及章末／全稿连读，不能一次生成整稿再补过程。

可操作的判据示例：当前“重要现场不用概括代替”应补上判断依据——决定关系变化的一次争执可能值得展开，随后重复的冷淡可以概述；方法应帮助判断何处值得展开，不能让 AI 把所有过程都写满。试写样例自行选取并说明依据，不把这个示例生硬写进正式故事。

### 其他环节的知识边界

| 环节 | 引用原则 |
| --- | --- |
| 剧本 | 按改编所需引用叙事、表演、声音等适用部分；不引用 Seedance，机位和模型参数由后续承担 |
| 实体／状态／素材抽取 | 主体是数据模型、唯一出处、命名、复用和独立制作需求；美术、空间或声音的具体疑难才按需查对应知识，不默认加载完整调度／美术章节 |
| 视听设计与各类素材方案 | 按当前创作判断引用适用影视知识；图像、声音、视频和字层各守职责，不能用通用模板抹掉已经形成的专项方法 |
| 镜头视频方案 | 按视频生成手册选用适用模板、参考与能力规则，再落实当前镜头；专业原理与模型表达各有用途，不能删掉手册的实际约束 |
| 生成、结果检查与两条辅助旁支 | 只引用完成本环节所需的操作或判断资料，明确条件；创作判断与系统校验分别承担 |

保留当前已确认的基础模型：普通实体 EN 与镜头 ASH 统一承接；状态 ST 有独立需求才存在；素材 M 唯一出处、当前方案原地维护，候选 MC 保存真实快照；故事至剧本及 SKILL 文件继续保留有效版本。不要因重写方法恢复旧制作版本链、逐对象审批、共享归属或批量生成的工作方式。

## 三、引用必须可理解，页面展示与实际加载一致

每个引用都在正文中交代四件事：**什么时候读、读哪部分、解决什么判断、怎样落实到产出或检查。** 使用清楚的中文名称和可解析链接，不能只写“读 narrative”或列资料名。阅读条件与实际绑定的条件一致，不能靠正文声称按需而执行整包加载。

右侧文件树呈现当前 SKILL 自身文件、它真正引用的章节／文件及必要图示媒体，不因引用某章就默认列出所属资料包的全部文件。条件引用平铺标明必要条件，不能被误读为所有工作必读，也不增加供人填写执行条件的管理表单。一个物理文件包含多个章节时，准确定位适用章节；不得为隐藏无关条目截断正文或破坏合法内链。正文明确引用的延伸资料可沿原链准确打开；过去资料入口、旧准确深链及原评论继续可到达，不用恢复整库默认目录解决访问。

当前证据特别要区分：故事结构、剧本执行包未加载 Seedance，但页面整包目录显示了它；本任务既要修页面过宽展示，也要按已定边界修当前方法引用，不能把未发生的执行误载当成迁移依据。

## 四、连续阅读交互

在基础流程中，滚动到下方点击节点、专项方法或右侧文件列表时，保留左侧流程图、文件列表以及整页的滚动与吸顶状态，只更新相应右侧内容和选中态。新文件可从右侧阅读区顶部开始，同文件及明确返回应恢复准确阅读位置；不得用整页 scrollTo(0) 实现文件开头，也不能重建左侧后丢掉原位置。

保留现有逐文件版本、默认最新、版本比较与评论。切文件／节点、打开比较并关闭、查看评论、返回和刷新要保持准确对象、版本及有效位置；未发送评论不串目标、不丢失。快速连续点击以最后一次选择为准，迟到响应不能覆盖。窄屏仍可顺畅阅读，在当前布局上处理内容更新，不引入折叠来藏内容、不新增编辑或审批能力。

## 执行顺序和具体验收

先复现并保存必要前例，再以“故事结构 → 小说 → 独立读者”和“素材方案 → 生成与制作 → 结果检查”两段完成方法及真实页面样例，回读和实际操作后修订，再扩展其余有效方法。样例先行不要求用户再逐段批准，执行者按本任务已定取舍自主迭代。方法正文按 `document-writing`、项目 SKILL 编制方式和适用专业知识编写。

1. **流程与阅读**：桌面将整页滚至吸顶、左图滚至下方，依次选择生成、结果检查、素材方案分支，再选文件；前后截图和实际观察证明整页、左侧及文件列表位置稳定，右侧准确切换。覆盖普通进入、同项重复点击、快速切换、返回、刷新、窄屏。独立读者明显可点击，四类素材方案表达一致，当前图不再有独立生成准备。
2. **方法质量**：对所有当前有效方法逐项给出职责、主要改变及试用依据；未改文件说明当前已满足哪些要求，不以批量替换名词或统一模板宣称完整重构。删除当前统一 continuity 依赖和历史试用限制。故事结构与小说的新方法、文件树和新执行均无影视／Seedance 的固定依赖；剧本无 Seedance；抽取的专业参考为实际疑难按需使用。其余分类与方法分支保持准确。
3. **小说专业方法**：用少量隔离样本走完结构设计、自然片段试写、相邻回读、修订及独立阅读，至少覆盖人物选择的因果／后果、场景与概述的取舍、视角／信息边界。展示实际文本前后例及阅读判断，说明新方法帮助作出了什么不同选择；独立读者不带作者未来信息。样本用于验证方法，不覆盖正式结构／小说，不以字数变短或测试通过代替质量判断。
4. **引用一致**：从故事结构、剧本、抽取、四图像专项、三声音分支、视频与字层实际读取当前方法；逐一核对正文引用、页面文件树与真实方法解析包。以普通抽取／存在声音疑难、视频普通方案／演唱案例等条件对照确认只加载所需内容；实际打开适用图文和既有可用媒体，声明看听范围。影视／视频手册正文及有效内链可到达，不制造新的知识副本。
5. **合并后的执行**：用真实准确输入的隔离方案实际走新生成与制作方法及既有准备／提交边界；以缺原件和有效输入作对照。无需完成旧独立准备方法即可进入同一执行流程，缺项仍准确拒绝，提交快照和输入不被偷换。本地字层用实际制作验证可生成真实工程候选；付费媒体通过本地测试替身或已有回执验证提交、回收、超时查询与重复保护，明确没有新付费调用及实片效果证明。
6. **历史与意见**：隔离环境对新 SKILL 文件评论并回查，切旧文件版本、比较并返回，核对旧 continuity／preflight 链接、原意见及冻结执行仍读原内容。当前文件未变化不造新版，旧候选／调用快照不回填新方法；新工作确实使用正式更新的绑定。包含并发更新、失败恢复及迟到读取的必要检查。
7. **正式交付**：相关自动检查通过后，完成双仓受管集成、必要推送、本机正式方法／配置增量及服务发布，再在正式 Chrome 只读复走核心路径。最终正式完整导出恢复至新空实例，回查新绑定与旧文件／评论／执行。按项目规则清理无效资源，保留可独立复验的最小方法试用、文本前后例和真实页面证据。不能只交隔离候选。
