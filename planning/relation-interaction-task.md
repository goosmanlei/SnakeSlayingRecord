# 关系图曲线分离与直连高亮，移除 Prompt 关系浮卡

## 要解决的工作障碍

人需要在实体管理中看清当前镜头涉及的实体怎样相关，再有目的地打开某个实体审阅。当前 AE001 → AS001 → ASH001 已收敛为 14 个实体、10 条真实关系，但折线共用路径、关系摘要集中在节点之外，看不清线接到谁；单击节点立即打开大卡，无法在图中聚焦它的直连关系。视听制作 ASH003 的 M2980 首帧方案中，Prompt 的 `@ASH003 · 阿蘅应对，听客散开 · 主机位` 弹出 R-M2979->M2980 等摘要与按钮，遮挡正在阅读的 Prompt。

改后：关系图的每条曲线可辨认地连接两端；单击在原图高亮当前实体及直连关系，双击才进入统一大卡。读 Prompt 时只保留可点击的准确素材引用，不再弹关系摘要卡。本任务承接用户本次两图要求，完成到本机正式服务实际可用。

## 已定的界面与操作

### 关系图

- 所有关系连线改为平滑曲线，分别安排端点和路径，禁止不同关系共用一段路径或贴合成无法区分的一条线。连接同一实体的多条边也要清楚分开。线不穿实体卡、摘要文字；实体卡和短摘要不互相遮盖。不能只把原折线拐角磨圆、仍让几条线走同一路径，也不能删除真边、隐藏边或靠点击后才可辨来过关。布局从节点、边和摘要一起考虑，减少跨越；确实需要交叉时，让交叉点两条路径清晰可追踪，不造成相接或重叠的视觉误读。
- 层级表达沿真实关系：有向依赖按上游到下游分层，反向字段先归一；多父共享同一节点，真实循环保留并合理归组。普通关联按连通组、主要连接节点及其邻接层次清楚布局，但保持无箭头，不从故事动作补造依赖。无关系的有效实体集中、紧凑呈现，不补造“本镜涉及”边。保持当前镜头准确范围及全部真实关系，不递归扩大范围、不新增关系数据实体。
- 单击节点：只高亮它、与它直接相连的节点、连接它的边及对应短摘要；其他内容仍可见但减弱。突出选中节点本身，使人分辨中心和邻居。不会打开大卡，不重排、不改变缩放和平移，不把两跳或邻居之间与中心无关的边算作直连。点击另一节点切换中心；再次单击同一节点、点击画布空白或在图内按 Esc 清除高亮。孤立节点只高亮自己。
- 双击节点：打开它原有的准确统一大卡，只打开一次；不得第一下就弹窗而吞掉第二下。关闭大卡恢复集／场／镜、图视野及选中高亮。普通实体和镜头节点一致。拖动结束不误触选择或开卡。键盘保留清楚焦点，空格高亮，Enter 打开当前节点大卡，不新增一组重复按钮。
- 复用现有实体卡、短关系摘要、缩放／拖动／适应全图／原始大小，不加新的管理页、折叠块或说明浮层。初次显示、换镜头、适应全图时给出完整且可读的图；不能以极小字号或大量空白掩盖布局问题。窗口尺寸变化后线仍跟随节点。图上现有摘要的有用直接点击功能及原关系评论能力继续保护。

### Prompt 中的素材引用

- 删除图2那种关系摘要 hover 卡及其关系编号、原文与意见、关联编号按钮。鼠标悬停、键盘聚焦和方向键都不再触发这个关系浮层；不把同一信息转移为另一个 tooltip、折叠块或页面常驻说明。
- 覆盖共用渲染的视听制作镜头、实体／镜头大卡、素材入口，以及实际带有这类引用的当前方案和候选快照。参考小卡在上一任务已删除关系浮层，本任务保持其结果。
- `@名字` 仍是可点击元素，沿原准确对象、修订、候选、组成和范围打开既有素材／参考入口；保留正常键盘激活、返回原阅读位置和评论草稿。删除的是浮卡展示和触发，不删除关系数据、关系意见、Prompt 正文、模型输入约束或真实调用快照，不修改生成内容。
