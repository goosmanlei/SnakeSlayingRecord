## 目标、范围与保护条件

沿用已有生产制作子页、路由、准确对象读取与返回能力，使最后一次用户选择决定当前页签、标题、URL、正文及审阅上下文。离开某个子页或集场后，属于旧选择的目录、场内容及相应失败响应不得再提交到当前页面；再次回到同一子页，也不能仅因名称相同而接受上一轮未完成的旧响应。

处理范围限于共享生产正文容器与其视听制作、实体管理、素材管理导航中实际受影响的读取、页面提交和返回逻辑。审查目录请求、场请求、有效缓存、切换及关闭/返回的共同影响，不扩为全站框架或状态管理重构，不建立新导航概念、加载管理页或另一套审阅面板。不以清空搜索/筛选、禁止加载中切页、强制等候或只重画标题掩盖旧响应仍可覆盖的缺口。

保留旧详情关闭/切换后的迟到保护、当前准确对象，以及有效搜索、集场/采纳等筛选、合法分页、历史准确版本、展开与阅读位置和未提交的意见草稿。页面还在读取时，应沿既有加载表达准确表示当前选择；真正不存在的目标沿既有能力说明不可用，不回退同名、最新版或另一个子页冒充成功。最后选择读取失败时可继续导航或重试；已经离开的旧请求失败不能用错误正文覆盖当前正常页面。

本任务不改作品内容、镜头设计、Prompt、采纳规则或评论持久化协议，不自动提交意见或决定，不调用外部 AI 或生成媒体。正式评论、原件、判断与修订历史保全。收益预期是减少看错当前页面、重复点击和手动刷新的成本；不承诺尚未测量的发生率或提速比例。

据观察和准确代码形成最小可运行候选，再沿相同工作目的实践，判断是否仍会回到已离开的内容、是否需要额外刷新、已有返回和筛选是否被打断。根据真实反馈调整后，才扩展到实际共享影响的其他子页、另一个集场与往返路径；过程记录随工作形成，不能一次产出后补写“实践导致修改”的顺序。

对难以自然固定的响应先后，补充有界受控检查：分别挂起一项目录或场请求，改变选择，再按预定顺序返回成功或失败；覆盖离开后返回同名子页的情况。每次只保留为证明该顺序所需的少量请求，明确结束/释放，不用无界延时、循环或后台轮询。受控时序可证明守卫契约，仍需使用最小候选完成真实浏览器工作与正常对照；报告把两类证据分开，不能把模拟截图或 API 正确替代真实 UI 验收。

## 验收标准

1. **最后选定页面完整一致。** 在最终候选真实浏览器中，从有效入口完成“制作加载中→实体管理”全过程并继续查找、打开、关闭实体。所有请求结束后，选中页签、标题、URL、正文类型和当前准确审阅目标相符，无需刷新或重复点击恢复。新标签和等待视听完成再切实体的正常对照继续通过；真实自然复现与未复现次数据实记录，不把偶然快速响应当作时序保证。
2. **目录与场的旧响应均失效。** 分别用有界受控请求验证目录迟到、场迟到、旧失败响应以及 A→B→A 后上一轮 A 迟到。旧选择不得写 URL、替换正文、重开旧对象、改变最新焦点或评论目标；当前选择的正常结果仍能提交，失败有当前对象的清楚结果。不能只比较工作区或子页名称而接受上一轮已失效请求，也不能禁用全部异步结果以换取不覆盖。
3. **实际共享导航与返回不回退。** 按实现影响核视听、实体、素材之间必要的正反向切换，切到故事再返回作为工作区正常对照；覆盖已有浏览器后退/前进、刷新、跨集场选择与有效缓存。返回后准确版本、筛选、分页、展开和阅读位置遵循既有规则，地址与正文一致；不可用的准确目标不会被替换为另一对象。保留各子页有效筛选参数，不以一律清空状态作为修复。
4. **审阅上下文和草稿受保护。** 在隔离实例从实际可评论内容建立明确标记、未提交的草稿，经相关子页切换和返回仍属于原准确对象。旧响应不能把它移到其他实体/镜头/版本或把新选择改回旧卡，关闭/返回不抢焦点。必要的准确目标与晚到响应契约由自动检查补足；正式不写测试评论、决定或生成记录。没有证据支持评论错写已经发生，交付报告必须保留这一事实边界。
5. **真实使用、正式交付与资源收尾可复查。** 提供最小候选的实际流程、正常对照和反馈调整，补充上述有界时序及受影响逻辑的必要回归，明确页面、源码、模拟与未验证部分。吸收最新主干并复验实际重叠，受管双仓交付、按序正式切换，从原入口只读复走并核当前版本确实包含修复。清理本任务无效过程资源，按准确 ID/路径回读，报告删除范围与数量、仍保留资源的用途及解除条件。
