## 交互样例的用途和实际验证

[prototype.html](prototype.html)与同目录[data.json](data.json)为独立静态样例；在本目录启动任一仅监听127.0.0.1的静态服务后打开prototype.html即可。它不连接业务接口、不保存评论、不执行生成。数据摘自调查时准确正式库，仅为样例输入，不可作为数据库迁移或正式发布包。

根会话在真实Chrome逐项操作：

- 实体管理全剧与AS001范围；点ASH001进入大卡，在机位参考、镜头首帧、镜头视频之间切换。首帧显示关键状态与素材列表，右侧为所选方案；10项参考用双列卡片，Prompt的@周家米铺打开M2624后可返回。
- 视听制作使用同一ASH001部件，阅读基础目的及素材方案。
- EN012的38个故事出处平铺，单击第1集米铺门口即出现完整32段正文，9段相关引用高亮，无“读完整场”额外步骤。
- EN046基础信息中读到完整四段16行词稿及开头/归家两处剧中选段，二者不混同。
- M003默认进入由真实历史参数/Prompt初始化的当前方案，点击历史候选1后读当时参数和Prompt，再切回当前方案；样例未载入音频，没有试听或声画质量结论。
- 素材管理截图观察到媒体分区、桌面五列、有结果在前；同组按素材编号自然序。

这支持共用基础信息＋Tab/素材列表＋右侧当前方案/候选的工作结构，以及全文引用与素材分组的可操作性。样例没有实现完整产品：关系图是简单布局草图，包含1个已撤回实体，按集场只取直接引用，缺完整用途筛选、摘要线卡及缩放；它不构成全剧图可读性或最终范围验收。正式任务明确按有效对象、完整用途与现有关系图能力实现并验收。除李寄、EN046基础信息和ASH001外，其余对象大卡仅验证定位；反机位、多状态、工程组、全量分页、评论持久化/消息层级、迁移及导出恢复均未在样例实现，不可声称已验收。

根会话以正式页真实正常对照、数据消费者调查和用户确定方向补足目标定义。B 实现阶段必须按[本任务完整正文](../material-media-groups-task.md)及登记的 acceptance 完成验收，不能直接复制样例，也不能将 A 的全部验收变成 B 的执行范围。
