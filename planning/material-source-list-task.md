# 基础素材直接归实体，实体与镜头统一为按来源分组的双列素材列表

## 要解决的问题与改后工作

0009 已交付，但 EN046“三道滩”的实体素材仍为空：完整演唱 M1195 被放在 ST354“独立完整演唱”，剧中省段演唱 M2725 则属于 ST111。人必须先切“实体状态”，再选状态，才能找到歌曲自身的基础产物。普通实体与镜头又分别使用两套素材 Tab，使人无法直接看到该对象需要准备哪些素材。

本任务同时纠正基础产物的归属和查找方式。打开 EN046 后，“素材列表”中直接看到“基础状态”下的 M1195，以及“省段清唱归家句”下的 M2725；点击任何素材，右侧显示这一个素材的当前方案与候选。打开镜头也沿同一方式，机位参考、镜头首帧、镜头视频按顺序平铺。来源标题后的问号按需说明该来源，用户不再先切 Tab、选状态才能找素材。

本任务由当前用户反馈直接授权；是 0009 完成后的明确后续，不恢复旧任务。交付终点包含 `--auto` 下双仓受管集成、必要推送、本机正式数据与服务生效及真实浏览器验收。任务定义会话只发布，不代执行。

## 已确定的素材归属规则

实体自身稳定的基础制作职责先归实体；只有不同展示、声音或结构形态确需独立准备时，才建立状态及其独占需求。基础不等于已生成、已认可，也不代表能无条件代替状态素材。每项需求仍只有一个实际出处（`scope`），使用范围或引用不增加拥有者。

“基础状态”在界面中只是实体直属素材的分组名，不建立一个名叫基础状态的 ST 对象。人物图像身份、说话音色、空间布局、道具结构、歌曲完整演唱均按实际职责判断，不把这一规则收窄成“只有图像才有基础素材”。修订现有“实体、状态与素材需求抽取” SKILL 及其真正使用的规则资源，使后续抽取遵循该原则；沿现有方法版本与执行机制承接，不另建一套方法或审批流程。

本次已查明的处置如下。执行时在最新有效数据上复核准确内容和消费者，沿同一语义落实，不凭名称批量改父级。

| 对象 | 具体改后结果 |
| --- | --- |
| EN046 三道滩 | M1195 保持原身份、两次候选及快照，改为 EN046 直属需求；ST354 必要的完整演唱说明归实体或该需求，撤下冗余状态并承接当前引用。ST111/M2725 继续独立承担阿蘅的省段清唱，不能与完整演唱合并。 |

| EN061 借据篡改贴纸 | 建立必要的实体直属结构参考需求：同张贴纸轮廓、纸质、接边及其与原借据手印的接位。具体文字仍受剧情时点约束，不提前揭示。ST150/M2765 保留湿揭后摊放留证、新旧字和手印位置对照的独立职责，不能移来充当基础。 |

EN061、EN137 只补必要的当前需求与方案，不要求生成原件，也不能为新基础需求自动反接所有旧输入造成循环。

全量复核执行时全部有效普通实体和状态的基础／差异归属，并修正同类已证实问题；当前调查分母为 137 个普通实体、79 个状态，不含 344 个镜头实体。这里只核对这项分类及受影响消费者，不重演全剧抽取，不改写全剧视频正文。

“默认有基础素材”不得成为为计数制造需求的规则。当前 EN035、EN132 仅被提及，EN116 的晾衣由场景表达，EN130 的记录沿歌本及字层承接，EN135 的浆糊为镜内普通道具：这 5 个零需求对象按已有依据保留身份，不因空值删除，也不虚构独立图像任务；在执行核对结果中写清实际承接位置。新增证据证明有独立制作职责时，再补相应直属需求。界面不为这类对象制造空状态、空分栏或“待生成”假素材。

## 统一的素材列表与选择行为

范围包含普通实体大卡、镜头实体大卡，以及视听制作页面内嵌的同一镜头工作区；通过关系图、素材引用、准确链接进入均使用一致结果。素材管理总列表的既有布局不在本任务改动范围。

1. 基础信息下只保留一个“素材列表”。删除普通实体的“实体素材／实体状态”Tab、状态按钮导航及单独铺开的大段状态框；删除镜头的“机位参考／镜头首帧／镜头视频”Tab。它们的必要内容由下述分组和来源说明承接，不删除有效状态或镜头关键状态数据。
2. 分组自上而下排列，每组内部使用现有素材小卡组成双列。普通实体先“基础状态”，再按真实状态顺序分组，如“湿袖”“湿鞋”“省段清唱归家句”；镜头按真实制作顺序排列机位参考、镜头首帧、镜头视频及确有需求的其他产物。不是并排增加多个状态面板，不新增折叠、下拉、分页或另一层分类。
3. 分组由真实出处和制作职责生成，一项当前需求只在其所属分组出现一次。实体直属需求归基础组，状态直属需求归对应状态；镜头沿现有 ASH 与其实际需求分组，不创造影子 ENTITY/ST。多个关键状态对应不同素材时保留清晰的对应关系：同一产物类别下按真实状态分小区，标题能辨差异，问号只说明该小区的状态，不能把冲突阶段合成一句通用说明。
4. 每个来源标题后放“?”。悬停或键盘聚焦显示该来源现有有效说明，普通状态对应完整状态描述，镜头来源对应其真实关键状态或产物职责；不放通用审阅标准、日志、关系链与泛泛的正确说明。浮层可读、可进入，移出／Esc 可关闭，不切素材、不改候选、不挤动正文。保留在准确状态／关键状态正文上评论和回查原评论的能力，沿已有评论入口从该说明内容操作，不另加审批或编辑功能。原评论链接仍能定位原对象及摘录。
5. 小卡复用当前名称、媒体类型、M 编号与必要结果信息；不同媒体都使用同一小卡，长名称正常换行，选中状态清楚。桌面列表为双列；确实放不下双列的窄屏可以降为单列，避免横向溢出。空来源分组不显示，整项确无素材时只给一处简短空态。
6. 点击小卡只切换右侧素材详情，复用当前“当前方案 | 候选”及生成结果、参数、参考和 Prompt 展示。普通首次进入选有内容的首组第一项并显示当前方案；恢复同一对象阅读时保留原选择。M1195 候选2切到 M2725 候选1再回去，仍分别保持自己的阅读目标，不把选择变成生成输入的采纳操作。
7. 现有准确素材／候选／评论深链优先于默认选择。旧 Tab URL 可映射到其实际素材或状态分组，不再呈现 Tab；找不到准确对象时明确缺口，不能悄悄打开第一项。切素材、开问号和关闭来源说明保持左右阅读位置，不影响草稿评论。
8. 平铺列表只读取卡片和分组所需信息，素材方案与候选原件仍按所选目标读取。不得为了显示所有分组而提前加载全部方案、参考原件或音视频；不能回退既有切集、切场与按需加载的性能改进。

可操作样例已用 EN046、EN002 与 ASH001 检验“纵向来源分区＋组内双列＋单一右侧详情”。验证结论与边界见 [调查依据](material-source-list-investigation.md)；它是任务决策样例，不是产品已完成。
