## 目标与边界

用户从已有制作工作临时查方法，沿方法正文里的站内方法链接继续阅读，再使用既有工作区导航返回时，能接着处理原准确内容。返回应保留原制作子页、准确集场及版本、搜索和筛选、必要页码／选中对象与合理阅读位置；本例先关闭素材卡后离开，正常返回应是原列表，不要求凭空重开已经主动关闭的卡。复用现有导航和恢复能力，以用户已表达的目标为准，不预设新增常驻「继续工作」按钮、书签面板、方法副本或第二套路由系统。

区分以下意图，不能统一拦截所有链接：

1. 临时阅读方法及方法之间的链接不应遗忘之前的制作工作；用户明确回制作时沿已存在的准确现场继续。
2. 方法正文「阅读版本四第一集《两份米》」等链接明确指定另一作品／版本／场，应打开这个目标。此后返回路径按真实导航顺序可理解，不被旧制作现场强行覆盖。
3. 新开或直接打开方法 URL，没有该标签页的既有制作上下文时，可以采用合理默认；不能从另一标签、另一个项目或旧发布环境借用现场假装恢复。Ctrl/Cmd、鼠标中键及“在新标签打开”保留浏览器通常语义，原标签的现场不受影响。
4. 外部来源链接继续按既有安全和浏览器行为打开，站内目录锚点仍到准确章节；方法多次互链、刷新和历史前进／后退不能把用户最后明确选择拉回过期目标。准确旧修订不存在时沿既有失效提示，不悄悄用最新内容顶替。

保留输入锁、准确引用、评论草稿与版本、人工判断及素材采纳分离。导航恢复不自动保存、采纳、选择参考或迁移旧意见；不把内部路由日志默认展示在创作页。作用于此次方法往返及同机制实际相邻入口，不扩成跨设备永久工作记忆、全部历史管理或所有页面生命周期重构。

## 实际工作方法

先从执行时最新双仓主干与有效正式发布核对上述行为，在自有隔离副本真实完成“找晚集旧灯→读准确原件和参考→临时读方法→沿正文继续读另一方法→返回继续原素材”的完整任务，与顶部页签路径对照。读到的方法应与当前核对目的有关，不只点入口截图；记录断点与额外动作，不因某次没有页面缓存便用内部函数或 API 替代使用。

据实际导航意图形成最小可运行候选，先复走原路径，观察返回后的内容、范围和阅读现场是否足以继续判断、是否增加不必要控件或记忆负担，再按观察修订。随后用根 M2673 全局查找和一个实体或镜头上下文检验共性，纳入明确作品目标、新标签及外部来源正常边界。无需人为制造多轮迭代；不能一次生成代码后补录测试清单来冒充流程实践。

隔离中实际留下明确功能测试草稿，离开查方法、返回、刷新／历史返回后核对准确目标和可恢复文本，不提交正式评论。不以未提交草稿测试冒充保存归属验证；如实现触及保存或恢复契约，才在隔离完成相应最小保存／读回并记录每笔写入。对迟到响应使用必要的受控时序时单列证据，不能把脚本直接设置状态当自然 UI。源码与自动回归负责补契约，不能代替页面端到端操作。

吸收实际并行变更后，以准确最终候选再验受影响分支，受管双仓集成并按协调的正式写入窗口发布。正式只读从原入口复走；不生成媒体、不调用外部 AI、不在正式写测试业务。没有实际完成的边界列为待验，不用旧截图或“测试全绿”代替最终结果。

## 验收标准

1. **沿正文查方法后能继续原工作。** 从晚集 AE017/AS065/M1194 路径查影视知识、经正文链接读视频手册，再回生产制作，保留素材页、准确集修订／场、M1194 搜索及可继续读取的结果。无需重新选集、选场或重输编号。再用全局 M2673 搜索或执行时相同用途的真实素材验证，不因没有集场而误套默认第一场。切顶部方法页签及同页目录锚点的正常往返不退化。
2. **恢复范围与最后意图一致。** 实际增加一个实体或后场镜头起点，查方法后返回仍是原准确对象／版本与合理阅读现场；已主动关闭的卡不自动重新打开。方法之间多次跳转、刷新、浏览器前进／后退以及快速改选后，旧返回记录／迟到响应不替换最新选择。不要求跨版本布局像素完全相同；准确目标已不可用时说明失效，不用当前版补缺。
3. **明确新目标和浏览器原生操作受保护。** 实际从方法正文打开明确版本四第一集《两份米》，进入所指版本／集场而非原素材；新开准确方法链接在没有原工作时合理落地。验证当前平台的 Ctrl/Cmd 新标签、一个普通新标签打开和外部来源链接：原标签工作范围不被清空，新标签不暗中接管另一标签的上下文；同页锚点仍准确。不能用禁止链接、统一新开窗口或一律携带原目标来伪装修复。未覆盖的平台组合如实报告。
4. **草稿与准确数据不被导航改写。** 自有隔离库实际留下素材或实体意见草稿，查方法再返回可恢复原文本，绑定原对象／修订／块；主动换目标和另标签不串草稿、不自动提交。保存保护、原件和用户判断保持既有语义；如确需保存测试，给出准确写入与读回。正式只读核历史素材、原件与判断仍可查，不据本次导航任务迁移或重认任何素材。
5. **交付和清理真实完成。** 提交最小候选的实际工作观察、必要修订与正反结果，区分自然 UI、受控时序、自动检查和源码解释；完成受管双仓准确引用、串行正式发布及正式只读复走。最终可见报告给实际任务编号、原问题、具体前后用户路径、仍未验证项和下一步；清理无用途的本任务容器、镜像、测试库、缓存、临时文件并回读范围与数量，保留项说明用途／责任／解除条件。没有清理或没有正式复验不得声称完成。
