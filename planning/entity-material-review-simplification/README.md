## 任务字段与仓库边界

- 摘要：实体大卡统一素材入口，直接审阅所选素材的结果与生成方案。
- 优先级：P0。
- 复杂度及模型：复杂，`gpt-6.1-sol / xhigh`。这是本次映射的默认强度，适用于双仓共用面板、准确版本选择、全系统帮助表达与迁移恢复验证；不选择 ultra。
- 同项目任务依赖：无。账本回读 `task-20261010-0012`、`task-20261010-0014` 均已结项；本任务承接正文明确的产品终态，不恢复旧任务。视听制作和故事评论的其他草稿由父会话分别安排，本任务不接管。
- 可隔离并行：是。与视听任务分工为“共用实体／素材卡及通用标准帮助组件”和“场镜模型与页面”；允许在各自受管双仓 worktree 开发，共用文件的可控交叉在集成时核对并复验，按实际变化吸收最新主干，不因同仓强制添加前置任务。
- 并行运行条件：可写数据库、缓存、媒体目录、预览端口及路径、服务、容器、镜像标签与浏览器草稿存储均须任务隔离，浏览器控制另行协调。共享正式库、服务、固定镜像和部署入口按序协调；本任务没有付费生成、部署或正式库写入授权。

## 已查清的前后例

父会话在正式 3000 的 Chrome 已观察：EN012 李寄的 ST209 描述 v2 对应 M2826；切描述 v1 后左侧列 M1218，右侧却跳到 M2597。目标是在同一 ST209 内按 v2 → v1 → v2 选择 M2826 → M1218 → M2826，并始终读取所选准确素材的方案。

M2597 素材版本 1 没有生成候选。证据里的需求对象 `version: 2` 是对象修订序号，`material_versions` 中的素材版本 `number: 1` 是另一种版本，不能混为一谈。14 条旧图是备选关联，13 条沿用是实际输入依赖，不能将其作为待批删的生成结果。目标是直接显示未生成占位与该准确版本的生成方案，同时保全真实历史及有效依赖。

JSON 的 `evidence_boundary`、`parent_browser_observation` 与 `source_reading` 分别保留 API／源码调查范围、父会话浏览器观察与实现线索。它记录调查时的现场，不表示本发布会话重新验收了正式产品；执行者仍须在最新准确隔离实例完成任务正文要求的真实操作。

## 样例用途与覆盖边界

[entity.html](entity.html) 以 M2597 为起点，演示两个素材归属 Tab、ST209 的两个描述版本、M1218 原图及直接可读的生成方案。图像通过同目录相对路径 [m1218.png](m1218.png) 加载，无需依赖原调查目录。评论与采纳只保存在当前页面内存，刷新清除，不连接业务数据库。

样例从 M2597 起步是为了展示未生成时的右侧内容，不是正式实体列表的默认入口决定。完整任务仍要求首次从实体列表进入实体状态 Tab、保留合法选择、准确候选与历史、草稿归属，以及全系统通用标准的 hover／键盘聚焦和点击稳定阅读。样例只有一个状态、有限素材和单一候选，不能替代多状态、多版本、多候选、音频、异步、跨入口、帮助交互及空实例恢复验收；本次不把样例扩建成产品。

发布会话尝试在 Chrome 打开复制后的本地 HTML，被浏览器 URL 安全策略拒绝：仅允许 `http:`／`https:`，不允许 `file:`。本轮停止浏览器尝试，未绕过策略，也未新增页面验收结论。复制交付仅核对正文、脚本未变、相对入口、原件字节与格式；父会话对独立样例的既有实操和执行阶段必须完成的产品验收分别保留。

执行验收范围仍包括李寄、阿蘅、墨耳、道具、场景、歌曲／音色和任务正文列出的所有入口。实际删除数据须核对归属、前后数量及共享引用；浏览器前后例、真实看图／试听、历史保全与导出恢复均由执行阶段完成，源码与自动检查不能替代。
