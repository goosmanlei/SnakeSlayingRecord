# 素材需求只有一个制作出处，清理无独立职责的状态并贯通准确参考

## 要解决的工作

打开 EN002 阿蘅，M2544 图像身份需求既出现在实体素材，也出现在六个状态中；在 ST093 读候选1、到 ST092读候选2，再回来会恢复不同选择。数据实际只有一个需求，`scope` 指向 EN002，是页面把适用关系、生成引用和拥有关系混在了一起。M2544 候选2实际引用的 M1133 又无法在素材管理中搜索到，虽然它就是 M2544 候选1，原件仍在。

改后，M2544 只属于 EN002；湿袖 ST092 自己的 M2714、湿鞋 ST093 自己的 M2715 各属于自己的必要状态，通过参考使用 M2544。阅读任何引用时，人能识别唯一素材及准确候选，不再猜另一份素材藏在哪个状态。这次同时完成全系统必要性清查：没有独立制作职责的状态不应仅为放共用素材或检查文字而继续存在；有效条件回到真正需要它的镜头或方案中。

这承接 task-20261011-0008 后的确切残留及用户进一步明确的产品决定。0008 原来允许同一需求在多个消费位置列出并保留全部状态，本任务改变这一取舍；不能谎称仍有七份 M2544，也不能只改数量、换标签或同页去重交付。

## 已定规则与完整范围

1. **一份当前需求，一个制作出处。** 复用现有 `scope` 表达实体、实体状态或镜头出处，镜头沿当前实体模型处理；不新增 owner、来源管理表或审核实体。`entities/states`、统一关系 contexts、计划输入与真实调用输入说明使用范围，不能增加拥有者。实体大卡、状态材料区、镜头工作区、关系图小卡计数和素材管理使用同一含义。集场筛选仍能找到在该处使用的素材，找到后回到唯一出处，不将筛选范围当作所属范围。
2. **逐项判断必要状态，再决定素材。** 核对当前全部实体状态、镜头关键状态及其直接需求、消费者与必要历史，先读故事依据和制作目标。实体身份已能承担的基准形象不另造基准状态；纯表演、连续性或阶段检查条件，移入真正使用它的镜头／方案，移好且验证后物理清理无用途的当前状态及专属冗余数据。若状态改变可见结构、空间通行、干湿、声音或确需独立制作输入，则保留必要状态与独立需求。不因“基准”“文字检查”、零直接需求或相似名称自动删除，不为保留状态制造新需求。镜头关键状态已有“确需独立准备才存在”规则，不与人物状态强行合并。
3. **当前参考可发现，历史输入保持当时事实。** 建立并复用一致的素材身份与准确引用解析契约：当前需求、原件旧编号、保留候选、准确修订和组成能够相互核对。M1133 搜索命中唯一 M2544，并清楚定位候选1；当前 M2857 方案引用 M2609 候选1时呈现该素材身份，旧 M1135保留为原件事实而不冒充第二份需求。引用卡和 Prompt 链接消费同一解析结果，保留原组件、裁剪和时间段。下游导航任务负责工作区往返，不能各自重造解析器。
4. **历史三种情况分别处理。** 活跃候选必须且只能归一个当前需求；已明确退役、只因历史输入或意见保留的原件，沿已有提交和退役记录说明准确旧出处、处置与可用原件，不能强塞进用途不同的当前需求；确实缺组件或未记录需求的历史，保留已知名称、作品出处和准确缺口，不编造归属，不用当前相似图补位。无需新历史管理页面或恢复旧需求树。M1469含母亲的居家图不能塞成 M2589无人空间母版；旧歌曲 M1202/M1203/M1386 未记录原需求，不能冒称出自当前 M1195。针对已知缺口检查现有受管恢复来源，能证实原件身份才恢复；无法证实则明确保留未知，不承诺不存在证据的全量恢复。
5. **把简单规则落到后续创作入口。** 同步实际数据契约、导入及编辑校验、导出恢复和真实绑定方法。`material-assessment` 要先判断状态的独立制作职责，再判断复用／编辑／新制；七个相关方法包的 `references/current-production.md` 应消除“任何剧情阶段差异都必须保留STATE”的歧义。沿 [受管方法](../production/managed-methods.md) 更新准确方法修订和相应绑定并实际 begin/read 验证，不能只改静态说明。旧执行继续使用冻结方法，候选的当年参数、Prompt、输入和 CALL 不改写。必要知识措辞随最终契约同步。

## 怎样完成和检查

先在最新主干与准确正式数据的隔离副本，做 EN002 和 EN112 歌本的完整可操作样例，再按相同判断扩展全部范围。歌本 M2635 母版多处重列是反例；M2909 夹入前、M2908 夹入后、M4080 字层工程具有不同职责，不能为了减少数量合并。湿袖、半落洞闸、通道、旧灯点亮、歌曲准确片段同样要用真实作品和必要图／音证据判断。每个有实质创作判断的处置先理解、回读，再修订；不以一次批量填表代替逐项工作。

本轮调查分母为1291当前需求（1042镜头、163实体、86状态）、280实体状态、257保留候选。280状态中194没有直接需求，只是定位线索，不是删除清单。执行时按最新数据重新取得分母，给出每项归属、状态保留／撤下理由、条件去向与准确引用核对；区分当前实体状态与镜头关键状态，不能漏审后者。记录真实前后数量，不设置减少比例目标。逐项完成后独立全局复审跨镜、跨状态与引用，修完再回查，不能只抽样后声称全量完成。

完成条件：

- Chrome 实走 EN002实体素材→ST092/ST093、EN046歌曲及阿蘅对它的引用、EN112前后状态、一个镜头素材。应只见各自直接需求；参考仍能到同一素材，计数与列表一致。改变一个状态的阅读不再制造同一素材的另一个“版本”。具体阅读恢复由配套工作区任务处理，整体回收时一起复验。
