# 制作审阅体验与页面精简任务

## 任务摘要

修复实体采纳循环与关系依据，统一素材筛选并精简制作页面操作。

## 任务目标

优化制作设定、素材管理、全剧制作的审阅体验，让用户以采纳／取消采纳和评论推进内容，由 Codex 通过后台工具维护制作数据。完整说明见 planning/production-review-ui-task.md（相对于本任务 worktree 根目录）。本会话仅澄清并发布，以下目标由执行阶段实施。

1. 修复阿禾“取消采纳”后“采纳”永久置灰的问题。同一有效内容范围内可完成采纳→取消采纳→再次采纳的循环，前后端状态、刷新及重新进入一致。兼容既有采纳记录，保留准确内容范围和历史；旧内容认可与新方案的生成许可分别核验，不以按钮强制启用绕过真实缺项、版本冲突或历史只读限制。
2. 核查阿蘅与李寄“相互照应”的关系表述、方向和所引剧情是否一致，按版本四准确集场、正文块选择充分证据，必要时校正关系表述。排查同类引用选择问题，修正实际受影响关系并列明范围；不凭同场出现或单个弱关键词确认关系，不修改定稿剧本去迎合标签。故事关系数据与编制工具归故事仓库，来源读取与展示归通用系统。关系修订保留原评论与准确锚点，需要重新认可的内容如实处理。
3. 剧情依据弹窗复用系统共用样式，统一标题、按钮、关闭和内容排版；显示准确版本、集场及能支撑关系的原文。沿用 task-20261002-0001 的共用弹窗改进，保持阅读位置、版本、焦点和未提交评论草稿。
4. 素材管理筛选区沿用制作设定的平铺点选方式，将现有适用筛选维度用分组按钮呈现，有明确选中态、类型图标、与搜索联动的数量及清除操作；现有类别全部可访问，零结果如实表达。未生成的真实素材需求在对应卡片显示按媒体类型区分的占位；绑定准确需求和所选素材轮次，生成结果可用时由真实预览替换，不伪造实际素材记录。声音缺项使用声音提示，不借人物图片假装声音原件。
5. 从三个制作页面及关联详情移除面向用户的批量导入、登记实际原件、编辑说明与设定、添加细节或声音需求、维护整体与细节关联等手工编写／登记入口及专用表单，并清理空态中引导这些操作的文案。保留用户采纳／取消、评论、素材审阅与准确版本选择、筛选、预览及缺项检查；后台 CLI／接口继续支持 Codex 导入、登记、维护、导出和恢复，不删除既有数据或追溯能力。
6. 删除三个页面左上的“剧本依据 → 制作设定 → 实际素材 → 镜头输入”流程导航，不新增图形替代；现有主导航、页面标题和全剧制作的必要剧本依据摘要继续提供定位与上下文。
7. 交付双仓改动、必要的关系数据增量与工具修正、实例系统版本引用、使用及验证说明，并按受控流程应用正式 3000。保留用户新评论、旧正文、实际原件、调用和准确采用，不以启动快照覆盖正式库。本任务不生成媒体或制作动态分镜、成片。

故事仓库复用当前 worktree。系统仓库以故事主项目根目录为基准定位 ../story-review-desk-python，系统修改另用本任务独立 worktree。执行前重新核对两仓基线、规则、正式数据和并行任务。截图原件 Image #1 发布时保留为 aheng-liji-relationship-source-dialog.png，用于核对关系标签、原文内容、弹窗排版和按钮风格；它是问题证据，不是目标设计稿。

## 可验证的完成标准

1. 在隔离实例通过实际浏览器，以阿禾既有记录完成取消→重新采纳→再次取消，并验证未采纳实体的完整循环；刷新及重新进入一致，无永久置灰或重复写入。覆盖历史只读、真实缺项、内容修订、重复点击及版本冲突；旧认可不得冒充新生成许可。
2. 阿蘅／李寄当前关系的标签、方向与原文依据语义一致，弹窗打开准确剧本版本、集场和正文块。提供修正前后对应及同类问题检查范围；受影响关系以新修订维护，旧评论、引用和剧本正文保留，不虚构双向事实。
3. 实际浏览器验证剧情依据及相关嵌套弹窗的字体、间距、按钮和关闭风格与系统一致；关闭、Esc、键盘操作、上层返回有效，阅读位置、版本、焦点及评论草稿保留。
4. 素材管理筛选平铺可点击且键盘可用，适用类型有对应图标；全部、单类、组合筛选、搜索、清除、零结果均正确。数量说明统计对象，以当前列表对象计数，不把历史修订或占位重复计为真实素材；桌面和窄屏可读。
5. 未生成、已有结果以及切换历史／当前轮次的卡片如实显示；图像、声音及其他适用类型的占位对应真实需求，结果可用后展示准确原件预览；占位不计入已生成或就绪，图像完整显示、真实音频播放及评论正常。与 task-20261002-0001 的素材轮次契约兼容。
6. 三个制作页面、详情及空态均没有目标手工录入入口、可触达的专用表单或相关引导；采纳、取消、评论、审阅、准确版本选择、筛选、预览和缺项检查可用。隔离实例证明后台数据维护、登记、导出和恢复仍可工作。
7. 三个制作页面不再显示该流程导航，也未添加替代流程图；主导航切页、当前页定位、标题和必要剧本依据摘要正常。
8. 针对采纳状态、关系准确引用、筛选／占位及入口移除完成有意义的自动验证，并在隔离浏览器回归故事采编、结构、剧本和制作相关评论／弹窗路径。导出→空实例恢复核对原件校验、旧评论、实际调用及准确采用不丢失。浏览器阻断按 AGENTS.md 报告原始错误及未验项，不以静态或接口检查代替页面验证。
9. 交付双仓变更、关系修正范围、实例版本引用及真实验证证据；串行应用正式 3000 后回读三个页面和关键样例。正式写前核对最新数据并增量发布，测试采纳和测试评论不进入正式库。集成、推送及任务完成按执行阶段受控流程和用户确认办理。
