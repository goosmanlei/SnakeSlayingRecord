# 剧本三全部评论：归纳与版本四修订依据

本次评论既要求修正具体文字，也要求改变部分场面的表达方法和斩蛇高潮的因果。版本四须逐条落实，并把归纳出的问题作为全剧检查依据；无评论处也要检查，不预先断言每个地方都有同类缺陷。

## 来源与范围

以本机正式审阅台 `/api/comments`、`/api/screenplays` 为来源，读取时间见[原始记录](screenplay-03-comments.json)的 `captured_at`。剧本三为 17 集、42 场、1,134 个正文块，整版修订 `3110548d5fa53b349085f4a3fb459df746da5011df95dc9d0b8968d24575adf4`；本工作区 `imports/screenplay-03.json` 全部正文块与正式接口逐块一致。

统计对象是剧本三整版及其分集上的当前评论记录，含已关闭，不含删除评论或编辑、状态变化等历史事件：共 73 条，71 条 OPEN（未关闭）、2 条 CLOSED（已关闭）。全部锚点有效，均关联当前分集的精确修订。第 1—16 集有评论，第 17 集没有评论；没有评论不代表该集已通过审阅。接口记录没有评论者身份字段，本次按用户所说的“我的全部评论”整理版本三全部现存评论，不另推断身份。

用户已在本次澄清中明确“已全部提交，以这些评论推进全剧修订”。执行开始及正式交付前再次核对新增、编辑和状态变化。C01—C73 是本报告按集、场、正文位置排列的索引，不是系统原生编号；原始记录保留系统 ID、原文、完整圈选、对象和修订、状态、记录版本及时间。C02、C12 已关闭，仍列入归纳与处理核查；关闭状态本身不等于修改要求被撤回。

## 三条必须前后联动的修订线

1. **应募、停祭与保护阿蘅。** C12、C19、C30、C32—37、C39、C49 共同涉及报名何时暂停送祭、准备期间阿蘅住哪里、报名者的身份和参与方式。统一告示、家庭决定、县衙登记、文书和后续执行，不只替换一处句子。
2. **施工准备、补位、无援与斩蛇。** C41、C45、C52—60、C65 要求调整准备场、现场人数、刀的位置、声音与恐惧、父亲补位、叫援结果、持续砍杀以及事后回顾。人群害怕不能写成预知心理的旁白；让不敢靠近或拒绝援手等行为形成可理解依据。保留成人已出力、门闸确实受压等成立条件，避免把李寄塑造成忽然无所畏惧或父亲主动安排她冒险。
3. **庙方败露、作证、问责与结果。** C29、C35、C50—51、C66—73 覆盖官府认知、证据经手者、作证动机、家属情绪和结案。县丞受到何种责任处理是执行时需要解决的改编判断，本次不替用户确定免罪或更换角色。保证实际行为、身份时序与最终结论相称。

## 版本四的检查方式

用户进一步明确：上述八类共性问题须逐场扫描，用来主动发现并解决每场潜在的问题。每场检查全部八类，不因没有评论而免检，也不只检查本场已有评论对应的类别。以下问题用于阅读实际场景，不是关键词搜索或自动判分。

| 类别 | 每一场具体要问的问题 |
| --- | --- |
| 1. 所指和目的 | 观众能否根据此前已经呈现的信息和当前场景，理解谁在对谁说、动作针对什么、人物要做什么及为什么？是否有含混的称呼、代词、对象、约定或关键后果？ |
| 2. 可见可闻的依据 | 场面所依赖的信息能否通过画面、声音、对白或已建立的上下文获得？是否把作者知道的身份、用途、心理、回忆来源或含蓄动作当成观众自然知道的事？ |
| 3. 自然且合情境的对白 | 台词读出声后是否符合人物身份、关系、目的、情绪和现场急迫程度？是否有不自然的自报姓名、礼貌询问、抽象总结、过度省略或排练式说法？ |
| 4. 冗余对白与枝节 | 这句话、动作或配角是否带来新信息、选择、关系或情绪变化？已经可见的事是否反复确认？适合沉默的地方是否被说破？精简后是否误删必要背景或后续承接？ |
| 5. 条件与因果 | 人物为何能／不能这样做，是否与前后行为一致？谁知道什么、何时得知、时间间隔、空间路径、道具状态和人员数量是否成立？场面结果是否由此前行动产生？ |
| 6. 准备与揭示分寸 | 理解本场需要的准备是否已有依据？是否重复讲解原理、过度演练或提前说出之后应由危机显现的变化？保留悬念时是否仍能看懂当前行动？无准备或预示功能的场可以说明不适用。 |
| 7. 关键行动与主动选择 | 在需要人物作选择的场面中，行动是否来自真实压力、人物动机和自己的决定？是否被不必要的许可、随手到来的帮助或程序式对白削弱？替代方案为何无效是否有依据？没有关键选择的场可以说明不适用，不强加危机。 |
| 8. 情绪、转变与结果 | 本场应有的情绪是否通过具体表演或对白发生？人物态度变化是否有触发依据？冲突结果与责任是否与经历相称？是否只有情绪标签或笼统结果？日常与静场允许克制，不为凑力度强加愤怒和冲突。 |

执行分三次落实：先对剧本三全部 42 场进行八项诊断；再在逐场创作版本四时，对保存后的候选八项复查，修正后才采用；全稿完成后，对版本四所有最终场次再次八项检查。新增、拆分和合并后的场全部覆盖。回修一场后复查受影响的前后场，不让问题迁移到别处。

检查记录按场与类别保存。每项说明“发现问题／未发现问题／不适用”及场景依据；发现问题时记录原文、实际影响、修改决定、新稿位置和改后回读结果，不适用时说明理由。没有直接评论的潜在问题也要主动发现并解决。剧本三的覆盖基线是 42 × 8 = 336 项，版本四按最终场数 × 8 核验覆盖；这个数量只证明是否漏检，不证明创作质量。

本次只定义扫描方法，尚未执行全剧诊断或创作。执行时把逐条评论、逐场八项扫描、原场到新场的去向相互关联；最终以实际正文判断因果、知情、动作与情绪是否成立，不以表格填满、字数或工具顺序通过代替创作质量。
