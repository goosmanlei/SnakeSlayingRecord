## 通用能力与方法分工

现行流程已经要求前后承接与实际原件检查。本次补足准确依据、职责交接、覆盖记录和变更后复验，专业原则保持唯一正文，不恢复所有阶段共同加载的旧连续性资源，也不改变独立首次读者、评论润色的职责。

| 现有方法 | 应完成的连续性工作 |
| --- | --- |
| `audiovisual-scene` 视听设计 | 结合完整场景和必要前后场确定观看顺序、连续／省略／有意转场，以及必须继承和允许改变的条件；每镜起点、变化、落点能够交给下一步。 |
| `image-plan` 的镜头画面专项与 `video-plan` | 对照前镜落点、本镜起点和后镜动作，解决空间及动作矛盾；明确当前依据是设计还是实物，将必要条件落实到参考职责、完整输入、真实指令、Prompt和参数。 |
| `generation-preflight` 生成与制作 | 提交前实际打开当前采用原件，核对准确版本、必要出入点、真实状态和本次输入能力；上游已生成时不能只复述计划，关键前提不满足时回修后重取准确包。 |
| `result-review` 结果检查与返修 | 按拟用切点原速连续检查前后声画，问题处再逐帧／定位听辨；记实际范围、问题、原因判断、最小修复和同窗复验，无法验证的项目保持未验。 |
| `episode-editing` 成片剪辑 | 核最终工程所用原件、入出点及声音处理；先查具体接缝，再连看整场及整集，确认空间、动作、表演和声音在实际语境中成立。 |

承接内容按作品需要选择：人物身份与体态、服装及伤湿脏状态、群演存在与位置、场景空间／轴线／视线／行动方向、持物手和道具归属、接触及动作完成阶段、光色、同一次演唱／对白／呼吸／尾音、环境及动作声。跨场持续状态需要追踪到实际使用处，不局限于相邻两镜；允许有依据的时空省略和表达变化，不要求逐像素一致。

明确区分三种依据：计划中的落点、实际候选的末态、成片采用片段的出点。前镜未生成时可以先完成设计和方案，但真实接缝尚未验证；已有前镜时须核实际原件及拟用片段。参考路线可使用身份／场景母版、准确状态、完整前片、独立端点参考或合适剪辑；作为检查依据不等于必须上传给生成模型。按实际模型能力适配，不让所有镜头形成串行上传依赖，不无界把新生成结果反复喂回。

候选、镜头顺序、关键状态、入出点或声音处理改变时，识别相关接缝与后续使用处，使不再适用的检查结论明确待复核；未受影响的证据可保留，历史执行、原始提交和旧成片保持准确旧事实。不得仅因输入哈希有效就宣称叙事连续性成立。

通用系统最小范围是准确表达／查询必要依据、检查覆盖与证据是否过时，并对缺失关键前提给出可继续处理的要求。先复用支持材料、方法阶段、现有阻断项、准确候选和工程快照；不能满足上述真实工作时再补必要的数据契约、校验、变更复核与针对性测试。检查系统可判定的身份、缺项和变化，不把自动语义评分当成作品质量裁决。不新增全员审批、永久连续性状态实体、冗余用户入口或自动全剧重生成调度。

方法更新须从正式当前绑定及准确正文开始，沿受管方法接口保存、绑定和发布；初始化JSON不是当前权威。新步骤取得新方法，旧执行快照和文件评论保持原组合。普通相邻镜也能按问题取到连续性知识，不能只依赖延长案例触发。同步直接受影响的职责／导航说明，包括已实际存在的成片剪辑入口；不扩大成全库文档清理。

3. 全剧设计与方案 Review。全量覆盖17集42场416镜的已有设计、视频方案和必要上游实体／状态／声音；具体对象数以执行快照回读。检查矛盾、缺失状态、不可行起点、参考职责、生成顺序与变更复验要求；高风险连续动作、群体调度、反打／离场、道具交接、伤湿状态、实唱及声桥深入审查。逐项实质判断，不能只关键词扫描或复制统一模板。未生成部分修正设计、方案和必要关联，保留以后真实上游生成后的检查义务。
4. 第一集实际 Review。覆盖20镜实际原片、全部实际剪辑接缝、两场及整集。优先复查群演／桌前空间／人物尺度、开合书／刮板／米袋、浆糊／红印、歌尾插话及试鼓削竹等已有线索；对每项区分仍可复现、已修复、合理变化、证据不足。原片整体曾获用户接受，不等于后续确认的问题已消失；旧报告未验也不自动推翻用户接受。
5. 完成范围内必要局部修复。先判断应改设计、参考、切点或声音交接，源片不足再局部补制；保留原候选和提交事实，不用遮掩问题、删必要动作／原词、只改Prompt或提交问题清单代替实际处理。修复重要道具或状态须同步实际受影响的使用处，不扩展无关美化。M017以0007交付为准确基线，避免重复覆盖。
6. 复验并更新交付。每项修复提供足够上下文的前后对比，在相同检查范围复验；更新首集受影响工程、混音、字幕和来源，输出可直接审阅的既有字幕／无对白字幕两版及可继续编辑工程，保留既有交付规格、片名、人名条与历史评论。整场、整集再查是否引入新问题。没有必要变化的内容保留原证据与原件。

Review记录至少能追溯准确对象／候选／工程时码、问题事实、依据、处理和复验结果；规划级风险与已证实媒体缺陷分开。自动检查、模型辅助、静帧／波形、真实连续动态看听和用户接受分别记录。没有实际感官证据不得以技术播放替代；需要用户看听时提供短而完整的上下文与具体判断点，不把剪辑制作工作交回用户。
