## 任务目标

完整细则、原件用途及验收以本文为准，执行时使用随任务保存的三张原始 PNG。

1. **统一分集导航。** 顶部分集菜单复用“故事创作 → 剧本创作”的视觉与交互，展示集编号、标题、场范围和评论数。评论数遵循准确版本和既有统计规则，写明本页统计对象，不借用剧本评论数冒充镜头制作评论数；场范围来自实际归属。保留选中态和窄屏横向访问。
2. **增加场内镜头导航。** 左侧改为“场 → 镜头”二级菜单，默认全部展开；场和镜头按制作顺序排列，点击直接到达对应内容。保留准确编号、历史链接、刷新及浏览器前进后退，切换与弹窗返回不丢阅读位置和评论草稿。
3. **清理场头与归属筛选。** 物理移除截图中的“已按版本四完整检查本场……未指定造型作为制作选择审阅”等通用检查说明及其无效空框，并停止在当前内容／生成模板中重复写入；保留有效场名、地点、日夜和剧情依据。删除本页全部素材归属筛选按钮及其遗留过滤效果，展示该镜明确关联的素材；不扩大到无关素材，也不删除真实关联。旧准确修订和评论继续可追溯，不借此清理业务历史。
4. **平铺镜头版本并标明 Prompt。** 镜头正文的视频制作版本由下拉改为全部版本按钮，普通进入默认最新版本，不强调“当前”，溢出可横向滚动。准确链接和用户手动选择优先，最新版本未生成时不借用旧版候选。Prompt 增加清楚的标题，与模型／参数区分；保留准确文本、顺序、评论锚点和已生成候选的真实调用内容。
5. **展示准确参考与统一入口。** 左侧参考素材复用统一素材小卡，显示本镜参考实际选定的版本和候选，如 `V3 C2`；部分或全部未选定分别明确显示，例如 `V3 C_`、`V_ C_`，图标有可理解的文字说明。小卡和 Prompt 中对应的 `@素材` 均打开同一素材的实体／素材大卡；已选定时精确定位该版本和候选，未选定时仍能打开并选择。引用按真实素材身份及有序输入槽位匹配，不凭名称猜测，也不把普通浏览默认值当成已选定。
6. **支持为本镜选定参考。** 从上述入口打开的大卡增加明确的“选为本镜参考”操作。浏览切换版本／候选本身不写入；确认后保存到当前镜头制作版本的对应参考槽位，并同步小卡与 Prompt，再打开或刷新仍一致。选择只影响当前引用，不改其他镜头或全局采用，不等于用户认可素材。未提交方案按既有规则保存；已提交、失败或结果未知的版本均保持锁定，改选进入新的制作版本，历史实际输入不变。保存时核对当前版本、候选归属和准确原件，冲突不覆盖他人修改，失败不显示成功。
7. **阻止不完整参考进入生产。** 缺版本、缺候选、版本候选不匹配、原件缺失或失效引用均不能作为可生产输入；明确指出需补齐的参考。所有实际生产入口在后台执行同一校验，不能只依赖页面禁用状态；历史缺项如实呈现，不自动选择最新候选补造事实。参考完整仅解除这一项阻断，已有方案认可、范围和其他生产条件仍须满足。本任务以隔离验证覆盖这些行为，不调用付费媒体生成。
8. **统一并收窄右栏。** 右侧“本镜素材”区域复用素材管理页的小卡与大卡打开行为，随卡片收窄右栏，为左侧参数、Prompt 和参考区保留阅读空间；宽屏、常规桌面与窄屏均保持逐镜左右归属清楚。沿用镜头制作右侧只放本镜视频、其他媒体参考位于左侧的既有边界，不引入第二套卡片样式。

3. **精简。** 当前场头及对应生成来源不再包含指定通用检查说明，也没有空框；有效场信息保留。全部归属筛选按钮消失，旧会话保留的筛选值不能继续隐藏本镜素材；真实引用、旧评论及准确历史链接仍有效。
4. **版本与 Prompt。** 覆盖单／多版本、最新版本未生成、旧版有候选、历史链接及快速切换。所有版本平铺可访问，默认最新、无“当前”标签，无旧候选串入；Prompt 标题清楚，与参数区分，原文及评论仍绑定准确版本或调用。
5. **参考入口。** 覆盖全未选、仅选版本、完整选定、多候选、共享素材及同素材多个输入槽位。小卡显示准确状态，小卡与各对应 `@素材` 打开同一目标；已选 `V3 C2` 必须落到该版本候选，无候选时不假装已选，缺失引用有可操作说明。
6. **选定与保存。** 用真实浏览器完成打开→浏览不同版本候选→明确选为本镜参考→关闭→刷新→重开。单纯浏览／关闭不修改引用；确认后准确持久化，当前槽位、小卡和 Prompt 一致，其他槽位及镜头不误改。覆盖取消、保存失败、并发冲突、迟到响应和多层弹窗，阅读位置、焦点、草稿保持正确。
7. **锁定和生产校验。** 未提交方案可按规则保存；已提交、失败和未知结果版本的改选创建新版本，旧调用输入、候选、评论与历史引用保持准确。绕过页面直接调用现有后台入口，验证缺版本／候选、错配、缺原件及失效引用均被拒绝；合法完整输入在满足其他条件时通过检查，验证不发起收费生成。
8. **共用组件与布局。** 宽屏、常规桌面和窄屏实测统一小卡、较窄右栏及逐镜对齐；右侧仍仅视频，左侧参考可打开大卡。实体／素材管理、制作拆解和普通大卡的默认版本、候选、评论、采纳及媒体预览不回退；本镜专用选择操作不泄漏到普通浏览场景。
9. **数据与交付。** 选择与校验的针对性自动检查通过，新增保存和必要数据修复具有准确对应；重复提交不重复应用，冲突无部分写入，导出→独立恢复后准确引用与选择一致。提供故事／系统双仓候选、必要增量包、迁移／恢复办法和逐项浏览器证据；接口、静态检查或截图不能替代真实页面交互，受阻按 `AGENTS.md` 报告。

## 解释与实施边界

“镜头正文版本”是本镜视频素材的制作方案版本；“参考版本／候选”是该方案输入槽位选用的上游素材版本与真实结果，两者不得混用。镜头正文默认最新版本是本章要求；大卡普通浏览的默认策略由前置大卡任务确定，但准确参考入口必须覆盖普通默认值。

Prompt 中重复出现同一输入标记时，均指向同一准确槽位；同名素材、同素材不同用途或同一候选的不同组成／时间范围仍按原引用区分。既有组成、裁切或时间范围必须保持或重新校验；不能为了只显示 `V/C` 而丢失实际生产所需的准确输入信息。

场头“物理删除”限定当前冗余展示内容及生成来源，不授权改写不可变旧修订、删除用户评论或更改制作覆盖事实。执行时先核对其真实存储位置与评论依赖，必要数据修复走准确新修订／增量路径，不能仅用 CSS 隐藏，也不能重写历史使旧哈希失真。

本任务新增的是准确参考选择和保存能力，不增加前台生成提交、通用内容编辑器或新的全剧镜头创作任务。通用交互、保存与校验留在审阅台系统；故事仓库保存实例说明、必要数据包、恢复及验收证据。正式授权边界沿用项目规则，本澄清会话只准备并发布任务。
