# 制作思路统一承接数据模型与基础流程，并清晰表达节点产出

## 要解决的问题与改后工作

人需要在一个地方理解审阅台为什么这样工作、有哪些数据、按什么顺序创作，并直接阅读和评论约束 AI 的 SKILL。目前“系统构想”和两个创作概览在制作思路，“数据模型”和“SKILL管理”却在系统管理；视频手册、影视知识又各有独立阅读页。入口分散且重复。现有基础流程的顺序已清晰，但节点下方的产出只是一行小字，难以看出数据由哪个工作节点产生。

改后进入“制作思路”，按“系统构想 → 数据模型 → 基础流程 → 故事创作 → 生产制作”理解系统。基础流程既解释创作顺序，也直接承接 SKILL 文件阅读、逐文件版本比较和评论；左图清晰表达工作节点及其产出。专业资料通过对应 SKILL 的引用就地阅读。故事创作与生产制作两张概览图只表达整体思路，图形中的所有可点击链接移除；生产制作同时删除用户指出的冗余解释和底部跳转。

唯一前置依赖为 **task-20261012-0016**。其素材分类、方法分支和镜头实体表达正式交付后再开始；执行/恢复仍以当时最新双仓主干和有效正式数据为基线。本任务消费 0016 成果，不重新分类全剧、不重编 Prompt、不恢复旧五类或镜头另建 EN 的设计。

### 2. 基础流程明确“工作 → 产出”

保留当前自上而下的工作顺序、已固化 SKILL 的可点击节点、真实方法分支以及回读/返修关系。改变的是产出归属的表达，不另造业务流程或数据模型。

每个工作节点与其产出组成同一个紧凑阶段框：上方为动作节点，下方为与动作形状有区别的纸张/数据区，两者直接以短箭头“产出”连接；产出区标明名称及必要编号前缀，主流程箭头从整个阶段框底部继续连接后续工作。不能仍将产出作为与箭头游离的小字，也不能仅改变颜色。一个节点的多个产出在同一区中自然排布，换行或窄屏时仍能看出归属；多方法分支共用该阶段的产出区。节点保持操作语义；产出是信息，不装成无实际动作的按钮，不添加逐项 hover 或折叠。组内关系与组间推进直接可辨，不多套厚边框挤占正文。

以执行时已交付的 0016 名称和模型为准，至少将以下关系做成真实可阅读样例：

- “故事剧本” → 产出“剧本 · 剧本集 E · 剧本场 S” → 后续视听设计。人不用读右侧正文就能判断 E/S 来自剧本节点。
- “实体、状态与素材抽取” → 产出“实体（角色、场景、道具、歌曲 EN；镜头 ASH）· 必要状态 ST · 素材需求 M”。镜头沿视听设计的同一 ASH 身份承接，不因图中两个节点都出现镜头就暗示抽取出第二份镜头。图中用已有模型需要的最少表达说明承接，细节留于 SKILL 正文。
- “素材方案”节点内承接 0016 实际分类与专项方法 → 产出“素材 M 的当前方案”；“生成与制作”才产出“素材候选 MC · 提交快照 · 原件”。不能让人把当前方案误读成新的素材或候选，不能画出不存在的素材版本链。

“产出”不全是新建数据实体：返修可以更新同一当前方案，准备可以产出准确输入包，评论辅助只给表达建议。沿实际职责表达，不为了整齐伪造新对象、假 SKILL 节点或生成能力。返修箭头/旁支应清楚区别主线推进，不穿过产出文字，不把全部产出画成每一后续步骤的强制输入清单。

风格沿系统构想现有的低饱和配色、细线和原生可读文字。先在真实页面完成上述连续片段，实际阅读并调整形状、间距、连接后再扩至全图；检查普通桌面和窄屏，不能靠整体缩小文字塞下，左图不能挤坏右侧文件阅读。不复制一份新的独立手绘流程作为第二真值。

### 3. 专业资料归入方法阅读，保全唯一来源

制作思路不再设置“视频生成手册”“影视专业知识”两个独立子页。它们仍是有效专业资料：`production/seedance-video-handbook.md`、`production/filmcraft/` 及已有资源继续是权威来源，通过现有受管来源投影供 SKILL 引用。不得物理删除正文、案例、图示、视频或另手工维护一份改写副本；冻结执行和准确旧包不能被新内容回填。

沿现有节点右侧文件结构阅读专业参考，保留完整正文、章内定位、图示和媒体、文件版本和评论，不新增顶层“共用资料/方法/工作环节”分类页。旧资料目录型入口迁到对应资源阅读入口；有文件、章节、历史版本或评论定位的链接必须落到准确内容，不能一律跳到基础流程默认首页。

已查明的缺口必须解决：影视知识 `applications.md` 的“六类本剧应用”未进入当前共享资源，README 和 quick-reference 又引用它。通过同一权威来源将它及必要依赖纳入可读资源和方法引用；检查六个案例锚点、往返专业章节与速查。执行时以真实当前源清单核对完整覆盖，不仅补文件名或显示一个下载链接。确属维护内部资料可继续仅后台使用，但当前面向人的专业阅读内容不能在移除旧入口后失联。

已有完整视频手册、案例输入图和示例视频沿现有投影复用；实际打开全文、章节、图片和视频核验，不因文件清单存在就宣称可看/可听。新资料资源按现有逐文件历史与准确包规则追加，其他文件无内容变化不造新版；原评论、文件历史、已冻结执行仍指原文和准确资源。

## 准确导航、版本与数据保护

文件版本比较保持仅比较当前文件、默认最新与上一版、可换任意两版、单版置灰；关窗回原文件/外层版本/位置。评论继续对应准确文件与版本，切节点/文件/页面不能串位、覆盖草稿或改变阅读版本。源投影、方法取得与生成准备继续可取得 0016 的准确适用组合；迁移不能改变旧执行输入或临时切换正式方法绑定。故事作品、实体/状态/素材/候选及原件、评论和既有执行记录须保全。
