# 从剧情选段读清准确全场，再回到原审阅位置

本任务面向素材用途与实体状态的剧情依据阅读。发布、执行和完成状态以主项目 `.codex-task/tasks.json` 为准，本规划不代替任务账本，也不将预期写成已实现。用户核对素材或实体状态的剧情用途时，需要先快速看引用，再在因果不足时读同一准确场的完整上下文。目标是让用户知道当前显示的是哪些选段、何处省略，按需继续读准确全场并辨认原引用位置，关闭后回到原素材用途或状态卡。复用既有依据弹层和完整场读取能力，不默认展开所有全文、不新增概念实体或独立阅读模块，不改原引用、评论及作品内容。

## 任务字段与依据

- 摘要：从剧情选段按需读准确全场，并返回原素材用途或状态卡。
- 优先级：P2。已有故事页能绕行读全文，没有数据损坏或真实制作事故证据，但额外寻找与误读成本已有实际记录。

- 同项目 task-id 依赖：空；与相邻任务的协作及并行资源边界见后文。
- 并行属性：允许（`parallelizable=true`）。独立工作区和可变资源隔离是前提，正式共享写入另行协调串行，不把无依赖等同于无互斥。

本次澄清只读取批准规格、已有文字证据、任务账本与仓库身份，整理本规划并受管发布；没有独立操作页面、请求业务 API、执行修复或复现问题。执行者须按下文重新建立自己的准确基线，报告实际结果。

3. **历史准确性与缺失边界明确。** 全文沿原 object/revision/scene 读取，场、块、排序及原引用高亮均属于同一准确版本，不因当前头更新混入新内容。仅有正文块但无法确认唯一准确场、历史正文不可用或引用失效时说明实际限制，不猜同名场、第一场或最新版；原有拒绝替换的保护继续有效。新旧结构的必要边界以真实样本或注明的隔离夹具验证，不另造通用引用体系。
4. **读完能继续原审阅工作。** 从选段到全文再返回后，M1134 搜索、页码、用途展开和阅读位置保持可继续使用；从状态卡发起也回到原准确状态。未保存意见仍属于原素材/状态/修订，不转成剧情意见，不丢失、不自动提交；关闭、切换另一来源以及迟到成功/失败不能恢复旧弹层或抢新对象焦点。必要意见写入只在隔离实例测试，正式只读，不据潜在风险声称已有错写事故。
