## 任务目标

交付一套独立可读、来源可核查、能够指导制作判断的影视专业知识体系，同时服务用户学习和后续 Agent 制作任务。通过广泛、深入的行业研究理解专业原理和创作选择，再将它们转化为适合本项目二维漫剧与 AI 制作的知识输入。

成果有两个使用入口：项目中的权威专业正文，以及现有“制作思路”下新增的“影视专业知识”独立子页。页面须完整呈现知识，不缩成摘要或外链目录；两个入口共用一个正文来源，不能维护两份手工改写稿。

“权威”指有可追溯依据、明确适用条件、后续相关任务必须查用。须区分可核查事实、专业经验、不同流派的选择和本剧应用建议，不把创作经验写成普遍定律。具体创作可以有依据地变通；本知识不得覆盖用户明确决定、已锁定的作品事实、准确参考和采纳规则。

本任务交付研究、知识、原创解释图示和阅读页面，不改剧本或现有制作方案，不发起图像、音频或视频生成模型调用；现有镜头的实际优化留给下游任务。

## 研究覆盖与内容要求

至少完整覆盖以下十二个领域，研究发现必要关联知识时在这些领域内补足，避免以无限扩张资料范围代替完成核心问题。

| 领域 | 应支持的理解与制作判断 |
| --- | --- |
| 视听叙事与导演意图 | 明确一场戏和一个镜头的作用，安排信息揭示、观众注意力、情绪及视角 |
| 分镜与镜头覆盖 | 从场面拆出镜头，选择必要信息与反应，判断覆盖是否足够及何时拆镜、合镜 |
| 摄影语言 | 理解景别、构图、透视、焦段、景深等怎样影响空间、人物关系和观看感受 |
| 机位与运镜 | 根据叙事与动作选择机位、运动方式、运动动机和镜头内时间，而非堆砌运镜名称 |
| 场面调度与空间 | 组织人物走位、场地关系、轴线、视线、出入画及跨镜运动方向 |
| 光线与曝光 | 运用方向、光质、明暗关系、曝光、材质与气氛表达人物和环境 |
| 色彩设计 | 理解色彩关系、情绪、视觉重点、色彩脚本及跨镜一致性 |
| 美术与场地安排 | 协调场地、置景、服装、化妆和道具，使叙事、动作、风格与空间互相支持 |
| 表演 | 通过角色目标、动作、反应、对白、身体语言和动画表演传达人物关系与情绪变化 |
| 剪辑与时间 | 处理连续性、节奏、时间压缩、镜头衔接及有意识的非连续表达 |
| 声音与声画关系 | 协调对白、环境、音效、音乐，理解声音视角、延续和声画关系的叙事作用 |
| 动画与 AI 制作转译 | 将专业意图转为二维漫剧的可执行设计、预演、协作交接和质量检查，不将模型能力当作影视原理 |

各领域按读者理解顺序解释概念、作用机制、适用条件、选择效果、常见问题及修正方法，必要时比较不同流派与反例。术语首次出现给出中文解释，确有检索用途时附通行外文名称。避免只有定义、口诀、提示词或结论清单。

另提供三类查询入口：术语索引、按实际制作问题组织的索引、按制作阶段组织的检查清单。速查应能返回相关原理、案例和依据，不能与正文形成另一套规则。

### 研究规模与来源核验

- 实质阅读并使用不少于 60 项有效专业来源，每个领域至少有 3 项独立来源。有效来源必须包含已实际读取、对正文判断有贡献的内容；转载、同一材料的不同网址和只读搜索摘要不能重复计数。
- 优先专业院校、行业协会、创作者原始访谈与制作复盘、专业著作的合法可读内容、官方技术资料。技术参数和可能变化的能力以执行时权威资料为准。关键判断交叉核对，不把二手转述当作独立验证。
- 每项来源记录作者或机构、标题、发表或适用时间、读取时点、可回查链接、具体章节或时间码，以及支持的结论。材料不完整时只使用实际读到的部分；不可读取的内容不得标为已研究。
- 画面构图、表演、镜头运动、剪辑时间或声音结论必须查看或试听实际相关材料。文字转写、文件名和缩略图不能代替这些内容的核验。
- 来源冲突须影响最终结论的条件或强度；区分事实、作者观点和本项目的推导。正文使用自主归纳，必要引用和可公开素材保留出处与使用依据，不整段搬运资料。
- 数量是覆盖下限，不是完成的充分条件。不能通过堆叠类似资料满足数量；不能遗漏影响核心制作判断的证据缺口。

### 案例与解释图示

- 至少完成 12 个深入案例，其中至少 6 个行业案例和 6 个本项目应用示例。行业案例以实际查看的材料为依据，清楚区分观察到的表达、主创说明与研究者解释。
- 本项目示例至少覆盖多角色对白、复杂动作、悬念揭示、情绪表演、歌曲或声音、空间与连续性六类问题。读取准确作品依据，给出制作问题、可选方案、选择理由、预期效果与检查方法。
- 至少制作 8 组原创解释图示，按实际问题呈现构图、调度、运镜、光位或剪辑关系等。图示须与正文及所分析条件一致；不能以装饰图片代替解释。
- 本剧示例仅演示方法，不写回正式镜头、视频方案、素材或采纳数据，也不冒称真实生成效果、作品认可或镜头优化成果。
