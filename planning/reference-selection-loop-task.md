# 优化任务：准确参考选定后能核对、调整并继续制作

本任务贯通准确参考的选择、保存、核对、重新打开与再次调整，让制作者围绕当前消费方案连续工作。本文完整承接已审定的方法、范围、证据与六项验收，供受管任务执行和交付使用，不依赖 Review 的临时容器。任务发布、执行和完成状态以主项目 `.codex-task/tasks.json` 为准。

原始断点及根因入口记录的是系统 `edeeedd4c718b55b67c5814eddab6d4923ab8387` 的调查现场，文中的“当前”与行号按该时点理解；后文另列系统 `1b2c2394e01a5fb4fe6a93f0c89200f6450f08b0` 的同范围复现证据。执行仍须以当时最新主干与有效正式数据重新核验。记录修订表示数据的一次准确变更，素材方案版本表示制作方案的冻结版本，两者不同；`V1/C1` 表示方案版本 1／候选 1，参考槽位表示消费方案中的输入位置，未保存修改状态也称 `dirty`。

## 用户目标与实际断点

制作者为某镜头选定准确素材及使用片段后，需要回到消费该素材的方案核对，再重新打开、调整并保存。当前第一次保存成功，但工作在后续核对和调整中断，不能以单次写入成功代表参考选择功能已完成。

主会话在与正式版本相同的3301隔离实例实际完成以下工作：从 ASH001 的视频需求M2975打开音频2 M1195（全部输入的参考3），在歌曲原件卡勾选“使用时间段”，填写1–4秒，点击“选为方案参考”。页面提示已保存，返回消费镜头后正确显示所选原件及V1/C1。之后出现两处断点：

1. 保存后同卡把结束时间改成5秒，输入框可以编辑，但按钮仍禁用并标记“已保存”。准确数据库读回仍是1–4秒，没有保存5秒。界面将已经保存的状态留在未保存的新输入旁，用户无法继续调整，也不能容易确认当前值是否生效。
2. 关闭并等待消费镜头完成刷新后，点击已选参考，报“此准确素材版本已删除；原链接不可用，请重新选择”。同镜普通“本镜素材”M1195仍能打开原件、播放、Prompt和自检；准确API也能读取所选候选，槽位issues为空。因此不是原件删除、ASSET与REQUIREMENT修订拼错，或真实旧版应当被拒绝的情形。

保存事实明确：M2975由原记录修订`fa30e789…`变为`398e4569…`，记录版本2，尚未提交的素材方案仍为V1；选择准确原件`asset-songs-boat-full`/`72894b94…`的original组成，范围1–4秒。正式M2975仍是原修订。这个片段只用于隔离功能测试，不代表旋律、音质、实际采用或真实生成判断；刷新完成前短暂旧标题不计为本例缺陷。

## 目标与范围

把“选择→保存→回到消费方案核对→重新打开→调整→再保存或放弃→继续制作”连成可完成的工作。当前选中内容、已保存值与未保存修改能够区分；保存结果明确属于哪个消费镜头、哪份准确方案、哪个输入位置和哪份原件的组成/片段。优先沿既有卡片、输入控件和返回路径表达，不增加新的外部流程、管理层级或要求用户理解内部版本基线。

受管素材版本在参考入口、普通卡片、候选与方案切换、准确深链间使用一致语义。保留当前基线与旧版本映射，真正已删除的旧版仍拒绝，不能通过取消校验、取同名对象或回退最新版“修好”链接。输入范围的变化属于当前消费方案的选择，不重写上游原件、别的镜头或历史真实调用。

范围修改后能继续保存；保存成功后，当前准确方案修订和槽位身份必须衔接到下一次操作。失败、并发变化、关闭前后请求完成或快速切换时，已保存与未保存事实不能混淆；不自动迁移旧方案、旧候选和旧认可。未提交方案与已提交冻结方案按既有版本规则处理，不能为了让按钮再次可点跳过准确版本校验。

声音时间范围和图像裁切共用选择组件，应在当前有效数据有相应场景时复用检查，覆盖必要的原件组成与候选切换；不为测试批量制造作品素材。既有参考完整性、方案/设计认可、文件与谱系检查仍控制生成准备。选择成功不等于准备齐备，不代表实际调用。

预期降低保存后无法核对、重复选择和误用未保存范围的返工风险，让用户能围绕真实消费方案连续工作。本轮没有量化耗时或实际生成对照，不承诺节约比例或素材质量改善。

## 实施过程与过程验收

先在当前版重走上述完整路径，实际观察第一次保存、返回、重新打开和第二次编辑分别发生什么；用普通素材入口能打开作为反证，区分原件、准确版本与入口状态问题。确认真实保存值和所属消费方案，不能根据按钮文字推断后台事实。

提出最小可运行改动后，在隔离候选完成“选1–4→保存→返回核对→再开→改1–5→保存或明确放弃→切换另一输入/版本→返回”的连续实践。观察控件和信息是否帮助判断本次选择、是否仍需记忆内部编号或离开当前工作核对；依据实际反馈调整后重走受影响路径。能够复用的图像裁切例按同一目的检验，不机械复制步骤或制造无业务意义的数据。

过程验收要求有改动前的真实断点、候选实际完成的工作及观察导致的取舍或迭代，正式发布后从原入口只读复验。必要回执保留准确保存与版本身份，不逐字段填过程表；一次性改完后补测试清单或截图不能替代实际使用过程。

## 验收标准

1. **保存事实与消费对象吻合。** 在隔离候选按本轮ASH001/M2975/M1195路径选定1–4秒，返回消费镜头核对为同一准确原件、组成、输入位置和已保存范围。只产生必要的方案修订，重复发送同一操作不重复落库；正式原件和其他镜头不变。
2. **保存后可以准确再开。** 由已选参考、普通素材入口和已有准确链接打开同一素材版本/候选，均能读到对应准确内容；M1195当前V1不被误认成已删除旧V1。真实删除的旧版、失效基线和不属于该版的候选仍拒绝，既有合法旧链接按准确映射处理，不回退最新。
3. **调整与未保存状态真实。** 保存1–4后改成1–5，当前输入被明确识别为未保存，能够再次提交正确的新选择；返回和重开读到实际保存值。另走修改后放弃，已保存值保持1–4，不把未保存的5秒标成已生效。范围为空、超界、起止倒置等既有校验保留，失败后草稿可恢复。
4. **候选、组成与裁切一致。** 使用有效的另一个候选/组成或图像裁切场景，保存与回读的对象、版本、范围始终一致；切换候选不沿用不适用的范围，不把试听组成冒充原件。只是浏览和比较不保存，不转为新素材质量判断。
5. **并发和版本保护不退化。** 覆盖另页更新同方案、保存中关闭、迟到响应、连续切换输入及冻结版本改选；不会写错消费位置、覆盖新选择或把结果刷入另一卡。当前编辑所需的准确修订和槽位身份更新正确，旧版本保留；设计/方案采纳和生成准备闸门仍按当前真实输入判断，不因一次选择成功放行其他缺项。
6. **实际交付可复验。** 完成必要的准确链接、版本映射、选择幂等与状态转换自动检查及上述隔离浏览器实践，按受管多仓流程集成、按序发布，正式页面只读复验可达性与准确值。区分记录修订和素材方案版本、API与页面证据、功能测试与内容判断；无外部AI调用或生成费用，完成过程资源清理。 最终可见会话答复在任务执行完成或未完成时均须给出真实摘要：开头先写准确任务编号 `task-20261009-0011` 和原本要解决的问题（准确参考保存后无法继续核对、重开并再次调整保存），随后清楚说明实际发生的变化及用户收益、真实验收环境和边界、尚未解决的事项与下一步，让用户在多个 `c task mrun --auto --wait` 窗口中一眼辨认任务方向及成果；不能只报告提交、测试数量或清理，计划及预期收益不能写成已实现。
