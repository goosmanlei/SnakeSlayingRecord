## 交接边界

本项只负责大卡打开生命周期及加载稳定性。调查中的候选卡选择、全站参考核查是另外两项目标，不能据此视为已发布或添加猜测编号依赖。发布前回读的 `task-20261011-0003`、`task-20261011-0006`、`task-20261012-0002`、`task-20261012-0015` 均已完成，分别提供导航、引用打开、连续阅读、来源列表基础，未承诺本项的一次开窗与稳定加载；不重开旧任务。旧任务独立复验或清理残留仍由原负责人承接，本项实施、正式验收和清理残留由本任务继续。

完整仓库范围为 primary（source=`.`）和 desk（source=`../story-review-desk`），均可写、target=`main`；source 相对主项目解析。desk 负责共用 UI、读取与测试，primary 负责实例准确引用、必要发布恢复材料及验收。先 desk 准确候选，再由 primary 的 `config/instance.json.review_desk_commit` 固定引用；草稿只登记附属计划，不创建 worktree。

独立工作区开发可并行，共同文件集成后复验。正式库、读缓存、3000 服务、发布恢复入口及固定镜像标签由本任务执行者在共享写入窗口协调，核对真实路径、版本和实际写者，完成回读及验收后解除占用。执行的共同终点是任务正文要求的本机正式可用、真实 Chrome、新空实例恢复及清理；本澄清的只发布限制不缩减该终点，不扩大到付费生成、VPS 或外部发布。
