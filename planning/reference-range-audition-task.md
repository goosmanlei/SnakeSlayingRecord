## 目标、事实与保护边界

按 planning/reference-range-audition-task.md 实施，让制作者打开当前消费方案已选的准确音频参考后，直接试听实际选择的时间段，无须记住并重输同一组数字；仍可明确查看/试听完整原件。消费方案指使用该音频作为输入的镜头或素材方案，准确参考固定需求版本、候选、原件组成及输入位置。复用现有参考卡片、范围控件、素材播放器和“试听选段”能力，不强制新增某个按钮、管理实体或播放平台。收益是减少重复选择及范围核对负担；没有耗时测量，不承诺节约百分比。

## 按实际使用推进

后续执行者先读本项目当前 AGENTS.md、KNOWLEDGE.md、STATE.md 及[工作区流程](../production/generation-workspaces.md)，再读取附属仓当前协作规则与相关播放器、准确参考、评论契约。不得将旧工作区、草稿创建提交或下述静态定位当作执行时正式状态。

1. **重核基线与原路复现。** 核对最新双仓本地 main、远端 upstream、实例准确系统提交及实际正式运行版本，从执行时有效正式数据建立隔离副本；保留准确原件及引用。沿当前消费方案依次打开 M2669→音频 1 M1134 V1 C1、M2673→音频 1 M1260 V1 C1，对照保存值与媒体实际时间，再做 Home/I 和 5.6 的正常手工试听。复现时记录入口、候选、原件组成、消费输入位置、起止与停止行为；正式页面仅只读，不能修改参考、评论或认可。若最新系统已修复，先说明真实复验结果，不重复实现。
2. **形成最小衔接方案。** 从手工“试听选段”可用路径识别复用点，说明打开已选参考时如何取得准确范围、临时调整时试听哪份数字、全长如何明确进入、何时停止或清除上一对象播放。操作应帮助用户判断或完成试听，不默认加按钮、标签、日志、内部修订或管理实体；必要状态由相应现有控件表达。
3. **先零起点，再非零起点。** 在本任务隔离候选中先修通 M2669 的 0–5.6，再用 M2673 的 2.7–7.08 核查非零起点、准确停止及重新试听。使用真实浏览器并回读真实媒体时间，不以把参数传入函数作为完成依据。
4. **走完有状态的连续操作。** 在隔离数据副本修改范围，试听后分别明确放弃或保存，再退出、重开和刷新；切换候选、版本与组成，关闭时核对停止。逐步核对已存、未保存、临时试听、评论圈选的归属和有效范围，观察是否仍需记住两套数字。根据实际操作发现改进并重验受影响路径，不能一次写完后只跑自动化。隔离试改值和测试评论不得发布到正式库。
5. **做必要共用回归。** 验证完整原件、所选片段来回切换、准确评论文件/范围、失败/越界/倒置、未提交与冻结方案、异步关闭和候选切换；自动检查只补充契约与时序证据。触及共用评论交互时按 desk 规则覆盖受影响故事采编、故事结构入口。触及音视频共用路径只使用实际可用视频样本，缺少样本说明未覆盖边界，不生成新媒体或用测试色块冒充作品。
6. **受管交付与正式只读复查。** 按项目当前多仓流程先系统准确候选、后主仓准确引用，登记检查器后准备整组候选。共享窗口按序交付与发布，保留正式数据和历史，不导入测试副本。正式只读原路重走两例，分别说明隔离结果和正式结果；随后完成本任务过程资源收尾及用户可见报告。浏览器初始化、媒体访问或正式复查受阻就保留实际未完成项，不以接口/静态检查代替。

## 范围如何区分

| 范围或状态 | 负责的事情与不允许发生的副作用 |
| --- | --- |
| 已存生成输入 | 消费方案已保存的准确候选、组成及范围；作为重开与放弃后的依据，只有明确保存才按既有规则改变。 |
| 未保存参考范围 | 当前准确对象的调整草稿；试听是否使用此草稿须可理解，不能显示为已生效，不能因切对象而套用旧数字。 |
| 临时试听 | 只控制本次播放起止；不能暗中写参考、评论或认可。 |
| 评论圈选 | 给准确候选、文件组成和区间写意见的定位；不得迁到另一文件，也不得变成生成输入保存动作。 |
| 完整原件 | 允许明确查看/试听全长；全长播放不能被标成当前所选片段。MP3 试听组成与 WAV 原件身份分开，不能替换或伪装。 |

上述设计不重新评价 40 个声音，也不解释为 0005 的内容判断错误；本任务对声音播放控制的验证不能代替听辨音色、口音、表达质量或模型输出。
