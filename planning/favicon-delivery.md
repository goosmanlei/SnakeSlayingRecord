# 站点图标候选交付

本任务为通用审阅台增加站点图标配置，并为《李寄斩蛇 · 把灯带回家》交付屋檐护着灯火的图样。当前 3000 已应用候选及最新正式图标配置；双仓正式集成、图样接受和实际标签栏显示验收仍待完成，不以配置成功替代这些判断。

## 交付物与职责

- 通用系统：独立工作区 `../story-review-desk-python/.worktrees/task-20260930-0002`（相对于故事主项目根目录），分支 `codex/task-20260930-0002-favicon`，过程提交 `46a0fb1`、`a22b1e4`。候选完整版本为 `a22b1e408767b1f4ea05363f40fd5d7fa71552dd`，包含系统 main `39ff95e` 已交付的剧本集场与评论快捷键功能。
- 故事实例：复用本任务工作区，`config/instance.json` 锁定系统候选；源 SVG、ICO、PNG、设计预览与渲染脚本随故事仓库提交。设计寓意、16／32 像素检查与生成方法见[图标设计](../design/favicon/README.md)。未调用 AI 图像生成平台。
- 功能与操作说明：系统 `docs/favicon.md` 维护通用协议；故事 README 提供本实例入口。配置为 `SYSTEM.site_favicon`，引用 `export/assets/` 的单个文件名；空值恢复书页图标，保存沿用配置版本检查及事件。支持上传、选择、替换、清空；上传不等于采用。
