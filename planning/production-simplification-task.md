## 1. 要解决的问题与结果

生产制作目前把内部的实体、状态、素材需求、引用关系、生成记录和采纳范围，较直接地转换成人的阅读目录。同一段创作信息在多个字段或对象中反复出现；大量内容通过折叠继续占据页面和注意力。人想理解一镜如何发生、判断角色形象或选择已有原件，却需要辨认这些内部对象及层层说明。

本任务覆盖生产制作全部功能：当前分布在视听制作、实体管理、素材管理三个子页，以及从这些页面、故事相关制作、参考和评论定位进入的共用卡。三个现有子页只是防止漏项的范围索引，不是必须保留的导航结构；可以按人的完整工作合并入口、重组页面及对象呈现，不得把任务缩成三页各删一些字段。形成一套一致的人类信息结构：人直接阅读作品和必要专业设计、看听准确原件、理解具体用途、表达意见并作出创作取舍；AI 按方法整理、检查和准备，系统维护准确版本、引用、范围与反馈。入口变化后，准确深链与已有反馈仍须到达相应内容并保留返回上下文。

用户明确要求：面向 Review 的内容不使用折叠。真正用于判断的信息直接呈现；重复表达合并；内部执行和确定性校验退出日常审阅页。不得以默认全部展开、改名、CSS 隐藏、更多解释标签、增加高级模式或技术详情入口代替整体简化，也不得将原来的信息堆转存到新的弹层或管理页。

这是一项完整任务，不拆成各子页分别换样式的小任务。成功意味着人需要理解的概念、必读内容和无价值操作实质减少，同时判断能力和准确性保留。页面更短、折叠数量减少或截图更整齐，单独均不足以验收。

## 3. 从信息价值决定结构

先按真实工作梳理各子页及共用卡的内容。每类内容只需保存一份足以指导实现的必要性判断：它帮助人理解什么、作出什么决定；当前是否需要；AI 或系统能否默认完成；重复来自哪里；保留、合并、删除展示或取消操作后，人是否还能完成原本有价值的工作。此记录留在任务依据中，不新建产品内的检查表或管理页面。

不得以后台字段存在、可追溯或曾经有控件，自动证明它应该成为人的工作对象；也不得仅因专业、较长或不易理解就删掉。

| 内容类型 | 必须完成的判断与改进 |
| --- | --- |
| 作品与专业设计 | 动作、对白／歌词、表演、空间关系、镜头、声音与必要剪接意图直接可读。相同信息不因属于不同字段而重复；真正不同的创作选择保留。不能机械截断文本、只取第一字段或用无依据摘要改变含义 |
| 实体与状态 | 人审阅人物／场景／物件怎样呈现，以及确有意义的阶段变化。检验实体和状态是否各有独立判断；没有时融入对应作品或形象的完整表达，不保留两个平行的必审对象。准确状态和跨镜约束由 AI 与系统承接 |
| 素材需求与实际结果 | 区分“准备制作什么”和“已经有什么可以看听”。需求不天然成为人的待办。复用、是否新做、重要制作路线等真实取舍直接说明；不能要求人为了消除零候选数字而补图，也不能隐瞒当前没有成果 |
| 引用关系与用途 | 直接呈现当前原件用于什么、保留哪些特征、允许哪些变化及实际限制；合并同一原件的重复说明。内部边方向、依赖清单和关系类别不成为人的阅读前提。人物之间有创作价值的故事关系不能与技术引用关系一起删除 |
| 人的判断与采纳 | 当前有效意见、理由及实际适用范围直接呈现。删除没有独立创作判断的重复采纳步骤；明确一个人的动作具体形成什么决定，系统如何准确记录。不得用合并按钮产生人未作出的多项认可 |
| AI 自检、准备检查和执行记录 | 可确定的版本、引用、尺寸、谱系及准备校验由系统承担，AI 按方法完成专业自检。历史自检不冒充当前人工认可。确需人的重要取舍给出具体内容和影响，不交付泛化检查清单 |
| 历史与追查 | 历史原件、意见、准确版本和恢复依据保留。追查沿已有且目的明确的版本、来源、评论、原件或相应工具工作入口；打开后呈现该工作真正需要的内容。不得新增“高级／技术详情”通用容器，或把折叠换成隐藏信息层后宣称完成 |

本任务允许为达成这些目标修改通用产品代码、展示数据的组织、必要接口行为及 AI 工作方法的交付契约。这里的交付契约指方法向系统提供什么可读内容、准确来源和检查结果，不是要求再新增一个人需要管理的对象。不能把实现锁死为 CSS 或纯模板删行；也不预设重做后台模型。确需改变系统行为时，以“消除人的无价值工作且保留准确语义”为依据，只改必要范围。正式业务数据保持只读，不通过改写旧内容、清空需求或迁移历史来制造简化效果。

小样约定的是人能读到什么、完成什么判断及怎样操作，不要求运行时用关键词删句、取首字段或简单字符串去重生成同样版面。现有自由文本既有完全相同的字段，也有语义相近而限定条件不同的表述；机械合并可能丢失动作时点、作用范围或专业选择。可以在隔离环境准备必要的展示数据或方法输出候选，形成可核对的整合表达；必须说明其与准确原文及修订的映射，合并了哪些重复、保留了哪些差异、新反馈落到哪里，以及旧意见如何仍定位到当时原文。新的解释或创作判断不能冒充已确认的正式原文。未形成可靠映射时，不能仅以摘要顺畅宣称可替代原内容。

采用何种共用实现由小样与反例决定，不在本任务中预定架构。不得逐条硬编码 AS001／阿蘅，也不得以实现语义整合为由开展全剧改写、在线无上下文自动重写或偷偷写入正式业务内容。若某种展示需要尚不存在的可靠方法产物，应在隔离候选中把实际可行范围和未解决边界说清，再检验必要的最小契约调整。
