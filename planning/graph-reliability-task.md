# 实体关系图完整呈现真实连线，修复单条路由失败造成全图关系消失

## 原问题与改后结果

人在第13集检查压闸时，需要从长杠、洞闸、木栓及人物之间的关系理解各自作用。第六轮正式 Chrome 调查在“生产制作 → 实体管理 → AE013 → AS046 → ASH242”看到了19张实体卡，却没有任何连线和摘要；单击 EN058 长杠仍会突出七个直连实体，但页面无法说明它们怎样关联。相邻 ASH243 同样失败。正式接口在这两镜各返回24条真实关系；ASH001 的15节点、11条曲线与摘要正常。这些都是调查基线的观察值，交付时按最新有效数据核对，不能硬编码。

改后继续使用现有关系图，当前准确镜头范围内的全部真实关系都有可追踪的曲线和简短摘要。人能直接读清长杠与洞闸“绑接后持续压闸”、洞闸与木栓“闸落底后穿栓固定”两种不同条件，再沿其他关系理解人物与道具的作用。单击只突出中心实体、直接相连的实体及对应关系；双击或 Enter 打开准确大卡，关闭回到原范围、视野、选择与焦点。本任务修复绘图可靠性和完整可读性，不改作品设计。

## 已定行为与修改边界

- 修复路由、端口或布局组合的真实缺口，使原失败输入和最新有效图的全部应有关系完整绘制。只捕获异常、跳过失败边、保住部分线、关闭报错或只核对 SVG 数量均不算完成。
- 同范围重新布局发生单条几何异常时，不能先破坏已经完整显示的边层；失败须沿现有错误处理明确表达并允许恢复，不能伪装成“没有关系”或部分成功。换范围失败不得让旧范围图冒充新范围。修复原失败图与验证异常保护是两项都须满足的要求。
- 不删关系、不减少应有节点，不用穿透卡片或摘要的直线换取通过。“闸落底后穿栓固定”带有阶段条件，不能因当前镜头尚未落底而删除。图的范围和关系语义沿现有契约，本项不承担素材归属、跨页工作位置、关系语义清理或全剧内容重写。
- 每条真实关系使用端点和路径可辨的平滑曲线；不同路径不共线重合，不穿卡片、摘要或遮住文字，必要交叉仍能追踪各自去向。不靠隐藏真实边、选择后才显示或极小字号达标。简短摘要服务理解，保留既有有用点击，不恢复冗余 hover 浮层，不新增关系管理页面。
- 仅沿真实有向依赖归一方向并尽量分层，多父不重复节点，真实循环与孤立节点保留；无向关联不造箭头或上下级。不能为演示方向改写正式关系。
- 单击只突出中心、直连实体、对应连线与摘要，其他仍可见；两跳及邻居之间无关边不被带入，选择不重排或改变视野。同节点、空白及图内 Esc 清除，另一节点切中心，孤立节点只选自身。Space 选择、Enter 开卡、双击仅开一次准确大卡，拖动结束不误选或开卡，关闭恢复原范围、视野、选择和焦点。
- 保留原始大小、适应全图、缩放、平移、窗口变窄再放宽后的完整绘制和可读文字。保全故事、镜头、真实关系、候选快照、原件、真实生成调用、原评论及准确引用；不继承0008的一次性资产删除授权。

## 可执行的完成标准

1. **准确重现与逐条核对。** 从执行时最新双仓主干和有效正式数据建立准确隔离实例，重走 ASH242、ASH243、ASH001 并保存前例及接口真实关系集合。将原出错输入和实测卡片尺寸做成可重复样例。修复后逐条比对关系身份、端点、方向、摘要及实际可见路径，原失败关系必须出现；每条路径都须可追踪，不能仅检查 SVG 元素数量。记录数据变化，不把旧19/24或15/11当作产品常量。
2. **实际读图与既有交互。** 在真实 Chrome 的 ASH242 读清长杠—洞闸、洞闸—木栓两种条件，逐条追踪全部真实关系。单击 EN058 只突出届时真实直接邻居及边，双击其中实体打开准确大卡并关闭返回；再切中心、同节点、空白、Esc，实际验证 Space、Enter、焦点和拖动。ASH243、ASH001 与末集有效镜头图作为失败相邻例及正常对照，同样完整可读可操作。
3. **视野与几何边界。** 在原始大小、适应全图、放大、缩小、平移及窄屏再放宽下实操，重排不丢线，卡片与摘要可读，连线不穿卡片／摘要，不出现共线重合；必要交叉可辨。隔离样例覆盖已有的真实有向／反向、多父、循环、孤立、共享端点、多边、密集图和长摘要类别；保留全部真实关系，不为夹具改正式数据。
4. **故障及恢复后的继续工作。** 在准确隔离环境触发单条路线计算异常、图读取失败和迟到响应，区分同范围重排与加载中切镜。已有同范围完整图不被先清空，错误不被吞没；新范围失败不冒充无关系，不串旧图、选择、评论或草稿。解除故障后经已有重试或重开，复走 ASH242 → ASH243 → ASH001、选择、缩放、开卡和返回，完整关系恢复且能继续操作。故障注入及任何写入验证不进入正式库。
5. **全量覆盖与数据保护。** 按最新有效镜头范围，自动比对真实数据集合与布局结果，并核对全部边的几何约束；实际阅读有差异及曾失败的代表图，差异不得以删数据消除。全量检查只证明集合覆盖及几何约束，视觉和交互结论来自上述真实浏览器实践。比对受影响数据与必要原件哈希，证明本项没有删改真实关系、作品、候选、真实调用或原意见。吸收并行任务的有效改动后，复验最终同版本行为。
6. **本机正式生效与恢复。** 按下述双仓交付和共享窗口完成受管集成、必要推送、本机 `http://127.0.0.1:3000/` 正式发布；回读准确双仓提交、实例系统引用、实际镜像／源码、挂载及发布回执，再从正式 Chrome 原入口只读复走两失败图、正常对照和核心交互，保存前后画面。按项目现有完整导出与恢复流程在新空实例核对关系、候选、原件、评论，再继续集场镜切换、完整读图、选择与开卡返回。代码提交、容器健康或隔离候选不等于正式验收。
7. **清理及交接。** 清理身份及归属明确、已无用途的本任务过程容器、镜像、库、缓存、夹具及临时文件；按准确 ID／路径回读，报告实际删除数量／范围，以及保留资源的用途、责任和解除条件。正式当前／回退／基底、原件、真实回执、Git 和必要恢复资料按实际用途保留，在用双仓 worktree 退出释锁后受管整组退役。最终回复先写任务编号与实际解决的问题，再用 ASH242 前后图说明可读关系、实际收益、准确版本／环境、验证边界、残留及下一步；执行自验与待负责人独立复验分别列明。
