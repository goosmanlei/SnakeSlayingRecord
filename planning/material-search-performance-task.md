# 素材管理首次检索与切换筛选快速响应，消除重复全量投影

人在“生产制作 → 素材管理”查找一个素材，应及时看到结果并打开当前方案或候选。当前保持 AE001／AS001，首次检索 M2635 等待 11.77 秒，首次检索 M2974 等待 11.38 秒，重复检索此前读过的 M2544 只需 0.03 秒。每次均只有一个素材业务请求，慢查询绝大部分时间发生在响应头返回前。改后首次输入、新关键词和新范围也能快速取得准确结果，不要求先搜过才能顺畅使用。

本任务交付终点是本机正式可用：`--auto` 执行者完成受管双仓集成、必要推送、本机 3000 正式发布、真实验收及自有过程资源清理后，才达到完成条件。本次澄清只整理定义、登记并发布任务，不执行上述工作，不启动 Goal 或新增调查 subagent；这不限制后续执行者在本任务授权内完成正式交付。

## 已定改进范围

结果仍按当前素材身份、准确集场范围、媒体类型及结果条件筛选，保持分组、排序、候选数量和必要历史输入。目录复用须在相关写入提交后及时失效，跨请求、跨服务进程取得一致新结果；固定历史修订仍返回其准确内容。缓存关闭、读取失败或不能写入时走正确、有界的实际读取路径。不得删真实关系、候选、评论计数或历史输入换速度，也不新增面向人的缓存开关、后台管理页或额外操作。

## 工作步骤与完成标准

### 1. 同条件前后比较

先在本机与正式服务相同代码、相同数据规模的独立实例建立同条件前后对照：记录提交、数据身份、条目数量、缓存状态、浏览器和并发负载。关闭请求剖析后计时；只能清理自己的隔离缓存，不能为测量清正式缓存、重启共享服务或靠裁剪数据制造快结果。正式发布所需的服务切换另在受控发布窗口完成。

验收分五类：隔离实例没有可复用派生缓存的首次查找；已有目录后换从未查过的关键词；同词重复查询；切换集场及媒体／结果条件；相关写入失效后的首次再查。每类至少三次，记录全部结果及最慢值，不能删慢样本。M2635、M2974 与 M2544 必须出现，另选名称检索、无结果词和另一集场作为正常对照。冷启动、共享目录已命中及完整查询已命中要分别标明。

完成阈值是本任务的预期目标，并非已实现效果：在上述同机、无人工限速、无并发压测条件下，每次首次、新词、范围变化及写后失效的素材列表请求不超过 2 秒，从用户触发到正确结果可点击不超过 3 秒；重复查询请求不超过 0.5 秒、页面不超过 1 秒。独立禁用或模拟读取缓存不可用时，正确结果仍应满足首次查询阈值。记录浏览器操作到结果可用、网络请求耗时与响应量，不能拿接口时间代替用户等待时间。若未达阈值须继续处理或明确未完成，不能用更改测量口径结项。

### 2. 真实工作与准确结果

在真实 Chrome 完成“查 M2635 → 打开方案／候选 → 返回 → 查 M2974 → 换集场和媒体 → 打开结果”，确认空态、返回位置与筛选正确，快速连续输入最终显示最后一个词而非迟到结果。保留每次结果集合，与未优化的准确读取对照；浏览器实操不由自动计时替代。

对照覆盖编号与名称、无结果词、同词重复、另一集场、有候选与无候选、媒体和结果条件组合，以及原有分页与分组排序。同一数据身份下集合、当前需求和候选计数、必要历史输入一致；与归属任务合并后的结果以新语义真值核对，不能拿删引用产生的小集合当性能提升。

### 3. 新鲜度、故障与恢复

写后失效只在隔离环境验证：经既有合法接口修改会影响目录的名称／条件、引用或候选结果，提交后由另一请求／进程读取原查询，看到新内容或计数；旧准确历史不被当前内容覆盖。覆盖失败、回滚和缓存不可用时的准确性。用适当自动测试补齐查询组合、失效和并发边界，解释减少了哪些重复计算，不以测试总数作为效果证明。

故障操作须准确且可恢复：隔离模拟列表请求失败、迟到响应、读取缓存不可读／不能写入及显式停用；失败不能伪装成成功空结果，保留当前查询、范围与重试上下文，最后一次选择不被旧响应覆盖。解除故障后沿原入口重试、开卡、返回并刷新，得到准确结果且恢复正常预算。失效验证中的失败提交／事务回滚不能泄露未提交结果，随后合法提交能被另一进程读到，原准确历史仍可回查。正式库不做故障注入、测试编辑或强制冷缓存实验。

若新增或调整持久索引／派生结构，隔离验证重建、中断恢复及受管导出到新空实例的必要恢复链，恢复后再走查找／开卡／返回；派生缓存必须可清除重建，不成为历史内容权威。未触及业务持久化时说明范围，仍核对现行恢复契约，不为验收另造一套恢复系统。

### 4. 正式交付与收尾

沿 [项目规则](../AGENTS.md) 和 [工作区与发布流程](../production/generation-workspaces.md) 完成执行时最新主干核对、隔离实现和上述验收、准确候选、受管集成与必要推送、本机正式数据库／服务的必要发布、正式 Chrome 新词／范围只读验收与自有过程资源清理。正式回读双仓准确提交、实例引用、实际镜像／配置／挂载及发布回执；从原素材入口复走三例和另一范围，分别记录真实请求与可点击时间及观察到的缓存条件，不把正式未知缓存状态称为严格冷样本。

正式部署、执行者验收与 Review 独立复验分别记录。核心阈值、真实页面或恢复未通过时，保留未完成状态和准确原因，不以提交、接口或测试通过结项。

清理归属明确且已无用途的本任务临时服务、容器（包括已停止容器）、镜像、测试库、缓存及重复文件；按准确 ID／路径回读实际删除数量和范围。正式当前版、回退版、必要原件与恢复证据按用途保留，说明负责人及解除条件。受管文件在最终候选前整理；完成回调后不补改，受管 worktree 待会话退出释锁后沿任务工具退役。不得清理 Review 或其他任务的资源。

最终回复先写任务编号和实际解决的问题，以三例前后等待、首访与重复对照说明收益，列明环境、样本、未解决项、下一步和资源清理，给出准确交付与证据入口。
