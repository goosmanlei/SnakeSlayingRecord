# 优化任务：让字幕与道具文字的制作分工和准确交接可执行

本任务规定准确文字与已承诺可编辑字层的最小制作交接，供执行者按准确故事依据实施，并供审阅者核验成果。任务发布、执行和完成状态以主项目 `.codex-task/tasks.json` 为唯一权威。本次澄清仅整理独立规划并发布任务，不执行制作；后续执行依本规划、执行时有效输入及项目既有权威入口进行。除另有说明，项目内文件路径相对故事任务工作区根目录。

## 用户目标与已核实差距

观众需要在正确时刻看懂时间变化、歌词或纸面证据；制作者需要知道准确文字来自哪版作品，应该由画面生成、既有素材复用还是后期字层完成，以及怎样检查它在实际画面中的正确性和可读性。这里要完成的是既有表达承诺的最小交接，不是新增全剧字幕系统或剪辑模块。

正式 Chrome 已检查 ASH304（E16/A01/01，10 秒）的当前方案：首帧 M3955 同时要求“只画动作开始的瞬间：二十多天后字幕”和“不加字幕”；视频 M3956 又直接要求“从二十多天后字幕开始”。主会话证据 `formal-ash304-caption.jpg`。另有 ASH052/M3128 的“十来天后、庙会前三日”时间标题，ASH291/M3917 的“数日后”且不能设为翌日。这些文字承担叙事时间功能，不能简单删去，也不能只把相反字符串中的一条删掉就认为交接完成。

道具文字有更早已明确的制作选择：

- EN083 迎蛇领唱旧纸/ST195 要求首张可读“米饵奉蛇神，四邻得安宁”，字层单独合成并逐字校对；EN112 歌本及其相关状态要求剧情已给原词后期排入可编辑字层，未知页不补造可辨歌词。
- ASH025（E02/A01/05，16 秒）的准确正文 s003:14 明确旧纸露出这行字。M3046 首帧直接将“字层单独合成”“可编辑字层”“后期排入”拼入图像生成 Prompt，M3047 视频要求呈现纸面原句，却没有说明与既定字层选择如何交接。纸面随翻页、遮挡、透视改变，与固定在画幅上的时间字幕不是同一种制作问题。
- 反证必须保留：旧 M1410 `asset-fg3-lead-lyrics-base-image-01`，准确修订 `ddf500437f0e69df7fd105e90c23ee61690bac60e6b1d08a69a086881b74c081`，原件 sha256 `cfa22c5ac103574a4c4796d6f53918583fb654a59b15d8cc9d4e0d82680fc06a`，1448×1086。本轮实际看过本地原图并核验哈希，十个字可辨且与原句相符；实际记录为图像生成的 PNG，并非可编辑字层。不能宣称现有参考已错字，也不能为了采用后期方法而强迫重画这份正确原件。

当前正式库没有本剧镜头视频、组合成片或字层工程。旧 task-20261008-0004 明确排除剪辑时间线、成片组合与导出，本任务不将范围外尚未交付认作旧任务违约。已证实的是现有方案职责矛盾和已承诺字层缺少可执行交接，实际成片是否错字尚未发生、也尚未验收。

## 目标与范围

依据 `production/seedance-video-handbook.md` 关于准确文字、字幕和发音分别判断及优先确定性排版的规则，结合影视专业知识中的信息揭示、实际显示尺寸、可读时间和运动遮挡，为执行时全剧当前必须可读的文字及已承诺字层形成最小必要交接。范围从实际叙事需要取得，不将所有提及文字、未知纸页或远景纹理都升级为字幕、道具实体或后期工程。

每项必要文字能回答：准确原词及来源、何时应被看见或暂不揭示、在什么载体上、需要达到怎样的可读结果、由哪一步负责，以及何时检查。已有正文、状态、素材、需求和方案能表达时直接复用；只有实际缺少的表达才补充，不机械增加固定字段。

明确画面生成需要保留的底板、空间、手部接触和运动；准确字形可按实际条件使用已有合格素材、正确文字参考或确定性字层。手册的“优先后期”不是所有文字一律后期的禁令；重要的是所选路线有依据，准确内容不会只依靠一句 Prompt 保证。已承诺可编辑字层的地方，要落实交接或以明确可审阅的制作选择调整，不能静默把平面 PNG 说成可编辑工程。

通用 REQUIREMENT/ASSET 已支持 project/document，真实制作记录也可登记外部编辑方式。优先用既有记录、准确引用和外部制作交接，只有真实操作缺口才最小修正通用系统；不新建后期管理模块、排期系统、逐字任务库或前台完整编辑器。ASH304 中叙述式书吏发声属于动作声音转译任务，不在本任务重复立项或扩写新台词。

预期减少执行者重新翻剧本找字、误把图像生成当排版、过早显露证据和后续重复返工的成本。报告交接已明确、仍待素材/真实画面验证和合理无需额外准备的范围；不把方案数量当作已完成字层，不给无依据的节省比例。

本任务不提交新增付费图像、音频或视频调用，不消耗历史授权，不制作全剧成片。可用既有有效原件和明确隔离的轻量排版/合成示例验证交接可执行，示例不得进入作品采纳或冒充真实镜头效果；真实画面缺失的可读性、透视、遮挡和逐帧稳定性保持待验。

## 必须采用的文字制作交接过程

按集顺序阅读准确剧本和已确认视听设计，结合人物、主题与信息揭示，逐场提取真正需要观众看清及明确承诺字层的文字。逐项核原词和时机，选择复用、生成参考或确定性后期等适用路线，再实际准备最小交接并从后续制作者角度读回；不能一次扫描全部文字后自动套用同一路线。已有准确素材和正确制作选择不重做。

每集完成后连看场镜关系，检查时间标题、证据露出/遮住和纸面变化是否支持本集人物与主题，前后镜是否可接；将所得应用到后续集，后续条件改变时回查相关前集。脚本只检查原词、来源、引用并汇编已确定的方案，不替代逐项选择与真实交接。

涉及逐镜生成 Prompt 的地方，先读视频手册并选适用模板/方法，读准确视听目的与起点—变化—落点，再核准确输入和字层职责，写模型友好的画面/动作表达，最后自检生成与后期没有相反或丢失的责任。模板帮助分清工作，不把字层交接要求全部塞给生成模型，也不为每镜添加机械字段。

### 实际工作、最小候选与观察反馈

先实际重走后续制作者的工作：从现有镜头或素材入口确认应读文字，回查准确来源和揭示时机，比较既有原件与已承诺字层，逐项选择制作路线，再实际取得并读回最小交接。记录哪些地方需要重新猜测、反复查找或无法承接；不以一次性生成全剧清单、最终方案或界面后补写过程代替实际工作。

先以一个必要时间标题和一个纸面文字情景形成最小可运行候选，观察实际查找、选路、交接及检查的反馈，再调整职责、引用或必要通用展示，重走受影响路径与不得提前揭示的反例。把已验证的方法用于后续逐集工作；最小候选不能代替全剧范围，无新影响时不人为制造迭代或返工。方案数量、准备数量及假设节约不能当作已实现收益。

全部逐集工作仍按“准确剧本与设计阅读→必要文字提取→逐项选路→实际最小交接→集末人物、主题、揭示和跨镜复核→应用后集并必要回查前集”的顺序进行。必要过程证据随实际工作形成，能说明观察如何支持或改变选择；脚本只辅助原词、来源、引用和已确定方案的汇编。涉及 Prompt 时先手册、准确稿和输入，再表达与自检。

这些要求共同约束第 5、6、7 项验收。候选中的登记、配置、选择、评论或采纳测试只写隔离实例，正式发布后从同一原入口只读复验。分别报告辅助检查、隔离实操、正式页面和真实画面效果；浏览器受阻时明确待验，不以 API 或静态检查代替页面验收。静态原件或轻量示例只能证明对应交接能力，实际视频的可读性、透视、遮挡和逐帧稳定性继续待真实结果验收。

## 验收标准

1. **全量但有必要性判断。** 按执行时准确输入锁复核当前时间标题、剧情关键纸面文字和明确的可编辑字层承诺，形成可回查的保留、修正或无需额外处理结论。至少覆盖本稿时间标题与领唱旧纸/歌本情景。未知歌词、远景不可辨笔迹、单纯对白及明确禁止出现的总结字幕不被机械新增。
2. **时间标题分工一致。** ASH052、ASH291、ASH304 的准确文字、出现位置/时机、画面与字层分工、校对方法均明确；首帧和视频不再同时发出相反命令。保留“十来天后、庙会前三日”“数日后”“二十多天后”的作品时间关系，不擅改成翌日或当天即判。移走生成指令后仍有可执行的交接，不让标题在流程中消失。
3. **道具字层可承接。** ASH025 的旧纸原句和相关歌本状态按准确版本交接。区分纸面字、画幅字幕和出声内容，明确纸页/手部运动、折叠遮挡及透视影响的处理和验收责任。旧 M1410 正确原件可以参与评估复用，原件与任何派生准确区分；平面图不冒充可编辑层，参考文字正确不冒充视频全程正确。
4. **揭示边界与反例。** 以 ASH055 旧墨被贴纸盖住、尚不能读出供奉条款等情景核验不得提前显露；未知页不编造可读长文，非关键远景字不强迫新增工程。不以“一律无字幕”删除必要信息，也不以“一律后期”增加无价值制作。
5. **最小交接实际可用。** 在隔离候选中，后续制作者从现有镜头/素材入口能找到准确文字、已有素材、待完成职责及检查依据，无需重新猜测故事来源。用既有原件或明确隔离示例实际检查至少一个时间标题和一个纸面文字交接；如生成底板或真实运动尚不存在，说明当前能证明什么、将来在哪个真实结果上继续验收。不得以静态示例声称完整镜头可读性通过。
6. **准确版本与发布闭环。** 保留用户评论、素材原件、真实调用、采纳历史及准确来源。制作选择修正产生可追溯新版本，不把旧认可自动迁给新字层或新方案。候选页面实际操作与必要回归后，按受管流程增量发布；正式 UI 只读回查标题样例、领唱旧纸/歌本及反例，分别记录方案、示例、页面和真实效果的验证范围，完成过程资源清理。
7. **按集提取、逐项选路、真实交接。** 全部必要文字的准确依据、路线取舍和交接位置可回查，按集完成的揭示/人物/主题/跨镜复核及后续应用可追溯；受影响前集有必要回查，无新影响则不强造返工。一次模型生成全剧文字清单、自动替换 Prompt 字符串或仅登记新需求不通过；逐镜 Prompt 的方法、目的、输入、表达和自检与实际交接一致。

## 任务安排、去重与并行边界

- 摘要：落实全剧必要准确文字与可编辑字层的最小制作交接。
- 优先级：P1。时间关系、纸面证据与既有字层承诺影响后续制作的正确准备，应在实际镜头制作前明确；目前没有据此认定正式服务紧急不可用。
- 复杂度：极复杂；模型 `gpt-6-astra`，推理强度 `max`。全剧逐集的信息揭示与人物主题、既有正确原件、纸面运动和字层职责需要统一判断，并通过故事编制、通用登记和真实交接路径迭代验证。提高到 `max` 是为处理这些相互约束和反例，不以材料数量或耗时升级。按集推进存在前后依赖，当前没有相对 `max` 明确可验的自动委派收益，不选择 `ultra`，不承诺固定提速或质量提升。
- 同项目 task-id 强制前置：无，`dependencies=[]`。发布前已将最新账本与既有规划去重；执行时重新核对最新有效成果，不用已完成任务的旧工作区充当固定基线。
- 并行属性：允许。两仓各自在受管 worktree、独立测试数据库、缓存、文件写入目录和端口中准备、开发与验证，浏览器控制窗口协调使用。本任务负责准确文字和交接，其他任务的动作声音、模式输入、状态准备及通用交互职责可分开；编制脚本、准确版本和展示组件的实际重叠在集成时协调并联合复验。共享正式数据库、配置、服务、部署入口、正式镜像标签与发布写入互斥串行，不能因独立 worktree 或无前置依赖就并发正式发布。无法隔离资源或实际语义冲突不能独立收敛时，停止对应并行部分重新评估。
