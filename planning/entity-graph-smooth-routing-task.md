# 实体关系图减少交叉，并将圆角折线改为连续平滑曲线

在“生产制作 → 实体管理”按集、场、镜查看关系时，应能顺着连线准确看清两个实体的关系，线条自然舒展，不需要在交叉和阶梯状转折中反复辨认端点。本任务统一优化全部集下各场、各镜的关系图布局与连线路径，并交付到本机正式服务。

当前 AE006 / AS017 / ASH106，以及 AE006 / AS019 / ASH111、ASH112 的图中，李寄、李诞、李寄母亲和李家的关系线在李家左侧、下方交叉绕行，“一家住所”的连线需要反复追踪；多条路径仍是长直线加小圆角的阶梯折线。发布者已在正式页面逐一复现，原图和技术依据见同目录 `entity-graph-smooth-routing-investigation.md`。这承接已完成任务 20261011-0006、20261012-0005 尚未解决的交叉与曲线观感问题，不重复其已交付的完整连线和交互能力。

## 改后工作与范围

1. 保持现有集 → 场 → 镜的筛选路径及实体小卡、关系摘要。切到任意镜头后，系统自动组织节点、摘要和连线；无需用户拖卡整理、手选布局模式或展开额外信息。
2. 联合优化节点层内顺序、关系摘要位置、端口和绕障路线，使可消除的交叉尽量消除。先利用合理排布解决交叉，再处理必要绕行；不能只给现有折线加大圆角。依赖关系尽量保留清晰层级，无向关系不伪造依赖方向，环、多父、孤立节点正常呈现。
3. 直接连线与绕障连线都采用真正的平滑曲线，例如 Bézier 或样条；长距离转向应连续、舒展，多段拼接处切线连续，没有密集阶梯、小拐弯或突然折向。简单对齐端点可保留自然的直连接段；不得把大量正交线段改写成退化曲线指令冒充完成。
4. 连线与其摘要应容易对应；不同关系不得长段重合、近距离纠缠或穿过不属于它的实体卡和摘要。对复杂图中仍保留的交叉，使用清楚分离的走向，使人能辨认各自两端；交代具体残留及取舍，不虚称全图数学最优或所有复杂图必定零交叉。
5. 优化通用绘制路径，覆盖当前全部集、场、镜及后续同类数据。当前界面按准确镜头范围出图，因此全量覆盖是遍历每集、每场的所有镜头；不新增“全部集／全部场”总图，不硬编码三张反馈图的坐标或实体编号。

图的内容语义不变：全部真实实体、关系身份、端点、方向和摘要保留；不能靠删线、删摘要、过滤复杂节点、复制实体、折叠或极度缩小来减少交叉。保留单击高亮自身及直连实体和线、双击及键盘开准确大卡、Space/Esc、拖动缩放、适应全图、返回位置与焦点；单击高亮不得触发布局跳动。不恢复已删除的关系 hover。

## 实施与验证顺序

以执行时最新主干及有效正式数据为依据，在受管隔离工作区重放三张反馈图；固定同一份输入，保存旧图的节点、边、实际卡片尺寸、曲线、画布及交叉基线。先完成这些小图和一个较复杂对照图的可操作候选，看清实际曲线与交叉变化，再推广到共用实现。具体算法和代码组织由执行者选择。

从当前生产目录逐集、逐场、逐镜枚举真实图。核对请求范围与返回范围一致，不能让过期地址被恢复到默认镜头后重复计为全量覆盖。对同一数据、尺寸与布局条件运行改前、改后几何检查，完成后在 Chrome 真实观看、逐线追踪并操作代表性图。最终发布前吸收最新主干；正式数据若在并行任务中变化，更新输入并复核受影响图及全量集合，不用旧任务快照覆盖活库。

## 完成条件

- **三个明确前后例：** ASH106、ASH111、ASH112 在相同尺度下对比。改前李家周围的折线路径交叉、阶梯状绕行；改后同一组人物／住所关系仍完整，能够从实体经过摘要跟到另一端，消除这些小图中可通过排布避免的交叉，连线具有明显连续曲线形态。分别留前后截图并描述实际减少的交叉与阅读障碍，不以其中一张代替其余两张。
- **全量真实图：** 提供执行时全部集、场、镜的目录及逐图结果。每图核对真实节点、关系、端点、方向和摘要集合一致；漏边、穿不相关卡片或摘要、标签互盖、路径长段重合、自身交叉、绘制失败均为零。完整计算后再替换图；单条路线困难不能造成全图关系消失或静默跳边，新范围失败不能显示旧范围假装成功。
- **交叉有可回查的比较：** 对实际绘制曲线统计不同关系的交叉点，排除共同端点合法接触，并说明容差和重复交点合并规则；不能把靠近端点的任意交叉都排除。报告逐图改前／改后交叉数、全量总数、改善／持平／退步图数及最差图。全量总交叉数须减少；逐一处理退步图，不接受新的明显阅读退化。保留必要交叉时给出准确图、端点及实际理由，不能用平均值掩盖局部恶化。
- **曲线和布局验证：** 增加能区分真正平滑路线与圆角正交折线的有效检查，并用可无交叉排布的小图检验交叉优化。不能只检查 SVG 含 `C`。真实 Chrome 至少覆盖三张反馈图、正常对照 ASH001、旧路由故障回归 ASH012/ASH242/ASH243，以及全量统计中最复杂与残留交叉图；按实际相同图合并复查，不虚报未看范围。覆盖常用桌面宽度及窄窗口、原始大小和适应全图，实际追线、单击直连高亮、双击开卡并返回。
- **性能与稳定性：** 同条件记录代表性图和最差图的布局耗时、画布尺寸与切镜体验，不能靠无界搜索、巨大空白画布或难读缩放换取交叉减少。全量检查有界执行。正常图不得出现明显等待、跳动或画布膨胀；发现回退应先修复，不以“效果更好”抵消操作成本。
- **实际交付：** `--auto` 执行须完成受管双仓集成、必要推送、本机正式数据库／服务发布及发布后真实 Chrome 验收，按项目既有恢复验证要求留准确回执，完成本任务过程资源清理，不能只交隔离候选结项。
