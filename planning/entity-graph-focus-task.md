# 实体关系图按集场镜聚焦，去掉涉及连线并按真实关系整理布局

task-20261011-0001 已把实体管理改成关系图，但默认全部集／全部场显示477个实体，大量派生的“本镜涉及”连线构成网团。用户图5要求删除全部选项、增加镜头筛选，默认第一集第一场第一镜；去掉无价值的涉及关系，依赖尽量按层级表达。目标是让人选择正在制作的镜头，直接读懂它相关实体之间的重要关系，并能打开实体继续审阅。

## 选定方案

- 实体管理只保留平铺的“视听集／视听场／镜头”三级范围，不加全部、搜索、内容分类、分页或新的管理页。首次无有效定位时选当前编排的第一集→其第一场→其第一镜（当前为AE001／AS001／ASH001）。切集重置为该集第一场第一镜，切场重置为该场第一镜；选项按实际制作顺序，不能按字符串编号乱序。空集或空场平实说明无场／无镜，不回退全剧。有效深链、浏览器返回、重新打开已选实体保持准确范围；旧“全部”／无效定位确定性归到上述默认，不让非法上下级组合渗入图。
- 图中只呈现选中镜头自身及它当前实际关联的实体：沿镜头当前 entities／states归属／occurrences／continuity_context 等已有准确用途求集合并去重；依实际已建素材输入归属补足真正使用但上述字段没有包含的实体。不能把本场其他镜头、整集所有实体、或仅因和可见实体有关系就递归扩张的全剧节点带进来。关系只在可见节点间呈现。本轮只改视图范围，不改故事或镜头事实。
- 去掉自动派生的 involves:* “本镜涉及”边及标签，不是仅隐藏这四个字、仍画密集虚线。镜头归属已由筛选表达，不重复用网线表达。保留真实RELATION关系及其简短摘要；实体卡沿用已有卡样式并适度变窄，点击继续打开同一统一大卡。图中关系不再弹 hover 详情，既有有用途的直接点击语义可以保留，不增折叠说明。
- 只有真实有向依赖才用箭头和上游→下游分层；forward/reverse统一到正确方向后布局。同一层尽量对齐，连线不穿卡片，关系短摘要不重叠或被卡片盖住；多父节点只画一个实体。循环依赖归同一组／层，不删真边、不复制节点假装无环。无向普通关联用无箭头连线，按连通组安排清楚；与其他实体无关系的有效节点仍保留。保留已有拖动、缩放、适应全图，选择范围后恢复可读视野；不以缩成极小字换取全图塞屏。

当前正式实体对实体的147条真实关系 direction 均为related，没有一条已声明的有向依赖；“阿蘅—歌本：抄写并持有”不能因左右排布就改成生成依赖。材料间有向依赖不自动等价于其归属实体间有向依赖。本任务要正确支持有向关系布局，但不得为了演示层级给正式实体关系补造方向。普通关联的分组排列只帮助阅读，不宣称上下级。此边界是本次定义已作出的判断，不能留给执行者通过改业务数据迎合图形。
