# 以抽取 SKILL 规范实体、状态和素材需求，并逐集重做全剧抽取

本文是本次执行的完整任务定义，配套证据见[抽取调查](extraction-skill-investigation.md)。代码和数据路径以故事仓库根为基准；附属仓库 source 相对主项目根解析，不相对澄清 worktree 解析。

协调者本轮在正式 Chrome 实操确认：当前 EN012 的 ST216、ST218 在实体大卡中都显示 0 项素材，打开后只有空素材区；只读数据调查确认相关素材 M2831、M2827 分别属于 ST214、ST210。M2597“李寄 · 身份母版”和 M2544“阿蘅 · 图像身份参考”又是同一种图像身份需求，却使用不同名称。问题来自抽取方法和数据约束，而不只是页面显示。本任务升级现有独立抽取方法，按新方法重新完成全剧抽取，使每个状态有真实独立需求、每个需求只有一个制作出处、名称明确且同类一致，正式服务全部生效。

## 已确定的结果

- 升级 `method.skill.material-assessment` 为“实体、状态与素材需求抽取”，保留同一方法身份、旧评论和执行快照；明确依据、抽取必要性、命名、唯一出处、复用、新制及下游交接。当前 v7 将“无独立职责”和“无独立需求”分开判断，这一规则由本次用户决定替代：**有效实体状态必须至少拥有一项真实独立素材需求**。镜头也是实体，同样按实际制作目标判断其状态，不一律强造状态。
- 一个素材需求只能以一个实体、状态或镜头为制作出处（当前 scope）；其他对象可引用它，使用范围 states 不算拥有权。仅是表演、事件阶段、账目或连续性条件的信息，迁回对应实体、镜头、方案和关系，不保留空状态，也不为了让状态存在而复制或虚构需求。
- 在正式导入/增量发布的整笔结果上维护这一不变量。新增状态与其需求允许同笔提交；移走最后一项需求时同步迁移或撤下状态及消费者。隔离作者文件可暂存未完成工作，不新增长期草稿库、审批或产品管理页面。既有退役收据和旧执行作为历史回查，不混入有效对象数。
- 全剧重新判断对象身份、必要形态、真实制作需求、准确归属、引用及命名。不能只清理当前六条或批量改名；也不因此改写故事、小说、锁定剧本和已确认叙事意图。保留有效原件、候选、真实调用、干净母版及谱系，当前制作维持一份方案，历史候选快照不追改。

## 命名写入方法并实际统一

实体用作品中可辨认名称，重名用真实身份/地点区分。状态用“实体名 · 必要形态”，标题表达独立制作差异，正文只写实际需要的属性。需求用对象加制作职责：角色/动物/群体“图像身份参考”；空间“空间布局参考”；道具“结构参考”；状态“整体形态参考”或明确部位的“细节参考”；说话人“音色参考”；歌曲按曲名、完整演唱或具体片段/演法区分；镜头“主机位参考／首帧／视频”；字层工程写明实际交付目标。编号独立展示，沿用稳定 EN/ST/ASH/M 身份，不因改名换号。

例如 M2597 改为“李寄 · 图像身份参考”，M2544 保持“阿蘅 · 图像身份参考”。“母版”是准确原件的质量/谱系事实，不混为需求名称。当前 title、输出名称、列表、详情、引用卡与 Prompt 链接名一致；历史候选提交时旧名、旧评论摘录保留。内部标识无必要不迁移，系统检查确定的一致性，不用中文正则代替创作判断。

## 依据与真实工作顺序

按 AGENTS、`production/managed-methods.md`、`production/professional-methods.md` 和适用影视知识执行。[调查附录](extraction-skill-investigation.md)列出了准确样本、历史任务分工、协调者页面实操及数据查询边界。调查时为 17 集、42 故事场、65 视听场、344 镜；有效普通实体133、状态87、需求1291（891图像/45音频/344视频/11工程）。以执行时正式当前头重核，不把数量不变作为目标。

1. 从执行时两仓最新主干和正式一致性副本开始，核对源锁、前置已交付事实、现有评论及全剧分母。沿受管方法保存新版、显式绑定并由真实作者入口取得全文，禁止修改初始化 JSON 代替正式方法生效。
2. 用李寄 ST216/ST218、阿蘅湿袖 ST092 与仅湿鞋 ST093、洞闸 ST120/ST122、米袋、湿浆、歌曲/声音、镜头及字层走完“读原文及消费者→抽取草稿→实际回读→检查修订→结果”。需要判断原件复用时实际看图/听音，不能凭名字代替。先用这些可操作样例验证方法与数据/页面交接再扩全剧。
3. 按17集顺序阅读准确原文和前后镜，逐场判断抽取并回读、修订，必要时回修前集。脚本只整理真实判断及结构检查，不一次填表后补写过程。对新增、保留、归并、撤下给出能定位的真实依据，最终交付覆盖整剧，不停在样例。
4. ST216若与ST214共用同一净布旧痂形态，其换布时点、战后余疲、夹筷迟缓进入准确消费者，不能在换布前用净布。ST218若沿ST210血布，则放刀后膝软、手指难伸、阿蘅扶臂进入镜头，不能提前举刀时倒下。其余空状态 ST250/ST264/ST284/ST287 同理按湿浆身份、退米后袋形、蛇伤深浅实际需要处理；不得为维持编号机械补图。
5. 更新全部当前引用、关系、状态选择、图像/声音方案中因抽取发生的变化与真正编制源；保住身体湿区、伤口部位、道具归属、声音状态等有效差异，删除模板套话。全剧视频正文重编由后续任务承接，本任务必须交付准确、可消费的当前状态和引用及必要语义迁移，不留断链等待后续兜底。检查旧脚本和恢复入口不会重生退役对象或旧命名。
6. 同步受影响文档、方法共享资料和系统校验，完成全剧回看、隔离真实 UI、受管集成及本机正式增量发布、正式只读验收、导出空实例恢复和过程资源清理。
