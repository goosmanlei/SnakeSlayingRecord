# 在参考素材小卡中预览并选定当前方案所用候选

## 原问题与改后工作

用户图 4、6、7：M2974 首帧和 M2714 湿衣方案的参考素材都只写“尚未选定原件”。这里用户真正需要完成的是：为这个生产用途选定上游素材的哪一个候选。当前小卡没有候选列表，无法就地看图和选择。

改后在当前方案的直接参考小卡内展示候选列表：图片候选 hover 或键盘聚焦即可看准确图片预览，点击候选就保存本方案这个输入位置的选择，并用对勾及选中色清楚显示。没有候选明确显示“暂无候选”；有候选未选显示“请选择候选”。只展示已存在的候选，不因为仅有一项或最新候选而自动选择。素材名/查看入口仍可打开详情，预览、比较和打开不改变生产输入。

## 具体交互与保存边界

- 保留现有双列参考卡的素材身份和名称，卡内用准确候选编号列出可选项，较多时自然换行且全部可达；窄屏可以单列。删除笼统“尚未选定原件”，不恢复旧关系摘要浮层。此处空态是生产输入选择的必要反馈，不改变素材详情顶部“当前方案 | 候选”的既有空态约定。
- hover 预览在指针到达或键盘聚焦对应候选时出现，移开/离焦/Esc 可关闭，不挤动布局、不挡住其他候选而阻碍选择。图片按比例显示，读取失败可重试且不串图。触摸设备提供同等可操作的预览入口；键盘能预览、选择和退出。
- 一个候选只有一个有效 original 时点击即保存，不另开大卡后二次确认。重复点击已保存的同候选、同原件为无变化操作，不重新写入、不清除已有 crop/range；只有实际更换候选或原件时才按规则处理旧范围。保存成功后稳定显示对勾；进行中给局部反馈，失败保留原选择并说明原因/可重试。候选含多个原件时就在卡中明确展开原件选择，选定具体原件后才保存，不能默认第一个；预览文件与 metadata 不能作为生产输入。
- 复用已有 POST /api/production/shot-reference 契约：消费需求 + 输入槽位 + input_key + expected_content + 准确 candidate/component；名称含 shot 不限制为镜头需求，普通实体/状态素材同样支持。更新消费方案唯一当前稿，保存后承接新并发标记。不得改变上游素材、同素材其他输入槽或其他消费者，不新增“全局默认候选”。
- 已有图像裁切和音视频时间范围继续可见，沿现有详情编辑范围；更换原件不能携带上一原件范围。验收重复点击已选音频片段仍保持原范围。声音/视频的候选列表和选择语义相同，播放由显式操作触发，hover 不自动发声；工程/非图像候选不造图片，使用实际媒体可用的查看方式。
- 历史候选中的实际输入按提交快照只读，不能给可改历史的选择；间接上游引用保持只读并可定位真实拥有者。明确无候选、文件不可用、不兼容、加载失败之间的差异；失败不伪装成空列表，不静默回落最新原件。
- 按可见需要取得候选摘要与缩略图、复用已有加载；不因为十张参考卡就预读所有高清原件/完整历史。保存响应绑定原消费者和槽位，连点、切素材、关窗及迟到响应不覆盖别处或遗失已成功保存结果。
