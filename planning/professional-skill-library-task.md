### 按真实工作逐步编制与实用

1. 先列各工作实际收到什么、交出什么，以及上一阶段未完成时不能替它猜什么。以既有工具和资料核实这一交接，不从理想流程虚构现有能力。
2. 先完成一个自然连续场的试用链：理解准确文本→选择适用原理→形成视听表达→判断必要素材→读取手册并选择方式/模板→转成当前镜头方案/Prompt→连看检查。每一步保存当前结果并重读，再进入依赖它的下一步。用真实发现改方法，然后扩大到不同性质的场景；不一次生成全部方法及示例后补写试用经过。
3. 视听方法要求先理解全剧，再逐集、集内逐场推进，集末复核人物选择、信息、空间、道具、声音和节奏，认识影响后集，必要时回查前集。专业选择说明适用原理、具体条件、方案与检查。允许有依据的变通，不把十二章变为每镜必填表。
4. 素材方法先实际看图、听音或检查相应原件，再比较复用、编辑、新生成和无需单独素材的路线；名称、元数据、使用次数不能代替内容判断，没有听看能力时保留未验，不虚报通过。完整状态描述同一时刻共存的特征；动作不自动变新实体或状态。需求服务一个可说明的生成或审阅目的，不默认每状态一图、每镜两图。准确参考、旧候选和真实调用区分，不能靠卡片层数推断图像代数，原件既有认可不自动转授新用途。
5. Prompt 方法先读适用手册，判断当前镜头的起点、变化、落点及观众要理解的内容，再选择生成方式与模板、核对当时能力和实际参考，最后用模型友好语言表达。给制作者的说明与真正发给模型的 Prompt 分开；不可机械拼整场动作、把修订哈希和检查待办全塞给模型，或删掉为理解动作所必需的声音、空间与顺序。
6. 发声先区分已锁定对白、仅给语意的叙述性发声、未定歌词/句段及非语言声。方法明确哪一阶段负责拟定表演原词、怎样形成准确可审阅候选及何时才可用于生成；不能擅造“已经锁定”的台词，也不能因原词未定漏掉必须发生的道谢、读回或画外回应。
7. 将这些方法接到实际操作绑定。补足现有后台创作检查点、独立读者和媒体准备/适配入口与统一方法契约的必要连接；不为本来只保存候选的工具增加模型调用。图像/视频模型继续只接收其需要的 Prompt 和准确媒体，技能是上游创作者及执行者的工作依据。未配置、不可读或不匹配的方法不能在受管新流程里静默略过。
8. 使用独立前向试用：执行者只拿真实工作请求、准确材料和适用 SKILL，不拿标准答案、待修问题清单或根结论。至少覆盖一个未作为答案提供的对话/信息连续场和一个空间/动作连续场，另检查声音或文字的特殊要求。比较实际产物与准确源文，指出方法帮助了什么、仍造成什么遗漏，收窄改进后复用。只验证模板格式或复制测试答案不通过。下述 166/170/174/179、230/233 等已知案例用于回归，不作为答案交给陌生场独立试用者。

只有加载和阶段回执时，仍只能证明方法交付与先后；作品是否正确须对照实际源文与产物，媒体适配须有相应原件检查。未知保持未知，但应给出明确下一步。沿原最终可见报告，用真实工作前后例子说明方法帮助了什么、仍缺什么，不以包数、章节数、字符数、模板校验或未发生的生成替代效果。正式交付、准确历史、恢复、共享发布窗口及资源清理继续按原任务执行。

## 可验证的完成标准

1. **方法可直接接手工作。** 从系统配置中能找到主要工作对应的方法；另一 Agent 通过支持入口加载准确包，可以按步骤完成一个自然工作单元，知道输入不足时缺哪项以及应返回哪个阶段。旧成果没有方法记录继续标未知，不能批量贴标签称已重做。
2. **知识跨场景共用而不泛滥。** 连续性知识同时服务视听设计、首帧/视频方案及审片；声音章节按角色、声源和表演问题调用，视频手册按当前方式和模板调用。普通小说段落或评论措辞不被迫带整本生成手册。共享章节改版能沿基础契约准确追溯，不产生多份相互竞争正文。
3. **阶段错误能被方法发现，正确反例保留。** 用准确旧剧本作回归样本：166 尚无抄件，170 才抄写分存，174 先带抄件，179 才核原件；230 取三册，233 回答陶伯才指年份。方法必须先确认阶段再选约束，不能只全局删除“抄件/指年份”。母亲隔门回应仅需声音与后显人物需要视觉身份应分别判断。必要复述、等待和人物犹豫不能被统一去重或提速。
4. **有陌生样本的真实行为证据。** 独立试用使用未作为修复答案提供的连续场；留下实际阶段产物、发现和修订，能够核对先后及相邻关系。加载记录证明用了哪份方法，作品检查证明是否正确应用；不索取或保留内部思维链，不用“已读/已完成”标签冒充理解。列明这些小样不代表全剧通过。
5. **入口、恢复与历史可信。** 新后台工作和受管生成准备能实际关联准确 SKILL/共用知识/项目输入；中断后按原快照恢复，变更方法需检查受影响步骤。独立读者不偷看未读后文，评论润色不新增创作要求，生成仍受准确参考、输入锁、采纳及授权约束。不得通过新方法绕过这些既有保护。
6. **交付完整而不越界。** 正式配置和原方法阅读入口一致可用；方法包及资源可导出/恢复，相关契约有必要回归，最终在对应版本隔离环境真实使用并正式只读回查。此次不重写已确认故事小说，不一次完成全剧，不发起收费媒体调用；真实听看、静态检查、受控调用和未验证效果分别报告。资源清理有准确数量、范围、回读与保留用途。

### 最终可见报告

每次完成、暂停或失败的最终可见回复，开头给任务号和实际解决的问题；用具体工作前后例子说明方法现在怎样被使用、实际减少了哪种遗漏及仍有何限制。给出真实试用环境、产物和反例，不以 SKILL 数量、字数或测试数代替效果；明确未完成事项和下一步。失败或暂停同样如实说明已完成与受阻部分，不能把计划、加载记录、模板校验或受控调用写成作品效果已经通过。
