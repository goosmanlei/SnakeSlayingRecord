# 核查全站素材参考合理性，明确当前依赖与已有候选复用

## 原问题与改后结果

用户图5：M2669 阿蘅音色当前方案出现同名 M2669 参考卡，要求梳理全站所有素材的参考关系合理性。任务须逐项核查有效素材的参考目的和准确来源，修正真实错误，使创作者能分清“尚待准备的上游素材”与“本方案复用的既有候选”，同时保留真实历史。

发布前已确认：正式 M2669（material-voice-a-heng）method=reuse，引用既有 asset-fg3-aheng-voice-01 的 original、0–5.6秒，该原件旧编号 M1134，现归 M2669 候选2。它是同素材已有候选沿袭，并非 REQUIREMENT 直接等待自身生成。desk/docs/current-materials.md 明确允许有证据的已有候选沿袭；不能按同 M 编号批删或全禁，也不能据这一例推断全站合理。

## 已定处置原则与完整范围

1. 从执行时真实有效全站素材开始，覆盖九类素材的每一份当前方案、有序输入及实际关系/消费者，不限截图、首集或有候选项。先按规范唯一素材身份统计有/无当前方案、零输入、待准备输入、准确原件输入，再对每个输入逐项审查用途、状态/阶段、上下游方向与适配性。脚本列举与图校验辅助审查，不能代替逐条语义判断。合理项也有紧凑可核对的依据，完整覆盖清单不得只列异常。
2. 分开检查稳定业务关系、当前计划依赖、已选执行路线与候选真实输入。错误当前自指、真实跨素材循环、悬空/退役目标、候选所属不符、原件组成/哈希/范围错误、错误重复以及无当前生产用途的引用均给出判断和处置。仅共享同一实体、同一 M 号或关系图上存在环，不自动等于执行闭环。
3. 经候选归属、准确修订、原件存在/哈希/组成/范围校验通过的已有 ASSET，才可作为执行依赖的原件终点；有缺口则保留准确历史并阻断受影响输入。可证明的本素材旧候选复用或修订保留。当前执行路线才参与阻断，未选的 optional/conditional/one_of 分支不能误报当前循环；未选候选/尚未生成如实作为准备缺口，不通过选第一项、虚构原件或自动生成消掉缺口。
4. M2669 当前界面改为清楚的“复用来源：本素材候选2 · 0–5.6秒”（同等清晰表达可），点击打开准确候选及片段，关闭回原当前方案；不再呈现成等待同名需求生产的依赖。该表达用于同机制合法沿袭，普通跨素材输入仍保持原名和准确候选。复用来源由真实方法/输入决定，不能只依名称猜测；不新增伪素材来消除同名，也不添加技术关系日志到创作页面。
5. 逐项核对该音色片段是否符合其当前“复用声音身份”职责；实际听已有原件并核对范围与下游用途，不能把候选自检或数据库记录当听审结论。全站其他素材按用途读取必要正文/原件，报告实际看听范围。这里只修参考关系及必要当前用途说明/受影响引用，保持已锁故事、人物设计与全剧制作正文；无法由现有依据作出的实质创作新选择明确列待决，不虚称全量完成。
6. 有据的当前引用/关系错误在隔离库形成最小增量修正，并完善共同写入、导入、readiness/执行包与恢复的确定性校验，防止同类错误再次进入。历史真实候选、当时 Prompt/参数/输入快照、原件、调用与意见保持原貌；发现历史不一致时保留事实和准确缺口，不能重写成今天正确的方案。合法同素材旧候选和正常跨素材引用必须继续通过。
