# 状态只保存实际制作信息，解除固定维度必填并清理当前方案套话

本文的 EN 表示实体、ST 表示实体状态、M 表示素材需求；Prompt 是实际交给生成模型的提示词。正文规定执行目标，全部条款均属任务要求；调查来源、准确版本和媒体判断见[输入交接](state-contract-followup-inputs/README.md)。链接相对所在文档，代码路径相对故事仓库根，仓库 source 相对主项目根解析。

人在实体大卡判断北端洞闸能否作为镜头参考时，需要知道闸已提起、木栓已抽出、南投食门关闭。当前 ST122 还要求人读“完整形态如上；材质、颜色及未写磨损细节待审”“组成与内容以上述描述及引用正文为准”“持有者与位置依本场引用和动作起止”等三段泛泛说明；同样内容又进入 M2736 当前生成 Prompt。ST240 旧灯及 M2857 也有这条传播链。它们不能帮助判断这一状态，还把人的待办和泛指带给生成模型。

这不是只删页面文字的问题。通用状态契约仍按类型要求填满道具 4 项、人物 7 项、空间和歌曲各 3 项维度。保留完整、明确的状态正文，删去无作用的维度后，现有校验仍以 `condition must be nonempty text` 或 `injury must be nonempty text` 拒绝。ST092 湿袖的页面正文具体可读，底层却把同一湿衣段落复制进伤势、健康、疲劳、附属物等字段以满足契约。

改后，一份状态用一份独立可读的当前描述讲清身份、此时实际形态及必要差异；只有真正用于业务的结构化属性才保留。AI 不必填“如上／依场次／待审”来凑字段，人直接阅读必要状态与对应素材方案，模型收到可执行的当前约束。保持状态及素材的稳定身份、唯一制作出处、准确输入和历史候选，不借简化改变已经确认的故事或生成事实。

## 已定改变与范围

**复用现有状态描述，取消固定填满要求。** 通用导入、编辑、读取、导出和恢复均允许实际完整正文配合按需属性，不按实体类型逐项强制无关维度非空，也不通过省略 `state_model` 绕开校验。不新增状态种类、字段管理页或审阅步骤。已有有用属性中的独有内容须继续可读、可消费，例如 ST093 的嗓音劳累及“未确定是否完全恢复”，不能因页面原来未展示就删掉。状态仍须属于准确实体，有有效故事依据和实际制作职责；全空描述、失配引用及不合法输入继续拒绝。

**修当前数据与作者入口，使内容不再反弹。** 在当前状态和受影响当前需求中，将有意义的完整形态、结构、开合、干湿、发光、声音和阶段条件收敛到实际使用位置；从正文、冗余维度、方案说明和 Prompt 中清除专属占位及重复。可执行 Prompt 只承载本次输入真正需要的确定内容。已有依据能决定的制作选择由 AI 做成具体方案；真正会阻断生成的未知进入既有准备缺项，不向模型下达“待审”指令，也不能为通过准备擅填新事实。只删字符串或只隐藏页面均不算完成。

当前精确三句匹配命中 **24 个状态／87 个有效状态、18 个需求当前 Prompt／1291 个有效需求**，清单在[证据附件](state-contract-followup-inputs/state-contract-followup-evidence.json)。这表示调查范围，不是 42 项可无条件删除的结论。先完成下列三个样例，再逐项处理这 42 个对象及已证实由同一原因影响的直接消费者、当前方案说明和写入来源；保持必要条件，记录保留或修改理由。ST092/ST093 的重复维度是另一个已证同因样例，纳入处理。执行时重核最新身份；新发现只在有共同原因和具体影响时扩展，不全剧重做、不重新清查全部状态是否存在，也不设减少数量或字数目标。

当前七个制作方法没有这三句，`image-plan` 和 `generation-preflight` 已要求 Prompt 只含必要内容，不能宣称新 SKILL 已被证明制造了套话。核对真正使用的作者契约、模板、实际绑定及读写路径：凡仍强制固定维度或把通用检查直接拼进模型输入的有效入口须同步；历史不可变方法、候选与执行不改写。当前编制不再调用的旧函数不因此重新启用。方法更新沿现有唯一入口并实际取得、应用，不增加事后填写的步骤。

## 完成条件

1. **真实读写与方法应用。** 使用既有生产写入／导入路径，在隔离环境保存上述道具、人物完整简洁稿并读回，在真实 Chrome 走状态→素材当前方案→准确参考→返回；更新现有拷贝和创建隔离测试状态均覆盖，新建测试状态不进入正式库。不需要凑齐无关维度，不增加折叠和新的表单步骤。对空间、歌曲和自定义类型验证同一按需契约；有用结构化属性继续工作。空描述、无效或失配实体／故事依据仍拒绝。实际从适用方法 begin/read 开始写一个样例、保存并回读，证明不是仅修改文档或页面过滤。
2. **当前内容清理完整且有界。** 核对调查清单与执行时当前稿，逐项记录实际改动与必要保留条件；命中内容如因最新交付已修好，给出当前证据。页面、API 正文、方案说明及实际准备的 Prompt 均不再有本任务认定无价值的填充。保持 ST122/ST120、ST092/ST093、ST240 未亮母版与点亮状态、ST292/ST361 的必要差异。没有无依据新事实或范围外重写；真实缺项不被抹除。
3. **历史与准确性。** M2736 候选1的真实局部修订 Prompt、M1558 旧原件，M2857 候选1的当时 Prompt／参数／M1135 输入，及其他保留候选快照、原件、调用、原用户意见逐项前后核对不变。历史中即使有套话也保持当年事实。当前内容原地维护并使用现有并发保护，不产生新素材、候选、重复出处或制作版本树；原评论仍能定位原摘录，不能漂移到改后文字。读取失败、准确目标缺失和连续切换的迟到响应不能串对象或丢原意见；解除故障后重试、刷新、重开，仍能回原状态、原候选和原摘录。
4. **发布和恢复。** 准确增量验证并发前进拒绝、事务失败回滚和同包重复执行幂等；另模拟写入成功但回执中断，先从新连接查询实际结果，再沿原包恢复，不重复新增或回灌旧快照。范围外新评论及其他在途内容保全。最终受管导出在新空实例恢复后重新走三个样例、一个正常对照及当前／候选切换，旧套话不因旧来源重新导入当前稿。两仓准确候选、实例引用、正式库发布和本机 3000 服务身份分别可核；发布后真实 Chrome 只读复走，不能以测试通过或候选交付代替正式效果。
