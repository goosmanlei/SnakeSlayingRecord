## 任务目标

依据本说明的七项要求及随任务保存的三张原图，优化“制作设定 → 制作拆解”的完整逐镜阅读流程：分集卡与剧本创作一致，左侧场／镜两级目录可快速定位，正文删除冗余说明及素材归属筛选，镜头标题旁可查看并高亮准确剧情依据，右侧使用统一紧凑素材小卡并按实际类型分组。

1. **统一分集菜单。** 复用“故事创作 → 剧本创作”的分集卡结构、选中态和横向溢出行为，显示集编号、标题、场范围与评论数。截图 01 中的 `E01`、`S001–S002`、“两份米”和“评论 0”用于说明结构，不硬编码示例。拆解页评论数按本集场与镜的准确当前修订汇总，包含已关闭评论，按评论 ID 去重，不含删除记录或编辑／状态事件，不混算原剧本及素材评论；历史准确视图按实际展示修订计算，不能套用最新版本计数。
2. **增加场／镜两级目录。** 左侧以场为一级，场内镜头为二级，按本集场序、场内镜序排列，初次进入默认全部展开。沿用稳定的 `E / S / SH` 编号及标题；点场定位场开头，点镜切至所属场并滚到对应镜头，标题不被固定顶栏遮住。目录显示当前位置，切集、跨场跳镜、刷新、历史准确链接及关闭弹窗返回后保留正确对象、修订和阅读位置；不将同名镜头或新镜序当作旧引用。
3. **精简正文顶部。** 删除截图 02 所示重复场景／时段行，以及“已按版本四完整检查本场 32 个正文块。画面、声音与仅提及分别登记；未指定造型作为制作选择审阅。”这类过程说明及其空框；从页面渲染中移除，不用隐藏样式保留空白。保留场编号、标题、必要剧情依据入口和逐镜正文。删除界面元素不清除既有场景元数据、制作说明修订或评论；旧说明上的评论仍可经准确历史入口定位，不转绑到其他正文。
4. **移除素材归属筛选。** 删除截图 03 的“素材归属”标签及剧、集、场、镜、状态等全部归属筛选按钮，包括实际出现的实体按钮。取消该页隐藏筛选条件，旧内存或恢复状态不得继续限制素材。右侧列出本镜已有明确关联的素材；剧／集／场／镜／实体／状态归属仍保存在数据中，不因取消筛选而把整场或全剧素材塞入每一镜。
5. **准确展示本镜剧情依据。** 将“查看本镜剧情依据”移到镜头标题旁。与场头“剧情依据”共用同一阅读弹窗，打开该镜锁定的剧本版本、该场的完整正文，再以本镜记录的准确正文块／范围高亮并定位，不只显示抽出的片段，不按关键词猜测，也不回落到最新剧本。多个不连续依据均应高亮，其间正文仍保留；缺失或失效引用如实报出，不能任意高亮其他文字。关闭后回到原镜头位置，已有评论草稿和媒体上下文保持正确。共享引用接口的改动保持其他剧情依据与真实生成输入的准确语义。
6. **统一并收窄素材小卡。** “本镜素材”复用 `task-20261005-0003` 为素材管理页确立的同一小卡组件、信息结构及打开大卡交互，不复制页面专用卡片。小卡收窄后同步缩小右栏，让镜头正文获得更多宽度；不把素材管理页的三列或分页布局搬到逐镜右栏。桌面记录改前／改后实际栏宽，小卡内容、编号、预览与点击区域完整可用，窄屏无横向溢出。关闭大卡恢复原镜头、滚动位置和评论草稿；准确版本或候选链接优先于默认选择。
7. **按实际素材类型分区。** 以媒体类型与已有实体类型／制作对象归属组合分类，设置清楚的分区标题，可辅以图标；“图像—角色、图像—场景、图像—道具、音频—角色、音频—场景、音频—歌曲、视频—镜头”是参考分类，不是穷举或必须存在的分组。依据真实对象关系归类，不从文件名猜测；无数据的分区不显示。同一真实素材在同一镜只列一次，多实体或多状态关联继续可追溯；存在多种归属或无法可靠分类时用准确的共有／其他分类，不伪造唯一实体。分组前后已关联素材集合一致，未生成需求仍可识别，无素材显示恰当空态。

范围以制作拆解页为主，共用导航、卡片、剧情依据弹窗、读取接口及必要实例配置随之适配。Notebook 中的实体／素材管理三列分页、大卡重设计、镜头制作页的版本平铺、Prompt 标题、参考版本／候选选定和生成门槛分别由其他任务负责，不在本任务重复实现；改到共用实现时验证这些页面没有回退。保留真实调用、原件、历史修订、评论、采纳及采用关系，不新生成素材或改写剧本。

在依赖完成后的准确代码与数据上建立基准，使用双仓独立工作区及隔离预览库完成实现、真实浏览器验收和可审阅候选。正式资源操作另按最终候选确认及项目流程进行；不能用隔离快照覆盖正式活库。交付范围、变更、验收结果、准确候选与恢复方法应独立可读，并按项目规则清理本任务已无用途的过程资源。

## 可验证的完成标准

1. **需求覆盖与输入。** 七项原文及三张图片逐项对应实现位置和证据；附件字节、像素及哈希与本说明一致，执行者可取得原件。交付中没有把本次澄清、静态检查或历史测试当作新功能已完成。
2. **分集卡与计数。** 与剧本页并排核对外观、集编号、标题、真实场范围、评论数和选中态；覆盖首／末集及多场集。用隔离评论验证新增后计数增加，编辑、关闭、重开不重复计数，删除后按现有删除语义更新；共享引用不重计，切准确历史视图不混入当前修订评论。
3. **两级目录。** 全剧已发布场镜按各自准确归属均能找到，初始展开；真实浏览器点击同场镜、跨场镜、切集、刷新、准确历史链接和浏览器返回，均定位正确且标题无遮挡。快速连续切换不出现迟到响应覆盖新选择，目录选中项与正文一致，弹窗返回后阅读位置稳定。
4. **文字及筛选删除。** 截图 02 所示重复位置／时段行与过程说明框不再出现在该页，截图 03 的归属标签和全部按钮不在页面结构中，没有空框或空白占位。取消筛选后，对照原全选状态逐镜核对素材集合一致；先保存局部筛选再更新／刷新等旧状态恢复场景不再漏素材。原数据和旧评论仍能准确追溯。
5. **剧情依据。** 镜头按钮位于标题旁，与场头入口打开相同准确版本和场次的完整正文。本镜引用的首段、末段和不连续多段准确高亮并定位，其他段落可读且不误亮；准确历史镜头使用锁定旧版。失效、缺失引用明确显示原因，不静默降级。关闭／Esc 返回后原镜位置和评论草稿保留，其他参考入口不回退。
6. **小卡与栏宽。** 与依赖任务完成后的素材管理页核对确实共用组件、结构和交互；素材、编号、预览及准确大卡目标一致。桌面同视口给出前后右栏宽度与正文可用宽度，达到右栏收窄、正文增加的目标；长名称、缺预览、未生成、单／多素材和窄屏均可读可操作，无横向溢出或文字遮挡。
7. **素材分类与完整性。** 用包含多媒体／多实体类型的镜头逐项核对分区、顺序、唯一素材数和准确 ID；全剧逐镜比较分类前后素材集合，无新增无关素材、漏项或重复计数。共享、多状态、多归属、无明确类型和空列表均有正确表现；不存在的实际类型如需构造验证，仅使用隔离测试数据并与真实覆盖区分。
8. **联合回归与交付。** 真实浏览器覆盖制作拆解主流程，并回归共用受影响的剧本页分集卡、素材管理小卡、实体／素材大卡、镜头制作、剧情依据、评论定位／草稿／快捷键和媒体预览。按实际改动补充必要接口、历史与导出恢复检查；浏览器受阻不能用接口或静态通过代替。交付准确双仓候选、逐项结果、缺口及恢复方法，最终候选确认后才按序集成、正式应用和推送。
9. **资源收尾。** 核对资源归属和其他活跃任务引用后清理本任务无效临时库、服务、缓存及重复文件；报告实际范围、删除数量、回读结果和仍保留项的用途／移除条件。原件、必要证据和有效恢复资料保留，未验证项不计通过，不把技术验收当作用户接受作品或素材。
