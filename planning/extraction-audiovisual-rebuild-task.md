# 用一至三轮提取与视听设计，重建全剧制作内容

在 task-20261015-0001 正式清空全部制作层后，应用0010最终正式方法，联动重做全剧“实体／状态／素材提取”和“视听设计”，优化镜头拆解、表达、状态及素材需求。不是把旧344镜重新填满字段；镜数、视听场数、状态与需求数量均由真实叙事和制作职责决定。完整原始要求及任务链见 `production-restart-plan.md`。

## 作品依据与工作范围

保留 `production/source-lock.json` 锁定的剧本版本四、故事结构与小说；故事17集边界和准确剧情、人物关系、对白／歌词原词不擅改。可重组同集内视听场，拆并镜头、调整调度与声画表达和合理时长，不把旧视听切分作为输入锁。当前源正文及用户意见、010的 `samples/material-assessment.md`、`samples/audiovisual-scene.md` 和 `samples/prompt-constraints-preview.md` 是阅读依据，样例自身未定原词／时长不作为已批准决定。

覆盖全剧普通实体（角色含群体／动物、场景、道具、歌曲）、完整有效状态、镜头实体、唯一素材出处、关系、用途及所选依赖路线。所有制作对象均从保留的锁定剧本重新建立，包括视听集／场／镜及其新实体、状态、关系和需求；不能导回旧对象、沿用旧身份或复制旧正文改名。编号按现有机制新建，不重置计数或重用退役编号；新对象通过准确剧本来源建立关系，旧文字意见保留原归属，不迁给新设计。只复用保留的作品事实、方法及文字意见，不沿用旧制作结构或旧方案。

## 一轮如何推进，何时停止

先核0001正式清空回执及当前有效恢复入口，确认制作对象、方案和候选全集均为空；从锁定剧本实际走通首个新建链路，再覆盖全剧，不从旧作者检查点接续。最少完成一轮、最多三轮。一轮包含：理解全剧与准确方法 → 从原始剧本建立视听设计与拆镜 → 联动提取实体、完整状态、素材职责及关系 → 连读镜头并将空间、动作、声音和交接决定反馈到提取与设计 → 逐集、全剧复审。必要基础实体可先提取，两项工作交替反馈，不能把旧视听编排作为起点。共享实体先建立可靠定义，再随集推进校正；不是先批量生成全稿再补造逐步记录。每步取得真实方法包，按该包阶段保存、实际回读，再开展依赖步骤；脚本只整理作者已作出的决定。

首轮必须完整覆盖全剧。轮末列出具体残留及对叙事、连续性或制作可行性的影响；只有仍存在会改变拆镜／设计／提取的实质问题，才进入下一轮。后续轮继续全剧检查，重点修问题和受影响上下游，无问题处不强行改写。最后一次改动后须回读涉及集场及跨集关系，并完成全剧一致性复核。所有关键问题解决时可在第1或第2轮结束；第3轮后仍有关键缺口则任务未完成，保留准确问题及所需决定，不自行开启第4轮，也不把缺口交给下一任务猜。

重要设计沿 `production/filmcraft/README.md` 查适用原理，尤其分镜覆盖、调度、表演、剪辑、声音与动画；镜头时长和实际可制作性沿 `production/seedance-video-handbook.md`。先按信息、行动和关系变化决定拆镜，再检验空间、主体、动作负载、自然发声及前后接续，不按台词行机械切分或以减少镜数为目标。

每镜须讲清观看目的、初始可见条件、关键行动／反应、声音、终态及相邻承接；起点容纳第一个必要动作，不能提前完成动作。全镜持续条件与镜内变化分别明确；物件同形制与同一实物、持物／接触／出入画、声音身份与剧情表演不混淆。状态只有真实独立准备职责才新增，基础身份／音色直接归实体，动作与普通转手优先由镜头承接；每个有效状态至少有一项唯一归属需求，类别按职责而非填满九类。

对白／唱句保留准确原词、发声者、发生次数和重叠关系。剧本只写语意的地方，优先用不新增台词的合法表演／构图方案；确需新增原词且会改变锁定作品时明确提出准确待定内容，不编造定稿。以自然读演、空间草图或必要低成本预演检查高负载镜头，记录何者只是时长预算；本任务不提交图像、声音或视频生成。
