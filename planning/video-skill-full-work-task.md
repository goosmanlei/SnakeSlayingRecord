# 以视频生成手册完善镜头视频 SKILL，并逐集重编全剧视频 Prompt

本文件是本任务完整执行与验收正文；[调查与完整可读样例](video-prompt-skill-investigation.md)为必要证据。Markdown 链接相对所在文档，代码与数据路径相对故事仓库根目录，附属仓库 source 相对故事主项目。Prompt 指提交给生成模型的文字指令，SKILL 指执行者实际读取并应用的工作方法。

当前已有 `method.skill.video-plan` v10，但全剧 Prompt 仍主要由旧片段拼接：ASH009/M2999 同时写“固定”和“同侧跟随”；ASH002/M2978 将唱句、接唱扑空、尾腔分成重复声音段；M3974 把 S026:4 等内部来源论证发给模型。本任务将现有视频 SKILL 编成可实际执行和自检的方法，依据它逐集、逐场、逐镜重写全部当前视频 Prompt，正式服务生效。只改 SKILL、加标题或替换共同前缀均不完成任务。

## 已定方法与内容结果

沿同一 video-plan 方法身份升级，保留旧评论、准确执行快照和绑定语义。`production/seedance-video-handbook.md` 是专业方法唯一正文，SKILL负责实际工作顺序、输入、产物、自检及按需加载准确模板/案例，不复制一套冲突手册。同步手册项目接入中“方案变化建立新版本”的旧条款：当前方案原地迭代，真实候选保留当次输入/参数/Prompt快照。

按手册组织“目标—参考职责—起始空间—连续事件与镜头—声音—必要约束”。自然先后可代替机械秒数；不强制每镜相同八标题。动作、对白、反应、运镜和落点应为一段可演的连续过程，句子只出现一次；参数留在参数字段，制作来源、内部编号、检查报告和待准备说明不塞进模型正文。模式和准确输入先决定再写 Prompt；普通参考不是固定首帧，不能靠一句话伪装端点控制。

引用按真实附件顺序安排，@图片/@音频编号与当前输入一致；界面显示可点击素材名称，实际提交能准确解析回候选、组件、裁切或音频区间。关系约束融入本镜所需表现，不整段搬运关系说明。语气、原词、换气、听者反应、声源远近和无声条件按适用声音方法处理。缺失准确词句或原件不捏造、不悄悄放行。

- M2999：原稿固定/跟随冲突，三句对白分散。改后按实际机位和参考明确选择一条相机路线，例如同侧随两人让到檐外后停成双人中近景。依次扎袋、走到檐外、李寄凑近歌本说“最后那段，你还得看词呢。”、阿蘅答“晚些你陪我一起练。”、李寄说“好啊。”，保留自然反应；米袋仍归阿蘅，交本留给下一镜。附录完整调查示例不是可直接发布的定稿，执行时看听准确参考再调整。
- M2978：把归家唱句、老汉刚起“二道——”后改口“哎，到了？”、阿蘅忍笑收住尾腔写成完整表演；尾腔是延续而非重唱。连读ASH001→002→003，不能补唱二道滩或提前下一镜完整打趣；实际试听旋律/声线、自然读唱后估时，缺原件照实保留。
- M3170：保住先第二笔再圈两笔，标题不算第三笔；只留本镜可见账页、手笔遮挡、动作、机位和纸笔声。字层沿准确工程和揭示时机，不将阿蘅白日工/母亲照护等镜外制作说明发送模型。
- M3974：内部 S026/S037/S038 来源论证回归依据；模型正文只表达原记工纸留证、新清账凭据此时递来等真正需要的物件与动作。最后一行读回原词未知时，不能删掉该事件或编台词来宣称已就绪。

## 真实工作顺序

1. 依赖 `task-20261012-0009`（本轮全剧实体、状态与素材需求抽取）正式交付，再吸收最新两仓主干并从有效正式数据建立隔离实例。核对剧本锁、各镜目标、状态和输入、旧意见。故事结构/小说/锁定剧本不重写。
2. 先完成上述对白、演唱、字层三类样例，从真实作者入口取得新SKILL及准确资源，读整集、自然场、前后镜和所需原件，再 draft→实际磁盘全文回读→自检修订→result。在隔离页面读新稿、点参考、准确圈选评论并回查；方法不能完成样例就先修方法。
3. 按17集和各场镜顺序推进。每镜从表达目标、准确起点、输入职责重新组织，逐镜保存回读，场末集末连读修订；后文改变判断时回修前文。不得一次批量改串后补造过程记录。脚本负责整理真实决定、覆盖统计和确定的结构检查。
4. 同步 `scripts/scene_reading.py` 等旧事件串依赖。旧工具要求渲染全文在Prompt出现一次，不能为了保存或评论定位保留旧壳；应核对准确原词/发声者/事件先后，定位最终实际文字。保留旧评论准确摘录，不把旧评论强移到新措辞。
5. 更新真正编制源、当前方案、输入索引、必要准确关系及方法依据；不复活退役对象。不改历史候选提交快照、原件、调用和旧执行。全部适用输入都实际看/听；未选定原件、未定原词或无法试听时明确方案成熟程度和后续责任，不能把计划重编等同于调用已就绪。
6. 完成全剧一致性回读、隔离与本机正式真实页面验收、受管集成/增量发布、导出新空实例恢复和资源清理。
