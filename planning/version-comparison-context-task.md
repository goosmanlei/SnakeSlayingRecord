## 用户目标与最小行为

用户从当前镜头选择另一集版本，目的是比较该镜头在那版中的实际设计。执行时先读取目标集的准确组成，再确定当前场或镜是否在该组成中存在可证实的对应，定位其对应修订和真实父场。保留的首先是“正在比较什么”，然后是能帮助继续阅读的段落、展开或位置；不同版本长度和布局可变，不要求机械保留同一像素坐标，也不把复制滚动值当作上下文保留。

没有对应时，明确当前场镜在所选版不可对应及可确认的原因，让用户在该准确集内继续选择。删除、拆分、合并、移场或历史信息缺失须据实际证据判断；不能仅用名称、顺序、业务编号相近或最新对象猜测。若同一对象仍存在但父场变化，按目标集真实父链定位，并使用户能理解正在看的新位置；若无法唯一确定，不冒称已连续比较。无需为了这些边界创建新的映射系统或改写历史数据。

现有集版本控件、场镜导航、来源、素材和意见入口继续承担相应动作。保留准确场级条件、单镜覆盖值、故事依据、素材方案、评论锚点和未提交草稿。比较版本不迁移意见、不自动采纳、不改作品内容或生成方案。

## 真实实施过程

1. 从执行时最新主干、有效正式数据及相关交付恢复上下文，在任务自有隔离环境先实际阅读 E02 AS006 的相邻镜，定位 ASH033，再通过现有控件完成版本 3 → 2 → 3。记录每次选择前的场镜、所选准确集、稳定后的正文和地址、是否需要重新找镜头，并确认正常单版阅读可继续。不调用内部函数冒充页面操作，不只测第一场而掩盖回首场的问题。
2. 根据该实际工作形成最小可运行候选，再按同一目的使用：比较 ASH033 在两版的内容，打开其完整准确 S004 来源并返回，继续比较 ASH032/034。观察是否保住目标、能否清楚辨认版本、是否需要重复导航或误读另一场；按反馈修正后，才扩展到场级选择和另一有差异的版本样本。已有正确成果不重做，不强造迭代次数，过程随实际工作形成。
3. 核对目标集的准确父子组成，选择最小、明确的边界样本：对象不存在、父场改变，以及同一准确孩子被不同父版本复用。正式数据没有必要反例时使用明确标注的隔离夹具，不在正式库制造历史。不为测试补造全剧拆并事实。
4. 隔离验证未保存意见、浏览器往返与刷新、版本切换中再切版本/子页的迟到响应。保留 0019 已交付的最后选择保护；对自然浏览器难以稳定出现的时序，用少量有界受控请求补足，分别记录真实使用与受控检查。
5. 吸收最新主干并复验实际重叠，完成准确双仓交付、串行正式发布和正式只读复走。正式不写测试意见或决定；没有权限或工具完成的验证明确列为待验，不能用代码、API 或截图单独代替实际使用。

## 验收标准

1. **同镜版本比较无需重新寻找。** 在准确最终候选的真实浏览器，从 E02 AS006 ASH033 完成版本 3 → 2 → 3，等待读取稳定后仍定位目标版可对应的 ASH033 及真实父场；版本控件、地址、正文和审阅对象一致，不回 AS004 后要求用户重新选镜。可接着比较 032/034，打开准确 S004 全文并返回。报告具体减少的操作和仍需查阅的内容，不以页面高度或未实测的省时百分比验收。执行时实际版本发生变化，仍按可追溯的原样本验证并补当前相应版本，不伪造旧输入。
2. **目标版决定准确父链。** 镜头、父场、集设计、场级条件和引用均来自用户选择的准确集组成；不能保留旧镜头修订却借新父场，也不能从旧镜头反查到另一集版而悄悄改回选择。实际覆盖场级切换、同对象在不同父场的有效变化和同一子修订被多父复用的边界；准确引用失效时明确拒绝，历史版不借最新版补缺。
3. **无对应时清楚且可继续。** 对删除/拆并或历史记录不足形成的无唯一对应情形，明确说明无法在所选版本继续定位原目标，保留所选集版本并提供现有导航继续选择；不静默跳到第一场冒充比较成功，不按同名/序号猜镜，不强制留在旧版。使用真实可得样本与必要隔离夹具区分验证，未发生的作品变化不得写成既成事实。
4. **阅读与返回服务于同一判断。** 目标仍可对应时保留合理阅读上下文和有价值的展开状态，跨版正文变化不造成落在无关镜头或错误字段；无需精确像素不变。实际验证来源和素材打开/关闭、后退/前进、刷新及正常换集，并回查历史意见定位。最小方案不新增重复比较入口或永久状态提示，不修改作品、历史修订、评论归属或采纳规则。
5. **草稿和最后选择不被带错。** 在隔离实例对准确原修订建立未提交意见，切版本比较后返回仍可恢复在原对象/修订，另一版不得继承成它自己的意见，不自动提交。快速 3 → 2 → 3、切换中离开到实体再返回，以及迟到成功/失败的有界检查保持 0019 守卫有效；旧响应不改当前版本、正文、URL、焦点或草稿目标。实际 UI、受控时序与自动回归各自说明边界；没有实证不宣称曾发生意见错写。
6. **可核对地交付与收尾。** 受管双仓准确提交、引用登记、按序正式发布和正式原入口只读复走均完成后才结项；保全正式原件、采用、评论及修订历史，不用任务快照覆盖活库。无媒体生成、无新增付费调用或外部 AI 调用，不宣称画面/声音质量已通过。按准确身份清理无效过程容器、镜像、测试库、缓存和临时文件，回读实际删除范围/数量及保留项用途、责任和解除条件；退出释放锁后受管退役工作区，不强删活跃资源。根 Review 独立复验与执行者自验分别报告，未独立抽核不得写成根已验收。
