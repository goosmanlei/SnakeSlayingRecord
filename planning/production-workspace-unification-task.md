# 合并“生产制作”入口与退役“组合与历史”

## 任务摘要

将“全剧制作”并入“制作设定”，统一为“生产制作”；把镜头制作内容合入制作拆解，并物理删除“组合与历史”页面及其专属代码、数据。

本文是后续执行依据。本次会话仅澄清并发布任务；实现、数据删除、集成、服务发布和验收在执行阶段进行。

## 目标

1. **统一入口。** 一级“制作设定”改名为“生产制作”，保留“制作拆解、实体管理、素材管理”三个子页；移除一级“全剧制作”及独立的“镜头制作”“组合与历史”子页。制作思路内原有的“生产制作”方法说明子页继续承担方法阅读职责。
2. **合并逐镜内容。** 以现有制作拆解为基础，保留集／场／镜导航和每镜设计正文，在同一镜头的设计正文下接入原镜头制作内容，包括视频制作版本、模型与参数、Prompt、直接和间接参考、准确候选及既有参考选定交互。右侧复用制作拆解的完整素材区，覆盖原镜头制作的视频子集，按稳定素材身份去重；正文参考区仍承担准确输入选择与追溯。两部分共用阅读位置、来源弹窗、素材大卡、评论及返回行为，合并相同评论时按评论身份去重。普通浏览、参考选定、方案采纳、候选采用和真实生成继续按既有语义区分。
3. **物理退役专属功能与数据。** 删除“组合与历史”的独立页面、导航、专属渲染及仅为该页服务的接口、类型、配置、测试和数据。执行时逐项核对当前数据库、有效导出／重放输入、文件和全部保留引用，形成实际删除与共享保留清单。只有该页独占且无保留用途的对象、修订、关系、评论／事件、文件和派生数据进入删除范围；不能只隐藏、软删除，或换个仍生效的存储位置。共用的剧本输入锁、场镜结构、素材、真实调用、原件和各自版本／评论／采用历史按实际引用保留，不能把页面名称中的“历史”解释成清空其他业务历史。
4. **保持现有能力并完成交付。** 同步准确旧链接、路由、评论计数、按需读取及缓存失效、导出恢复和确实受影响的现行说明。旧镜头制作链接进入合并后的同一准确位置；已经物理删除的目标明确不可用，不借最新或同名对象冒充。执行会话开始后、任何实施前，先通过内部回调分别登记下文的提交引用约束和清理检查器并回读；当前安装的任务工具只在执行会话支持这两项。采用故事与审阅台各自的受管工作区、隔离数据库与预览端口，按现有多仓流程准备系统候选、更新故事版本引用、验证整组候选，再按执行阶段有效授权完成正式应用与实际页面验收。
5. **服务下一阶段。** 本轮交付连贯的“素材生产到镜头制作”工作入口。后续具体内容创作、素材或镜头生产以及进一步系统优化另定任务；本轮不以验收为由生成媒体、改写全剧内容，或增加新的组合／剪辑功能。

## 可验证的完成标准

1. **导航与合并结果。** 一级入口只有一个“生产制作”，其下仍为制作拆解、实体管理、素材管理；旧两个独立子页和专属页面实现移除。每镜先展示原设计正文，后展示原镜头制作内容；完整素材区包含视频子集且不重复。同一镜头及素材身份没有因页面合并而复制、改名或重建。
2. **全量关联与核心行为。** 对执行时全部集、场、镜核对导航、设计正文、视频方案、素材集合及准确关联；澄清时基线为 17 集、42 场、297 镜，执行时重新记录。版本／候选选择、直接参考选定、间接参考归属、Prompt 引用、来源定位、未生成及缺项状态、评论目标和去重计数符合既有规则。保持生产前校验，不把浏览默认值当作已选定输入，不改写旧调用事实。正文与弹窗的阅读位置及草稿保持稳定。
3. **真实浏览器验收。** 在隔离实例实际验证桌面与窄屏下的集场镜导航、合并正文、完整素材区、大卡、版本／候选、参考选择、评论与返回；覆盖有产物、无产物和缺参考情况，并回归实体管理、素材管理及受影响的共用评论入口。测试写入只进入隔离数据。刷新、前后退与旧镜头链接仍定位准确对象；退役页及被删目标不会打开错误内容。自动化或接口检查不能替代实际页面证据。
4. **删除与保全可核验。** 提供逐项删除／共享保留依据及实际条数、文件数和字节数；准确回读确认专属代码和目标数据已物理移除，保留数据及文件哈希按基线核对，引用无悬空。若某类目标原本为零，如实报告零，不为凑删除量扩大范围。现有 Git 历史不重写，其他任务资料不擅删；仍有效的恢复来源须正确承接退役，不能让旧输入重新激活已删除内容。
5. **数据操作与恢复。** 如有业务数据删除，先在隔离副本预演并验证准确范围、版本／哈希漂移拒绝、重复执行无额外删除及失败／中断恢复，再在协调的正式写入窗口应用。同步本任务影响的缓存和有效导出／恢复契约，净化后的导出可恢复到新实例，保留对象、引用与原件一致。没有实际业务删除时，不额外建设通用迁移系统。
6. **正式交付与性能。** 执行账本中已登记并回读提交引用约束和清理检查器，整组候选满足准确系统提交引用。按执行阶段有效授权交付双仓准确候选，正式入口实际呈现上述合并结果；关键路径完成正式浏览器复验，数据库／服务身份及回执可追溯。合并保持按当前集场读取和有界请求，不引入无关的全剧完整加载；针对合并页首开、切集场和开卡核对原有性能优化是否失效，对新增明显等待定位并修复。
7. **文档与收尾。** 更新受影响的当前导航、使用及恢复说明；历史任务原始记录保留其时点含义。本任务失效预览、临时库、夹具、容器、镜像和文件按归属清理，报告实际删除、回读以及仍保留资源的用途、责任和移除条件；未完成的验收或清理如实说明。
