## 任务目标

完整依据为 `planning/system-page-style-task.md` 全文及随任务保存的八张原始 PNG。

1. **统一全部页面的三层页头。** 先优化“故事创作 → 剧本创作”页头与固定顶部菜单间过大的留白，再将统一结构用于制作思路、故事创作、制作设定、全剧制作、系统管理的全部子页面，包括前置任务新增的编号说明页。三层按截图理解为“短标识、页面标题、一句用途说明”，每页说明与当前子页相符；窄屏可自然换行，不为凑三行重复导航、增加无效说明或截断文字。已有页头就地整合，避免叠加重复标题区。
2. **统一配色与信息层级。** 以制作思路两个子页已有的清爽浅色、协调色彩为基准，调整截图标出的故事采编、故事结构、剧本创作、制作拆解、镜头制作及系统与 AI 页的深色块和突兀选中态。覆盖资料／正文标题区、侧栏菜单、结构稿次、剧本版本、分集和场镜菜单及模型／推理强度选择。保留清楚的标题层级、评论提示和选中识别，不改图片、视频、图示原件或把正文深色文字一并淡化。
3. **统一菜单与控件细节。** 为相关导航、按钮、版本／候选选择、输入框和选择控件统一字体、行高、内边距、边框、圆角与状态表现，让外观平滑协调。默认、悬停、选中、键盘焦点、禁用和错误状态均可分辨；多项选择溢出仍可访问。复用共同样式和组件，保持前置任务确定的平铺选择、小卡、分页、准确引用与业务行为。
4. **重整系统与 AI 配置区。** 将“站点图标”和“评论润色”作为两块有清楚标题、分组及留白的独立功能区。图标区清楚组织当前图标／待保存预览、选已有图标、上传新图标、恢复默认及保存结果；区分上传成功、选择变化和保存生效，取消或失败不冒充应用成功。沿用既有配置保存机制及图标格式、大小、受管文件校验，不新增自动保存或拆出两套保存契约。
5. **优化评论润色表单。** 模型和推理强度按钮与全站风格一致，保持实际目录中的可选项与两者联动，不写死截图里的旧模型。两个输入项“API Key 环境变量名”和“AI 参考上下文字数上限”有清楚标签、帮助、对齐和校验状态；前者仍只保存变量名，后者保留有效数值限制。保存、失败、冲突及草稿恢复遵循现有语义，布局分区不造成另一块未保存输入丢失。
6. **交付完整可审阅候选。** 在依赖完成后的准确版本上，用双仓隔离工作区完成实现、逐页浏览器验收及必要回归，提供前后对照、覆盖清单、变更与恢复说明。保留正文、评论、准确历史、采纳、候选和真实调用语义；本任务不承接 Notebook 下一章的制作思路正文重构，不执行媒体生成。最终候选确认后再按项目流程办理正式集成、应用及推送，不能以任务副本覆盖正式活库；按项目规则收尾过程资源。

## 可验证的完成标准

1. **全章与全站覆盖。** 本章每条文字要求及八张图片均映射到实现位置、实际结果和证据；根据前置任务完成后的真实导航列出制作思路、故事创作、制作设定、全剧制作、系统管理的全部子页及新增编号说明页，不只检查六张问题截图所在页面。原件名称、字节和哈希可核对，受阻或未验证项不计通过。
2. **页头与留白。** 所有子页使用同一套三层页头，内容能说明当前页用途，切子页后不残留前页说明。以相同视口测量并截图对比剧本页顶部菜单下缘至页头首行的距离，确认过大的间距已收敛；其余页面使用一致的间距规则。无重复页头、空占位、固定顶栏遮挡或新增不必要的正文挤压，窄屏文字完整可读。
3. **视觉一致性。** 逐一对照截图 02—07 标出的全部区域及制作思路基准，确认原突兀深色块与选中态已统一。真实浏览器检查默认、悬停、选中、焦点、禁用和错误状态；不能仅靠颜色辨认当前选择。菜单、按钮、输入框和分页保持协调，图片原件、评论高亮和正文可读性不受损。
4. **系统配置完整交互。** 在隔离实例中完成图标的选择已有、上传、预览、取消文件选择、恢复默认、保存与刷新回读；验证无效文件、超限、上传／保存失败及版本冲突不会显示已应用或丢失有效输入。验证模型与推理强度联动、两个输入项有效／无效值、两块同时编辑、保存及刷新恢复，键盘可操作。既有图标恢复／导出能力与配置草稿、结果未知处理按实际改动回归；正式配置和图标不被测试修改。
5. **全部页面与关键行为回归。** 在常规桌面和窄屏逐页检查，并抽查宽屏、长标题、多版本及空态。导航、分集／场镜定位、版本／候选选择、筛选／分页、准确历史链接、浏览器前进后退、弹窗关闭后的阅读位置及评论草稿保持正确；前置任务新增的编号说明、小卡、大卡和镜头参考选择没有退回旧行为。回归评论定位与快捷键、采纳循环和媒体预览等受共用样式影响的路径。
6. **证据与交付。** 提供准确故事／系统候选、逐页结果和必要前后截图，说明未覆盖项；仅对实际改动运行必要的自动检查，浏览器交互受阻按 `AGENTS.md` 报告，不用接口或静态通过替代。全站视觉候选须可供用户实际审阅，技术验证不代替用户对视觉效果或素材的接受。
7. **资源收尾。** 核对本任务资源归属与其他任务引用后，清理无效临时库、服务、缓存和重复文件，报告删除范围、数量、回读结果及保留项用途／移除条件。保留原件、必要验收与恢复证据；正式集成、应用、服务切换与推送按项目确认边界串行办理。
