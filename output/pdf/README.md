## 重新生成

在项目根目录运行，使用独立 Python 环境安装 `reportlab`。字体须为含全部原文字符的中文 TrueType 字体；支持 `.ttc` 的第一个子字体。本次使用 macOS 的宋体，字号 11、行距 18，A4 纵向。替换成其他字体后须重新核对全文、分页和页面呈现。

```bash
python3 scripts/export_screenplay_pdf.py \
  --source imports/screenplay-04-clean.md \
  --output output/pdf/把灯带回家-剧本版本四.pdf \
  --font /System/Library/Fonts/Supplemental/Songti.ttc \
  --date 2026-10-13
```

生成器只读取指定干净稿，不自动判断正式版本；导出新的“最新剧本”前须核对正式版本目录及准确正文。生成失败保留既有 PDF，成功时替换临时成品；生成成功仍须完成 PDF 的全文与视觉验收。
