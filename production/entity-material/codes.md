# 业务对象编号

本表由系统实际前缀清单生成，系统管理只读说明使用同一来源。准确对象映射、剧本版本归属和历史位置见 [codes.json](codes.json)；候选及正式发布状态见[拆解与镜头制作交付](../breakdown-shot-v2/README.md)。

| 类型 | 前缀 | 示例 | 唯一性范围 |
| --- | --- | --- | --- |
| 集 | E | E02 | 同一剧本版本内；按该版本完整集序编号 |
| 场 | S | S003 | 同一剧本版本内；按完整集场顺序连续编号，不在每集重新起号 |
| 镜 | SH | SH034 | 本实例内；不随切集、切场或显示顺序重置 |
| 实体 | EN | EN001 | 本实例内 |
| 实体状态 | ST | ST001 | 本实例内；历史保留状态也有独立编号 |
| 素材 | M | M001 | 本实例内；准确共享身份共用编号，旧身份可追溯 |
| 素材版本 | MV | M001 / MV002 | 同一准确素材身份内；沿用方案版本号 |
| 素材候选 | MC | M001 / MV002 / MC001 | 同一素材版本内；按实际结果登记顺序分配 |
| 实体关系 | RL | RL001 | 本实例内；不计素材采用及后台依赖边 |
| 制作设定审阅对象 | RV | RV001 | 本实例内；保留旧审阅对象身份 |
| 评论 | C | C001 | 本实例内；原文圈选、修订和评论身份不变 |
| 审阅决定 | DC | DC001 | 本实例内，每个可访问的决定对象 |
| 组合 | A | A001 | 本实例内，每个组合对象 |
| 交付物 | O | O001 | 本实例内，每个交付物对象 |

集、场按准确剧本版本的完整顺序编号，场号跨集连续；切换版本各自从一开始。其他对象按首次登记次序递增，已分配编号保留。编号不替换稳定身份或准确修订。

资料、剧本与故事结构不使用简写编号。后台调用、依赖边、事件、配置表和输入锁也不增加编号。V/C 是当前素材内的局部版本／候选序号，须连同素材身份理解。

集和场以完整准确剧本版本为编号范围。例如版本四共 17 集、42 场，显示 E01—E17、S001—S042；场号跨集连续，其他剧本版本各自从 E01、S001 开始。准确剧本、集修订与场身份决定编号，筛选、页面排序和历史浏览不会重编号。

镜头 SH、实体和素材等对象仍以整个故事实例为唯一范围，不因剧本版本切换而重置。正文“第几集／场／镜”仍为原位置，稳定身份和历史链接不变。

旧 D/B 及已存在的跨版本 E/S 分配可以导出恢复，但不进入界面映射。本轮未发布的跨版本 E/S 分配已从候选增量移除；编号调整不将局部 V/C 改造成全局流水号。
