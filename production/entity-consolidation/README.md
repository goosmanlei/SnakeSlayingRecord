## 两个贯穿样例

阿蘅原关系图显示6状态、10素材，而从详情各入口最多可达20项。两处投影范围不同，且身份、基础状态、旧首轮需求和歌曲切片重复承担同一用途。现在实体及其状态的必要素材并集为5项：图像身份 M2544、声音身份 M2669、省段清唱 M2725、湿袖图 M2714、湿鞋图 M2715。实体自身列3项，另外2项属于湿态；图中5不是各行数量相加。

六个状态全部保留：日常青衣、捞书湿袖、连唱嗓哑、嗓音劳累并湿鞋、点名后形态、脱险泪痕。它们改变衣物干湿、发声与表演阶段，不能删成一套形态；相同身份图和声音则共用。六行分别显示3、3、2、3、2、2项，包含当前镜头以外的状态，切换和重开不改变口径。嗓哑、谨慎或泪痕不再各造同衣着身份需求，也不把湿鞋提前恢复成干鞋。

挑柴老汉保留1状态、2需求：图像身份 M2662 和声音身份 M2673。M2961基础状态图、旧M1069归同一图像需求；基态与实体入口指向同一身份。图像回答外观，声音回答说话人，二者不能合一。保留图是实际单视角候选，不能因新方案要求正侧背母版就宣称旧图已经满足；原意见仍指向原件。

《三道滩》的旧开头 M1213、归家 M1212 与 M1206源音频的两个区间逐采样完全相同，见 [准确范围验证](crop-verification.json)。当前省段需求 M2725承接两个真实演唱候选；对于M1206这份源，开头0.18—7.14秒、归家7.66—17.686979秒由同一原件加范围表达，删除重复切片及其多余需求。完整歌曲仍是独立用途，未选原件的镜头输入仍明确缺项；没有把清唱省段冒充全曲，也没有将播放功能通过写成声音质量认可。
