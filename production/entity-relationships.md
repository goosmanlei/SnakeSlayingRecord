准确导入批次和全部证据摘录见 [entity-relationships.json](entity-relationships.json)。这是本次交付批次，不可再次导入覆盖当前版本；维护时重新准备并核对增量：

```bash
python3 scripts/entity_relationships.py plan --system .runtime/review-desk-worktree --instance .runtime/production/review-instance --file .runtime/relationships-next.json
python3 scripts/entity_relationships.py apply --system .runtime/review-desk-worktree --instance .runtime/production/review-instance --file .runtime/relationships-next.json
```

`plan` 只校验和写候选批次；`apply` 重新核对输入与当前版本，一致才原子写入。剧本出现新修订时拒绝自动换稿。制作实例、集场和实体须保持准确引用；按评论调整本故事脚本中的关系定义，不把抽取规则移进通用审阅台。最终恢复使用 [replay.json](replay.json) 或最新完整数据库导出。
