## 原曲与剧中演法

[逐镜用法](uses.md)列出27个实际发声镜头对应的原曲歌词行、发声者和演法；[准确映射](uses.json)保存同一对应关系。用户已在原曲中定位9处乐句，准确起止和来源见[定位回执](../../receipts/song-human-cues-task-20261015-0003-stage13.json)，另存48kHz PCM引用件的实际操作见[剪辑回执](../../receipts/song-source-edits-task-20261015-0003-stage13.json)。原曲定位与新角色录音分别保存准确身份，不互相代替。纸上的迎蛇歌词、对歌曲的提及和普通疑问哼气，不自动增加演唱素材。

当前按角色与实际演法整理了16个独立演唱或哼唱文件，同一乐句在多个镜头中复用。16件均已生成并通过实际试听，2份原速教唱合件也已获用户确认；5处跨镜尾音时间也已由用户实际保存。逐件状态见[角色制作清单](../../reports/task-20261015-0003/song-role-worklist.json)。完整原曲的认可不自动覆盖另唱、拼接或远景混音。

《送青篷》的第二段仍是最后一段，失词仍从“柳影到船边”之后开始。第一段扩写没有进入锁定剧本；第41场只取首段前两行与第二段三行，完整唱一次。舞台五句的真实文件依次为8.665417、24、27、6.848917、17.118917秒；当前镜头方案据实安排演唱和换气，跨镜余尾按用户定位和准确原轨连续接续。短试唱取消长拖腔，歌娘示范使用歌娘声线，母亲只无词哼；均沿准确原曲另唱并通过用户试听，没有变速或把原曲换名充作角色录音。
