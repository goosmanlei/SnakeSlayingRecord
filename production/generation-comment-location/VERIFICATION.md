## 实际变化及依据

调用文字定位沿原件的准确调用修订恢复原候选、文件组成及历史状态，复用已有完整审阅上下文；需要时只展开原卡中的生成详情。M1612 的 `state=null`、`review_state` 指向 ST140 版本1，不能按当前状态查找后退入无输入的第二份调用。独立 CALL 保留完整读取，实际缺准确组成的输入继续显示缺项。

文字定位在当前完整卡、参考窗或制作阅读容器内找准确修订和能完整承载范围的表面，优先选可见正文。有效范围高亮实际字符，并滚到选句；完整上下文、内联参考链接和原评论入口保留。省略类型的已有文字锚点仍按文字处理，省略结束块时沿起始块；没有有效起止的旧意见只作块定位。连续段落沿原文换行计算偏移，不能跨过未显示的原文间隔。图像区域和音频时间仍走原有范围语义。

本例准确 CALL 为 `call-fg3-crossbeam-eight-image-04@dabee604f4cc373e1b8bb47573dcd96fde044c675af3973ac810bc41bd574081`，块 `@review/call/prompt`，全文2806字符。范围 `[1375,1409)` 的原句为 `No hanging rope, no post bindings.`。当前协议按 Unicode 字符计数；本例此前字符均在基本多文种平面内，UTF-16 与 Unicode 字符偏移恰好相同，不能推广成所有文字都按 UTF-16 计数。
