# 第一集原生有声视听预演

第一集使用 Seedance 2.0 生成有声视听预演，再按镜头设计剪辑为 16:9 动态分镜。独立音频只制作角色音色与歌曲旋律基准；对白、演唱、动物声、环境声及动作声由模型随画面生成。定稿台词和歌词逐字保留，模型产出仍须实际观看和听辨。此方式于 2026-10-02 经用户确认，不代表具体声线、旋律或预演已获接受。

## 输入与声音职责

| 输入 | 作用 | 精确引用 |
| --- | --- | --- |
| 构图、角色状态、空间与道具 | 约束身份、空间及动作起点 | 图像版本、组成，必要裁切；同图可覆盖多个需求 |
| 角色音色母版 | 固定说话人的基础声音，允许状态表演变化 | 先审阅完整母版，再选择用于本镜的短片段 |
| 歌曲旋律基准 | 固定旋律、节拍与演唱处理 | 歌曲身份与原歌词独立保存；实际参考指向准确录音片段 |
| 镜头文字 | 指定本镜原句、说话人、演唱方式、环境动作声及预计时间 | 定稿分集与正文块、镜头修订；不以参考录音内容代替本镜台词 |

全剧当前 32 项音频需求为 28 项角色音色参考和 4 项歌曲旋律基准，部分状态明确复用日常声线，不要求再生成一个文件。实际送入镜头的参考按说话人去重；每句台词仍保留独立文本和预计窗口，直接写入提示词。

独立逐句／演唱段与环境动作音轨的 337 项需求、987 个修订已从任务数据中清除；它们没有评论或保留对象的历史引用。已有五份声音候选及其原件、调用与意见全部保留，没有原件需要删除。新关联修订只对应新的参考用途，不改写原始生成记录。清理清单和校验见 `evidence/review-simplification-data.json`。

只需通过文字随镜呈现的声音状态使用 `reference_mode: description`，保留完整状态描述、剧情出处与出场关系；不要求独立整体原件。该方式已用于画外台鼓及《送青篷》的四种局部呈现状态。歌曲完整旋律仍保留独立基准需求。`reference_media: none` 继续只用于仅被提及对象，两者不能混用。

## 逐镜计划与执行限制

视频生成选型按 `../AGENTS.md` 的约定：可以通过 `pippit-tool-cli` 调用 Seedance，默认 Seedance 2.0 Fast、720p；镜头需要较长视频时长时，可以采用 Seedance 2.5、720p。16:9 横屏与原生有声视听方向继续沿用。

`../config/seedance.json` 和现有逐镜清单仍保存此前的 Seedance 2.0、1080p 待执行配置。下次准备实际调用时，应先按新约定更新配置并重新导出待执行计划，再核对 CLI 的实际模型标识、参数、时长限制、参考支持与额度。2026-10-04 已通过 CLI 的 `model list` 与 `model describe` 核对：默认模型标识为 `seedance2.0_fast_vision`，支持 4–15 秒；较长镜头采用 `Seedance_2.5`，支持 4–30 秒；两者均支持 `--resolution 720p`。这些是当前服务配置，执行时应重新核对。尚未提交生成或查询额度。既有准备工具按 4–15 秒、最多 3 段参考音频、每段 2–15 秒且总长不超过 15 秒、最多 9 张图片组织输入；这些旧接口约束不能直接视为 pippit-tool-cli 或 Seedance 2.5 的当前能力。[原接口依据](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)

原生音画联合生成支持以音频参考声音特征，具体身份、语气和本镜内容仍需在提示词中说明；参考不会保证每次生成的台词、音色或时点完全准确。[提示词指南](https://docs.volcengine.com/docs/ark/seedance-2-0-prompt-guide?lang=zh)

现有 17 秒声线／歌曲原件超过一次参考的时长限制，不会直接传入。实际短片段必须记录：母版素材和准确修订、组成、起止时间、裁切所得真实文件及校验值。先听辨再选择，不按文件前几秒自动截取；参考是音色／旋律依据，不要求它包含本镜每一句话。同一生成中超过输入上限时，先复用、组合或调整镜头安排并复核，不静默忽略必要人物。

[逐镜清单](episode01/seedance/manifest.json)覆盖第一集 33 镜、37 个对白／演唱单元，暂定 227 秒。每镜包含模型、参数、完整提示词、准确需求、前后镜头及预计时间，旁边的 `.txt` 为可阅读提示词。当前清单明确 `ready: false`、`executed: false`：尚缺准确媒体选择和实际执行条件，不能当成已可执行输入包。两镜原计划 3 秒，按模型最短 4 秒提出生成并裁去尾部保持的方案；是否可自然裁切，须实际回看后确定。

```bash
python3 scripts/seedance_preparation.py \
  --system .runtime/review-desk-worktree \
  --instance .runtime/production/review-instance
```

这个工具只导出计划，没有网络调用或生成提交能力。时间窗口是表演目标，不保证帧级口型／语音控制；生成后逐字听辨，核对动作、空间、歌词、音色及声音衔接，需要时调整安排或返工。

## 清理、恢复与后续交接

清理先用 `scripts/native_audio_workflow.py plan` 生成准确删除和更新批次，再用 `apply` 调用通用导入操作；参数为 `--system`、`--instance`、`--file`。操作在同一事务核对当前修订，拒绝删除任何有评论或保留历史引用的需求，出错完整回滚。脚本和初始抽取、镜头与场级需求编译已同步，不再重建逐句／环境音轨。

旧 Git 提交和 `.runtime/` 中明确标记的历史备份仍可追溯清理前状态；它们不是当前恢复入口。当前恢复使用最新完整库导出，或 `production/replay.json` 加故事基础导出。完整库保留全部意见；内容重放只包含基础故事评论，不能代替真实任务数据库备份。

基准审阅后才批量生成预演。交付须含可播放动态分镜、可编辑时间线、实际片段、全部参考与精确依赖，并完成整集回看、听辨和第二轮用户审阅。正式镜头与最终成片仍由后续任务完成；当前只有准备能力与计划，不能宣称预演或第一集已就绪。
