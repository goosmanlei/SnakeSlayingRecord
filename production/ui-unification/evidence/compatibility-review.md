## 共享图片绘图的独立复核

主代理在真实页面发现已有评论区域上的拖动问题，导航实现者改为在捕获阶段处理手势，使用原始事件路径找到图片区域，并在获取评论目标前明确聚焦被拖动的准确素材。结束手势时继续核对工作区、准确评论目标、阅读器身份和原图片节点归属。这段逻辑同时用于来源图片、故事结构图片和制作素材，因此本轮同时执行三个限定测试文件。

本审查者在既有兼容性文件另补 3 项跨函数检查：使用真实 `focusProductionReview`、`commentTarget` 和 `startDraft`，验证从同一图片的新修订焦点开始拖动旧修订时，最终评论仍绑定旧修订与旧原件；拖动途中改选新修订时，迟到结束事件保留新修订草稿；执行真实统一弹窗关闭回调、恢复外层修订和草稿后，内层迟到结束事件不能覆盖外层状态。3 项均通过，未发现新的已确认兼容性缺陷。

其余 27 项绘图回归包括：已有评论多边形被同步重绘移除、弹窗停止冒泡、工作区／修订切换、阅读器替换、弹窗关闭、图片节点移除、来源原件核对及小选区处理。这里调用真实事件处理函数并模拟 DOM 与事件路径，未执行物理拖动；真实鼠标、像素位置与提交结果仍以主代理的浏览器记录为准。

该轮实际运行总数为 56 项：当时本文件 29 项，加上述 27 项绘图回归。之后为 C10 再增加 3 项，因此当前兼容性文件共 32 项；不同轮次的重叠用例不相加宣称覆盖数量。

## 其他已验证的契约

素材默认选择优先当前版本的明确采用；没有采用时按结果时间选最新，不依赖对象名称或数组顺序。当前版本未生成时保持空结果，不借用历史已采用候选。实际实体素材渲染器能够显示已采用的准确文件组成，未退回候选的第一个文件。

读取投影按持续素材需求计数，多次生成和素材元数据修订不重复增加数量。实体筛选按当前有效采纳判断：修改基础信息使旧采纳失效后，即使仍允许取消历史采纳，也归入未采纳。取消后保持未采纳。组合筛选数量保留其他筛选条件，零结果仍保留已存在的媒体类别。准确历史需求读取保留原修订及其方案，当前新方案可以继续处于未生成状态。

全部 Node 回归还覆盖既有准确素材导航、评论定位、保存重试、关闭／重开、草稿、来源、结构和剧本接口。选定 Python 回归覆盖素材方案、内容采纳、整实体评论、制作拆解及读取事务边界。这里的通过表示这些测试执行成功，不表示全部真实数据或所有浏览器行为都已覆盖。
