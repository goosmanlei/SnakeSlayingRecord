## 故障与自动检查分别证明什么

任务专属第二端口的最小 HTTP 夹具，仍读取同一本任务隔离副本；故障控制仅消费指定的一次请求，不写业务账本。真实 Chrome 验证：准确整稿404提示失败；延迟成功期间切回八稿原圈选，迟到结果不覆盖；延迟失败期间关闭 C135 并打开 C134，失败不串入；准确站位原图404明确不可用、禁用放大且不替换，恢复后原件5504×3072正常。没有在正式实例注入故障。

`tests/comment_review.test.cjs` 用受控 Promise 检查迟到成功和失败在切步骤、另一意见、关闭、重开及另一准确稿时均失效，检查无锚点完整图文、局部／全文去重复、纯文字及图像失败。此项证明受控条件，不冒充页面实操。`tests/test_comment_review.py` 三项检查准确引用、错误锚点／版本拒绝、原决定、原子登记及导出恢复。

同步后的自动回归：上述 Python 3项、Node 92项全部通过；Node 包括共同阅读上下文、结构位置与版本导航、故事草稿、资料选段上下文和浏览器历史导航。首次候选的对应66项也通过，后续因主干新增共用导航而扩验。
