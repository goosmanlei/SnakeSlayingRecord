# 第一集实体的制作描述与生成方案

本轮补全第一集实际呈现或发声的 33 个实体，以及它们在全剧的全部 77 个完整状态，共提出 165 项素材方案：94 项图像、71 项音频，其中 151 项拟生成、14 项明确复用前置原件。包含第一集 37 条定稿对白／演唱、角色三向参考、空间布局和反向机位、手部细节及环境／动作声。这里只登记制作选择和执行方案，没有发起新模型调用，也没有代替用户采纳。

全剧抽取仍为 133 个实体、267 个完整状态。首批选取第一集所需实体并补齐它们的所有状态，是为了让“整实体采纳”的范围完整；其余实体保持抽取成果，不冒称已有完整生成方案。两名仅被提及对象不因此增加媒体义务。全剧 824 次场内／镜内使用的归属与转换检查继续通过。

## 如何审阅

打开 [制作设定](http://127.0.0.1:39103/?workspace=settings.workspace)，先看实体基础信息，再选完整状态。描述明确当时同时存在的衣着、伤势、湿痕、持物或空间情况；剧本事实与本轮提出的造型、色彩、伤侧等制作选择分开。下方按图像、声音排列具体素材，展开可检查模型、配置、完整提示词、参考输入用途及检查要点；圈选内容即可评论。

“采纳”覆盖基础信息、全部完整状态、逐素材方案及其准确前置方案。采纳后显示“取消采纳”，评论始终开放。新增结果不改变方案认可；实体、状态或方案改变则重新待认可。参考可先绑定母版需求的未来产出，执行前必须明确采用准确原件及范围，不能自动取最新候选。取消保留已经执行的输入及记录，并阻止新的生成。

版本切换在对应内容旁，采纳历史有记录时才显示。真实音频使用波形、选段、精调、试听和时间评论；图像占位或缺音频提示只表示某个已列明的素材尚未生成，不代表实际成果。已有音频没有人物封面。

## 工具与准确输入

图像遵循 `config/openart.json`：OpenArt 优先，项目 `8K6WcbrPLghSBJXBtWAE`，`gpt-image-2-5-sunburst`，`high`、原生 `4K`、单张；人物参考主要 3:4，道具和三向参考 4:3，空间 16:9。先以文字探索干净根母版，状态、角度和局部参考直接依赖根母版。执行以最深实际谱系计数，最多两代；不能通过追加母版重置。提示词限制轮廓、色块和线条，明确禁止新增纸纹、颗粒、写实皮肤和过度锐化。两次实际 4K 请求未达到尺寸要求，已作为执行阻断保留，不能据方案中的参数宣称已解决。

音频采用豆包 `seed-audio-1.0` 与项目 `scripts/seed_audio.py`。计划配置为 WAV、48 kHz，音高／语速／响度偏移均为 0，启用字幕；字幕仍不能替代听审。声线先由角色文字选择探索；各条对白准确引用定稿和声线母版，歌曲参考阿蘅声线并保留定稿两句歌词，逐句再依歌曲母版锁定旋律。临时镜内时间用于试排，不要求录音机械变速到估时。执行前重新核对平台和额度，不新增充值或购买。

6 个现有素材以新修订明确对应准确状态和本轮需求，原件、文件组成、谱系及 7 次实际调用没有改写。图像仍缺原生 4K，声音仍未实际听审；候选关联既不表示按新方案生成，也不表示已被采用。

完整实际描述、提示词、参数、引用和原子增量批次在 [generation-preparation.json](generation-preparation.json)。当前与历史准确修订在 [replay.json](replay.json)；初始抽取文件继续作为剧情事实的编写依据，不用于覆盖已补充的制作描述。

## 维护与恢复

命令从故事任务工作区根目录执行；通用系统代码在独立工作区。先编辑 `scripts/generation_design.py` 中明确的制作选择或 `scripts/prepare_generation_plans.py` 中方案规则，再生成可审阅增量：

```bash
python3 scripts/prepare_generation_plans.py plan \
  --system .runtime/review-desk-worktree \
  --instance .runtime/production/review-instance \
  --file .runtime/production/next-generation-plan.json
```

回读批次和内容后，通过同一工具 `apply` 对该文件执行增量导入。它检查剧本文件 SHA、批次摘要、读取的对象头和每项版本；同一事务中拒绝并发覆盖。本轮在隔离副本重复预演为零变化；首次批次已应用，不能重复应用历史批次。共享实例的应用与其他写入按序协调；技术测试的评论和决策不得导入。

用户实际采纳后，用 `production-generation-ready REQUIREMENT_ID` 检查生成前缺项；`production-generation-package REQUIREMENT_ID --output 空目录` 仅在采纳、前置原件和范围满足时输出清单及原件。HTTP、CLI 使用同一操作，完整契约见通用系统 [generation-preparation.md](../.runtime/review-desk-worktree/docs/generation-preparation.md)。本轮真实方案均未采纳，因此不交付伪装可执行的包。

当前完整库恢复、生产修订重放与真实浏览器证据见 [verification.md](verification.md)。现有事实、来源、旧修订、评论和实际调用保持；“制作思路”已经吸收本轮可验证能力。动态分镜、工程、实际听审、首轮与第二轮创作审阅仍未完成。
