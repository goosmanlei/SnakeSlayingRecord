# 第一集实体的制作描述与生成方案

第一集实际呈现或发声的 33 个实体，包含全剧 77 个完整状态，现有 122 项素材方案：94 项图像、28 项音色／旋律参考。37 个定稿对白／演唱单元保存在逐镜设计内，随 Seedance 2.0 画面生成；不再逐句建立音频素材，也不独立制作环境动作声轨。实际媒体生产仍聚焦第一集。

打开[制作设定](http://127.0.0.1:39103/?workspace=settings.workspace)，先看基础信息与直接关系，再选完整状态。每份素材卡按两列排列，模型、参数、提示词、参考用途默认展开。当前页弹窗打开准确参考版本，历史版本留在原卡片切换；不显示执行日志、采纳时间或重复历史提示。圈选文字、图像或声音时间段即可评论。

“采纳”认可基础信息、关系、全部完整状态和逐素材方案，允许推进素材生成准备。采纳后可取消，评论一直开放。内容换版需重新认可；新候选不撤销已有认可。执行前仍需选择准确原件及范围、核对平台和额度，不能自动用最新候选。只需描述的声音状态仍是实际发声状态，不等于“仅提及”。

## 维护与恢复

具体内容按评论通过通用导入追加修订，不改写旧稿。`scripts/prepare_generation_plans.py plan --system ... --instance ... --file ...` 只预演从故事设定重编方案；检查差异后再用 `apply`。重编可能更新多个前置方案，不能未经核对覆盖用户意见。脚本已取消逐句、环境与动作音轨的生成逻辑。

要刷新只读方案清单，执行以下命令；它直接读取当前库，不重编或应用方案：

```bash
python3 scripts/prepare_generation_plans.py snapshot \
  --system .runtime/review-desk-worktree \
  --instance .runtime/production/review-instance \
  --file production/generation-preparation.json
```

现有计划清理使用 `scripts/native_audio_workflow.py plan/apply`，准确版本与被引用检查在同一事务内完成。完整恢复用任务实例的最新导出；生产内容重放用 `production/replay.json`，不能从旧初始批次恢复已删除需求。使用路径及当前验证入口见 [README](README.md)和[验证说明](verification.md)。
