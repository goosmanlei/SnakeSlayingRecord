## 编号与参考规则

集、场的 E／S 在同一准确剧本版本内唯一：E 按完整集序编号，S 按完整集场顺序跨集连续编号，各版本分别从一开始。版本四为 E01—E17、S001—S042。编号跟随不可变剧本版本所引用的准确集修订，不由筛选、排序或当前集对象的新修订推算。镜头 SH 及其他对象仍按前缀在整个故事实例内唯一。原正文位置、稳定身份和历史链接不改写；资料、剧本与故事结构不使用简写编号。全量映射及范围见[编号交付](../entity-material/codes.md)。

MV／MC 和小卡 V／C 保留局部序号：V 是该素材的制作版本号，C 是该版本内的候选号。两项独立判断；已选版本但未选候选可以显示 `V2 C?`。普通素材小卡的版本／候选总数统计全部真实制作版本与候选，与当前输入选择分开，修订、组成文件、别名与重复关联不增加总数。

参考分为直接模型输入、通过关键画面或声音选段传递的间接素材，以及仅提及、无需媒体输入的对象。每条有效路径绑定准确素材身份、完整状态、上游修订和输入下标，避免把整场素材塞给每镜。参考卡与 Prompt 审阅标记打开同一目标；模型实际提交的图片／音频序号按真实直接输入排序，审阅标记不冒充模型语法。新增槽位明确待选。

直接输入选择归当前镜头方案；间接选择归准确关键画面或声音选段方案，详情显示归属与影响范围。浏览不保存，明确选定才写入。不能通过本镜操作静默修改共享上游或其他镜头。未选、错配、失效引用、缺原件及超模型限制继续阻断生产。模型约束及本次只读查询依据见[输入契约](model-input-contracts.json)。
