# 影视专业知识维护与交付

学习入口为 [README](README.md)，专业正文为 `01-` 至 `12-` 十二章，本剧离线应用与速查分别为 `applications.md`、`quick-reference.md`。源码与生成关系由 `scripts/sync_filmcraft.py` 显式列出。任务状态只在主项目 `.codex-task/tasks.json` 维护；这里说明可复用的维护方式，不记录执行进度。

## 正文、来源、图示与页面

章节 Markdown 是唯一专业正文。三份 `sources-*.json` 是唯一来源记录，`sources.md` 由它们生成；每项只记录实际读取的内容与适用范围。原创 SVG 唯一编辑源位于 `diagrams/`，派生工具按原字节复制到 `content/production-approach-assets/filmcraft-*.svg`。不得手工编辑生成页、来源目录或图示副本。

从故事仓库根目录执行：

```bash
python3 scripts/sync_filmcraft.py
python3 scripts/sync_filmcraft.py --check
python3 scripts/sync_video_handbook.py --check
python3 -m unittest discover -s tests -p 'test_sync_filmcraft.py' -v
```

派生工具完整保留章节中的段落、标题、单层列表、表格、代码和图示，重写本集合交叉链接为页面准确锚点，并把来源编号转为可直接访问的子节。它拒绝未知标记、缺失文档、破损来源、重复来源地址、未知锚点和缺失图示；不能丢掉不能解析的内容后继续发布。内容文件及图示哈希汇入子页的来源声明；`--check` 重新派生并逐字节核对图示。视频手册同步保留其他子页及顺序，两项检查都必须通过。

正文用一个一级标题，章节内采用二、三级标题。图示使用 `![说明](diagrams/name.svg)` 独立行；SVG 必须有整数 `width`、`height`，包含 `viewBox`，仅使用形状与文本。通用系统拒绝脚本、事件、外部资源、HTML 嵌入、样式元素与非本地引用。复杂图示需要先简化阅读结构，不能靠缩小文字塞进图面。

## 内容审查

新增或修改重要论点时核对实际来源，并更新所属组的 `review-input-*.json`。关键论点逐项交给非作者核查；其他论点每领域至少抽查三项，发现实质错误时扩大该领域检查。核验记录说明检查了什么、发现何种偏差及如何修正，不把启动了多个 Agent 当作质量证据。

画面和声音结论按实际原件核验。静帧只能支持所见空间与构图，连续帧采样需标明粒度；文字访谈只能证明作者说过什么。声音的转写、波形和文件存在不能代替听辨。原件不完整或感知能力受限时，在相应结论处限制强度，并在任务验收报告写明未完成项。

原始研究副本和工具输出放 `.runtime/filmcraft/`；公开交付使用自主解释与链接，不随意复制行业版权画面。受管 `research-contract.md` 保存研究和证据约定，`review-input-*.json` 供复核，不进入学习页面；实际审查结果和验收记录归 `evidence/` 或任务本机回执，不混进专业正文。

## 页面与发布

独立子页沿 `/?workspace=production.approach&tab=filmcraft` 访问，专题目录和章节内链接均沿通用方法页实现；三类速查、完整案例、来源和图示都来自同一集合。文件缺失或损坏时，生成检查应先拒绝候选；运行时方法 JSON 加载失败由方法页明确报错，媒体原件缺失或哈希不符由该媒体显示错误，其他业务页面仍可读取。

真实浏览器需检查桌面与窄屏的子页切换、目录与内部链接、刷新、前进后退、阅读位置、完整长文、表格、放大图示和错误恢复，并联合回归故事创作、生产制作、视频手册及旧链接。接口和自动测试分别记录，不能取代浏览器结果。

双仓集成和正式发布沿 [生成工作区流程](../generation-workspaces.md)；先提交系统候选，再更新 `config/instance.json.review_desk_commit`，准备整组候选。`material_review_release.py` 为本任务冻结方法页与声明图示，发布时核验准确镜像、只读内容挂载及业务数据保全。本知识没有业务数据库增量。任务的自动授权不等于内容与页面已验收；未满足标准时保留现场，不调用 `_complete`。

预览、测试数据库、原始研究下载与无效容器、镜像在用途结束后按准确归属清理。公开正文、必要证据、真实调用回执及有效恢复资料保留。worktree 由任务工具在会话释放后受管退役。
