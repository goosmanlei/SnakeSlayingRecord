# 制作速查：术语、问题与阶段

此页提供返回原理和案例的入口，不另立一套口诀。表中的简释只帮助定位；影响制作的条件、反例和来源请进入所链章节。需要比较完整方案时，联读[本剧应用](applications.md)。

## 按实际问题查找

| 遇到的问题 | 先辨认什么 | 原理、案例与下一步 |
| --- | --- | --- |
| 一场戏拍完却没有重点 | 观众应当形成的认识是否明确；视觉与声音是否争抢重点 | [叙事](01-narrative.md)；[木牌揭示](applications.md#悬念揭示木牌什么时候让观众知道名字) |
| 多人对白像逐句点名 | 重要的是谁说话，还是谁接收到信息 | [覆盖](02-coverage.md)、[表演](09-performance.md)；[米铺](applications.md#多角色对白米铺门口谁在改变关系) |
| 想拆镜但不知该拆哪里 | 信息、动作因果、反应及生成复杂度哪一个需要新视角 | [覆盖](02-coverage.md)、[动画](12-animation-ai.md)；[斩蛇](applications.md#复杂动作斩蛇不是一次英雄挥刀) |
| 广角或长焦的效果说不清 | 是否改变了机位、主体尺寸和背景距离 | [摄影语言](03-cinematography.md)；固定条件后比较 |
| 运镜华丽却妨碍读动作 | 运动是否追踪必要信息，起止处是否可读 | [机位运镜](04-camera.md)、[调度](05-staging.md) |
| 角色反打像在看不同方向 | 轴线、眼线、站位高度与视线目标是否一致 | [调度](05-staging.md)；[门闸空间](applications.md#空间与连续性两道门为什么挡得住蛇) |
| 地点换角度就不像原场地 | 地标、几何、光源与出入口是否共享同一设计 | [美术](08-design.md)、[调度](05-staging.md)；回查平面与侧面 |
| 夜戏看不清但提亮又无气氛 | 主体层次与背景亮度关系是否明确；监看是否正确 | [光线曝光](06-lighting.md)、[色彩](07-color.md) |
| 每张图漂亮，连起来跳色 | 色彩脚本、白平衡、显示变换与镜间明度是否一致 | [色彩设计](07-color.md)；用同一监看条件并排比较 |
| 道具很多却不讲故事 | 哪个物件参与动作、关系、信息或伏笔 | [美术场地](08-design.md)；[歌本](applications.md#歌曲与声音完整唱完怎样成为行动) |
| 表情夸张却感受不到情绪 | 目标、障碍和反应变化是否存在 | [表演](09-performance.md)；[两次不去](applications.md#情绪表演两次不去怎样形成变化) |
| 动作看得见却没有重量 | 重心、接触、加减速、反作用和声音是否相互支持 | [动画](12-animation-ai.md)、[声音](11-sound.md)；[斩蛇](applications.md#复杂动作斩蛇不是一次英雄挥刀) |
| 剪得快仍然拖沓 | 是否重复同一信息；观众是否没有得到期待的变化 | [剪辑时间](10-editing.md)、[叙事](01-narrative.md) |
| 镜头一接就跳，补转场仍跳 | 跳的是空间、动作阶段、明度、表演还是声场 | [剪辑](10-editing.md)、[调度](05-staging.md)、[声音](11-sound.md) |
| 歌曲只是背景装饰 | 谁在唱、唱给谁、哪句或哪次呼吸改变关系 | [声音](11-sound.md)；[完整唱完](applications.md#歌曲与声音完整唱完怎样成为行动) |
| 音乐把情绪说得太早 | 画面尚未确认的结果是否已经被配乐宣布 | [声音](11-sound.md)；[斩蛇后等待](applications.md#复杂动作斩蛇不是一次英雄挥刀) |
| AI 总把复杂动作做错 | 是否混合多个独立动作与接触，参考能否表达开始和结束 | [动画转译](12-animation-ai.md)，再查[视频手册](../seedance-video-handbook.md) |
| 单镜合格，全场仍难理解 | 单镜没有覆盖的知情变化、空间桥接与节奏曲线是什么 | [叙事](01-narrative.md)、[剪辑](10-editing.md)及下列全剧检查 |

## 按制作阶段检查

| 阶段 | 要完成的判断 | 检查动作与结果依据 |
| --- | --- | --- |
| 读剧本与定意图 | 哪些是作品事实，哪些是可选表达；谁知道什么 | 读输入锁及完整相关场，写出本场变化、必须让观众知道和必须保留的未知；回查[叙事](01-narrative.md) |
| 场地与视觉开发 | 空间能否容纳动作，光色美术是否讲同一件事 | 画平面与必要侧面，标门、路、遮挡、光源、关键道具和人物尺度；联读[调度](05-staging.md)、[光线](06-lighting.md)、[色彩](07-color.md)、[美术](08-design.md) |
| 分镜与覆盖 | 必要信息、动作、反应、衔接是否都有可用镜头 | 先看关系与完整因果，再删重复覆盖；明确机位、景别、起止状态和切点；联读[分镜](02-coverage.md)、[摄影](03-cinematography.md)、[运镜](04-camera.md) |
| 动态分镜 | 时间安排与声画关系在连续播放中是否成立 | 放入临时对白和声音，逐场看、连续看，区分读不清与故意留白；不要拿静帧通过替代时间验收；联读[表演](09-performance.md)、[剪辑](10-editing.md)、[声音](11-sound.md) |
| 生成或动画执行前 | 专业意图能否变为稳定可执行的单元 | 锁定准确参考、完整状态、接触与遮挡；明确什么必须保持、允许什么变化；查[动画转译](12-animation-ai.md)与[模型手册](../seedance-video-handbook.md)，另核对调用授权及实际参数 |
| 单镜检查 | 生成结果或动画是否达到了事先写明的意图 | 看原件完整时段、关键接触帧和实际音轨；检查身份、动作、空间、光色、口型及声音；记录实际偏差，不用 Prompt 文本证明结果 |
| 场与集的组合 | 单镜衔接后是否保持方向、动作、声音与信息 | 连续播放并回查重点镜；校对出入画、道具状态、声桥、反应与时间省略；联读[调度](05-staging.md)、[剪辑](10-editing.md)、[声音](11-sound.md) |
| 全剧复核 | 风格、角色变化、空间规则、声音主题是否有一致发展 | 按剧中顺序看全部最终镜，再按人物、场地、歌曲和关键道具横向复核；重要变化须能追溯剧情或明确制作选择，不能以“每镜都通过”替代 |
| 交付与恢复 | 他人能否找到准确结果和继续制作 | 保留来源、准确版本、原件、真实调用、必要决定和未解决问题；技术完成与用户接受分开；使用项目已有评论回查与发布流程 |

## 最短决策记录

记录应足以让另一名制作者复现判断，而不必复制整章知识。可以沿下面的顺序写在下游任务原有方案或交接记录中。

1. 制作问题与观众需要理解的变化。
2. 准确作品依据、人物完整状态和不可更改条件。
3. 所读章节、适用原理与来源；不同流派的选择若影响结果也注明。
4. 至少两个实际可行选项，所选方案及放弃另一方案的理由。
5. 预期效果、检查材料和通过条件。
6. 实际原件与连续观看的结果、偏差及下一步；未经检查的部分保持未知。
