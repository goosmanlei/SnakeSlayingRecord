# 从制作问题进入影视专业知识

一场戏要让观众知道什么、期待什么、感到什么，决定了镜头、空间、光色、表演与声音怎样配合。本知识集合从这些选择的原因讲起，再把它们转成二维漫剧可执行的方案与检查。它面向学习者，也供后续 Agent 在实际制作前查询。

## 怎样阅读与使用

初读可按十二章顺序：先明确[叙事与导演意图](01-narrative.md)，再安排[分镜覆盖](02-coverage.md)、[摄影语言](03-cinematography.md)、[机位运镜](04-camera.md)与[空间调度](05-staging.md)；随后确定[光线曝光](06-lighting.md)、[色彩](07-color.md)和[美术场地](08-design.md)，最后联结[表演](09-performance.md)、[剪辑](10-editing.md)、[声音](11-sound.md)与[动画及 AI 制作](12-animation-ai.md)。光色、表演和声音也会反过来改变镜头设计，阅读顺序不等于把制作切成互不沟通的部门。

遇到具体困难，从[制作速查](quick-reference.md)的术语、问题或阶段入口进入；先看原理与适用条件，再看[六类本剧应用](applications.md)。来源编号可跳到[阅读依据](sources.md)，那里说明作者、时间、实际读到的范围及它支持的判断。来源不替读者作决定；主创使用过的做法不一定适合当前场景。

## 一次制作判断怎样形成

先用一句话写明当前难题，例如“观众必须看懂门先关、闸后开，才知道蛇为什么出不来”。再锁定不能改的剧本事实、人物完整状态、准确参考与既有用户意见。查相关章节，列出至少两个确有差别的办法，比较信息可读性、情绪、连续性与制作成本。用低成本分镜、空间草图或带临时声音的动态分镜检查，最后决定是否进入真实生成。

重要选择留下简短依据即可：读了哪一章、它在这里的适用条件、选择了什么、为什么放弃另一方案、怎样检查结果。需要变通时说明它要换取的表达，以及怎样避免让观众无意迷失。不是每个镜头都要填写全部十二个领域；跨镜与全剧复核负责发现单镜看不出的失衡。

## 哪些结论可以依赖

光学、曝光和数字颜色处理有可核查的技术条件；表演、节奏、色彩联想与镜头选择常是专业经验或流派取舍。正文会说明这一区别，并把本项目的选择写成建议。示意图表达给定条件下的关系，没有实拍、生成或观众测试的证据时，不把预期效果写成已实现效果。

本集合的权威性来自可追溯依据、明确适用条件和后续任务的查用约定。它不能覆盖用户明确决定、[制作输入锁](../source-lock.json)、准确作品事实、素材参考和准确选择规则。当前应用示例绑定剧本版本四，属于离线方法演示，不改变正式镜头方案、素材或历史认可。

模型能否接受某类输入、一次能生成多长、Prompt 如何组织，查[视频生成手册](../seedance-video-handbook.md)并在执行时核对。这里负责“为什么这样表达”，手册负责把已经明确的专业意图转成相应模型的调用与返修方法。模型暂时做不到某种镜头，不会改变镜头语言的原理；需要选择分镜拆分、二维合成或其他制作路径。
