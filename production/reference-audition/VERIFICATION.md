# 已选音频参考的准确试听

制作者从消费方案的“音频1”打开已选原件后，可直接点“试听已保存片段”，不用记住起止数字再圈一次。范围控件紧邻播放器；修改后点“试听未保存范围”只试听草稿，明确保存才改变生成输入，放弃恢复已存值。“播放完整原件”从文件起点播放全长；MP3 试听组成显示“播放完整预览”，不能保存为 WAV 原件。

本页记录 task-20261009-0029 的隔离使用和复验方法。正式发布、准确候选、正式两例回查及资源清理只认该任务账本和实际发布回执；系统准确提交由 `config/instance.json.review_desk_commit` 维护。规划和保护范围见 [任务规划](../../planning/reference-range-audition-task.md)。

## 隔离连续操作

Chrome 使用独立标签页，任务副本由执行时正式库的一致性备份初始化，预览端口56831。实际顺序为正式两例及手工对照、最小范围衔接、零起点、非零起点，再进行草稿、保存、退出重开、刷新与切换。

老汉范围试改为3–4.5秒：按钮明确显示未保存，试听不写输入。首次连续采样发现原有低频媒体事件曾让播放到4.553588秒后才停回4.5；据此增加终点调度。修复后捕获起播3秒、播放中最大4.497270秒，最后暂停在4.5。调度在终点前最多0.01秒内停止并定位终点，按实际媒体时间重查，停顿不按墙钟提前跳到终点。

明确放弃恢复2.7–7.08。再次保存3–4.5后，按钮转为已保存；退出后消费卡更新新值，重开捕获3秒起播、4.493202秒以内仍播放、4.5暂停；刷新消费页再打开，3.004118秒的首个播放采样、最大4.491818、4.5暂停。试改只留隔离副本，随后恢复原范围，不发布这些修订。

越界与倒置范围均拒绝试听；服务端保存失败保留原数字，放弃仍能恢复已存值。空数值、保存结果迟到、保存中继续输入、候选切换后回执、冻结方案产生新版本和制作许可由原契约及定向回归覆盖。

评论另圈1–2秒并在副本显式提交C282，仍绑定M1260的准确修订、original和原WAV文件；定位恢复评论1–2秒，生成参考仍为3–4.5。试听生成参考不改评论选段，清除评论选段不扩大试听范围。关闭时捕获旧媒体从连接且播放变为断开且暂停，不留后台播放。

## 切换与覆盖边界

真实两例均只有一个音频素材版本和一个候选。因此用只读进程把已有M1134与M1206准确原件临时组成两个显示版本及比较候选；不写版本索引，不创建音频或素材记录，禁止所有POST/PATCH。此处的组合只用于控件切换验证，不是已发布版本或内容判断。

真实浏览器换候选时，旧M1134播放器从0.189226秒播放变为断开、暂停于0.205609；新M1206 WAV未继承0–5.6。切为它已有的MP3 listening组成，原WAV停止，新组成从0暂停，显示“完整预览”，参考保存禁用。回原候选恢复0–5.6；切到另一显示版本，即使使用同一准确文件，也不继承保存范围；回V1恢复保存值。夹具端口63056，仅用于隔离验证。

134项定向前端回归与13项服务端准确参考测试通过，覆盖真实媒体时间调度、评论与参考分离、候选/版本/组成草稿隔离、元数据迟到、关闭、失败及准确引用；它们补充真实页面证据。冻结与制作许可用已有服务端隔离测试验证，没有新真实提交。当前有效数据没有视频原件，所以没有视频媒体实测，也没有生成补样本。

本任务只验证UI播放控制，不承担音色内容听审、音色保持或真实生成；外部AI和付费媒体调用均为零，没有耗时测量或节约百分比。

## 复验与保护

在[素材管理](http://127.0.0.1:3000/?workspace=materials.workspace&production_tab=materials)分别搜索M2669、M2673，打开方案后点音频1。直接试听已存片段，回读媒体起止；再明确播放全长，结束后返回片段，最后关闭并核对停止。正式复验只浏览和播放，不改范围、Prompt、评论、认可或历史。

浏览/试听没有保存请求，评论需明确提交。候选与文件读取失败不改投其他原件；冻结版本仍按原规则建立新制作版本，试听不绕过制作许可。正式发布采用既有代码服务发布器，逐表核对业务数据保全，不导入测试库。

必要本机证据包括任务`.runtime/reference-audition/`的基线记录、实际媒体时间序列与隔离截图，以及正式发布包和任务完成说明。正式两例、0005内容判断、输入范围、Prompt、历史、原件和任务inputs均保留。过程服务、数据库、缓存与只读夹具在完成发布和实际复查后按归属清理；worktree等会话退出、锁释放后再由受管入口退役。
