# 参考素材小卡候选选择

任务 `task-20261013-0004` 解决 M2974 首帧与 M2714 湿衣方案只显示“尚未选定原件”、无法就地比较和选择的问题。当前方案的直接参考小卡现在列出已有候选：图片悬停或键盘聚焦看原件，点击候选为这个方案的这个输入位置保存；对勾及绿色显示已选。没有候选显示“暂无候选”，有候选但未选显示“请选择候选”。唯一候选也不自动选择。

## 操作

在当前方案的“参考素材”找到对应小卡，移动指针或键盘聚焦候选以看图；触摸屏点击“预览”。点击候选即可保存，保存中显示局部进度，成功后对勾保持。一个候选含多个原件时先展开，再明确选择原件；不会默认取首项。素材名称继续打开原有实体／镜头详情，裁切和音视频范围沿详情调整。重复点击已选同候选、同原件不写入、不清除原范围；实际更换原件时清除上一原件的范围。

音视频在显式预览中提供播放控件，没有悬停自动播放。读取失败可就地重试；保存结果未知时重试原选择，沿原操作身份核对，不能先改另一项。并发冲突保留原选择并提供“重新读取方案”；重新读取后使用最新并发标记继续选择。历史候选展示真实提交时输入，不能通过这里修改历史；间接引用仍定位真正拥有者。
