# 已有音色的复用评估

当前工作用于把旧真实录音接回现有声音身份需求，依据原音、准确来源和具体镜头用途决定复用、等待比较或必要的新准备。候选匹配不代表质量通过；新的方案及片段不继承旧母版认可。

逐项判断和按集用途复核维护在 [reviews.json](reviews.json)。[analysis/](analysis/) 保存经脱敏的音频理解请求元数据、实际响应和用量回执，原始音频仍只引用受管 `export/assets`；没有新增媒体生成或虚构调用。后续复核先打开对应准确原件，不把模型转写写回历史记录。

本会话模型无法直接接收音频。经用户本次授权，Gemini 与方舟的音频理解服务直接读取原始 WAV，Codex再将可听观察与制作原文、真实时长及完整气口核对。模型的音区、语气和背景声描述可作为候选判断依据，个别文字、年龄感、混入说话者和时间估计仍可能错；有分歧时保留证据、针对原音复核，不能凭台词推测环境音或自动采纳。切点先有原音依据，再用 PCM 低电平间隙辅助定位；波形本身不证明音色合适。

选择通道的当前依据：

- Gemini 的[官方音频理解说明](https://ai.google.dev/gemini-api/docs/audio?hl=en)支持原音问答、说话者和表达分析。实际接口已成功读取受管 WAV，并返回音频输入用量；主要使用 `gemini-3.8-flash`，争议原音另用 `gemini-3.1-pro-preview` 复核。接口内部重采样和混为单声道，结果不能代替原生双声道细节、专业无损音质或设备回放验收。
- 方舟实时目录与接入点解析确认 `doubao-seed-2-0-lite-260428` 支持原生音频输入，见[火山官方能力说明](https://developer.volcengine.com/articles/7636596381943070763)。用户提供的现有接入点已实际接收 WAV 并返回音色、说话者与表达分析；此前另一个接入点不接受音频，失败回执保留，不计为听审。没有建立新部署或改变默认资源。
- 豆包语音的识别服务主要支持转写定位，不能以文字识别独立代替音色、表达和噪声判断。本次已有理解通道可用，尚未调用该识别服务。

本轮音频理解使用已有凭据，逐次调用、记录实际用量，不自动重试未知结果；本机采用保守的累计调用预留上限。目录价估算与真实账单分开，不据此宣称扣费为零或节约了多少生成费用。当前40个声音身份均已逐项完成原件分析与用途判断：26个可形成说话身份参考方案，7个需比较声音方向，3个需按当前方向新准备，4个因准确原件不足2秒需更长参考。这是候选判断，不是26个已获认可或已生成的视频，也不是已节约26次费用。全部17集按顺序复核，绑定269个含明确身份声音的镜头、443个“镜头—声音身份”组合；其余镜头没有本轮身份槽位。隔离候选已实操阿蘅、周掌柜、未认可的挑柴老汉和1.88秒听客原件：查看准确旧词与判断、播放、比较当前用途、保存合规范围及独立采纳。测试写入只在可弃测试库，不进入交付；正式增量发布与正式页面验收尚未完成。


原件与使用范围在逐项判断中记录：准确素材修订、原件组成、SHA-256内容指纹、起止秒、声音职责与不继承内容。26个适合项只采用2至15秒内的完整短段；超过15秒的整件通过选段使用。四份不足2秒的原件保持待准备，不补静音、不改时长、不搬用另一人声线。7个比较项的范围仅供对照，暂不启用；3个当前方向不合的旧件仍可回查，不作执行输入。

后续在当前音色需求的“已有候选”关系打开准确旧素材，核对原词和真实调用，再审阅本次复用或待准备方案。适合项的代表镜头直接引用准确旧原件与范围，当前音色需求保留用途说明，避免把旧录音登记成新模板试读结果。旧阿蘅与周掌柜两份母版认可仍只属于原准确版本，新的片段、方案与镜头不自动通过。

全量判断仍有专业边界：本会话没有设备直接回听；音频理解服务的观察不等于用户选角认可、专业音质或可靠声纹鉴别。年龄感、同音字、细微背景声和模型切点会出错。独立原件与调用只证明来源独立，不能证明多个相近声线的可听区别足够。说话参考只能提供身份线索，唱、哼、哭、笑、远送、新对白与声源空间须在真实输出中另验。未生成新视频，没有模型音色保持、口型或实际节约的验收结果。

迭代依据保存在各项的原音分析及17集复核中。后续原音使李寄原先低厚的判断失效，改为当前方向待新准备；李绡的轻清声亦不足以证明成年偏实方向。老妪的年龄与干涩、屋后伙计的声区等模型分歧保留，不靠模型票数裁决。多个模型推荐的起止点会截词，已用完整气口纠正；这不代表所有细微声学描述均获确认。若作品、声音方向、原件或具体发声事件发生变化，编制闸门会要求重审相应准确用途，不自动沿旧结论选择。
