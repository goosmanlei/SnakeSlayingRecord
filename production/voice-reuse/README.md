# 已有音色的复用评估

当前工作用于把旧真实录音接回现有声音身份需求，依据原音、准确来源和具体镜头用途决定复用、等待比较或必要的新准备。候选匹配不代表质量通过；新的方案及片段不继承旧母版认可。

逐项判断和按集用途复核维护在 [reviews.json](reviews.json)。[analysis/](analysis/) 保存经脱敏的音频理解请求元数据、实际响应和用量回执，原始音频仍只引用受管 `export/assets`；没有新增媒体生成或虚构调用。后续复核先打开对应准确原件，不把模型转写写回历史记录。

本会话模型无法直接接收音频。经用户本次授权，Gemini 与方舟的音频理解服务直接读取原始 WAV，Codex再将可听观察与制作原文、真实时长及完整气口核对。模型的音区、语气和背景声描述可作为候选判断依据，个别文字、年龄感、混入说话者和时间估计仍可能错；有分歧时保留证据、针对原音复核，不能凭台词推测环境音或自动采纳。切点先有原音依据，再用 PCM 低电平间隙辅助定位；波形本身不证明音色合适。

选择通道的当前依据：

- Gemini 的[官方音频理解说明](https://ai.google.dev/gemini-api/docs/audio?hl=en)支持原音问答、说话者和表达分析。实际接口已成功读取受管 WAV，并返回音频输入用量；主要使用 `gemini-3.8-flash`，争议原音另用 `gemini-3.1-pro-preview` 复核。接口内部重采样和混为单声道，结果不能代替原生双声道细节、专业无损音质或设备回放验收。
- 方舟实时目录与接入点解析确认 `doubao-seed-2-0-lite-260428` 支持原生音频输入，见[火山官方能力说明](https://developer.volcengine.com/articles/7636596381943070763)。用户提供的现有接入点已实际接收 WAV 并返回音色、说话者与表达分析；此前另一个接入点不接受音频，失败回执保留，不计为听审。没有建立新部署或改变默认资源。
- 豆包语音的识别服务主要支持转写定位，不能以文字识别独立代替音色、表达和噪声判断。本次已有理解通道可用，尚未调用该识别服务。

本轮音频理解使用已有凭据，逐次调用、记录实际用量，不自动重试未知结果；本机采用保守的累计调用预留上限。目录价估算与真实账单分开，不据此宣称扣费为零或节约了多少生成费用。完整判断、复用方案、候选页面和正式发布仍在推进，当前文件不是结项报告。
