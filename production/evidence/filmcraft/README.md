# 影视专业知识交付证据

本任务将影视制作判断整理为一个可独立阅读的知识集合，并沿既有“制作思路”交付 `filmcraft` 子页。[专业正文](../../filmcraft/README.md)是唯一正文来源；本目录仅保存核查证据，不进入学习页面。

## 研究与非作者复核

[研究审计](research-audit.json)记录十二领域的实际来源、案例、图示和文件摘要。共70条来源记录，68项计入有效独立专业来源：LD20只作实际观察的画面来源，不计专业文献；PA11与SP04属于同一套Yale教材，不重复计数。每领域有4至8项有效来源。所有来源说明机构或作者、时间、读取范围、定位和支持的判断。

六个深入行业案例为《十二怒汉》《1917》《寄生虫》《布达佩斯大饭店》、Big Buck Bunny 与 Caminandes；另有六类本剧应用、十二组原创解释图、49项术语、18个问题入口和9个阶段检查表。行业静帧仅支持实际可见内容，两段影片使用每0.25秒采样并声明粒度；没有把采样当作连续播放、完整运动质感或声音验收。

三名 gpt-6-astra / ultra 研究者分别负责01—05、06—08、09—12章；主执行者负责统稿、应用、速查、派生与页面。非作者交叉复核全部45项关键论点及38项普通论点，每领域至少3项普通抽查。回执分别见 [空间复核](../../filmcraft/review-space-by-post.json)、[光色复核](../../filmcraft/review-light-by-space.json)、[表演后期复核](../../filmcraft/review-post-by-light.json)。

复核实际发现并修正了围栏出现顺序、超出已读原文的归因、两处图示歧义、术语和创作者实践的适用范围；发现实质偏差后扩大了对应章节/图示检查。主执行者完整通读各章、应用及速查；[应用复核](../../filmcraft/review-applications-by-light.json)另完整读取10场276块、核对锁内文本摘要，并修正未熟词、门闸空间与阿蘅动作时序。这些是本任务可证实的分工收益，未估算相对单主线的提速或质量百分比。

## 音频核验边界

用户补充授权使用Google Gemini，最多3次理解调用、预算1元人民币。两次请求成功、一次因模型对新用户不可用返回404，均无媒体生成；实际模型与用量见 [脱敏回执](audio-validation.json)。一个零值PCM静音对照被错误描述为哼唱；后续组合分析也不足以构成可信的原件听辨。全部输出均未纳入声学事实，未宣称已试听行业片段或本剧歌曲。

声音章以实际读取的声音创作者文章、专业课程职责、原始技术资料及标准建立方法；本剧声音例仅基于准确剧本提出后续方案。任何实际音质、口型、声场或混音接受仍须在相应制作任务中用准确原件试听。报价估算不是账单：成功请求按返回token及公开单价约0.00476325美元；事前保守预留按预算换算不超过0.75元，没有把换算用的10元/美元写成实时汇率。

## 页面与实现验收

正文完整派生为16个阅读章节，来源目录和SVG也由同一输入生成。独立审查逐字顺序比较56,651个非空白可见字符无差异，264处本地链接均有准确目标。保留故事创作、生产制作及视频手册的正文、路由和顺序。两个确定性同步检查通过。

[独立代码审查](code-review.json)发现并复验两项修复：SVG声明/外部基址的校验边界，以及未完成的故事结构圈选阻止方法图打开。桌面和390像素窄屏真实Chrome验收见 [浏览器回执](browser-preview.json)，包括目录、来源小节、刷新、历史与阅读位置、表格、原始尺寸图示及缺失/损坏状态。自动测试及VM检查不代替这些页面证据。

系统完整Python测试373项通过；随后两项修复通过受影响API7项及前端24项独立回归；最终完整前端670项通过。主仓派生4项、视频手册3项、发布保全14项通过。正式运行的准确提交、镜像、挂载、数据比较、正式浏览器和清理结果由冻结包及主账本完成回执保存，避免交付后回写候选。

## 发布与保留

本次不改剧本、镜头方案、素材、采纳或业务数据库。双仓准确提交引用、集成、必要推送、正式服务切换和数据保全沿既有发布脚本执行；只有正式浏览器复验后才能结项，技术验收不等于用户逐项接受知识与作品。
