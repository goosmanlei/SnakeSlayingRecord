# 借据揭纸：原约与添字

准确依据：S022:10 先露“六”；12 露完整“本息共六斗”；13—14 新贴纸另放后，边缘小字“愿入庙供奉”可读，末尾对着母亲手印的原接位。第9集 A03/04—05 连看；第3集 A02/04（ASH055）不得启用本交接的可读条款。

original.svg 与 overlay.svg 各一竖列 text，保留独立载体。旧据“本息共六斗”来自原约，贴纸“愿入庙供奉”是新增小字；其余逾期添粮条款没有准确全文，不编造条款、日期和整页借约。手印是原有图像，不重画成签字。

从准确贴合的完整旧据字区起做遮罩，润湿、等待、挑角的底板保持纸材与接触；盖纸遮罩先仅开到“六”，再随湿纸翻起显全列。不是把其他四字后写到纸上；字一直在下层。下一镜贴纸放旁才使供奉小字完整可读。两张纸分别跟踪并按湿皱做局部网格，湿布、手指、木条和翻起纸角处于前景；字不可穿透纸、黏到木条或随镜头固定。

按真实帧率逐帧回看从遮住、露六、全列到分放：第一处不能读全句，第二处正常速度完整读五字并停两秒，下一镜读清供奉五字及与手印的拼接关系。两纸随后分别夹好留证。静态文件只证明字层可编辑和原词正确，不证明已有真实揭纸镜头；实际视频未产出。
