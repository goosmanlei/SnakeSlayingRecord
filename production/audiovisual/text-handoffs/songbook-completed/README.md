# 《送青篷》补词新页

准确来源：剧本四 S039:5、7、9—16。阿蘅先唱到“柳影到船边”，歌娘才接下句；末句核准“认旧桥”，不是“过旧桥”。page.svg 分六个可编辑竖列，右至左依次对应 words.txt 的六句，标点在原词文件保留、竖排以分列代替句读符号。没有创造其他段歌词。

第16集 A03/01、03 尚未访师，继续使用缺词页工程，之后空白；A04/02 在听歌娘接唱，不能把她未核过的全部歌词提前铺满纸；A04/03 才随李寄落笔增加后四句，问末句时停笔，核准后完成并交老师逐行看。询问“过还是认”不等于写过一个错字，不新增“过→认”的涂改。剧本只说补正一个写歪字，没有指定哪字：实际画面选择已给字中的一处轻微歪笔作局部修正，不新增错词；完成字形必须逐字正确。

纸形、笔尖接触、手指与夹板由画面准备，后期在准确纸面位置排字。先将“柳影到船边”既有列对齐前页锚点，再布置已知首句与新增四列，保持左脊、纸边和页方向，不能因换SVG尺寸就移动原有字的位置。六列是可编辑源排版，不是已经贴合的镜头；可按实际净纸区等比缩放列距与字号，但不改原词、列序或补齐时机。

写入用笔尖路径遮罩控制各字出现，纸弯曲用网格跟踪，手和笔作为前景。A04/04—05 已核完可用完成版，唱词沿已有音频方案，字层不变成卡拉OK字幕；李寄听唱时不再假写，老师只在规定换气处拍膝。静态层已可编辑，真实笔迹、读时、遮挡及稳定性要在实际视频逐帧和正常速度检查，不能以SVG替代。

验收时逐句比对“青篷过河湾／柳影到船边／莫怕远山高／隔水灯相照／明年春水暖／归来认旧桥”，重点防“篷”写成蓬、“认”写成过、桥字漏木旁。先看旧页仍缺，再看新页核完；旧损坏不能被新文本覆盖抹平。

第17集 A01：S040:1—9 从歌娘核词稿誊抄新页，开头只写到半页，李寄疤绷笔歪后停，阿蘅主动接笔；“莫怕远山高”“隔水灯相照”按朗读一句、写好一句控制，最后一行写完才放笔。最终仍是同一六句，不增未知错词，也不把先前核词稿误作本镜已写满的起帧。之后先低唱通过断处，再把旧残页夹后、将新页对齐穿线，试翻不松才合本交回阿蘅。

演出时 A03/03 台侧翻到新旧页交接，字列随纸翻动，另一面及被指压处不可透字；回家 A04/07 摊给母亲，复用同一新页。第一段演唱当前没有逐字阅读纸面的镜头，未知旧页不因歌词出声而重新补满；本工程只准备必要的第二段新页，不新建全本歌词字幕。最后门半开不另叠结论文字。
