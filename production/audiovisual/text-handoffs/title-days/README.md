# 数日后：时间标题

准确来源为剧本四 S035:1“数日后，县衙廊下。”；第15集 A03/01（ASH291）。只排“数日后”，不补日期，不改“翌日”。此刻从归家饭局跳到数日后的遗物认领，还不是二十多天后的复查处置。

layer.svg 为透明1920×1080、可编辑 text 的独立画幅字层，words.txt 是UTF-8准确原词。画面生成负责廊下、桌、两块布及遗物分放，首帧不把时间字当实物或动作。剪辑合成在廊下开头叠标题，建议先试约2秒，正常速度读清后消退；实际素材若动作遮挡或读时不足再调整。标题保持画幅坐标，不跟踪纸页，不遮手、遗物与脸，不新增旁白。

继承另外两个时间标题同字形、字号与画幅内边距，但保留各自原词与故事间隔。验收时先逐字比对，再以720p实际播放尺寸看正常速度；还没有真实视频，SVG可读不代表认遗物镜头已验收。
