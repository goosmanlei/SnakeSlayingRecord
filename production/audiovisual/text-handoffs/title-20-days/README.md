# 二十多天后

用于 ASH304（第16集 A01/01）新告示场开头。准确依据是剧本四 S037 第1段“字幕：二十多天后。”；第2段接新告示贴平、人群聚听。它说明调查与复查经过时间，不能改为翌日或当天即判。

## 如何使用

选择确定性画幅文字层：`layer.svg` 是透明 1920×1080 画布，保留可编辑 `<text>`；`words.txt` 保留准确原词。字体示例为宋体，导入编辑器后确认本机实际字体并逐字校对，不以缺字替代。此文件是排版起点，不是成片字幕轨。

画面生成负责白日庙前告示墙、浆糊刷压平纸角、人物聚拢和自然声音。首帧从新纸尚在贴平的动作开始，不绘制画幅标题。视频延续贴纸到人群聚听，不在画面中变形生成时间字。

合成者在镜头开头叠入标题，建议先试 2.5—3 秒，随实际镜头停顿微调；应在书吏开始长句前读完、淡出，避免与纸面告示争夺注意。标题置画幅下部留白，避开人脸、手和纸面证据；具体位置随真实底板调整，不绑定纸墙透视。

## 检查与交接边界

先核原词与透明底，再在交付 720p 画面及实际播放尺寸正常速度观看：一次读清、不被裁切、不遮动作、淡出后不重现。只有“二十多天后”，不加剧情解释或标点替代原词。

当前交付只证明文字可编辑、原词准确、文件可取得。没有本镜生成视频；叠入真实画面后的读时、位置和逐帧稳定性由合成者检查并交回审阅，不据静态示例宣布镜头通过。
