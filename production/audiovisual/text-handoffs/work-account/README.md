# 歌本背页记工：从“两升”开始

第3集 ASH059—060（A02/08—09）依据 S006:27—33。赵执事先答“两升”，阿蘅用半截炭头在歌本背页记下“两升”，再口头确认“一天两升。做一天，就从欠账里扣这些。”；李寄绕浅滩来后才看背页，没有旁听谈判。

本阶段 `rate.svg` 仅是纸上“两升”的透明可编辑两字。不要把口头“一天两升”整句提前写到纸上，不提前出现第二日记录、圈四升或未知日期。

生成者保留残本的灰青封皮、皱旧页和背页，炭头由阿蘅拿起并接触纸面；可写区域留干净纸纹，不新增可辨数字。合成者按炭头动作显出两字，字附着同一背页，随持纸、展示与翻回变化；手指遮住之处不穿字。炭灰粗细应像炭头，不能做成印刷单据。

正常速度读清两字，核对动作先写后展示、字迹不滑、不跨页，不把“升”变“斗”。后续实际记工将沿同一背页追加，不能在本镜用一张已经填满的母版。当前交付为可编辑排版与制作交接，实片的手部遮挡和书写轨迹仍待生成后检查。

## 第4集：两日累计

ASH064（A01/03）依据 S007:3，夜账已经明确约定写作“一日两升”，在其下记第一笔；ASH066（A01/05）依据 S007:5，再记一行“两升”，然后圈住两笔，合计四升。`day-one.svg` 与 `day-two.svg` 分别提供这两个阶段。不能把“一日”误排为“一天”，也不能把约定的两升计入已做工钱，变成三笔六升。

三个文件沿同一横排坐标：第3集只露工价末尾的“两升”，第4集夜账完整标题为“一日两升”。具体日历日期原文没有给，实际笔动作保留，日期栏用画面裁切、手指或不可辨笔迹处理；示例不造年月日，也不把“第一天”“第二天”当纸上原文。第二夜只圈两笔，不额外写未指定的“共四升”汇总句。

旧参考 `asset-fg3-songbook-account-image-01`（原件 `35a0241a103f9ce8034c3aedeaab3687415d5edcfa80b2ef016a0ef6384747c7.png`）实际可读“一天两升”及一笔“两升”。它可比较灰青本、炭字和布局，不能直接证明本镜“一日两升”及两笔工钱已经准确，更不能用于第3集初写时提前填满。保留旧原件与原评价，按本镜阶段决定局部字区修正；不用重画整本。

夜账近景应在笔移开、圈合拢后正常速度看清两筆“两升”属于不同日、圈里没有工价标题。第一晚镜尾与第二晚镜首沿同一纸向和已写位置，只有日期/第二笔与圈增添；灯影、手与笔遮挡随真实运动复核。
