## 选择与责任

本镜涉及翻页及揭开，采用保留纸面运动、独立校准字层的路线。生成者保留碗压封皮、夹纸所在层次、风翻页后露出首张、纸页连续轮廓；手指与纸的接触、折痕和视差真实连贯。用于贴字的可见纸区避免随机可辨字，保留纸纹和光照，不把层名或后期说明送入画面。

合成者将文字贴到首张纸的同一局部坐标，随纸透视、弯曲和翻动变化；用纸缘、折痕确定跟踪，折面必要时分区。文字在碗、上层纸、手指后方，先被遮住再随露纸显出，不能浮在遮挡物上，也不能跨到歌本封皮。若实片无法可靠跟踪，先退回较稳定的读字停顿或局部补板再复核，不以固定画幅字幕替代纸面证据。

采用旧 PNG 直接复用时同样逐帧核字；模型如果改动字形，就改用这份字层修补该可见纸区，保留未经修改的原件另行引用。字层透明 SVG 的 600×800 只是纸面局部排版坐标，不是要求实物长宽或画面分辨率。

## 检查与交接边界

合成前比对原词、右左顺序和旧原件；在真实 720p 镜头及实际观看尺寸正常速度读一次，再逐帧看翻页开始、最大透视、遮挡交叉、展开停顿及离镜。要求十字在应读的停顿完整可辨，不变字、不滑动、不穿遮挡；不要求观众在翻动过程强行读完。
