# 县衙文书与祭册

依据剧本四 S017:7—12、19—24、43—49；第7集 A02/02、A02/04、A03/03—04。先错误旧纸，后县衙抄本，再新白纸声明。词与载体是三组，不能叠成一份文书。

旧纸：old-form.svg 的“李寄”与下一行“自愿入祀”。李寄姓名来自 S017:5—7，条款由李绡读出。先填名后向下写，父亲压住时字随纸被手遮住；此旧纸未接受，不放任何本次同意手印。用书写遮罩逐笔或按笔尖揭出，不把字悬浮到画幅上。

祭册抄本：copies.svg 的“阿禾”“小满”及各自“自愿入祀”。现有准确候选 asset-fg3-sacrificial-registers-copies-image-01（修订 0cc7110c104c7efac06aa70c33d17d6a68e84b89970fa788580d08ebb7ac6836；原件 3c47553e6cb3d3c181800b31aca70cf1e370d38f6f35e6a69aa8175dab027585.png）已看，可优先保留正确片段；SVG 是局部替补。两个册页分开贴，不把它们当作后来封出的原件。年份、送祭日期和发粮数没有逐字给出，用不可辨笔迹、翻页及构图表达类别，不能编造年号或账数，也不能让未知数字成为阅读焦点。

新纸：nonvoluntary.svg 采用阿蘅要求写下的原句“我不是自愿的”（S017:47），这是按原话落纸的制作选择；写前该行空白，书吏写完她才收手。旧参考 3e83f8cd4e9063b6d64d8071b25c6de340ca77aa5d8342f6189a2b169e1618dc.png 中已有多项条款、另一种转述“本人非自愿”和多枚手印，不能直接当此刻完整新纸，更不能把旧认可迁给本字层。仅可参考纸张和核准条款片段。

阿蘅免祭纸与四人各领的应募文书分开。关键条件沿原有场内读回：此次免祭、不抓别人补数、查清以前不索人；不把“永久禁祭”提前写来。全文、具体日期、姓名之外的签名和官印文字未给，不补造可读长文。读回与条款动作沿已有声音方案，不新增念纸的旁白。没有必要让每项全文同时清晰入画。

交接步骤：纸材、空行和手部运动由画面准备；只在需要读的镜头将字贴合相应纸面。分别跟踪抄本、旧纸、新白纸，使用各自四角透视与弯曲网格，指尖、笔、压纸手和折叠页作为前景遮罩。按原始帧率逐帧核出字时机；在720p实际显示大小正常速度读一遍，检查名字与声明可读、没有提前写满、折起后不透字。文件只有透明可编辑 text 排版，真实视频尚未形成。

第11集 A03/01：S026:26—30 的“那一行”依紧邻阿蘅担心再被改口的对白，选非自愿声明作为纸面阅读焦点，这是具体构图选择，并非原文另给新条款。沿 nonvoluntary.svg，纸已写完且折过；灯移近只改变照度，字不重新出现或自行发光。承接她明日仍要亲口说的行动，不以这一行替代她的发声。

第15集 A04/01、08：阿蘅转今年原册，姓名沿已看三本原册的阿蘅字形；父亲翻阿禾、小满原册指出自愿入祀与官印。copies.svg 的准确字形可分别贴到原册对应页，文件名表示首次使用，并不把原册替成抄本。纸材、折痕与保管来源沿本镜准确原册；未知入洞日期不拍逐字特写。借据供奉字层独立使用，不贴进祭册。
