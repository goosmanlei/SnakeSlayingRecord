# 准确文字与可编辑字层验收

本交接覆盖剧本四当前必要的准确文字，逐集判断见 [文字复核](text-review.md)，操作入口见 [制作说明](README.md#准确文字与可编辑字层)。它交付准确排版和责任分工；没有新增图像、音频、视频付费调用，也没有完成真实镜头合成。

## 已核对的候选

先在原入口回查 ASH304 时间标题、ASH025 领唱旧纸与 ASH055 未揭纸反例，再用本任务隔离库实际登记、打开和下载最小工程。第一次操作发现工程内联没有原件与交接正文，且外部制作未绑定制作时的要求；修正通用展示和准确引用后重走下载、原词和反例。其后按集顺序推进到第17集，每集的取舍和相关前集回查随实际完成记录，不以最终清单代替过程。

最终候选共11份ZIP、17个SVG；已逐包核对原件哈希、UTF-8、可编辑`text`元素、制作记录及准确要求引用。旧M1410保留原修订和1448×1086 PNG原件，十字正确但没有变为可编辑层。没有给新工程自动登记认可或采纳。

在吸收执行时双仓最新主干后，Chrome从“生产制作 → 视听制作”进入对应集镜，实际选中ASH304的标题工程及ASH025的纸面工程，读到准确原词、来源、操作职责、检查依据并下载同哈希ZIP；工程显示外部制作说明，不显示不存在的模型。ASH055的视频方案仍是纸角翘起、旧墨不可读、伸手未揭便被收回，原对白保留，后集供奉条款未提前出现。

静态示例检查透明字层的字形与列序；示例底色不是故事底板。标题与纸面工程都没有纸面运动成片，实际720p中的透视、遮挡、书写进度、阅读停顿和逐帧稳定性仍须在真实视频上复验。

编制复跑为零变更；全剧344镜的声音说明、视频音频输入、原有未定发声阻断及明确发声行与基线相同。全剧输入职责核验覆盖65场344镜，原模式和采纳／原件选择闸门保留。合并后的通用系统Python与前端回归通过；本任务相关故事编制测试通过。确切数量、日志及页面证据保存在任务本机回执，不作为未来固定基线。
