# 视听制作重构核验

本页记录交付候选的实际检查范围；正式切换、两仓 Git 交付、容器身份、正式页面复验与过程资源删除以主项目任务账本和本任务冻结包 `run/` 回执为准。这里的技术验证不授予作品采纳，也不把隔离测试媒体算作本剧成果。

## 全剧编制与内容

已逐集重编 17 集、42 故事场，形成 65 视听场、344 镜，完整覆盖 1114 个正文块。作者稿给出目的、场划分、构图、动作起止、表演、调度、轴线、光色、声音、剪辑和连续性；[逐集复核](review.md)记录具体制作选择及跨镜检查。正文覆盖检查不是文学判断的替代。当前预留 6021 秒，约 100 分钟；按用户选择允许适度加长，优先让动作和表演读清，没有生成实片证明时长。

编制包包含 426 个视听对象、1534 项新需求及 4807 条素材生产关系，另外保留四项独立歌曲需求。既有 134 个实体、280 个状态及素材按当前用途重新核对；133 个实体在日常管理页有效展示，一项已撤回的包布身份仅承载必要真实来源，不重新授权生成。317 份保留素材及其 951 个原件／请求／回执组成逐项核对。出现与提及、状态适用与镜内变化分别编制，旧镜数没有作为新拆镜约束。

## 系统与真实页面

通用系统回归覆盖不可变视听引用、同镜多需求、每需多版多候选、选择路线、缺项与循环拒绝、自定义说明不执行、裁切及时间范围、准确来源、组采纳与子项撤销、异步返回保护和当前 Schema 9 恢复。故事导航实际回归发现并修复了采纳接口局部函数名遮蔽结构读取的问题，增加真实 HTTP 回归；系统 387 项 Python 回归与 672 项 JavaScript 回归通过。故事侧最终 190 项回归全部通过，包含真实 HTTP 评论／恢复及正式切换辅助脚本的五项文件身份和冻结输入边界检查，无跳过。

Chrome 隔离浏览器已操作 1440、1280、850、390 像素代表视口。覆盖全剧导航、长镜方案、来源全文与高亮、实体关系、状态关联镜头、叠层返回，以及管理分页、候选和参考交互。390 宽度无全页横向溢出，素材管理每页 40 张卡在 390 与 1280 切换后保持同一集合。

明确标注的隔离合成夹具验证同一镜头的正面、侧面、首帧与视频需求；视频空结果版不混入其他版结果；同需求跨版本双候选比较。实际点击播放合成音频及视频，确认互斥播放和关闭暂停。图像裁切、音频区间保存后重新打开核对；评论圈选、跨版本草稿、提交、编辑、关闭、重开和定位均在测试库操作。测试没有写入正式作品库，也不构成音质听审或作品生成。

## 正式发布与恢复顺序

1. 故事与系统候选分别提交，实例固定准确系统提交；任务工具准备两仓集成候选。
2. `audiovisual_release.py prepare` 冻结准确设计、清单、导出与辅助脚本，核对正式基线和保留原件；构建准确镜像并只读预检。
3. 在正式发布锁内再核基线和运行身份，停止旧应用写入，消费任务工具 Git 交付回执；事务切换后核对结果指纹、外键、原件，并回收数据库空页。
4. 安装新服务，真实 Chrome 复验后按准确 ID／路径清理本任务预览、旧副本和测试媒体；当前正式库、镜像、配置与最小凭据保留。
5. 已切换时沿同一冻结包向前恢复；完成后只用当前净化导出恢复到新空实例。禁止回灌旧库。工作区仍被会话使用，退出后由任务工具受管退役。

本任务实际图像、音频、视频生成调用数为零，媒体生成额度消费为零。
