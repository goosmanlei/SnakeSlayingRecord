# 镜头阶段一致性复核

本记录说明每场怎样从准确剧本确定可见起点、动作与声音，再在隔离审阅台回读。起点和条件以各集逐场稿及 `shot-contexts.json` 为准；准确参考职责、局部文字状态和输入锁见 `video-inputs.json`。这里只记录实际完成的判断与回读，不把方案一致性写成生成结果。

## E01 · 两份米

### A01 · 唱到跳页处

观看任务是先建立阿蘅靠手艺换米、与老汉打趣的日常，再让李寄由手先入场。按动作连续性原则，ASH001 改从歌本尚在手中开始，摊本、压石、唱第一句、老汉立扁担、翻页依次发生；ASH002 从已翻到归家页开始，保留老汉接唱扑空与阿蘅尾腔；ASH003 从尾腔收住而听客未散开始。ASH004 只先显露伸来的手，后续完整人物仍由原补充图负责。稳定的米铺方向、光色保持。

首轮隔离页面连读并打开故事依据、首帧后，发现文字状态仍把“扁担已竖好”和预付米的后续使用带进首帧。据此只为 ASH001 的文字状态明确斜持扁担和柜内干米，保留准确状态引用，不修改状态准备路线。又把 ASH003 同一源段的笑声、回话、欠身、散开交错排列；阿蘅应答原词未定，仍由原阻断项拦住准备，不补词。

修正后已在 Chrome 的本任务隔离实例回读 ASH001 完整首帧与视频、ASH003 完整视频及待准备说明。原唱句、接唱和尾腔保留；尚无实际媒体生成或播放。

### A02 · 工钱与预付

观看任务是区分已挣到的工钱与下一场婚礼工作的预付，并用递本又收回体现两人的亲近。五镜分别从“端斗尚未倒”“米倒尽尚未系袋”“答应邀唱后尚未回柜”“预付已入袋尚未移开”“檐外两手仍空”开始；量、倒、撑袋、答应、另抓、再开袋、扎袋、移步、欲提袋、递本又收回均保留。柜内到柜外的交米方向继续适用；后两镜改为檐外同侧双人关系，不再要求掌柜占据前景对话轴。

已在隔离 Chrome 切到最新集版本，连读五镜完整视频，打开 ASH006 首帧并返回比较 ASH010。按首场发现继续限定前三镜米粮文字状态；原空袋、工米袋、同袋加预付的准确状态变化保留。

### A03 · 干净的手与旧名字

观看任务从净手后才接本，转入邀请与女孩对旧名字的警觉。每镜起点前移到尚未倒水、尚未搓手、狗尚未跑来、话尚未停、旧纸尚未取出等可见状态，保留擦手、递饼、抢答、阿蘅接回本子的自主选择。赵执事离开与李寄取纸未果同属 ASH017；不删离开动作，也不让他在 ASH018–020 继续站场。普通街道光色保持，末镜只留陶伯的手、篮口与空凳；不以回忆画面替代被提及的死者。路人短唤后赵执事点头，发声与反应按次序穿插。

已在隔离 Chrome 连读十镜的完整视频，打开 ASH017 对应的 S002 全场来源，再返回打开该镜首帧，核对赵执事仍在起点、随后离开的连续过程。ASH018–020 的条件不再召回赵执事。首帧参考已收窄手部近景、未取出的饼和未抽出的旧纸，后显身份沿直接补充图交接。

本集连读后的回查：A02 原轴线把周掌柜固定在柜内，与他走出来、再回柜抓米冲突。改为保持画面左右关系而允许实际移动。后续各集同时检查镜头稿、条件、文字状态、参考裁切、声音位置与当前版本；不能只修改起止摘要。E01 的设计、来源和素材方案已实际打开回读；原件均未选择或生成，缺词阻断继续生效。

## E02 · 河里的歌本

### A01 · 手比话快

观看任务是让李绡的劝告与李寄随后擅自取本形成因果。ASH021 先放米袋和歌本才工作；ASH022 先索取、端来浆糊，再扶下颌、装竹条、姐妹同笑，阿蘅最后端盆去浅滩。后两镜保留姐妹同侧，阿蘅在远处，不能站在旁边听她们谈论自己。

ASH025 原首帧和准确字层补充起点都已到窗前，却仍要求从屋后呼喊、姐姐离开重演。现选择一镜轻跟：姐妹仍在纸蛇旁 → 画外呼喊 → 李绡离开 → 李寄放稳纸蛇 → 到窗前看旧纸 → 听见河边练唱并转回目光。代价是开场由歌本近景扩为姐妹中景，再收近；保留行为因果而不新增剪切。字层仍在风翻页后才露，屋后伙计与阿蘅留画外，呼喊和练唱原词未定仍阻断准备。

已在隔离 Chrome 连读 ASH021–025 的完整视频，打开 ASH025 首帧和 S003 完整来源，再返回 ASH024。首帧仍是姐妹与纸蛇，窗前字区在后段才显露；两条缺词说明留在“生成前仍需”。

### A02 · 水里的几页纸

ASH026 从“碗仍压歌本”起，接前镜李寄看旧纸的落点，保留移碗、取本、门口迟疑、跑下浅滩、扔本、松手与阿蘅发现书页。根据完整动作所需停顿把预留由12秒调为18秒，计划使用既有长时段模型路线；没有实片时不认为自然时长已验证。镜头从窗台同侧跟向浅滩，沿既有出路展开，后显阿蘅与浅滩由补充图负责。

ASH027–029 分别从仍在上游、李寄尚在岸边、两人尚未交纸的可见状态起，保留阿蘅主动抢救、李寄辩解被截住、卷裤下水、陷脚与扶稳后松手。ASH030 保留明确时间省略：暮色中残页已摊在石上，不再补演整个晾页过程。ASH031 先听收铺声再收残页、回门内提米、扶盆后追；米袋在首帧不提前入手，结束时也不再被条件固定在屋内。

已在隔离 Chrome 连读六镜完整视频，打开 ASH026 完整 S003 来源与首帧，再返回 ASH027。起点明确是窗台碗压本，已离开的姐姐不返回；后显阿蘅由直接参考负责，18秒仍为未实测的方案预留。首帧 M3049 和视频 M3050 保留原对象身份，新修订未自动采纳。

### A03 · 退回那一份

本场让失词产生失单、退预付的现实后果。ASH032 从掌柜尚未挪开算盘、阿蘅仍抱纸包开始，扩为三人中景以容纳腾柜台和铺页。ASH033 从第一次句尾仍有拍子开始，再找下一行、拍子独停、提出重试、靠近灯下、吸气重唱；第二次仍唱同一已锁定起句，不合并两次尝试，不补缺词。ASH034 先看黑纸，李寄才提问母亲，病情仍由掌柜口述，母亲与咳声不入场。

后段分别由纸条仍在柜上、残页仍摊开且米袋系着、袖口尚余最后一粒开始。阿蘅主动收纸、退米、捻米和道谢都保留；李寄伸手来迟不能变成代她完成。最后一粒跨镜接续是同一动作的落点，不重复捻完两次。

已在隔离 Chrome 连读六镜完整视频，打开 S004 来源与 ASH032 首帧，返回第二次试唱。回读编制结果发现米粮文字状态仍含领米动作，已收窄 ASH036/037 并在页面分别重开首帧复验：退米前袋口系着，收尾仅余一粒；未改变原状态身份或原件准备闸门。

### A04 · 不能补回的一句

两人共同出铺，阿蘅先行，李寄追问；原场境中的“李寄在出口等待”和全场面对面均结束适用。ASH038 从两人尚在门内起，短随到岔口；ASH039 保留阿蘅转身抱紧残页的主动中断。ASH040 的反问仍可在画外，画面留给李寄答不上来的沉默，不因有阿蘅音色而把她挤进平视近景。ASH041 从尚未点头起，阿蘅拉开距离后回头；ASH042 则保留已经回头的状态，让提醒、回应和各走一路继续发生。

已在隔离 Chrome 连读五镜完整视频、打开 S004 来源和 ASH038/040 首帧，再返回 ASH041。集末回查发现共享轴线仍混有出门与离场动作，进一步改为静态岔路方位，出门动作只留在本镜覆盖条件。显式切到最新第2集版本8，复验末镜分路，并回走 ASH025→026，窗台看纸与移碗取本连续；阿蘅的两次试唱、纸张损失和未修复关系保持。

## E03 · 不住进去

### A01 · 能赔的与不能赔的

观看任务从能赔的纸钱、眼前劳动转向不能代替别人做决定。ASH043 保留开场柴已劈开的省略，但从李寄尚未捡柴起，姐姐后入场；伤手、铜钱和刀的落位随接触发生。前三个谈话切点保留照顾中的停顿，拈木屑与再次碰痛不合并。上午的未包手和午后的包手分别限定，旧湿衣已换为干衣。

ASH047 从纸尚未摊开起，手部近景随李寄起身抬到双人中景，20秒为暂定动作与对白余量；阿蘅与幕布后入场由直接参考承接，不预先挤入木板首帧。ASH048 先轻哼到断句、摇头、说话，再由阿蘅夹入新纸；不把已到缺词处当作哼唱前起点。ASH049–051 区分尚未数工钱、尚未收钱抱布、尚未交布边三个阶段；保留阿蘅照顾伤手和李寄等待抚平的合作，不以“成品已完成”替代交接动作。

已在隔离 Chrome 连读九镜完整视频，打开 S005 全场来源、ASH047 首帧并返回 ASH048。新纸开场未写、阿蘅后入场，午后用新光线切入。轻哼后的摇头原先同时写在声音指导与动作序列，现由动作序列负责一次，声音指导只到收声，避免表演重复。

### A02 · 账页上的条件

本场先明确十来天后的时间省略，再让阿蘅自行追问债务与照料母亲的代价。ASH052 起点改为尚未拧布、赵尚未递纸；时间字仍走已定后期字层。ASH053–055 区分赵单手持正面、双方抓背面、翻回正面才露翘角；阿蘅擦手、抓纸、想揭而被收回的主动动作不省掉。ASH056–058 保留问条件、对方折据、拒绝后挡手追问的先后，李寄不提前进场替她决定。

ASH059 在两升答复前仍是阿蘅挡住收据的手，炭头未取、背页未写；写完口头核定，赵执事带借据离开。ASH060 不再继承赵的画左站位或借据条件，首帧只有阿蘅持本与炭头，李寄由浅滩后入；ASH061 从已会合开始，说好山脚等候后先放下炭头和歌本，再共同抬布。两镜保留同岸日光，失效的只是谈判人物、持物与站位。

已在隔离 Chrome 第3集最新版本6连读十镜完整视频，打开 ASH060 的 S006 全场来源及 M3151 首帧、M3152 视频，再返回 ASH061。赵离场后只保留同岸的方位和光线，背页与炭头在阿蘅手中，李寄由准确补充参考后入场。集末回到 ASH048 验证轻哼收声后只执行一次摇头，时间省略、缺词和两人的主动选择均保留。
