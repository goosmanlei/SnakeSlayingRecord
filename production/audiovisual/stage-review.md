# 镜头阶段一致性复核

本记录说明每场怎样从准确剧本确定可见起点、动作与声音，再在隔离审阅台回读。起点和条件以各集逐场稿及 `shot-contexts.json` 为准；准确参考职责、局部文字状态和输入锁见 `video-inputs.json`。这里只记录实际完成的判断与回读，不把方案一致性写成生成结果。

## E01 · 两份米

### A01 · 唱到跳页处

观看任务是先建立阿蘅靠手艺换米、与老汉打趣的日常，再让李寄由手先入场。按动作连续性原则，ASH001 改从歌本尚在手中开始，摊本、压石、唱第一句、老汉立扁担、翻页依次发生；ASH002 从已翻到归家页开始，保留老汉接唱扑空与阿蘅尾腔；ASH003 从尾腔收住而听客未散开始。ASH004 只先显露伸来的手，后续完整人物仍由原补充图负责。稳定的米铺方向、光色保持。

首轮隔离页面连读并打开故事依据、首帧后，发现文字状态仍把“扁担已竖好”和预付米的后续使用带进首帧。据此只为 ASH001 的文字状态明确斜持扁担和柜内干米，保留准确状态引用，不修改状态准备路线。又把 ASH003 同一源段的笑声、回话、欠身、散开交错排列；阿蘅应答原词未定，仍由原阻断项拦住准备，不补词。

修正后已在 Chrome 的本任务隔离实例回读 ASH001 完整首帧与视频、ASH003 完整视频及待准备说明。原唱句、接唱和尾腔保留；尚无实际媒体生成或播放。

### A02 · 工钱与预付

观看任务是区分已挣到的工钱与下一场婚礼工作的预付，并用递本又收回体现两人的亲近。五镜分别从“端斗尚未倒”“米倒尽尚未系袋”“答应邀唱后尚未回柜”“预付已入袋尚未移开”“檐外两手仍空”开始；量、倒、撑袋、答应、另抓、再开袋、扎袋、移步、欲提袋、递本又收回均保留。柜内到柜外的交米方向继续适用；后两镜改为檐外同侧双人关系，不再要求掌柜占据前景对话轴。

已在隔离 Chrome 切到最新集版本，连读五镜完整视频，打开 ASH006 首帧并返回比较 ASH010。按首场发现继续限定前三镜米粮文字状态；原空袋、工米袋、同袋加预付的准确状态变化保留。

### A03 · 干净的手与旧名字

观看任务从净手后才接本，转入邀请与女孩对旧名字的警觉。每镜起点前移到尚未倒水、尚未搓手、狗尚未跑来、话尚未停、旧纸尚未取出等可见状态，保留擦手、递饼、抢答、阿蘅接回本子的自主选择。赵执事离开与李寄取纸未果同属 ASH017；不删离开动作，也不让他在 ASH018–020 继续站场。普通街道光色保持，末镜只留陶伯的手、篮口与空凳；不以回忆画面替代被提及的死者。路人短唤后赵执事点头，发声与反应按次序穿插。

已在隔离 Chrome 连读十镜的完整视频，打开 ASH017 对应的 S002 全场来源，再返回打开该镜首帧，核对赵执事仍在起点、随后离开的连续过程。ASH018–020 的条件不再召回赵执事。首帧参考已收窄手部近景、未取出的饼和未抽出的旧纸，后显身份沿直接补充图交接。

本集连读后的回查：A02 原轴线把周掌柜固定在柜内，与他走出来、再回柜抓米冲突。改为保持画面左右关系而允许实际移动。后续各集同时检查镜头稿、条件、文字状态、参考裁切、声音位置与当前版本；不能只修改起止摘要。E01 的设计、来源和素材方案已实际打开回读；原件均未选择或生成，缺词阻断继续生效。
