# 全剧视听设计

这份稿件从已确认的剧本版本四重新编排。每集文件可独立阅读：开头说明整集目的与节奏，每个视听场确定空间、轴线、光色、声音和连续性，表格再给出逐镜正文范围、时长、动作起止与表演、剪接安排。视听场可以拆分一个故事场，也可以组合同集内的多个故事场；没有改写故事集边界或故事正文。

这份全剧视听设计供全剧制作审阅，不代表用户已采纳具体设计或生成方案。执行与完成状态以主项目任务账本为准。本任务不发起图像、音频、视频生成，不交付剪辑时间线或组合成片。

## 如何读镜头稿

视听集、视听场、视听镜分别使用独立编号 AE、AS、ASH。本剧视听镜为 ASH001–ASH344，从 001 起号；它与已退役的旧镜头 SH 属于不同类型，不共用编号计数。准确对象和修订仍是引用依据。

`s018:20-21` 指故事场 `s018` 的第 20 至 21 段正文，包括叙述、对白与声音。编译时通过现有制作输入锁解析为故事集的准确修订号、场号及完整正文段落 ID，不把当前头自动替代锁定输入。每段正文在这份镜头稿里恰好覆盖一次；画外声、回忆和省略行路分别写明表达方法。

“秒”是当前方案为对白、歌唱、动作接触和反应预留的单段生成时长，不是已经拍成的影片时长。现阶段各镜合计 6033 秒，约 100 分钟；原剧本的集估时合计约 73 分钟。用户已确认允许适度加长，以动作和表演读得清楚为先。这里保留了问答气口、两次试唱、机关逐步查验和等待确认，不能为追平旧估时而把对白提速。当前数值是方案预留，仍须结合后续真实表演审阅；时长不合适时修订具体镜头，而不是擅删台词。本任务没有生成实片，不能把这项估计当作验证过的成片时长。

每镜的机位、动作和声音由作者逐项指定。场级概述保留整场调度与事件顺序，不能直接作为每镜执行指令。[镜头上下文](shot-contexts.json)逐场确认可共享的固定条件，并为门闸阶段、地点、昼夜、持物等提供镜头覆盖值；继承项的原文一旦变化，编译就要求重新审阅。编译器不从段落数量自动造镜头，也不读取旧场准备或旧镜头记录来补齐内容。[画面出现范围](appearances.txt)与故事中被提及的依据分别维护；[状态适用范围](state-ranges.txt)与[镜内状态变化](state-transitions.txt)另列依据，避免把未入画的人塞入画面，或把相邻两种状态误当成同一时刻的造型。

## 关键制作选择与复核方法

| 问题与条件 | 采用的制作方案 | 原理与检查 |
| --- | --- | --- |
| 李寄常急于替别人决定，阿蘅有自己的谋生与作证目标 | 给阿蘅完整拒绝、提问、走前与收证据的动作；李寄收脚、等她收纸或只托罐底 | [叙事与信息](../filmcraft/01-narrative.md)、[表演](../filmcraft/09-performance.md)：逐场查是谁提出目标、谁回答、谁完成行动，不以反应特写抢走行动主体 |
| 两份米、歌本与多种凭据在不同人手中流转 | 交接保留起点、接触、承重与放手；原件、抄件、凭记各自标明去向 | [调度](../filmcraft/05-staging.md)、[美术](../filmcraft/08-design.md)：按镜尾到下镜头逐项点物，不允许无来由换手、复原、消失或多出一只手 |
| 后院南北短道、前后门互锁与两侧人位必须让观众记住 | 先用成人膝与一步量尺度；东侧保持北右南左，转西侧前经正南全景；父亲绕南前门的路径完整给出 | [摄影](../filmcraft/03-cinematography.md)、[摄影机](../filmcraft/04-camera.md)、[调度](../filmcraft/05-staging.md)：回看门、闸、缝、饵、刀和人数；任何镜像或穿越石道都不通过 |
| 蛇头多数在封闭盖下，女孩不能提前知道成人窥缝所得 | 用擦声、闩震、成人口述和有限缝内细节；不给洞内全知镜头，不把传闻当实见 | [叙事与信息](../filmcraft/01-narrative.md)、[声音](../filmcraft/11-sound.md)：逐镜记录视点和声源，检查新增画面是否越过人物知情范围 |
| 七人不足、八人仍很吃力，李寄下刀并非突然无畏 | 先证明父亲不能离杠，再保留两次退缩、找缝、碰石停手、抽刀后退和群体反作用 | [表演](../filmcraft/09-performance.md)、[动画与生成](../filmcraft/12-animation-ai.md)：按接触点与受力顺序回看，刀、双手和脚不能在镜间跳位；不用加速掩盖失误 |
| 断开之后还有余声，不能立刻开门欢庆 | 留下观察、等待、同号慢卸与继续封门，分别给女孩和成人情绪释放 | [声音](../filmcraft/11-sound.md)、[表演](../filmcraft/09-performance.md)：检查口令前后动作和声源，不用胜利配乐抹掉等待 |
| 旧灯反复出现且本次进庙未点燃 | 清晨、后院、返家保持无内光；最终散场由母亲当面点亮，走路时照台阶和幕杆 | [灯光](../filmcraft/06-lighting.md)、[色彩](../filmcraft/07-color.md)：查灯芯、补纸、照射方向和持有人；情绪变化不擅改灯的物理状态 |
| 独立歌曲的已认可词稿与当前正式剧本演唱范围并不完全相同 | 保留歌曲实体与真实候选；剧中镜头只唱当前输入锁正文，不将旧同步提案自动写进剧本 | [视频生成手册](../seedance-video-handbook.md)：参考只锁定已明确用途，候选质量、旋律范围和故事改版分别审阅 |

## 起始图与镜内后续参考

[逐场输入审查](video-inputs.json)记录全部 65 场、344 镜的直接图像职责，并锁定已审阅的机位、动作起止、表演与空间条件。77 镜补充 135 项必要的身份、后续状态或空间依据；267 镜保留起始图覆盖路线。这里统计的是计划输入项，同一状态在不同镜头分别计数，不代表新增原件或实际调用。

本轮选择普通参考生成，以便起始构图、镜内后显身份和原生表演的声音参考共同工作；接受其不能固定首帧像素的边界。ASH004 的李寄只先伸手，完整状态图服务后续挤到身旁的脸与身体；ASH012 起始只画手，阿蘅和擦净手后的李寄完整状态服务抬到双人及交接之后。ASH218 的母亲只是画外声，不因此添加母亲视觉图；ASH333 另给远处歌者阿蘅的视觉身份，近处李寄仍是听者。起始图方案同时限定未显露内容不能提前出现。

依据[摄影机](../filmcraft/04-camera.md)的景别与揭示次序、[调度](../filmcraft/05-staging.md)的遮挡和入场、[生成制作](../filmcraft/12-animation-ai.md)的身份与状态约束，只补原起始裁切无法承载的后续信息。参考仍须选择准确版本和候选；最终选图时核实际可见范围，生成后逐镜、逐场和跨集复核服装伤侧、物件交接及空间。当前没有真实生成效果，普通参考不能保证身份与动作一定稳定。方法与渠道边界以[视频生成手册](../seedance-video-handbook.md)为准。

输入审查与镜头、状态或发声方案一起变化时，沿下方 `revise_audiovisual.py` 入口编制和核对完整增量；本次合入新动作方案后，同时补全 ASH067–ASH070 的李绡出现范围，ASH067 只在进门后使用其完整身份参考。已选原件和冻结版本必须按准确引用审阅，新原件选择继续触发独立采纳与准备检查。只读全剧核验使用 `scripts/verify_video_inputs.py --system <受管审阅台目录> --db <隔离或正式数据库> --output <本机回执.json>`，检查审阅范围、直接输入顺序与职责、计划契约及未选阻断。

## 编制与核验入口

在故事仓根目录运行：

```bash
python3 scripts/audiovisual_design.py audit
python3 scripts/audiovisual_design.py bind --system <受管审阅台目录> --db <隔离实例数据库> --output <本机校验结果.json>
```

`audit` 检查全剧正文覆盖、镜头字段与单次时长。`bind` 以只读数据库连接核对输入锁和正文原文，并生成准确状态、镜内变化与向下的集／场／镜引用；它不把结果写进库。编译同时读取[发声事件表](vocal-events.json)。直接标注的人物对白按原词进入，叙述中的答话、读回、轻哼、接唱、咳笑和群声按源段落及段内次序进入。每项分别说明发声者、方式、明确原词／仅明确语意／未指定句段／非语言声音，以及重叠或停止条件。复用 [voices.py](voices.py) 的准确音色；匿名背景声无需新建人物，曲调只在实际演唱或哼唱时引用。图中出现范围仍由 `appearances.txt` 决定，发声不自动等于入画。

原词或表演句段未锁定的镜头，视频方案会明确列为待准备并要求复核自然时长。不能把一个语意说明直接当成已经批准的台词。哼唱即使不需要词，曲调片段仍须听审、选定；所有参考未选状态和原有采纳闸门继续生效。

当前设计修订使用以下入口，先在受管工作区初始化独立预览，再准备、读回并应用增量：

```bash
python3 scripts/revise_audiovisual.py prepare --system <受管审阅台目录> --instance .runtime/generation/review --plan .runtime/generation/av-revision.json
python3 scripts/revise_audiovisual.py apply --system <受管审阅台目录> --instance .runtime/generation/review --plan .runtime/generation/av-revision.json
```

该入口只写本任务隔离库；源稿、输入锁或当前头变化时必须重新准备。相同内容不产生新修订，新增声音关联不改变其他关联的身份；旧方案、调用、评论和采纳保留在原准确版本。正式发布沿[工作区与增量发布流程](../generation-workspaces.md)，不再次执行首次体系切换脚本。

媒体方案按[视频生成手册](../seedance-video-handbook.md)编制；[能力观察](capabilities.json)只是当时只读模型目录结果，实际生成前仍须核验当前能力与额度。

[系统、数据、恢复及页面核验](verification.md)说明实际完成范围；[切换清单](cutover.json)、[文件退役清单](retired-files.json)与[真实来源去向](provenance-files.json)分别维护唯一事实。正式发布与任务完成以主项目任务账本和冻结包回执为准。
