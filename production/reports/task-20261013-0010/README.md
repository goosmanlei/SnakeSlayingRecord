# task-20261013-0010：SKILL 与制作知识优化

本任务解决首次使用者读完方法后仍不知道怎样判断、取得准确输入、推进和检查的问题，同时兼顾人类理解与 AI 执行。十九项已完成共102轮有效全文阅读及各自实际样例，最终方法已在本机正式生效；十五个现行系统 SKILL 各保留准确最新版，旧使用记录已按本次授权清理。任务等待用户核验和明确完成确认。

每轮由新的独立读者逐段阅读，全文结算后再作分离修订判断；读者、协调和修订实际使用 `gpt-6-astra / max`。只计算已经完成全文结算和修订判断的轮次，未完成、异常中断及拒收尝试不计入。轮数不是质量分数：最后实质改稿已完整复读，可执行性另用准确方法完成隔离样例。

视频方法现在要求实际提交的 `generation.prompt` 连续覆盖0到总时长，说明动作和状态变化、摄影、准确对白与声音进入或重叠、结尾状态及下一镜承接。时间分段不机械等分，也不自动表示切镜；估计秒数不冒充实测。三个样例完整保留相邻镜的尾腔与动作衔接。ASH002 的随手音频选择不作为有效选用；准确参考未确定时保留缺口，不根据无效选择推导时长结论。

正式 Chrome 已打开73个准确方法文件，十五个 SKILL 的自有文件均只显示一个当前版本；未改的独立读者及五种模式、系统构想评论也已回查。最终完整导出在新空实例恢复，43张持久业务表逐行一致，882份原件逐份摘要一致；恢复页面再次打开十五个方法、完整手册及代表性作品与素材。具体版本、入口、验证和范围外残留见[交付与核验](delivery.md)，清理数量和保留用途见[历史与过程资源清理](history-cleanup.md)。

按用户本次说明，没有重新看听既有多媒体，也未调用模型生成媒体。字层样例已实际打包、登记、取回，三张静态图经过渲染查看；这不证明视频运动、声音效果、合成成片或真人用户测试通过。正式故事、小说、剧本和全剧镜头 Prompt 没有在本任务重写；对应制作缺口仍由后续制作处理。
