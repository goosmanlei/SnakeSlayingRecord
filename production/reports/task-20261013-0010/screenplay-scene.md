# 剧本改编分场：让保存与回读能够实际定位

本方法已完成五轮全文阅读，并以最终准确绑定完成四场隔离分场样例。第一轮修订后，第二至第五轮均完整复读并保留；第四、五轮在三份共享资料稳定后进行。实际读者和分离修订者均为 `gpt-6-astra / max`，证据见[机器索引](screenplay-scene.json)。隔离页面已核对，正式方法页面与最终恢复已验收，见[交付报告](delivery.md)。

原句“通过原作者入口保存本场草稿并全文读回”，让第一轮读者知道应当回读，却无法识别保存目标和回读途径，全文结算后问题仍在。现稿明确沿用本次剧本作者工具及任务指定的 `--run`、`--method-url`，用 `save` 保存后再以 `read` 取得实际全文。第二至第五轮读者都能准确复述运行位置和保存、回读、检查的次序。最后两轮也正确区分“判断人物方法是否改变”与强制每轮对话都改变，以及文字时长估计与实际表演验收。

改编仍围绕人物目标、行动、因果、观众知情和前后承接展开，保留原作事实与授权边界，不把小说逐句拆成镜头。[《交回那一页》四场干净稿](samples/screenplay-scene.md)先呈现漏记与藏页，再让求保、求缓失败，继而交页、核验、更正并交出钥匙。两袋只指交入粮；领取保持为约定种粮，不增加袋数或兑换比例。账页是记账证据，粮袋与名签才支持实物核对。

五轮共54个逐段及结算上下文、54次原生推理、648个事件，全部准确输入与审计摘要已回查。最终正文保存为隔离方法第10版并更新剧本绑定，422份已有配置版本保持原内容，五种独立读者方法包不变。

样例实际经过四次取得方法、保存、全文读回与接受，以及一次整稿连读判断；四个执行的草稿、意见和结果均从隔离服务读回。最后一稿与准备稿一致，是应用最终方法后有依据地保留，并非为了展示改动而重写。十九个已定原词片段保留；四句新增对白标明改编归属。原词尚缺的报户名事件及补正、署名、凭条字面继续交后续字稿和声音准备，没有删除事件来绕开缺项。

默认 Chrome 已打开并读回最终正文，实际比较文件第3、4版，逐一点击叙事、表演、声音三个正文引用，核对准确资源及代表性段落；声音参考刷新后仍为同一版本。[页面证据](isolated-browser.json)没有新增截图或媒体播放。

这证明本次小样能沿准确入口完成文本改编、保存与检查。各场秒数只是排练前估计，没有真人试读、实际表演、声音听审或成片效果验证，也没有导入正式剧本。正式生效和空实例恢复仍沿任务后续验收。
