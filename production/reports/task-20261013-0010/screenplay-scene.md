# 剧本改编分场：让保存与回读能够实际定位

本方法已完成前三轮全文阅读。第一轮修订后，第二、三轮完整复读并保留；共享知识稳定后的后续轮次与隔离分场样例仍待完成。实际读者和分离修订者均为 `gpt-6-astra / max`，证据见[机器索引](screenplay-scene.json)。

原句“通过原作者入口保存本场草稿并全文读回”，让第一轮读者知道应当回读，却无法识别保存目标和回读途径，全文结算后问题仍在。现稿明确沿用本次剧本作者工具及任务指定的 `--run`、`--method-url`，用 `save` 保存后再以 `read` 取得实际全文。第二、三轮读者都能准确复述运行位置和保存、回读、检查的次序。
