# 演唱与歌曲：完整词稿与音乐说明各自成稿

本方法已完成六轮全文阅读。本轮在原五轮交付的基础上，补齐风格与演唱说明、完整歌词的写法、内容触发条件及填好的教学例；第六轮从头读完27个正文单位和全文结算，分离修订者完整回读后保持，没有未解决问题。新稿已隔离保存为方法 v16，整曲和短唱段都已完成准确绑定下的实际样例。当前仍待正式发布，准确证据见[机器索引](song-plan.json)。

前五轮保留了整曲、短唱段、说话音色与旋律母版的职责，修清完整生成参考与后期剪辑区间。歌词版本、呼吸和尾音留时、音乐进退、声部和配器等专业判断继续保留；不以字数估时替代可唱性，也不把历史模型记录当作当前能力。前五轮共54个逐段及结算读者上下文，本轮新增28个；读者和分离修订者均实际使用 `gpt-6-astra / max`。

原规定要求检查全部歌词段落，却未明确最终提交文字怎样分区。新稿先分别完成风格与演唱说明、全部准确歌词，再映射到当前入口支持的字段；只有一个 Prompt 字段时明确分段组合。重复歌词逐次展开，独立短唱段写全本段，纯哼唱不编词。固定旋律、多声部、字音、视频交接和格式要求只按实际职责触发，不相关项省略，真正缺项仍保留草稿。

四行原创教学例具体写出情绪推进、乐句、换气和尾音，并标明没有正式歌曲、采纳或生成结果。首次读者可直接据此组织文本，AI 可按同一顺序执行；冷读没有留下理解障碍，但没有真人参与者测试。
