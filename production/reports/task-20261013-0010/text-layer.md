# 字层方法：前三轮阅读与待完成验证

前三轮已补清字稿、方案保存和工程制作之间的交接，保留“观众此时允许读到什么”的叙事判断。当前完成的是候选方法的前三轮；最后两轮、最终工程制作和登记尚待完成。

原文要求“通过既有媒体作者入口保存同一素材的准确文字 blocks 与 specification”。第一轮读者初时找不到入口，随后从“当前制作协议”链接知道去哪里查；这条疑问已解释，不能写成遗留问题。分离修订者另核实际入口，补明项目脚本、同一素材、草稿保存与全文回读，并用普通语言解释两个字段分别保存字稿说明和制作规格。

修改后的第二、三轮读者能区分三个结果：保存文字方案、取得真实可编辑文件、在最终画面里检查可读性。静态 SVG 是矢量图文件，能够帮助检查字稿和版面；人物翻页、手部遮挡及运动透视仍需实际合成检查。正文保留账册只露一行的例子，使人理解信息揭示的理由，也使 AI 能据准确原词和阶段限制工作。

三轮分别有9、11、11个正文单位，每轮另有全文结算；读者和修订者均为 `gpt-6-astra / max`。第1轮改稿已在第2、3轮完整复读，34个读者上下文的原始调用、事件和逐段审计摘要已回查，见[证据索引](text-layer.json)。

协调检查另确认：该方法同时用于一般字稿与版面设计、具体素材的制作方案。候选目前只解释素材作者入口，尚需补清通用创作入口与它的职责区别。此项在第四轮全文结算后处理，再交第五轮完整复读；不为两种工作另建重复方法。

样例采用已有“歌本背页记工”的准确字稿与工程。工价版只写“两升”；第一夜的“一日两升”是工价标题，下方另有一笔收入；第二夜增加第二笔并只圈两笔收入。不能把标题算成第三笔，也不新增具体日期或纸面“共四升”。源 SVG 已做过静态渲染准备，最终仍须从本次真实登记的新候选取回文件、渲染并查看，不能把旧候选或源文件检查当作最终样例。动态合成、视频效果和真人测试没有通过结论。
