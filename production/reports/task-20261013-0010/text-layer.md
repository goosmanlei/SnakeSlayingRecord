# 字层方法：准确字稿、版面、出现时机与交接

本轮将“准确字稿 → 版面规格 → 出现与交接 → 检查目标”明确为制作指令格式，补清随内容出现的条件，并增加完整便笺教学例及独立底图 Prompt。当前第21版已在隔离实例保存、绑定并完成歌本记工方案的三个实际阶段；Chrome 已读新正文。第六轮独立全文复读及分离修订判断已完成，保留当前稿，现已正式发布，并在正式与恢复实例复验；准确证据见[机器索引](text-layer.json)。

此前方法已说明何时用字层以及观众何时能看见文字，但没有把完整制作指令的要素组织成可直接成稿的顺序。新稿要求写出逐字原文、页或面与行序，坐标基准、文字区域、字级、字形、行距、对齐、颜色及底面关系，再交代阶段、可编辑文件、预览和合成职责。多页揭示、书写遮挡、字幕同步、特殊字形、透明叠加或多尺寸用途出现时，补对应约束；静态单页不硬造时间线。

本地排字无需模型 Prompt。需要生成底图时，模型正文只管承载物、视角、文字留白、光色画风及保留条件；准确文字由字层承担。选择模型直接生成字面时，仍须逐字给原文、行序、位置与禁止改写要求，并核对路线能力。已有一般创作与具体素材两类入口继续共用同一方法，不复制字稿或另造需求。

[实际歌本方案](samples/text-layer.md)把六段制作说明写入原有字段，完整内容见[预览](samples/prompt-constraints-preview.md)。纸面工价只写“两升”；第一夜上方“一日两升”是约定，下方一笔“两升”是收入；第二夜追加另一笔并仅圈两笔收入。坐标以600×800源画布为基准，明确字中心、三条基线及独立圈线；出现顺序沿炭头接触、写字、展示和翻页安排，未定日期不得自行补出。

此前五轮已完成可编辑 SVG 工程的实际制作、登记、取回、渲染及结果检查，本轮沿用这项未变成果，只核对五个源文件哈希并完善其制作说明，没有重做字体渲染或动态合成。当前没有以方案文字宣称透视跟踪、炭灰质感、遮挡和成片阅读时间通过，也没有更改正式原件与采纳。
