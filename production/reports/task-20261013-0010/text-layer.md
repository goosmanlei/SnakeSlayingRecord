# 字层方法：两类入口衔接到真实可编辑工程

五轮全文阅读已经完成。最终方法分清一般文字设计与具体素材方案的入口，保留“观众此时允许读到什么”的叙事判断。两类入口已用同一个歌本记工样例完成保存和回读，并实际制作、登记、取回和查看可编辑工程；最终结果检查方法的联动也已完成，本机正式发布及最终恢复已完成，见[交付报告](delivery.md)。

原文要求“通过既有媒体作者入口保存同一素材的准确文字 blocks 与 specification”。第一轮读者初时找不到入口，随后从“当前制作协议”链接知道去哪里查；这条疑问已解释，不能写成遗留问题。分离修订者另核实际入口，补明项目脚本、同一素材、草稿保存与全文回读，并用普通语言解释两个字段分别保存字稿说明和制作规格。

修改后的第二、三轮读者能区分三个结果：保存文字方案、取得真实可编辑文件、在最终画面里检查可读性。静态 SVG 是矢量图文件，能够帮助检查字稿和版面；人物翻页、手部遮挡及运动透视仍需实际合成检查。正文保留账册只露一行的例子，使人理解信息揭示的理由，也使 AI 能据准确原词和阶段限制工作。

五轮分别有9、11、11、11、13个正文单位，每轮另有全文结算；读者和修订者均为 `gpt-6-astra / max`。60个读者上下文、61次原生推理的原始调用、事件和逐段审计摘要已回查，见[证据索引](text-layer.json)。第五轮读者对通用入口的初读疑问，由下一段的具体脚本、字段和步骤解释；全文没有遗留问题，最后实质改稿已完整复读。

协调检查确认：该方法同时用于一般字稿与版面设计、具体素材的制作方案。原候选只解释素材作者入口；第四轮读者没有提出遗留问题，协调者仍据实际双工作类型绑定补清用途：一般文字设计沿创作步骤保存草稿、复核和结果；已有具体素材对象则直接沿媒体作者入口推进同一对象。两种工作使用同一方法，不复制字稿，也不强迫一般文字设计先造素材对象。第五轮读者已经准确理解这种分工。

实际[歌本背页样例](samples/text-layer.md)中，工价版只写“两升”；第一夜的“一日两升”是工价标题，下方另有一笔收入；第二夜增加第二笔并只圈两笔收入。五个源文件已按最终方案打包成真实候选，取回后逐文件核哈希，并实际渲染查看三张 SVG：字面、行数和圈线符合要求，标题未算成第三笔，也未新增日期或“共四升”。同一操作恢复返回原候选，没有重复登记。通用设计、具体素材方案及本地制作的九个阶段均保存并读回。

定稿后的[结果检查方法](samples/result-review.md)已对同一实际候选完成三个阶段：保留正确字面与静态排布，按具体偏差交接后续字层质感、显露、遮挡、跟踪和阅读时间的返修位置。四种工作共十二个阶段均保存并全文读回；没有重复制作或人为制造字稿问题。
