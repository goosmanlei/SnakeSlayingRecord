# 人物音色：固定中性试读，分开身份与表演

本方法已完成八轮全文阅读。用户追加的固定中性试读稿已通过第八轮原生冷读和分离修订结算，保持全文、无遗留问题；当前候选已隔离保存为 v16，并完成准确绑定、两个实际方案样例和 Chrome 核验。新版仍待正式发布，不能把隔离结果当成正式交付。准确状态与证据见[机器索引](voice-plan.json)。

新稿要求同轮候选使用相同的原词字面、句序、读法和录音条件，包括约定语速、停顿、距离与背景，回放响度保持可比。候选可以改变已声明的稳定声线设计；演法测试固定声音身份，分别记录目的、原词与各次差异。不同条件的旧原件只用于身份初筛，不能冒充同条件比较。

统一中文中性稿为“桌上放着一本书，旁边有一只白色的杯子。窗边的椅子朝着门口，几张纸整齐地叠在一起。”完整教学 Prompt 分开声音身份、统一试读条件与这两句原词，不再使用正式剧情原句。它是共同的比较材料，不是全音素标准，也不宣称覆盖所有音节；其他语言或专项发音须先确定整轮统一的相应稿件，专项测试另记。

前七轮有效记录保持原样。前五轮收敛参考范围、证据边界与作者入口，共53个逐段及结算读者上下文；第六轮和第七轮各完整阅读22个正文单位及全文结算，第六轮发现无依据的“克制”默认值，第七轮在修改后复读通过。用户追加固定稿要求后，第八轮另读23个正文单位及全文结算。读者与分离修订者均实际使用 `gpt-6-astra / max`；分离修订者已通读本轮全部24项观察、最终记忆与冻结全文，确认固定条件、身份可变项、演法分工、完整原词和实际保存检查均已准确理解，没有继续改稿的依据。

原方法将“原件、候选、组成与起止时间”并列，容易把试听区间误作生成参考。此前修订已明确生成参考使用准确候选的完整原件，试听定位与后期剪辑区间另记用途。新稿保留这项边界，也保留缺少可用原件时只能写待试声方向、不能编写已听结论，以及历史模型不代表当前能力已核验的要求。

[老汉音色样例](samples/voice-plan.md)现已在 v16 下分别完成完整原件复用与固定稿另制试声两个实际方案，均保存并全文回读草稿、检查、结果三个阶段。另制样例实际 `generation.prompt` 逐字包含统一的两句原词，公开样例与保存文本相同；拟用 `seed-audio-1.0` 只代表项目选型，当前模型、原词字段与长度能力仍留为缺项。首个未填型号的草稿被契约拒绝，回查没有草稿结果，随后另起准确样例，未发生模型调用。

实际复用路线保持准确完整原件，不补造模型或 Prompt。登记时长7.08秒来自已有记录，旧“四秒”规格没有变成截取参考或压缩完整试读的权限。实际声线预期、原件、reuse 方案与剧情中的“二道——”接唱不因本次修订改变；两个结果包均未导入作品。原 v15 的剧情台词教学分支只保留为此前过程证据，不证明新固定稿要求完成。
