# 生成与制作：分清要求、原件与恢复依据

本方法已完成六轮逐段独立阅读。前五轮收敛准确输入、制作与恢复；用户追加 Prompt 格式和要素要求后，补入实际提交内容的逐类核验，并由第六轮完整复读。实际读者和修订者均为 `gpt-6-astra / max`。新稿已隔离保存为方法v14、绑定v13，并完成新样例；本轮正式发布和再次历史清理尚待整体交付。准确身份及逐轮证据见[机器索引](generation-preflight.json)。

| 原句造成的疑惑 | 修改后怎样推进工作 |
| --- | --- |
| “准确制作出处”可能指制作要求，也可能指素材来源。 | 明确需求归属的实体、必要状态或镜头是要求出处，候选原件是实际输入，两者分别核验。 |
| “历史执行仍读它当时的原文”没有明确原文对象。 | 恢复时取回当时的方法正文、方案和输入，不把今天的修改回填到旧执行。 |
| “未定原词”没有说清适用范围。 | 对白、演唱和画面文字分别核对已确认的台词、歌词和书面字稿，不能临时补词后宣布就绪。 |
| 原生成承接没有明确要求逐类检查实际 Prompt 的格式及条件要素。 | 直接核视频时间线、声音原词与风格分离、图像结构和字层显露；外部方案表写齐不能替代实际提交正文。 |

后四轮读者能按材料核对、制作方式选择、保存提交身份、取得真实文件和恢复原操作的顺序说明工作，没有未解决的文本问题。正文保留具体例子和判断理由，并给出准确操作入口；此处的人类可读性判断没有真人参与者测试。

第六轮17个正文单位及全文结算没有遗留问题。读者能说明必备内容和条件要素必须进入实际提交内容，缺项应回原方案，复用与本地制作不补造模型字段。新[提交内容样例](samples/generation-preflight.md)实际读回三类当前方案，指出视频无时间线、无效音频选择、图像混入制作说明及字层缺版面规格；三个阶段保存回读已完成。隔离 Chrome 已比较新增段落，保存并刷新回查准确版本评论。
