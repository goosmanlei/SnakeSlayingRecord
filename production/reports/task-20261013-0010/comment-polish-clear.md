# 评论表达润色：保留原意和判断强度

本方法完成五轮逐段独立阅读及一次实际润色样例，原有520个字符的正文保持不变。五轮读者都能说明输入、整理、逐句核对及交回草稿的顺序，没有发现仍成立的理解或执行障碍；分离修订者据此保留原文，没有为达到轮数制造修改。实际读者、修订者及样例执行者均使用 `gpt-6-astra / max`，准确方法与逐轮证据见[机器索引](comment-polish-clear.json)。

原文通过“好像有点快”不能改成“节奏错误，必须重写”的对照，解释润色不能增强用户的判断或诉求。读者也没有把建议的整理顺序误解为固定模板：短评论可以保持简短，必要的背景和不确定性应保留；指代不明时不能凭相似段落猜换对象。用途、理由和例子可供人直接理解，输入与输出边界可供 AI 执行。这里没有真人参与者测试。
