# 结果检查与返修：具体观察决定检查路径

本项已完成六轮全文阅读及真实字层候选的最终方法检查，补清了图像修订代数的判断依据、后期编辑与生成参考的区别，以及检查记录的保存入口。第五轮发现专题选读条件仍有含混用语，第六轮已完整复读修订稿并确认没有遗留问题。

原句“图像修订核对最深谱系代数，超过允许范围回干净母版”使第一轮读者明白了方向，却无法计算代数或找到限值，因而不能判断是否还能继续修图。候选现说明：没有图像输入的根图为第0代，新图取全部图像输入的最高代数加1；本故事优先一代、累计最多两代，改名、加入母版或重新选用都不归零。来源不清先追溯，超限回到条件合适的干净母版。后续两轮读者准确理解了起点、算法与停止条件。

方法仍先问观众实际看到或听到了什么，再把现象与原因假设分开。例如“手穿过桌面”是观察，空间安排、参考冲突、同一时段动作过密或生成失误只是可能原因，须比较准确输入与结果。修订没有把专业判断缩成技术检查清单，也没有把用户本次免看听旧媒体的授权写成长期免验规则。

第五轮读者对“时间负荷问题”的疑问到全文结束仍未解决：不知道看见什么表现时该查动画专题。现稿改为短时间多项动作挤在一起、关键阶段来不及看清，并以递物时接触被跳过为例；仍要求对照方案和实际运动，区分时间安排、动作路径及生成稳定性，不凭现象认定原因。这次修改依据已稳定的动画章节，未添加固定时长或默认拆镜规则。第六轮第7单位读者已准确解释触发条件、检查重点与不能直接认定原因的边界。

第一轮8个正文单位，第二至五轮各10个，第六轮将标题单独作为单位，共13个；每轮另有全文结算，所有轮次覆盖完整正文。读者与修订者均实际使用 `gpt-6-astra / max`；67个独立上下文的原始调用、事件和逐段审计摘要已回查，见[证据索引](result-review.json)。

本任务的可编辑字层工程已实际打包、登记、取回并渲染查看。最终[检查与返修交接](samples/result-review.md)用第18版准确方法完成三个阶段的保存与全文回读：检查五文件原件和三张实际静态呈现，确认标题、收入条目及圈线正确，保持原文件；按具体偏差说明应改字稿、字层质感、显露时点、跟踪遮挡还是剪辑时间。没有为展示返修而制造缺陷，也没有重写正确上游。

本轮实际检查了字层静态图，没有查看旧多媒体或合成成片。炭字质感、手部遮挡、透视跟踪、正常速度阅读及跨镜连续性仍待真实镜头验证；正式发布和清理后的完整恢复验收已完成，见[交付报告](delivery.md)。
