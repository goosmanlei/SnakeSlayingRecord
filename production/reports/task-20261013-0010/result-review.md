# 结果检查与返修：前三轮阅读与待完成验证

前三轮补清了图像修订代数的判断依据、后期编辑与生成参考的区别，以及检查记录的保存入口。第二、三轮完整复读后保留候选；最后两轮和准确新字层候选的实际检查仍待完成。

原句“图像修订核对最深谱系代数，超过允许范围回干净母版”使第一轮读者明白了方向，却无法计算代数或找到限值，因而不能判断是否还能继续修图。候选现说明：没有图像输入的根图为第0代，新图取全部图像输入的最高代数加1；本故事优先一代、累计最多两代，改名、加入母版或重新选用都不归零。来源不清先追溯，超限回到条件合适的干净母版。后续两轮读者准确理解了起点、算法与停止条件。

方法仍先问观众实际看到或听到了什么，再把现象与原因假设分开。例如“手穿过桌面”是观察，空间安排、参考冲突、动作负载或生成失误只是可能原因，须比较准确输入与结果。修订没有把专业判断缩成技术检查清单，也没有把用户本次免看听旧媒体的授权写成长期免验规则。

第一轮8个正文单位，第二、三轮各10个，每轮另有全文结算。读者与修订者均实际使用 `gpt-6-astra / max`；31个独立上下文的原始调用、事件和逐段审计摘要已回查，见[证据索引](result-review.json)。
