# SKILL 历史清理：修正后待最终演练与发布

工作隔离库与正式库尚未删除方法历史。旧副本演练暴露的两处保全缺口已修正，相关36项隔离检查通过；全部方法与样例定稿后，必须用修正代码重新生成清理包并完成最终演练。旧演练包不能发布，旧副本能成功导出恢复也不证明其清理范围正确。

本次按用户授权一次性收敛十五个范围内的系统 SKILL：各保留准确最新版，清除旧版本、关联使用记录和旧版评论。清理不永久关闭后续版本或执行记录。作品正文、素材方案的其余内容、真实调用、候选和原件不因方法历史清理而被改写，旧成果也不能被归因于本次新方法。系统构想的评论及准确目标、范围外方法仍需引用的资料受到保护；待删除评论只报告数量，不复述内容。

| 旧演练发现的问题 | 已修正的行为与证据 |
| --- | --- |
| 277条操作回执中，213条的旧方法引用嵌在有效业务依据内部；原实现把外层一起替换，误清了素材语义整理依据。 | 只替换内层旧方法凭据，保留操作身份、原内容摘要和抽取判断；未知结构拒绝清理。对清理前真实副本逐条只读核对，213条保留了原业务依据，其余64条与旧方案相同，均无待删除方法引用残留。[回执保全证据](history-cleanup-receipt-preservation.json)。 |
| 系统构想评论指向 Review 共用资料的当前第6版，却阻止删除全部旧包，使方法正文和项目适配仍有旧版。 | 当前头上的评论随该准确版本保留，不保护无关旧包；历史版本上的评论仍保护原目标。只读新计划纳入5个无依赖旧资料版本，并保留该评论。[当前资料评论保全](history-cleanup-current-resource.json)。 |

修正后的36项检查覆盖原业务依据直接比较、事务回滚、并发新增评论时拒绝旧方案、两类资料评论的准确目标，以及空配置恢复。继续创建方法步骤、追加新版和重试原清理操作也有覆盖：重试不得删除清理后产生的新工作。这些是隔离实现验证，不能替代最终准确数据上的演练和正式发布验收。

旧演练副本实际清除了147份旧 SKILL 定义、115份旧绑定、1份当时可清理的资料旧版本、489条方法执行和1,464条阶段产物；评论清理4条，其中原用户评论3条、隔离测试评论1条。它还处理了454份当前方案和277条操作回执中的方法依据，后者存在上表所述误清。上述数量仅说明旧演练实际范围，最终数量须由修正后方案与发布回执重新确认。

旧阶段配置在空实例恢复了82条记录，其中27个对象声明了保留历史的起点。方法整包保留原版号和准确修订，文件历史按剩余整包重建；最终须回查范围内方法的自有文件各剩一份，文件序号从1开始，内容及所属整包不变。另一次 Schema 14 完整公开导出恢复核对了11,071个对象、11,125份修订、882个原件和43张持久数据表；原件共708,354,358字节，逐份摘要一致，两库完整性检查通过。两张表只有建表文本格式差异；读取缓存、129个缓存失效触发器及2个非唯一查询索引未随包携带，不涉及作品记录或完整性约束。[恢复证据](history-cleanup-recovery.json)证明的是旧阶段副本可完整搬运，不能抵消其清理错误，也不能充当最终候选恢复。

最终发布沿已有受管入口完成。先从未清理的隔离方法库导出临时安装配置，再得到清理后应保留的准确注册表；以当前正式库、临时安装配置及最终注册表运行 `scripts/method_history_cleanup.py prepare-release`，只在任务 `.runtime/` 准备包。`scripts/material_review_release.py prepare` 同时接收 `--method-registry`、`--method-audit`、`--method-history-package` 和 `--read-only-system`。正式写入窗口停止应用后，安装准确方法、重新核对清理范围、执行事务并压实，再从清理后基线检查服务和数据。清理已提交而后续中断时，依据原回执恢复，不重装已删历史。候选或正式数据前进时重新准备，不能覆盖活库。

本任务只有故事仓可写，审阅台复用准确且未改动的主干提交；发布数据操作使用包内冻结代码。受管集成、必要推送、正式发布、真实 Chrome 和最终完整空实例恢复完成后，再按启动文件要求请用户核验并确认完成。

原始演练及核对记录位于本任务 `.runtime/skill-cold-reader-fresh/history-cleanup/`。已删除完成恢复检查的两个临时实例，共1,772个文件和8个目录，含2份数据库、882个原件硬链接副本及882个恢复副本；准确路径已回查不存在，仍有效的882个原件身份与大小不变。没有停止共享服务。原演练数据库和清理前副本仅留作本次核对，正式清理验证结束后由本任务删除；包含旧历史的临时安装配置也须删除，不能用于回灌。活跃方法隔离实例继续用于未完成样例与验收，必要逐轮审计另按任务证据保留。上述物理删除不等于正式 SKILL 历史已清理。
