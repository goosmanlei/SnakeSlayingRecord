# SKILL 历史与过程资源清理

十五个现行系统 SKILL 已在正式库各收敛为准确最新版，28个可清理的方法文件各剩一版。文件版号从1开始，所属方法整包身份与内容保持；旧方法使用记录和本次获准删除的旧版评论已清理。正式事务、逐表保全和服务回执见[正式发布证据](formal-release.json)，完整恢复另见[最终恢复证据](final-recovery.json)。

本次是用户授权、在同一任务内完成的收敛，不永久关闭以后的版本与执行记录，也不把旧作品归因于新方法。故事、小说、剧本、当前制作方案的业务正文、真实调用、候选和原件没有被重写；旧版评论只报告清理数量。

最终注册表保留81条配置记录，十五个现行 SKILL 各只有一条。影视知识和视频手册的部分旧资料仍被范围外定义准确引用，因此保留必要版本；它们不会恢复已删 SKILL 或执行记录。独立读者本体、五种模式契约与绑定保持原内容，系统构想原评论及其准确目标保留，正式和恢复页面均已打开核对。

清理业务依据时只移除内层方法出处，不整块清除素材整理依据。281条回执中的215条嵌套业务依据逐项保持原操作身份、原摘要和抽取判断，其余66条也与准确预期相等。安装与清理前后逐表双向比较范围外数据，454份当前方案的其他内容保持。最终恢复仍保有404条范围内应保留及范围外评论，没有写入正式测试评论。

正式写入前已从当时正式库取得准确副本演练。首次隔离路径缺原件、随后归档原件检查的连接相锁，均在正式写入前发现；两次失败事务的44张表逐行核对回滚。修正事务内读取后，完整正式副本演练通过；正式发布时再次核对当前版本，持有写入窗口并停止原应用，安装准确配置、事务清理、压实与保全后切换服务。最终导出从清理后的正式库生成，不能再安装含旧历史的临时配置或回灌清理前数据库。

本轮追加方法修订产生的9份旧定义和8份旧绑定已再次清理，未新增删除评论或作品数据。清理操作以准确方案区分回执；同包恢复不会重复删除，旧包也不能覆盖已经前进的方法。正式发布和最终空实例恢复均回读确认十五个 SKILL 各一版、方法执行和阶段产物为零，404条应保留评论仍在。
