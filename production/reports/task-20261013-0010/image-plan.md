# 图像方案：共同格式与四类图的重点

本轮把图像 Prompt 的组织顺序、共同必备内容和内容触发条件写进方法，并为角色、场景、道具、镜头画面各补一个完整教学例。当前第24版已在隔离实例保存并准确绑定；四分支五份实际方案和 Chrome 五文件阅读及最新共同正文的版本比较均已完成。第七轮指出裁切代数边界不清，第八轮已完整复读修订后的五文件包并保留定稿，现已正式发布，并在正式和恢复实例回读准确五文件。实际模型与证据见[机器索引](image-plan.json)。

实际 Prompt 按“产物与主体 → 有参考时的参考分工 → 画框与可见结构 → 光色与画风 → 保留和排除项”写成短标题或自然段。仅凭正文应能知道画什么、几个主体、处于哪个完整状态、从哪里看、必须看清什么。多主体接触、局部编辑、状态变化、多视图和准确文字等条件出现时，再补对应约束；不为静态单体图强塞动作时间线或群体站位。

| 工作与原缺口 | 新稿怎样帮助完成工作 |
| --- | --- |
| 有通用美术判断，却缺少实际 Prompt 的成稿格式 | 共同正文给出顺序、必备要素、适用条件与保存后核读方法；格式直接落实在实际 `generation.prompt`。 |
| 四类图的关键要求容易被共同清单掩盖 | 角色图强调身份与完整形态；场景图强调出入口、通路、方向和可见范围；道具图强调连接、材质与操作状态；镜头图强调一个时点的构图及第一动作尚能发生的起点。 |
| 第六轮读者指出“新制才准备真实模型与Prompt”与模型改图也需 Prompt 矛盾 | 改为模型生成和模型改图都准备真实模型与实际 Prompt；直接复用及确定性裁切不填生成字段。第七轮完整复读已核清该问题。 |
| 第七轮读者不清楚普通裁切是否增加改图代数 | 明确只累计模型改图；确定性裁切继承原图代数与谱系，第2代裁切后也不能再送模型改图。第八轮全文阅读已理解该边界，分离修订者核原文后保留。 |
| 早期读者不清楚干净母版与改图代数 | 保留此前五轮已解释清楚的母版核对条件与“根图0代→改图1代→再改2代”，不因本轮增加格式删去这些判断。 |

[五份实际方案](samples/image-plan.md)均完成草稿、检查与结果保存后全文回读；完整 Prompt 集中在[预览文件](samples/prompt-constraints-preview.md)。检查竹器摊时纠正了“他左侧”被擅自理解为画面左侧的问题，现明确人物朝向的试设计与画面方向的关系；首帧与视频统一阿蘅、老汉、歌本、河石和扁担的起始状态；主机位图只画静态环境，不再要求一张图同时运镜。

本轮未重新观看旧图或生成新图。未选参考、真实模型能力、实际像素与画面效果仍按各方案保留缺项；文本自洽不等于外观、手物接触或跨机位一致已通过。正式作品、原件与采纳没有改变。
