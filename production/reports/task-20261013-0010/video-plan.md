# 镜头视频方案：格式必须进入实际 Prompt

本轮进一步明确五部分成稿格式及六类内容触发要素，让镜头内故事板演绎落实到模型真正接收的正文。当前第25版已在隔离实例保存并准确绑定；ASH001—ASH003三个相邻镜样例均完成草稿、检查、结果的保存与全文回读，Chrome 已读主文、回读页和准确视频手册引用。第六轮独立全文复读与分离修订判断已完成，61个正文单位及全文结算没有遗留理解问题；尚未再次正式发布；证据见[机器索引](video-plan.json)。

五部分依次是镜头目标、参考分工、初始空间与总体声画约定、镜内时间线、关键限制。无直接参考时省略参考分工；实际 `generation.prompt` 必须从本镜局部0秒连续写到总长T，并写出结束时的持物、位置、动作及声音状态。持续机位和底声可以在全镜约定中说明，段内写变化与延续。时间分段由事件决定，不机械等分，也不自动代表剪辑切镜。

| 镜头表达需要 | 实际 Prompt 要写出的内容 |
| --- | --- |
| 多角色、出入画或交接 | 各自起点、行动与反应顺序、出入口、接触点、持物手及物品归属。 |
| 动作、触碰或遮挡改变信息 | 起点、通路、关键接触、可见结果，以及摄影怎样让重点可见。 |
| 对白、画外声或多人交叠 | 发声者、准确原词、起止与同时关系，避免凭声音增加入画人物。 |
| 演唱或跨段尾腔 | 歌词、乐句与输入职责；同一次尾腔如何延续、被插话并收住。 |
| 文字、书写、揭纸或翻页 | 此刻可见的准确字面与区域、显露顺序、遮挡，以及生成与后期字层的分工。 |
| 固定端点、延长或编辑 | 准确原片或端点的作用、继承状态、本次范围与保留项；延长段使用新增部分的局部时间。 |

这些要求直接检查实际保存的正文、参数与输入。未定原词或输入保留为缺项，不能删事件、编台词或写“自然表现”后声称就绪。此前五轮已经补清准确输入目录、保存回读入口、整本手册取得方式和字层前后置条件，本轮继续保留。

[三个相邻镜样例](samples/video-plan.md)的完整 Prompt 见[预览文件](samples/prompt-constraints-preview.md)。ASH001补清老汉扁担从斜靠肩部到竖起的动作起点；ASH002写清归家唱句、同一次尾腔与老汉问话交叠及自然收声，用户随手选择的两条音频只在隔离方案中撤回为待选；ASH003保留三句准确台词和原词未知的应答事件，并把20秒试预算与现有16秒设计的差异列为缺项。

三份方案没有导入正式镜头，未重新看听或生成视频。时间线是表演预算，尚不能证明秒点、口型、音色、运动或构图已被模型实现。准确参考缺失、未定应答原词和时长冲突仍须在正式制作前解决。
