# 米铺切点的环境补缝方案

这是一个条件练习：假设后期需要把米铺同一空间的两个镜头接起来，并单独控制背景音量，才制作这条独立音轨。正式作品没有新增独立场景音的要求；本例只完成方案与交接，不导入正式素材库。

依据第一集第一场的完整32段原文及相邻 ASH006、ASH007：先结清阿蘅当天的唱工，再商量次日邀唱。后面的另加一把米是预付款，不属于这两镜的补缝内容。原生镜头继续承担对白、量米、木担触地和其他现场动作；独立底声不重复这些声音。

希望听见的是低而稳定的米铺空间空气及远处河街环境，能够在镜头切换处保持同一空间的连续感。独立输出不含可辨台词、清唱、配乐或需要贴合动作的单次响声。重要对白出现时，这一层退到背景；不能用抬高所有声音来解决对白被掩蔽的问题。

拟采用后期编辑，先取得一份确已试听、可合法复用的完整底声原件。当前尚未取得，因此方案保留空输入和明确缺项，没有模型、生成 Prompt 或虚构的调用参数。原件选定之后，另记实际剪辑区间与接缝；这类后期使用区间不作为生成参考的截取范围。

约20秒只是覆盖切点附近并带首尾余量的初步素材预算。两镜现有方案分别预留12秒和22秒，20秒不能证明覆盖两镜全长，实际使用区间和长度应据真实剪辑确定。若需更长底声，也不能反复循环倒米、脚步或单次叫喊来填时长。

返回音频后，先完整听独立单轨，再放回两个镜头比较空间、对白可懂度、进入退出与首尾接缝。文件格式和测量只能支持技术判断；没有听过的声音不能标成合格，也不能因原视频被认可就推定独立音轨通过。

## 有新制职责时的完整 Prompt

另用与正式作品无关的虚构院门请求检验新格式：约 8 秒独立混合音频，门内固定听觉位置、门外低风、两次轻敲及尾响。以下实际文本已写入本次检查阶段并回读，不是米铺的生成指令，也不是正式素材需求：

```text
制作约8秒的院门音效，作为一份独立混合音频。听者固定在门内近处，厚木门位于前方；门外低风隔着门传入，距离比敲门声更远。
0—3秒只有微弱、稳定的门外风声。风不骤强，也不在敲门后重新起一遍。
约3秒和4秒各响一次轻敲木门声，间隔清楚；每次都有短促木质接触和自然衰减，不变成连续急敲。风声一直留在背景，不盖住敲击。
4—8秒保留第二次敲击的自然尾响并回到低风声，留出可剪接尾部；不循环或重复敲门事件。
不加入开门、脚步、对白、音乐或其他活动声。
```
