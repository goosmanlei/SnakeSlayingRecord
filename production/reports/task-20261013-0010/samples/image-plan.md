# 图像四分支：五份实际方案

这轮按新增的格式和要素约束，在隔离实例使用图像方法第24版完成五份样例的草稿、检查、结果保存及全文回读。该方法的第八轮最终独立复读及分离修订判断已完成；目前没有导入正式素材、修改正式需求或调用生成。完整实际 Prompt 统一放在[样例预览](prompt-constraints-preview.md#图像共同格式与四类重点)。

| 用途 | 本次实际发现与取舍 | 仍待验证 |
| --- | --- | --- |
| 阿禾身份 | 分开主体、完整可见形态、三分之四视角、光色和排除项；外观沿当前实体制作方向，不当成小说原文。 | 实际像素、身份与表演。 |
| 竹器摊空间 | 初稿误把人物自身左侧当作画面方向。结果明确：本样例拟定低座面向米铺，空凳在陶伯自身左侧、当前画面右侧；图中仍无人。 | 拟定朝向须与完整场景及反打核准，不能据此宣称已有空间一致。 |
| 木担结构 | 完整单根、两端留白、肩面与弯度、轻俯斜视写在正文；同类形制不等于同一实物。 | 轮廓、承重尺度、真实接触及原生尺寸。 |
| ASH002首帧 | 翻页已经完成，手已释放；补阿蘅在篮后、老汉在靠街一侧、右手扶担，接上相邻视频样例。 | 七项原件未选；新站位和手位是方案选择，须与准确参考核对。 |
| ASH001机位 | 环境静图保留运动所需空间，不画运动箭头或多个时点；保留已选河街和未选米铺两个不同输入状态。 | 米铺原件、河街谱系及跨机位关系。 |

最终第24版五项共15个实际阶段已完整读回；裁切规则的补充没有改变这五份Prompt。第1代裁切仍为第1代、随后模型改图为第2代，第2代裁切也不能继续模型改图；这是规则推演，本次未处理图片。本轮图像四个专项与共同正文在Chrome逐一打开，四个专项文件第2版的准确正文与原有检查继续有效；共同正文已增加裁切不增加模型代数但继承谱系的说明，共同正文已在Chrome完整读回，并比较第2→3版的准确改动。此前五轮样例和媒体元数据证据保留在原审计归档，不能替代本轮图像效果验收。本轮未重新看图，未生成新图。
