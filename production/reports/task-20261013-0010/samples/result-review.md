# 歌本背页字层：保留准确排版，交接镜头合成检查

本候选通过五文件完整性、可编辑结构、准确字面和静态阶段关系检查。已实际查看三张由候选 ZIP 渲染的图：初记只有“两升”；第一夜为“一日两升”标题与一笔“两升”；第二夜增加第二笔，圈只包住两笔收入。没有额外日期、提前出现的第二笔或把工价计入收入的问题。

本次保持三个 SVG、字稿及交接说明原字节，未为检查而制造一次返修。排版文件为后期提供准确原词与分层，不能直接证明纸上炭字、手写动作或最终视频的效果。默认白底预览不改变透明工程底；历史参考图的既有描述也不作为本轮新增的视觉结论。

| 后续出现的具体问题 | 应改的位置与再检查方式 |
| --- | --- |
| 字错、漏字或把“一日”排成“一天” | 修对应 SVG 的准确文本，再渲染整张，核同一纸面的其他字未受影响。 |
| 炭字质感与背页不一致、规则圈线像排版标记 | 在保留原词和布局的前提下处理字层质感与圈的手写表现，再放回实际画面比较。 |
| 字迹在接触前出现、第二笔提前出现 | 改合成显露时点或对应镜头的动作交接，正常速度连看起点、书写、展示与下一镜。 |
| 字随纸滑动、穿过手指、圈误罩标题 | 改纸面跟踪、遮挡蒙版或圈层变换；回看持纸、笔移开及圈合拢后的完整阶段。 |
| 正常速度来不及看清两笔收入 | 结合实际构图与相邻镜调整展示和剪辑时间；不预设一个通用秒数，也不把所有动作统一放慢。 |

这些是针对尚未合成部分的返修交接条件，不是本轮已经发生的五个缺陷。当前没有真实合成镜头，炭灰、显露、跟踪、遮挡、正常速度可读性及跨镜关系仍未验证。后续制作者取得实际结果后再检查；本任务不改正式镜头、不新增模型调用、不更改用户采用，也不替其他制作任务关闭残留。

检查依同一准确候选和来源保存为隔离方法产物。相较只有“文件存在、字稿正确”的技术说明，本次增加了实际静态呈现观察和可执行的返修层级判断；原素材字节没有改变，不宣称已修好未制作的成片效果。
