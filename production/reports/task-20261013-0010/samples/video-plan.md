# 三个相邻镜头的时间线 Prompt 样例

本样例已按最终视频方法完成三次独立步骤：取得准确输入，保存草稿，全文读回，记录发现，保存修订结果并再次回读。以下代码块来自实际结果中的 `generation.prompt`，不是另外编写的展示摘要。三份均保留真实制作缺口，未导入作品当前方案，也未提交生成。

采用同一输入锁及 S001 完整场景，连读前三镜和第四镜起点。第一镜交出已翻好的歌本与竖稳的扁担；第二镜交出停唱和扬下巴；第三镜交出听客散开、两名听客进铺后的门口状态，河风掀页和李寄入画留给第四镜。普通参考不保证固定首帧。

| 镜头 | 方案时长与路线 | 本次实际结果 |
| --- | --- | --- |
| ASH001 | Fast、720p、14秒、普通参考 | 完整覆盖摊本、唱句、竖担及翻页，五项原件仍未选 |
| ASH002 | Fast、720p、14秒、普通参考 | 同一次尾腔与插话重叠；按用户说明撤销离线样例中的无效音频选择，四项参考均待选 |
| ASH003 | 2.5、720p、20秒、普通参考 | 对白、应答与散场连续；应答原词、起图和听客音色仍缺 |

时间是离线表演预算，不是实测结果。第三镜原视听条目预留16秒，现有生成方案预留20秒；样例沿后者排演，未据此宣称负载可行。第一镜最后四秒及第三镜最后两秒尤其需要真实预演，不能删词或强制提速以凑秒数。

## ASH001

```text
白昼河街米铺门外，阿蘅先安放歌本再开唱，让人看出她做熟了这份活，听客也愿意应和。二维人物与轻手绘背景，青衣、米白和灰木在柔和日光里清楚；歌本不发光，不过度增加纸纹和细碎纹理。
@图片1提供街景、倒扣的空竹篮、阿蘅手中歌本和篮底河石的普通起始参考；@图片2约束相机靠近后阿蘅的脸、青衣与比例；@图片3约束听歌老汉的身份。@音频1只约束阿蘅的声音身份，@音频2只约束《三道滩》的旋律与乐句，不带入参考录音的其他歌词、伴奏或录音空间。
本镜计划14秒，一镜连续，以下时段不是切点。相机始终在临街侧，从门口全景缓慢靠近，以最后能同时辨认阿蘅、老汉、歌本和扁担的中景结束；柜台至门口的方向不反转。近远街声和柜内量米声作为较轻的连续底声，给近处歌声留出清楚的位置。
0–3秒：起点是歌本仍在阿蘅手里，河石搁在倒扣竹篮的平稳篮底。相机开始缓慢靠近；她把干燥歌本摊在篮底，取河石压住页外缘，留出手指翻页的位置，随后站稳，用脚轻打拍子。摊本和压石依次完成，手与书、石的接触位置清楚；这一段尚不开唱。
3–10秒：承接已摊稳的歌本与轻拍子，阿蘅自然换气后唱：“一道险滩水急，船头慢慢行——”。句尾在本段内完整收住，只唱这一次；相机继续同方向轻缓靠近，让脸、手与歌本逐渐可辨。听客留在门口，柜内量米与远近街声延续，不盖住字音。
10–14秒：唱句收完，老汉把扁担竖到腿边，跟着点头。阿蘅随后提开压页河石，连续翻过两页，再把石头压回新页外缘，手从可翻动的页缘松开。相机收稳在两人同框的中景；翻页声和石头轻落纸面的声音属于这个动作。结束时新页已经打开，阿蘅看着新页，老汉扁担竖稳、仍等着接唱，留给下一镜归家乐句起唱。
摊本、首次压石、完整唱句和翻过两页的过程各按上述顺序发生，不从已摊本状态跳开，不在下一镜重做翻页。歌本始终干燥完整，阿蘅的米工钱尚未交付，李寄不入画；本镜不唱归家句，不加配乐、旁白、字幕或额外对白。
```

## ASH002

```text
白昼米铺门外，阿蘅轻巧唱到归家，老汉刚要接唱便发现自己扑空。这是熟客之间有分寸的玩笑；阿蘅没有唱错后遮掩，也不嘲弄老汉。二维人物与轻手绘背景，青衣、米白与灰木在自然日光下清楚，檐下略暗，不过度增加纹理。
@图片1提供阿蘅、挑柴老汉、倒扣竹篮和歌本的起始构图与可见身份，作为普通参考；@音频1只约束阿蘅的声音身份，@音频2只约束老汉的声音身份，@音频3只约束本段《三道滩》的旋律与乐句，不引入参考录音的其他歌词、伴奏或空间。
本镜计划14秒，一镜连续，以下时段不是切点。相机在临街侧固定中景，两人的脸、阿蘅面前的歌本与老汉腿边的扁担同框可辨，沿用上一镜结束时的站位和空间方向。轻的近远街声、柜内量米声从头延续到尾，歌声与问话在前景清楚，不另铺配乐。
0–8秒：起点是上一镜已经翻好的新页。干燥歌本摊在倒扣竹篮的平稳篮底，河石压住页外缘并留有翻页指位；本镜不再翻页。阿蘅看着新页，按归家乐句唱：“船靠岸，灯来迎，家里人等到如今——”。唱到最后一字时进入同一次演唱的尾腔。老汉的扁担始终竖在腿边，他认真听着，仍预备接下一段；机位不动。
8–12秒：阿蘅保持刚开始的同一声尾腔。老汉循熟悉的曲子起接唱，半句还没展开就发现已到归家，转成意外又亲近的问话：“二道——哎，到了？”这次接唱和转问发生在阿蘅的尾腔之中，两条人声短暂交叠；问话要能听清，尾腔不消失后重起。阿蘅忍住笑，让尾腔随这口气逐渐减弱，但尚未完全收声；两人、手、歌本和扁担的位置连贯，相机仍固定。
12–14秒：老汉的问话已结束。阿蘅把尚未收尽的这一声尾腔自然唱完并停声，嘴形随后放松；老汉再朝她扬一扬下巴。镜尾留下已停唱的阿蘅、下巴刚扬起的老汉和仍在门口的听客，衔接下一镜的打趣，机位和街声保持连续。
不重新起唱同一句，不补第二道滩，不提前说下一镜的打趣或让听客散入店内。保持干燥完整的歌本、倒扣竹篮及河石摆放；阿蘅的米工钱未交付，李寄尚未入画。无旁白、歌词字幕或其他人开口。
```

回读后把“持续收住这口气”改为尾腔逐渐减弱但尚未完全收声，最后时段才停声，避免被理解为先结束再补唱。ASH002原先随手勾选的音色不作为有效输入，不据此计算有效组合是否超限；其他镜头的选择不因此失效。

## ASH003

```text
白昼米铺门口，熟客和阿蘅把省唱的玩笑接完，听客带着笑意走动，能看出她唱歌也是替米铺招徕生意。二维人物与轻手绘灰木背景，青衣与米白保持柔和日光和清楚轮廓。
@图片1参考阿蘅、老汉、倒扣竹篮、歌本和听客的站位与可见身份；@音频1只约束老汉的声音身份，@音频2只约束阿蘅的声音身份，@音频3只约束发话的米铺听客音色，不带入参考录音中的试读词、旧语气或空间。
本镜计划20秒，一镜连续，以下时段不是切点。临街侧固定中景同时看见阿蘅、老汉的脸和门口听客，保持上一镜的站位与柜台至门口的方向。柜内量米声和河街底声持续、较远；笑声和人声随现场距离出现，不另铺配乐。
0–6秒：阿蘅的唱声已经完全收住，老汉承接上一镜刚扬起的下巴，笑着问：“昨天还得过三道滩，走大半天呢，今天这么快？”阿蘅听着，听客仍围在门外。机位不动，问话完整说清，不重放上一镜的尾腔或接唱。
6–14秒：老汉问完，阿蘅顺势回答：“您昨天都陪他走了一路啦。今天让他早些到家，您也少站一会儿。”她以熟悉街坊的自然口气说完，留出句间换气，不为赶秒数缩词或提速。老汉和听客的反应留在同一中景里，不以大笑盖住尚未说完的话。
14–16秒：阿蘅说完后，听客自然笑起来，其中一人笑着说：“下回补上”。其余人是现场笑声，不齐喊这句；相机和轻的街声、量米声延续。
16–18秒：阿蘅听见邀约，欠身作口头应答。她只从原站位欠身，不拿起歌本或领取工钱。
18–20秒：接着几个听客提起自己的米袋，另两个顺势进了铺子，门前出现空隙。结束时另两个听客已越过门槛进入铺内，其他提袋听客仍向门外散开，门前留出空隙；阿蘅和老汉仍在门口；干燥歌本仍摊在倒扣竹篮的平稳篮底，河石压住页外缘，留有翻页指位。镜尾暂不演下一镜的河风掀页，也不让李寄提前入画。
本镜所有时段共享上述固定机位，不按时段自动切镜；老汉的扁担在腿边保持竖稳。听客手中的米袋属于听客，阿蘅的工钱仍未交付。无重新演唱、额外配乐、旁白或字幕。
```

回读后明确两个听客在镜尾已越过门槛，避免“进了铺子”与“刚开始分开”混为同一终态。16–18秒仍只有“欠身作口头应答”的已知事件，准确原词未定：不能补“好”，也不能删成无声动作。补齐原词并重核负载之前，这份 Prompt 不可直接提交。

## 输入与验证边界

ASH001五项参考未选；ASH002四项参考未选；ASH003只保留当前方案的老汉和阿蘅完整音色原件引用，起图及发话听客音色未选。全部附件编号仍须在实际选择及上传后重核。没有截取原件、填补静音、改写正式选择或生成新媒体。

本次验证了时间线确实进入保存结果、原词次数、跨镜状态与方法阶段交接。没有重新看听既有媒体，没有测得演唱或动作时长，也没有口型、声音、视觉效果或真人测试通过结论。三个阶段的完整原值、服务产物和前置链均已回读核对；原制作方案保持原内容。
