米铺十镜的完整顺序检查发现，第九镜末开书与第十镜起合书之间没有展示开合，李寄浆糊与红印的可见度、位置有波动。整场模型也曾合并镜头、误读剧情玩笑、虚构交书要求和石头携带要求；这些结论已与锁定设计、单镜原件和准确边界对照，不直接采信。逐场及整集记录见[顺序检查](sequence-review.json)，每份模型原响应另见[模型复核](model-reviews.json)。

河街擦手镜首版把湿布水落到打开的歌本上，返修将闭书、米袋与湿区分开；白色残留物的位置和红印仍有偏差。邀约镜首版两种模型复核均转写“迎神”，返修后完整视频转写“迎神”、纯音轨转写“迎蛇”，因此该词保持听审待定，不能宣称已纠正；返修的多次切镜与空间漂移也未通过。合书镜返修去掉了错误的对岸男子，保留双人反应，但削竹声桥模型未辨出。收尾镜从先削后停返修为先停后重新削竹，和前次停刀镜形成区别，摊位细部仍有漂移。
