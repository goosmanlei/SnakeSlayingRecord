## 方法与系统怎样改变

六个既有方法分别更新并实际使用：场级视听设计确定人物、空间、动作、持物、持续状态和声源的交接；图像方案与视频方案确定可行起落点及准确参考职责；生成前检核对实际原件和完整输入；结果检查核对候选起落点及拟用切点；剪辑方法核对工程接缝、整场和整集。方法唯一正文仍在受管方法中，专业原理集中在 [剪辑](../../filmcraft/10-editing.md) 和 [视频生成手册](../../seedance-video-handbook.md)，本报告不另建一套规则。

新增检查依据保存在已有方法阶段产物中，可以查询覆盖范围、冻结观察依据和现在是否仍适用。对当前制作正文，稳定修订地址不等于正文不可变，因此另核正文并发标记与所选字段。对工程接缝，记录准确片段顺序、来源、入出点和声音处理；整片归一化使用全片声音时，不能把最终混音影响误缩成一个局部切点。

这套能力判断的是“旧结论的输入是否还适用”，不自动判定作品质量。缺关键原件会留下明确阻断和继续处理要求；合理转场、尚未生成的设计，以及无关字段变化不会被误当作声画缺陷。旧方法组合、旧候选、成片与评论保持准确历史身份。准确方法变化见 [method-versions.json](method-versions.json)，系统候选、针对性测试和实际隔离试验见 [system-verification.json](system-verification.json)。
