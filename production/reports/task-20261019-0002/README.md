## 使用与数据

- 普通点击时间线元素暂停播放，进入现有实体、状态或镜头大卡，定位准确候选、原件和字层条目。默认评论当前成片轨道片段；“源素材评论”仍属于原素材。关闭返回保留版本、播放帧、缩放、滚动与选区。
- “选择”开启框选，横向为连续时间、纵向为轨道；可反向、跨空隙、独立调整非相邻轨道。四个输入共享整数帧与有理帧率换算，非法范围不能提交。多轨范围只产生一条评论。
- 页面移除全部工程草稿、编辑、保存和渲染控件；不读取、应用或删除遗留本机工程草稿。后台 get／validate／save／submit 和渲染仍可用。

准确业务契约维护在系统仓 `docs/episode-editing.md`。素材唯一制作出处沿 ENTITY／STATE／AV_SHOT；普通实体是故事逻辑组成，镜头是独立平行的一等体系。字幕、人名条和片头尾属于表达对应的镜头，人物仅作为人名条身份信息来源。

[登记明细](text-layer-registration.json)固定第一集当前输出、全部条目、准确原件、唯一出处和使用镜头。当前输出修订为 `b0975db30b78dc1aff17100f1c64b9e14b79aa1d9126fa45ab0496a494339f7c`，24 fps、6838 帧；59 条字幕和 7 条 titles（5 个人名条、片头、片尾）按 19 个来源镜头分组。跨镜同句保持一个制作出处，另有明确使用关系。

登记同时覆盖该集另外 4 个已存在成片版本，复用同一字层素材的不同准确原件组件。合计新增 81 份小型 JSON 原件、19 个素材、21 条使用关系、5 份不可变追加关联；未来工程补齐 66 个真实条目引用。登记来自既有冻结工程的确定性提取，无模型调用或素材需求虚构。

历史成片及快照保持原字节；追加关联只说明事后登记依据，不声称旧渲染已使用新素材。关联固定输出修订、轨道、元素类型／ID、文字和时间摘要、候选、组件、条目与版本链。旧评论仍固定原依据；旧无轨道时间评论保持原混合成片范围。
