最终使用这 20 条视频与两条对白补录，共 22 个准确来源、24 个画面片段、50 个声画片段和 59 条对白／唱词字幕。人名条分别介绍阿蘅、李寄、周掌柜、赵执事和陶伯，陶伯补充“阿禾的父亲”；身份沿锁定资料，不预告后续命运。李寄在58秒清楚露脸后出现，跨切保留至62秒，避开歌本、胶手和对白。每条有准确起止帧与位置，在独立轨道可编辑。先实际完成第一场演唱、打断与声桥样片，再完成粗剪、精剪和混音；样片指出的闭口反应问题保留在原版本评论 C417，最终修正后关闭，原版本、原范围和历史不改绑，见 [处理记录](sample-comment-resolution.json)。

没有加速演唱、冻结补时或为时长指标删关键动作。周叔邀请后转身入店的 49 帧已恢复，后续声画和字幕同步顺延。阿蘅补录问句的尾部以同镜李寄倾听反应承接，完整问句保留；裁切放大约 1.82 倍会损失细节，未称为画质提升。原片误字“赵取事”在局部时窗去除，正确字幕为“赵执事”，原有 AI 标识保留。

## 实际验证及边界

- 两版视频完整解码均为 6838 帧，无解码错误；整片解码帧没有连续完全相同帧。低运动阈值会标记本片的低幅动画，不能当作冻结事实。独立较严静止检查无触发，黑帧检查识别的开头两帧属于既有淡入；详见 [技术检查](technical-qc.json)。新增人名条后已重做两版完整解码与逐帧重复检查，实际 AAC 音频字节、混音母版、SRT 和来源映射均与此前精剪一致。
- 最终 MP4 综合响度 −18.0 LUFS、响度范围 17.9 LU、真峰值 −1.5 dBFS；PCM 响度范围为 17.8 LU。LUFS 表示节目整体响度，LU 表示响度变化，dBFS 以数字满刻度为基准。技术电平通过不等于对白、演唱或混音听感已由人耳接受。
- 59 条字幕文本保持锁定对白和实际唱词，53 条时间重新校准，见 [校准记录](subtitle-calibration.json)。此前精剪的独立检查覆盖 235 个实际烧录边界帧，出现／消失均符合工程；新增人名条未修改字幕文本、时间或对白音频，复用该证据，没有把它当作新视频逐边界重查或逐音素听辨。Google AI Studio 免费模式的四音频补充复核在明确授权后上传，两次均返回内部错误，未取得可用答案，见 [失败回执](google-audio-crosscheck.json)。
- 私有 Chrome 实操覆盖平铺筛选与 640 px 窄屏、三旧页、准确版本切换／原片返回、逐帧、循环、范围评论、片段分割／替换／声音修改和撤销重做。鼠标横向滚动后在 x=1701／1705 的相邻 4 像素点击，实际从第 969 帧到 970 帧；播放器对应 40.375／40.416666 秒。定位与缩放证据见 [页面截图](screenshots/private-precise-timeline.png)。正式和恢复实例的实操另记运行回执。

## 发布、恢复与资源归属

系统候选先提交，故事配置固定其准确提交，双仓由任务工具集成和推送。方法配置先按准确注册表增量迁移，制作包再按对象／修订并发条件发布；原始私有基线保留不改，普通制作增量使用复制后应用准确方法注册表的派生基线。正式库保全其他评论、采纳和历史，不以任务快照覆盖活库。

剪辑运行环境单独冻结镜像 ID、旧基底 ID、Dockerfile 摘要及真实中文渲染证据。服务切换在共享锁内停止准确 HTTP／worker 写入者，成功后才移动固定镜像标签。正式发布后须从最新正式完整 Schema 15 导出恢复全新空实例，核查业务表、原件、评论和准确版本，再实际编辑和渲染。运行回执另存本机任务证据，不为补日志修改已冻结候选。

过程清理只处理本任务确认无用途的私有容器、失败／过时渲染中间件、测试库与临时目录。保留交付原件、三阶段输出、调用费用事实、精确工程与评论、独立报告及最小恢复凭据。任务 worktree 由当前会话使用时保留，退出释锁后由受管 cleanup 退役；正式容器／当前和上一版镜像不当作临时资源删除。实际清理数量和解除条件归最终清理回执。
