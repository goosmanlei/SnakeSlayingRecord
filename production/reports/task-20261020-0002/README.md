## 使用规则

- 普通入口和未选候选的参考入口，一次新打开按权威候选号展示最新真实候选；无候选才显示当前方案。方案后来更新不改变这个排序。
- 已选参考按当前消费方、当前输入槽位已确认的对象、修订及组件打开；保存失败、冲突和保存中仍使用已确认选择。只查看不保存参考选择。
- 明确的当前方案、历史候选、生成输入、评论和成片来源继续优先定位准确目标。失效或不属于素材时报错，原件读取失败不换候选。
- 卡内手动选择、同卡素材往返、嵌套返回及准确路由刷新保持原阅读选择和草稿。新一次普通打开重新读取最新候选。同来源素材首次切入后的评论焦点与显示候选一致。

通用契约维护在系统仓 `docs/materials-and-relationships.md`。本次不改作品、Prompt、媒体、采用或业务数据，不向VPS发布。
