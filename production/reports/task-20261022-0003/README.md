## 使用方式与职责

默认读源策略为 `local-first`。`generation_review init` 自动登记正式实例、工作区及来源已登记的恢复介质；`production_review` 恢复、制作／媒体预检、集成内容检查、完整导出均走同一解析层。来源按项目、bucket、region、实例身份和准确内容核对，最多16个，不扫描其他任务，也不猜旧路径。

从任务环境调用通用系统：

```sh
python3 -m review_desk --instance "$INSTANCE" resource-verify --mode local-only
python3 -m review_desk --instance "$INSTANCE" resource-verify --mode remote
python3 -m review_desk --instance "$EMPTY_INSTANCE" --resource-policy remote restore
```

第一条完整核对导出目录、全部原件／派生、快照、逐表指纹、数据库完整性及业务引用，并禁止云读取。普通制作不永久设置 `REVIEW_RESOURCES_OFFLINE=1`；该变量只用于离线实例及本地候选制作。

后两条是明确的云端审计／在线恢复入口，仍完整GET每个准确版本；同SHA的另一个版本不能代替可读性结论。新上传继续真实完整回读，合格字节原子留缓存；后续物化不再下载。普通本地命中不修改历史云验时间，`full=False`只查描述，不能当作内容验证。唯一操作契约见[资源存储](../../resource-storage.md)、[任务工作区](../../generation-workspaces.md)及系统仓 `docs/resources.md`。
