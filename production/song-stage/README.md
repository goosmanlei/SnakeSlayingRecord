1. 四首均有用户实际听审提出的词音问题；追加的《三道滩》仍未修准。可用于理解音乐方向，不能当作歌词准确的演唱终版。
2. Lyria 原生无损 WAV 尚未取得。旧 Seed WAV 是另一批录音；MP3 解码或升采样不能补作新母版。
3. [30 项全剧用法](uses-with-audio.json)中有 20 项发声、10 项文字／歌页事项。当前 Lyria 逐句时间、短参考和角色演法未完成，空字段保留。第一集仅对接既有两处镜头，未新增镜头或生成视频。
