## 内容、归属与中断

六类制作工作逐类取得实际方法及真实阶段，不硬编码全部为三阶段；视听五阶段，其余当前包为 draft/review/result。共用原值交付核对 `output.sha256`（规范 JSON 原提交值）与 `output_sha256`（压缩外层）各自摘要，媒体另核对 requirement/generation，阶段确认固定前置产物引用。数据库仍只有约定摘要及原 assessment，没有新存制作全文。

隔离 HTTP 故障代理在服务接受 understanding 后丢弃响应，CLI 失败时本机原值已安全保存、确认回执未落盘；新客户端 read 重取同一产物，未追加执行。另实际让子进程在阶段原值、阶段回执及 result-import 临时文件写到一半后退出。未完成的目标文件没有被发布；沿原目录、原阶段和原正文恢复。中断 finish 恢复包与同一执行正常 finish 包相同，method_basis 指向同一 execution/result。

缺全文、篡改、异目标/阶段、前置缺失、输入/条件变化、符号链接、越界和已有不同文件均保持明确拒绝；有效文件不被覆盖。准确原文件可核验接入旧摘要步骤，无证据则报“本机阶段全文缺失”。只有服务确认才可 read 成功，未确认原值不标成已完成。

隔离库实际导入一次完整包，再重放旧并发基线，服务拒绝；随后 recover 只回读并未覆盖已前进的目标。另在可校验的定稿之后修改所读镜头，导入被“方法准备所读内容已改变”阻断。恢复保持原输入 guards 和 baseline_marker，不自动导入、不手改并发标记继续旧包。
