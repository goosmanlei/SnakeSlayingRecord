# 全剧逐镜连续性自审

本稿以版本四逐场原文为依据，按人物与道具移动、空间轴线、动作先后、时序和声音逐段回看；下列结论落实在逐镜构图、动作与承接中。1114 个块的覆盖检查只证明未漏掉来源，不替代这里的内容判断。镜号与精确原句均可从 [首稿](shots.md)和 [覆盖清单](coverage.json)定位。

| 范围 | 已落实的连续性 |
| --- | --- |
| E01—E02，s001—s004 | 两升日工、额外预付一把与后续退米分开；毁本在浅滩，不改为深水溺水。垫书竹篮、木斗、米袋及湿袖动作不断链。墨耳始终是左耳缺尖的狗。第一集数处暗含内部切镜的构图改成连续机位或画外声音桥。 |
| E03—E04，s005—s008 | 母亲唱喜歌与舟行曲分开；歌词缺处保留，不能提前补齐。陶伯在对街而非隔河。红绳的完整双结、剪断与名牌分别交代；阿蘅额角伤保留到后续状态。白日前殿、黄昏山路、当夜家中分别拆镜，家门不误认作前殿门。 |
| E05—E06，s009—s015 | 借粮五斗、实还六／七斗与工钱四升不混用。船板先收起，偿清借粮不自动解除祭童身份。父亲开门、端饭、夜间修背带有先后；李家与阿蘅家按到达动作切换，不把提及目的地标成已经到场。 |
| E07—E09，s016—s022 | 夜间讲述与天明包刀分镜；喂蛇顺序为先插销、再喂食、手退出、关横闩、抬洞闸。提前备粮单先于本次选祭，与借据原纸／覆盖贴纸分开。查验诉求先阻止任何一家继续送祭，再处理本次救人。 |
| E10—E11，s023—s027 | 南喂食门、北洞闸、中间有顶短石道的方位一致；刀只从窄缝进入，不为了下刀扩宽蛇道。装杠、封册、绳子避石角按实际动作拆开。屋里以通道图讲解长杠，只是提及，不把实杠画进屋。旧灯此时未点亮。 |
| E12—E13，s028—s031 | 无名父亲不误归李诞。先取三册，阿蘅留后门内传话；前门差役未逃走。七人压杠：西侧孙六、李绡和两名帮手，东侧程差役和两名帮手。父亲带刀到场，将刀留西侧石台，绕南端加入东侧后成为八人、两边各四人。李寄随后拿刀试砍。 |
| E14，s032—s033 | 第一刀浅，后续反复落在同一处；李寄脚位稳定，刀在缝内，没有蛇全身出院或新增血腥场面。洞闸是压住蛇而未落到底，不能提前插销。最后声响停住后先等、再慢卸力，砌石工确认后才进场。父亲肩伤仍在，相触前额避开阿蘅受伤侧。 |
| E15—E16，s034—s039 | 陶伯与小满家人辨遗物留安静，不在后场重复渲染。三份祭册、米账与退粮凭据分开；梁书吏撤下后才出现新书吏。两人共撑米袋时分别扶口／托底，父亲先交书再接袋。仓院木斗单独维护，不补写从米铺转运。补词场地为歌娘院子，不是阿蘅家。二十余日核查与一个多月后演出分开。 |
| E17，s040—s042 | 李寄先逐句念写，阿蘅随后唱、母亲哼末句；念读与演唱使用不同完整状态。旧残页夹在新本后，没有丢弃或变成另一本。演出只用版本四 b009 等原词，唱过原空白再等尾音收住，掌声才入。散场只卸一根幕杆、两人各扛一端。 |

灯与歌本跨集单独核对：E11 灯未点 → E12 墙边 → E14 阿蘅带出 → E15 交母亲；E17 李母点亮交阿蘅，李寄抱书同行。阿蘅家门口先照阶、交书，再还灯；阿蘅抱书入屋，李寄提灯追姐姐。先去道具屋放稳幕杆，最后才到李家。末镜只有李家的灯、饭与半开门，不增添全员团圆、闩门或歌本再次跟回。

场内同一物体随动作变化时，保留完整状态及明确转换点；仅提及的实体不进入画面参考列表。旧拆解中家门、院中、幕杆、泛称父亲及歌词念读的误归在 `occurrence-review.json` 校正，旧修订仍可阅读。

生成阶段仍需视听判断的项目已经写为每项方案的阻断条件：演员声线与歌曲旋律、唱词换气及实际时长、模型对手部接触和多人承重的实现、画面可读文字的后期排版、真实输入裁切／选段、最深图生图谱系。它们属于制作选择和媒体检验，不改变本稿明确的剧情事实；本次没有假装完成这些媒体检验。
