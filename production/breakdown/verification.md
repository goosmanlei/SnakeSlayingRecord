## 全剧数据下的读取性能

同机 macOS、Python HTTPServer、单进程、本机回环 HTTP；每类先读取一次及 5 次预热，再取 50 次完整响应，P95 为排序后的第 48 个样本。以下是 HTTP 接口时间，不代称浏览器首屏或交互耗时；真实页面另见上表。

| 读取对象 | 最终 P95 |
| --- | ---: |
| 常规实体阿禾 | 135.06 毫秒 |
| 素材最多的李寄 | 230.75 毫秒 |
| 阿禾历史修订 | 210.77 毫秒 |
| 第 1 集 33 镜目录 | 7.81 毫秒 |
| 第 17 集 18 镜目录 | 6.78 毫秒 |
| E17-002 上下文，3 个直接需求及 3 个状态参考 | 1.62 毫秒 |
| E17/s042 视频筛选，7 项 | 67.34 毫秒 |

实体三类均低于前置的 300 毫秒 P95 门槛。[最终实体原始样本](evidence/entity-performance-final.json)与[范围读取样本](evidence/scoped-performance.json)保存完整测量。此前相同快照的 [优化前](evidence/entity-performance-before.json)与[优化后](evidence/entity-performance.json)三个响应哈希逐一相等；李寄从 467.47 降到 258.08 毫秒。最终表另包含随后少量场状态修正的数据快照，未混用两组数据作比较。

优化限定实体所需的记录类别，并在一次读取中复用相同素材的版本展开；不保留跨请求缓存。下一次读取可见实体、状态、方案、媒体、关系、评论与认可变化，并发写入不会把多个时刻的头拼进一次响应，见读事务回归用例。复测脚本为 `scripts/benchmark_entity_review.py` 和 `scripts/benchmark_production_breakdown.py`。
