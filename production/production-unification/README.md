# 生产制作入口合并与组合页退役

任务 `task-20261008-0001` 将主导航统一为“生产制作”，保留“制作拆解、实体管理、素材管理”。制作思路中的同名方法说明仍供阅读。每镜先呈现原设计，再呈现原视频方案、版本、候选、模型参数、Prompt 和参考。右侧保留完整素材集合，按稳定素材身份去重；准确参考选择仍在正文与素材大卡中完成。

本轮只改变工作入口和相应系统契约，没有生成媒体、修改故事内容或新增组合、剪辑能力。旧镜头制作链接保留集、场、镜、修订、方案和素材参数，进入合并后的准确位置。退役页、不存在的准确修订及不属于场镜的旧目标明确说明不可用或提供准确来源，不以最新内容替换。

## 删除范围与共享保全

执行时重新核对正式库、有效导出、恢复入口和原件。基线为 **17 集、42 场、297 镜**，逐镜比较设计正文哈希、素材身份集合、视频子集、视频方案与采用记录，合并前后全部一致。完整逐项身份、表行数及哈希见 [baseline.json](baseline.json)，验证结论见 [verification.json](verification.json)。

| 检查对象 | 实际处理 | 删除量与依据 |
| --- | --- | --- |
| “组合与历史”导航、页面、专属渲染和样式 | 从现行代码物理删除 | 移除专属分支；共享文件继续使用，不删除整份文件 |
| 专属生产对象类型、格式和业务编号 | 从导入、恢复、校验及目录契约移除 | `ASSEMBLY`、`DELIVERABLE`、对应格式及 A/O 编号不再可写入 |
| 独立历史视图与专属测试 | 删除专属接口分支和测试 | 保留共用来源、判断、异步评论及恢复测试 |
| 专属对象、修订、关系、评论、事件、编号 | 无待删除记录 | 各类 **0 条**；当前库及有效导出没有退役根对象或格式，全库前后逐表哈希一致 |
| 专属文件及派生数据 | 无独占文件 | **0 文件、0 字节**；全部原件有保留用途，未迁移或另存专属业务数据 |

现行数据库共 40 张表保持一致，其中 39 张为完整导出保全的业务表，另有可重建的读取缓存代际表 `read_generations`。保留剧本输入锁、场镜结构、实体与素材、准确调用、原件、版本、评论、事件及采用历史。**1,005 个原件，共 778,319,086 字节**逐文件 SHA-256 一致，数据库完整性检查通过、外键无悬空。已有缺失的旧准确参考继续明确显示缺项并阻止不完整输入保存，本轮没有替换其身份或增加悬空引用。

此前版本收敛任务已删除的文件、数据及历史任务原始资料不计入本轮删除量。没有业务删除，故本轮没有引入通用数据迁移系统；正式应用只更新系统和获授权的方法说明文件。

## 有效导出与恢复

当前有效来源仍为 [版本收敛交付](../version-consolidation/README.md) 的 Schema 8 导出与恢复回执。已校验清单内全部文件哈希及现行恢复输入，退役对象、退役格式修订均为零。新实例恢复后的 39 张业务表、全部原件和逐镜关联与基线一致；读取缓存代际按既有契约重建，不属于业务导出。

旧格式专属对象即使重新构造有效文件校验和，也会被当前恢复入口拒绝，失败后目标库保持空库。历史任务资料保留时点含义，不能作为当前业务重放来源。准确源文件与哈希保存在基线的 `recovery_inputs` 中。

## 实际验证

审阅台最终回归通过 **369 项 Python、664 项前端测试**；故事侧发布与多仓交付相关测试 **24 项**通过。全量核对覆盖全部 297 镜，不依赖浏览器抽样证明全量数据一致。

真实 Chrome 隔离实例验证桌面及 390 像素窄屏：集场镜导航、设计与视频方案连续阅读、全素材区、大卡、直接参考保存、间接参考归属、来源定位、评论草稿与返回、准确评论计数、刷新及前后退、旧镜头链接与退役链接。实体的采纳／取消采纳、素材的候选浏览和共用故事评论入口亦已实际操作。所有测试写入只进入隔离库。

当前数据没有已生成的镜头视频，实际“有产物”验证使用已有图像及音频；视频方案的未生成、缺参考状态已实际查看，未为验收生成视频。多版本及候选规则由既有回归测试补充，不能将其表述为实际视频播放验收。

## 准确交付与正式验收

系统成果先提交，再更新 `config/instance.json.review_desk_commit`，由任务工具准备整组候选并验证已登记的提交引用约束。发布沿用 [受管多仓流程](../generation-workspaces.md)：冻结准确候选包，构建准确镜像，预检，通过 `_deliver` 集成并推送双仓，再由 `material_review_release.py apply` 在正式发布锁内切换服务。页面写入和隔离测试数据不随包发布。

正式发布清单、镜像与服务身份、双仓远端回读、正式库前后比较及最终浏览器复验以本任务账本与本机 `.runtime/production-unification/` 回执为准。正式入口为 `http://127.0.0.1:3000/`；应用后核对合并导航、准确镜头与旧链接、大卡及返回，重新检查业务表与原件哈希。Git 推送不能替代正式页面验收。

结项停止本任务预览进程，清理隔离库、重复原件副本、基线系统副本、测试缓存和失效过程文件，并按准确路径回读。冻结发布包、必要验收回执及当前／回退运行材料保留供恢复；本任务工作区和会话由任务工具在退出后退役。实际删除数量、保留用途与移除条件写入最终任务回执，交付后不为补日志修改候选。
