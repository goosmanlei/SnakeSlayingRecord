# 准备可直接审阅的制作内容

人的工作是读作品、看听准确原件、判断具体取舍并提出意见。AI 先整理完整内容和必要参考，完成专业自检；系统负责准确版本、文件、范围与执行条件。入口可以按完整工作组织，不要求人沿实体、状态、需求、用途逐层处理。

## 作者怎样交付

1. 从准确故事版本和当前制作内容开始，顺读整场动作、原词、表演、摄影、声音与剪接，再看跨镜承接。区分实际出场、随后发生和仅作背景的条件；不能把未来湿衣、持物或人物提前带入当前镜头。
2. 视听镜卡按叙事目的、关键状态、生成方案组织。目的说明观看作用；状态只关联确需独立准备的素材；产物按实际制作顺序排列。集场当前说明从导航悬停或聚焦读取，工作稿与准确组成分开。身份说明、实体状态和镜内时刻不能相互替代。
3. 沿准确参考打开共用素材卡，读取真实原件及已有判断。完整方案交代本次保留什么、允许变什么、尚未决定什么，不把相同文字另存为关系上的用途意见。旧母版认可只适用于该准确原件；没有产出就给准确空态，准备需求不是人工逐项待办。
4. 技术参数、输入装配、尺寸和谱系检查、生成时自检由准备流程承担；真实调用与原件追溯保持。不能把独有的表演、湿区、画面方向、原词或未定内容当作技术重复删掉。
5. 视听作者稿沿 [全剧镜头入口](audiovisual/README.md) 编制，动作、原词、摄影与声音保留在准确 Prompt。其他阅读入口需要准确投影时，`config/instance.json.production_reading` 保存原块哈希、Unicode 区间和处置理由，`scene_reading` 保留准确 Prompt 区间；二者不再用于建立视听共同条件或单独动作对白卡。不得按关键词裁句、匹配近似新句或硬编码人物名。
6. 对每项省略，核对其意义是否仍由准确方案承载。部分原块只显示一个区间时，尤其检查其余内容。系统的哈希和区间校验只能证明身份，不能证明语义完整；必须实际连读与看听。
7. 验证新意见仍落到原修订和原偏移；原来未显示的区间、跨块草稿和历史意见仍能回到准确原块。新修订未编排时完整显示原文，不套用旧版区间。不能为整理展示改写旧调用、冻结方法或原始意见。

对仍需原文投影的非视听镜卡入口，后台工具 [production_reading.py](../scripts/production_reading.py) 提供 `inspect`、`validate` 和 `apply`。在当前受管故事工作区运行，`--system` 指向任务账本登记的审阅台工作区，`--instance` 指向本任务隔离实例；默认配置为 `config/instance.json`。`inspect --object-id … --revision-id …` 读准确原块，`validate` 核对全部编排及伴随修订。

`apply --plan … --expected-config-sha256 …` 接受作者已逐块判断的 `authored-production-reading-v1` JSON：每项包含准确 `reference`、覆盖全部原块的 `sources` 处置及理由、原区间 `sections`、准确 `requires` 伴随对象。它校验原块、区间、全部既有编排和配置版本后才原子替换配置；配置在校验期间变化也不写入。它不自动决定语义、不改存储中的作品，不改旧原件与意见。对象编号只属于本次作者的准确交付，不进入通用运行时规则。

## 意见与准确输入各自回答什么

原件选择固定本次具体使用的版本、候选、组成和片段；评论说明对准确作品有什么意见。AI 在任务授权内读取原意见和上下文，实际整改后保存回应及准确改动；暂不改时解释理由和剩余问题。评论关闭／重开只整理意见，不能推断质量或阻断准备。

方案不再需要实体、状态、单项方案或结果的审批记录。真实缺项、准确版本不匹配、输入锁、冻结输入、文件与哈希继续校验；付费与正式写入仍以本次授权为准。

## 实例校验入口

从 AS001 五镜及ASH015连读叙事目的，判断劳动、亲密、保护心与回答权的变化；开唱前起点复用M2974，翻页结束不增加空需求。再核ASH080转牌前与揭名后的两项既有需求，以及ASH052同一状态的首帧与字层。动作和声音仍在准确方案内检查，米袋不能提前入开场，李寄第四镜才入画。三部分页面、全剧覆盖、迁移和空恢复见 [当前验收](audiovisual-three-part/VERIFICATION.md)。

人物比较先读EN002的M2710当前方案，再打开M1133历史原图，判断衣色、低髻、比例和本镜持物；未生成方案不冒充原图。M1134基础音色与M1187嗓哑补充分别可达。文件和播放器检查不代替试听，没有真实视频不声称视听效果通过。既有交付边界见 [task-20261010-0012 验收记录](reports/task-20261010-0012/VERIFICATION.md)。

当前作品范围、图像区域与声音时间意见、返回草稿及当时整体许可的历史实践见 [task-20261010-0014 验收记录](reports/task-20261010-0014/VERIFICATION.md)。历史记录只说明当时页面和范围，当前信息结构按三部分入口执行。普通素材比较仍不要求先阅读全剧关系；新创作范围须重新实读，准确原文回退不等于完成内容准备。
