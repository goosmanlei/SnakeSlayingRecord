## 下游分别领取什么

[下游范围](downstream.json)提供三个已经排序的集合，数组中上游先于下游：

- `ordinary_state_order`：全部普通实体170项与完整状态21项，共191项。闭包仍为这191项，可在第二至十七集镜头尚未制作时完成。
- `e01_complete_order`：第一集20项视频、1项字层及所需上游，共46项。先完成25项上游，再按镜头及字层职责制作。此集合与上一集合共享上游，不能重复生成同一身份。
- `all_order`：全剧651项的依赖顺序。它说明准备先后，不自动授权全部生成，也不是批量提交清单。

当前勘画纸及补刀缝状态两项本地制作已通过执行者看图检查，准确完整原件已选到20个输入位置；没有用户采用记录。代表性阿蘅图像与试声已有真实返回，分别因规格和听审缺口尚未选用。范围与逐项断点见[本轮阶段记录](../reports/task-20261015-0003/README.md)。执行时须选定实际文件，记录准确候选、哈希、规格和上传槽位后，才形成真实调用请求；不把需求引用、预算或拟定文件名当成已上传附件。生成效果、音色辨识、逐字演唱和实际空间表现均需对新原件看听验收。

## Prompt与页面的关系

以[原M4464／现M017的当前Prompt](M017-prompt.txt)和[输入映射](M017-input-map.json)为例：模型正文使用`@图片1`、`@音频1`等槽位，页面把它们显示成可点击的`@M001 · 阿蘅 · 基础形象`等中文素材引用。页面没有另写一份Prompt；实际提交时按类型和顺序绑定选定的完整文件。

M017使用Seedance 2.5、18秒、720p、16:9，计划4个图像输入和2个音频输入。两件音频分别为第二唱句完整派生文件（预算不超过14秒）与老汉完整中性短句（预算不超过4秒）。原始Prompt及参数已定，附件仍待新原件，本阶段没有发生这次生成调用。

视频按已核验的渠道约束选择Fast或2.5；长台词、两人说话和完整歌尾需要留足时间。77镜调整了原预算，416镜的最终方案、制作说明及帧数已经按同一设计同步。全剧方案预算7889秒（131分29秒），是尚待真实表演校准的设计时长，不是成片实测。

图像采用16:9原生4K与干净母版，实际像素和谱系在生成时核对；Seed Audio音色与场景音按原生48kHz WAV方案。完整歌曲在0003实际返回后，经用户明确允许，改用平台原生44.1kHz双声道MP3，准确原件与听审边界见[完整歌曲](../rebuild/songs/README.md)。参考短件独立保存，不以`range`声明代替文件，转码与重采样工程不冒充原生无损母版。局部修正从干净母版出发，不能用串接重绘积累纹理。声画制作、共享正式写入与恢复继续沿[生成工作区](../generation-workspaces.md)。
