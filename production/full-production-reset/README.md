## 一次性操作与恢复边界

所有命令在原任务工作区运行，`DESK`为本任务已纳管系统工作区，`INSTANCE`为准确目标实例：

```bash
python3 scripts/generated_candidates_reset.py --system "$DESK" --instance "$INSTANCE" --plan production/full-production-reset/plan.json check
```

正式`apply`及`clean`另外要求准确已集成源提交、已停止的正式应用及共享写锁；只应用匹配全表基线的同一清单。中断后先查事务回执和文件状态，再从同清单续清；物理字节没有回滚承诺。普通候选历史保护继续启用，本轮没有永久清空网页按钮。

后续恢复使用当前 `export/manifest.json`、`production/audiovisual/index.json` 与 `recovery.json`，由 `scripts/production_review.py recover` 恢复到新的空目录。索引必须包含上述重置身份；旧包和下载／迟到登记不能复活已删制作身份。后续新制作入口见 [视听编制](../audiovisual/README.md) 与 [抽取](../extraction/README.md)。
