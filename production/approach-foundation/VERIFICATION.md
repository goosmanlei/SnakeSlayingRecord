# 制作思路统一入口与节点产出

task-20261012-0017 将分散在系统管理的模型与方法阅读归入制作思路，按“系统构想 → 数据模型 → 基础流程 → 故事创作 → 生产制作”排列。人可以先理解协作目标，再查数据、读方法，最后看两个领域的整体关系。系统管理只保留故事项目、系统与 AI。

## 具体变化与阅读

原流程把产出作为动作下方的小字；现在每个阶段框用上方动作、短“产出”箭头及下方纸张形数据区表达归属，主线从整个阶段继续。剧本产生 E/S；视听设计产生 AE/AS/ASH；抽取承接同一 ASH，与角色、场景、道具、歌曲 EN 一起形成必要 ST 与 M。素材方案的九个真实方法分支共用“M 当前方案”产出；生成与制作才形成提交快照、MC 与原件。小说、剧本的独立读者循环、回读／返修和两个辅助分支仍在。

执行者只读左图的结论是：动作与其产出可在同一框内对应，M 当前方案与 MC 的发生阶段有明确区别，抽取没有创造另一份镜头身份。这是执行者自读判断，不代表用户认可。

故事与生产两张概览的节点、反馈及候选都改为静态表达，鼠标与键盘不再跳其他工作区。生产概览移除指定说明、两条专业资料链接、底部重复“当前方案／实体”及“回到问题所在处”；反馈线仍回连主图原节点。旧图节点锚点继续定位。数据模型编号、对象链接与系统构想原图保留。

专业资料从适用 SKILL 右侧文件树连续读取。[影视知识](../filmcraft/README.md)的全部 16 个阅读文件、12 张原 SVG、来源记录及 [六类应用](../filmcraft/applications.md)的准确输入锁可读；[完整视频手册](../seedance-video-handbook.md)、五类走查、两张输入图与五个原视频继续沿唯一源投影。186 个旧章节／小节映射到相应资源、文件与章内位置。原 METHODS 六项准确身份保留，CODES 转入模型；新链接生成新入口。
