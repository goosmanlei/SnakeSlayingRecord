# 素材唯一制作出处与准确参考

任务 `task-20261012-0001` 解决两个相连的问题：同一素材因使用范围而出现在多个“拥有者”下，以及没有独立制作职责的状态让实际条件和准确原件难以追查。当前需求只沿 `scope` 指向一个实体、独立状态或镜头；使用范围仍可筛选和引用，但不会增加归属或需求数量。

## 逐项处置及收益

本次从执行时的正式数据重建分母，逐项阅读 1,291 项当前需求、280 个实体状态和 344 镜的 351 个关键状态，再独立通读 17 集复查跨镜条件与引用。最终需求保持 1,291 项：1,047 项直接属于镜头，163 项属于实体，81 项属于状态。280 个状态中保留 87 个，另 193 个的有效条件已承接后撤下；没有按名称、零需求或删除比例批量判断，也没有为了保状态新增需求。

阿蘅的 M2544 图像和 M2669 声音只属于 EN002；湿袖 ST092/M2714 与湿鞋 ST093/M2715 保持独立。身份、普通表演和动作阶段回到实体或实际镜头，不能把疲惫状态图固定成所有镜头的起点。歌本仍保留不同页况和制作职责，M2909、M2908、M4080 不互换；洞闸半落、通道、旧灯点亮和歌曲片段等必要差异继续独立。

每个状态的决定及理由在 [逐项判断](reviewed-decisions.json)；条件承接、消费者和最终引用见 [完整核对](complete-audit.json)。逐集复审发现的 30 项实体条件与旧编号修正在 [全局回修](global-refinements.json)，操作回执依次为 [样例](sample-receipt.json)、[全量](full-receipt.json)、[跨镜回修](refinement-receipt.json) 和 [歌曲可读性](readability-receipt.json)。已撤下状态只保留身份、原内容摘要、处置原因和操作身份，不保留可恢复旧制作树的冗余正文。

本机验证、发布及清理的持续回执放在本任务 `.runtime/unique-origin/`；恢复用途结束后删除无效预览、重复数据库和方法临时包，保留准确发布／恢复记录。工作区在 TUI 退出释锁后受管退役，分支与提交保留。负责人独立 Review 另行承接，不由执行者自验自动关闭。
