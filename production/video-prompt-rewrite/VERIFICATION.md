# 全剧镜头视频 Prompt 重编

task-20261012-0011 将旧事件串改写成逐镜连续声画，并完善同一身份的 `method.skill.video-plan`。交付范围为 17 集、65 场、344 镜的 344 项当前视频方案，以及 M2999 所需的两项上游图像方案校准。没有生成新视频，没有改动锁定故事结构、小说或剧本。

## 从哪里阅读和继续制作

审阅台从“生产制作 → 视听制作”进入各集，选择镜头的“视频”素材，阅读“当前方案”。模型参数、制作依据、准备缺项与 Prompt 分开保存；页面中的素材名链接对应提交正文里的 `@图片1`、`@音频1` 等准确附件编号。正式服务、双仓提交、发布后页面和清理的实际结果由本任务账本及主项目 `.runtime/task-receipts/task-20261012-0011/` 维护，不由源码提交状态推断。

[逐镜索引](index.json) 记录全部需求身份、当前内容标记、Prompt 摘要、真实方法执行、准确源块、有序输入、缺项和负责阶段。当前正文只在制作需求与其完整导出中维护，索引不另存一份 Prompt。继续创作使用 `scripts/video_prompt_work.py` 取得整集、相邻镜和关系，再提供实际作者稿与审阅判断；这个工具不选择机位、不创作台词、不拼接旧事件串。

专业方法唯一正文仍为[视频生成手册](../seedance-video-handbook.md)。系统管理的“视频方案”提供 SKILL、三个实际样例、自检、字段契约及按需手册章节；按文件显示的版本号与整个方法包的版本号不同。

## 已实施的验证与保护

最终实际 Prompt 的段落区间及摘要由 `scripts/scene_reading.py` 建立，并检查准确原词、发声者和先后；保存及定位不再要求包含旧事件渲染全文。旧评论保留自己的原摘录，不能迁到相似新措辞。

- 三个实作样例在隔离 Chrome 完成新稿圈选评论、保存、刷新、重开、原选区定位及准确参考往返；新方法也实际创建并重开文件评论，比较前一文件版本，读取所需手册章节。测试评论留在隔离库，不发布正式。编制基线没有既有 `method.*` 评论；正式切换时新收到的故事结构方法评论 C413 已原样保留，并在正式 Chrome 和最终恢复实例实际定位到 SKILL.md 第 2 版的原选区。旧方法文件和冻结执行保持原记录。
- 真实方法 API 拒绝缺方法、缺文件、缺必要章节和方法修订错配；四类正常条件取得准确当前方法与非空章节。不存在的 `@音频99` 不能通过输入契约。
- 隔离补选真实李寄音频候选 2 的 `original`、0–5.6 秒，准确解析为音频 1，阿蘅 0–5.6 秒仍为音频 2。图像未选继续阻断。临时移走该隔离原件触发缺附件阻断，恢复同一哈希字节后解除该项阻断；没有将试选写入正式方案。
- 过期内容标记被拒绝，正文与已保存选择保持；两项存在前后依赖的图像修改整笔冲突时回滚，随后按机位、首帧、视频顺序重新取得准确输入。服务已保存 draft 而客户端丢失响应的演练，沿原执行、原阶段查询回执并读回全文，未创建替代步骤掩盖未知结果。
- 故事侧 22 项阶段、交付及文字区间检查，审阅台 44 项方法、文件和准确阅读检查，以及 13 项界面定位与素材切换测试通过。为完整增量新增的 LFS 文件核验及发布范围守卫，另通过 11 项工作区和 21 项发布检查。单独试跑的旧 `test_method_media` 有 11 项仍依赖已退役制作版本模型，不能记为通过；相关旧测试迁移沿现有独立残留承接，当前任务链路另有上述真实接口与页面证据。

正式发布只消费[准确镜头增量](../publications/video-prompts-20261012-0011.json)和[准确方法登记包](../../content/managed-method-registry.json)。先追加方法，再以原内容标记逐行应用 346 项当前方案及其 1,384 项实际执行／阶段记录；增量不含评论、候选、真实调用或原件改写。大体积完整增量由 Git LFS 管理，正式发布按已合并指针的 SHA-256 和字节数流式核对工作区与正式文件，未下载的指针文本和损坏原件均拒绝。隔离预演已将全部业务表与作者定稿逐行比对一致，并从新连接核对事务回执及每一行变更。服务切换及宿主机 SQLite 写入沿[共享写入窗口](../generation-workspaces.md)，不能用任务快照覆盖活库。

本机正式服务已通过准确源码、实例配置和运行镜像核验；正式库 344 份 Prompt 的摘要全部与逐镜索引相同。真实 Chrome 已复走普通动作、后显输入、对白、演唱衔接、字层、长镜、未知原词和末集路径。正式增量逐行回读通过，404 条评论、257 个候选和 328 份提交快照保持不变。

## 收尾与独立复验

任务执行者负责发布、页面复走、恢复和无效资源清理；负责人独立 Review 单独保持开放。必要逐镜草稿、实际回读与本机回执仅为独立复验追溯保留，复验结束后由负责人确认缩减；正式原件、准确发布包和幂等回执继续保留。临时数据库、预览服务和一次性脚本的实际删除数量、回读结果及仍有效用途写任务清理回执。双仓工作区由当前 TUI 占用，退出并释放清理锁后通过受管入口退役，不强删活跃目录。
