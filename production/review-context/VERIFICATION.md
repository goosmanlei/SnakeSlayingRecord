# 评论润色参考：实现与复验

本交付让审阅者先核对被评论的准确内容，再表达当前意见。系统提交由 `config/instance.json.review_desk_commit` 唯一固定，正式生效和结项以任务 `task-20261009-0006` 的受管交付及本机发布回执为准。全过程不调用外部 AI；确定性模拟只验证输入与交互，不证明润色质量、费用或耗时收益。

## 实际使用与取舍

执行阶段从正式库的一致副本在 Chrome 重走译注路径：圈选“你们胆怯，被蛇吃掉，真叫人哀怜。”，写对责备语气的疑问，查看参考，返回并改写意见。当前代码仍无条件显示 45 份资料和“素材准备”及当前漫剧设定；审阅者在核对译文语气时被带去阅读无关背景。规划中的 25988 字符是上游历史测量，本轮没有把它当作重新测得的数量。

反例是在精修一实际圈选“阿蘅已经把一支长歌唱短了”，明确比较精修二的开头。候选只加入这两个准确文本，并说明比较稿不能定义当前稿事实；改为普通赞同意见后只剩精修一。由此采用按意见目的选择的方案，不规定所有评论固定保留几份资料。

第一次候选试用发现节选尾部停在半句话，随后调整为尽量停在句段边界；1000 字符检查又发现邻文缩减不能从文首取片段，改为围绕圈选缩减。重走译注时完整圈选保留，界面与后端均显示 1000/1000；恢复 12000 后重新核对。明确“回到意见”收起参考并聚焦原输入，保留圈选和草稿。

实际圈选未选方向一《九女有名》，参考仅保留其姓名、木牌与追责情节，不带方向三设定。结构第十稿的整体意见绑定本稿和其准确方向选择；剧本版本三第一集实际圈选并查看参考，保留该分集及锁定小说、结构的准确修订。版本三与四往返后原草稿仍归版本三。试用还发现普通开场措辞意见不需要阅读改编依据正文，因而改为保留依赖身份；涉及改编、小说、结构或方向的意见才展开必要正文，并重走该路径。依据文本与当前稿不一致时以当前稿为评论事实。

## 契约和确定性检查

- 完整对象、修订、锚点、圈选与意见优先；邻文围绕圈选节选，缺失内容不可推断。明确命名比较稿才引入，泛称旧稿不猜最新。图像／区域继续核对准确资产。
- 总预算按完整 `canonical(context)` 的 Unicode 字符数计算，原文、意见、背景、来源元数据与格式均计入。验证 1000 下限、12000 现值、Unicode 长文末尾圈选、大来源元数据及长背景；完整必要内容超限明确拒绝，不截断圈选。
- 已查看且目标、锚点、意见未变时复用同一参考快照；服务端重建并校验摘要，变化返回 409。失效修订拒绝；迟到响应不串对象、不覆盖新草稿。采用建议后清除旧参考，仍须人工保存。
- Python 全回归 408 项、前端全回归 681 项通过；后续依赖正文取舍变更复验结构、剧本、参考构建与异步草稿。新增配置发布检查会拒绝原评论被修改。模型切换的页面联动及1000预算保存也在隔离实例实际核对，未使用密钥。

## 配置与权威

只更新 `PROJECT.story_background` 和 `creative_background`。已现场核对正式库四首歌曲实体；“尚未进入当前审阅台”改为准确歌曲入口及 [歌曲交接](../songs-review.md)。369 图像加42录音共411原件的句子保留，并明确这是非歌曲首轮历史批次。稳定设定限定为已确认剧本版本四；动态制作进度由 `STATE.md` 和对应交接维护，作品采用沿 `production/source-lock.json` 与准确采纳记录回查。模型、推理、总预算现值及其他项目字段不变。

[两字段包](project-update.json) 保存预期版本、完整旧正文摘要和准确结果摘要。先交付代码并按既有 `scripts/material_review_release.py` 切换正式服务，再由 `scripts/publish_review_context_config.py` 持同一发布锁按版本增量更新。原作品、意见、历史、采纳及其他配置逐行摘要核对；不导入任务数据库或回放旧配置。变化或未知结果先核查同一回执，不能重复覆盖。

## 正式复验及恢复入口

从原入口 `http://127.0.0.1:3000/` 进入故事采编，再圈选译注、写本机草稿、查看参考并返回；另核对明确精修比较、结构与历史分集的准确版本，以及系统配置总预算说明。只调用参考构建，不提交测试意见、不调用 AI。正式结果保存在任务 `.runtime/review-context/` 的发布与浏览器回执，不能用候选或 API 检查替代正式页面结论。

配置更新后，从当时正式库新建隔离一致副本，通过既有导出与空实例恢复流程保存 Schema 9 完整快照；任务初始测试库不能进入正式恢复包。结项前停止任务3306预览，核对并清除无效测试库、重复原件副本、构建过程目录与过程容器。正式当前、回退及基底镜像、发布清单和最小验收回执保留；准确删除数量、ID、回读与工作区占用记录在任务收尾回执，工作区由 TUI 退出后的受管清理退役。
