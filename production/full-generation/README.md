# 非歌曲素材的真实来源与认可

本目录保存既有媒体制作的用户原始决定、逐原件自检和实际渠道事实。新视听设计复用的候选由当前完整导出与 [素材来源索引](../audiovisual/provenance-files.json) 定位，不按旧计划或旧覆盖数量安排生产；旧需求、编排、登记包和迁移回放已退出。

过去该轮产生过 369 张图、42 份声音及四次输入校验拒绝，这是历史调用数量，不是当前保留素材数或新体系就绪数。当前仍复用的每个原件以准确 SHA、候选身份和真实输入追溯；图像没有放大冒充原生 4K。旧自检通过不等于新镜头采用，声音未获听审认可的仍待听审。

用户认可沿 `*-approvals.json`、原始意见及当前审阅记录保存；阿蘅、李寄、李绡、赵执事、孙六、旧灯与河街浅滩等均须看准确候选和范围，不能按实体标题泛化。已用完的一次性生成授权不随恢复重新生效。

OpenArt 当时 37 次图片调用对应独占窗口余额差 9902 credits；连接器原生输出尺寸逐原件记录。后续内置图片工具没有暴露底层型号、服务器调用 ID、质量档或计费用量，未知字段仍为空，不拿本机文件 ID 冒充真实调用 ID。四次参考超限拒绝有请求与错误，没有原件。

声音沿 seed-audio-1.0 的真实回执保存。后续 38 份调用共 362.94 秒，控制台免费余量 33.95 → 27.91 分钟；全部该轮录音合计 411.68 秒。独立额度截图和通道观察保留在 `../evidence/`，媒体／请求／回执组成优先通过候选准确引用读取。

正常登记使用 [record_builtin_image.py](../../scripts/record_builtin_image.py) 等仍有效工具，并遵循 [生成工作区流程](../generation-workspaces.md)。当前恢复只使用 [生产制作说明](../README.md) 中的 Schema 9 完整导出，不使用旧生成工作区、旧端口或历史一致性库作日常基线。
